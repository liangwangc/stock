## 医疗检查记录分析与汇报项目

本项目用于**分析你以往在医疗机构进行检查的记录**，并自动生成一份面向领导的汇报（Markdown 文档），报告中会包含：

- **整体检查概况**：检查次数、时间跨度、就诊机构、检查类型等
- **每次检查摘要**：按时间顺序列出每次检查的关键信息
- **通用检查规则**：例如「年度体检中，每次都会做的固定检查项目」
- **个人健康重点**：哪些项目多次异常、需要长期关注

### 1. 安装依赖

在命令行进入项目根目录：

```bash
cd medical_exam_report
pip install -r requirements.txt
```

### 2. 准备你的历史检查数据

1. 在 `data` 目录下创建文件：`medical_exams.csv`
2. 建议用 Excel 整理后另存为 CSV（UTF-8 编码）
3. 至少包含如下列（列名要一致，可以多列，但不要少）：

```text
date,institution,check_type,item_name,result,unit,ref_low,ref_high,abnormal_flag
```

- **date**：检查日期，例如 `2022-03-18`
- **institution**：检查机构名称，例如 `北京市某某医院`
- **check_type**：检查类别，例如 `年度体检`、`入职体检`、`专项复查`
- **item_name**：检查项目名称，例如 `血常规`、`肝功能`、`血压`
- **result**：结果值，例如 `5.6`、`正常`、`轻度升高`
- **unit**：单位，例如 `mmol/L`，如果没有可留空
- **ref_low / ref_high**：参考范围下限、上限（可为空）
- **abnormal_flag**：是否异常，建议用 `Y` 表示异常，`N` 表示正常，也可以留空

一个简单示例（仅供格式参考）：

```text
date,institution,check_type,item_name,result,unit,ref_low,ref_high,abnormal_flag
2022-03-18,北京市某某医院,年度体检,血压,135/85,mmHg,,,Y
2022-03-18,北京市某某医院,年度体检,空腹血糖,5.8,mmol/L,3.9,6.1,N
2023-04-02,北京市某某医院,年度体检,血压,140/90,mmHg,,,Y
```

### 3. 运行分析并生成报告

在项目根目录执行：

```bash
python -m src.main
```

运行成功后会在 `output` 目录下生成：

- `medical_report.md`：面向领导的 Markdown 汇报

你可以将该 Markdown：

- 直接粘贴到 Word / WPS 中排版
- 或者作为 PPT 文稿的文字基础

### 4. 报告结构说明

生成的报告大致包含以下部分：

1. **概况摘要**：总检查次数、首次与最近检查时间、主要机构与检查类型
2. **检查时间线**：按时间列出每次检查的摘要与异常项目数量
3. **通用检查规则**：
   - 按 `check_type` 统计：例如「年度体检」中每次都做的项目
   - 便于总结成「制度化、常规化的检查安排」
4. **个人健康重点**：
   - 多次出现异常的项目及其出现次数
   - 可作为向领导说明「长期关注点」和「已经持续跟踪的项目」
