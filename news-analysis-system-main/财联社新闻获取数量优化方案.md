## 一、问题分析

### 1.1 当前情况

从日志可以看到：

- 新闻数量明显不足

### 1.2 原因分析

**当前代码**（`get_cls_news.py` 第40行）：
```python
news_df = ak.stock_info_global_cls(symbol="全部")
```

**可能原因**：
1. **akshare API限制**：`ak.stock_info_global_cls()` 可能默认只返回20条新闻
2. **没有参数控制数量**：函数调用没有传递任何参数来控制返回数量
3. **API本身限制**：财联社API可能有限制，每次只返回20条

## 二、解决方案

### 方案1：多次调用API（推荐）

**思路**：如果API每次只返回20条，可以多次调用，每次获取不同时间段的新闻

**实现**：
```python
def fetch_and_store_news():
    print(f"[{datetime.now()}] 开始抓取财联社新闻...")
    try:
        all_news_list = []
        
        # 方案1：多次调用，每次获取不同时间段
        # 获取最近1小时的新闻（分3次调用，每次20条）
        for i in range(3):
            try:
                news_df = ak.stock_info_global_cls(symbol="全部")
                if news_df is not None and len(news_df) > 0:
                    all_news_list.append(news_df)
                    print(f"第 {i+1} 次调用获取 {len(news_df)} 条新闻")
                    # 如果获取的新闻少于20条，说明没有更多新闻了
                    if len(news_df) < 20:
                        break
                    # 短暂延迟，避免请求过快
                    time.sleep(1)
            except Exception as e:
                print(f"第 {i+1} 次调用失败: {str(e)}")
                break
        
        # 合并所有新闻
        if all_news_list:
            news_df = pd.concat(all_news_list, ignore_index=True)
            # 去重（根据标题和内容）
            news_df = news_df.drop_duplicates(subset=['标题', '内容'], keep='first')
            print(f"合并后共 {len(news_df)} 条新闻（去重后）")
        else:
            print("未获取到任何新闻")
            return
        
        # ... 后续处理逻辑保持不变
```

**优点**：
- 简单直接，不需要修改API调用
- 可以获取更多新闻

**缺点**：
- 如果API有频率限制，可能触发限流
- 可能获取到重复的新闻（需要去重）

### 方案2：使用时间范围过滤

**思路**：获取更多新闻，然后根据时间范围过滤

**实现**：
```python
def fetch_and_store_news():
    print(f"[{datetime.now()}] 开始抓取财联社新闻...")
    try:
        # 获取更多新闻（尝试多次调用）
        all_news_list = []
        max_calls = 5  # 最多调用5次
        min_news_per_call = 10  # 每次至少获取10条新闻才继续
        
        for i in range(max_calls):
            try:
                news_df = ak.stock_info_global_cls(symbol="全部")
                if news_df is not None and len(news_df) > 0:
                    all_news_list.append(news_df)
                    print(f"第 {i+1} 次调用获取 {len(news_df)} 条新闻")
                    
                    # 如果获取的新闻少于阈值，说明没有更多新闻了
                    if len(news_df) < min_news_per_call:
                        break
                    
                    # 短暂延迟
                    time.sleep(0.5)
                else:
                    break
            except Exception as e:
                print(f"第 {i+1} 次调用失败: {str(e)}")
                break
        
        # 合并所有新闻
        if all_news_list:
            news_df = pd.concat(all_news_list, ignore_index=True)
            # 去重
            news_df = news_df.drop_duplicates(subset=['标题', '内容'], keep='first')
            
            # 时间过滤：只保留最近1小时的新闻
            now = datetime.now()
            one_hour_ago = now - timedelta(hours=1)
            
            # 解析发布时间
            def parse_publish_time(row):
                try:
                    if pd.notna(row.get('发布日期')) and pd.notna(row.get('发布时间')):
                        date_str = str(row['发布日期'])
                        time_str = str(row['发布时间'])
                        dt = pd.to_datetime(f"{date_str} {time_str}")
                        return dt
                except:
                    pass
                return None
            
            news_df['parsed_time'] = news_df.apply(parse_publish_time, axis=1)
            news_df = news_df[news_df['parsed_time'] >= one_hour_ago]
            
            print(f"时间过滤后剩余 {len(news_df)} 条新闻")
        else:
            print("未获取到任何新闻")
            return
        
        # ... 后续处理逻辑保持不变
```

**优点**：
- 可以获取更多新闻
- 通过时间过滤，只保留最近的新闻

**缺点**：
- 需要处理时间解析
- 可能获取到很多旧新闻（需要过滤）

## 五、注意事项

1. **API频率限制**：

   - 如果某次调用失败，不应该影响其他调用
   - 需要记录错误日志

4. **性能考虑**：
   - 多次调用会增加处理时间
   - 需要平衡获取数量和性能
