### ⚠️ 2. 基础字段存储 - 部分正确

**news-analysis-system-main 存储的字段**：

**smart_stock_advisor 需要的字段**：

**问题**：
- ❌ **news-analysis-system-main 没有进行情感分析**

- ❌ **relevance_type, relevance_score 未设置**

---

### ⚠️ 3. 股票预测使用的字段 - 不匹配

**stock_predictor.py 使用的字段**：

```python
# 从数据库获取新闻时使用
news.get('sentiment_score')      # ❌ news-analysis-system-main 未设置
news.get('sentiment')            # ❌ news-analysis-system-main 未设置
news.get('is_positive')         # ❌ news-analysis-system-main 未设置
news.get('is_negative')         # ❌ news-analysis-system-main 未设置
news.get('is_policy')           # ❌ news-analysis-system-main 未设置
news.get('relevance_score')     # ❌ news-analysis-system-main 未设置
news.get('keywords')            # ❌ news-analysis-system-main 未设置
```

**实际查询**（`news_storage.py`）：
```python
SELECT * FROM news_articles 
WHERE symbol = %s 
AND DATE(publish_time) = CURDATE()
ORDER BY publish_time DESC
LIMIT %s
```

**问题**：
- 如果 `sentiment_score` 为 NULL，股票预测会使用默认值 0.0
- 如果 `is_positive`/`is_negative` 为 NULL，无法正确识别利好/利空
- 如果 `relevance_score` 为 NULL，无法正确计算相关性权重

---

### ⚠️ 4. LLM分析结果 - 未映射到预测字段

**news-analysis-system-main 的 LLM 分析结果**：
```python
✅ llm_category          # LLM分类
✅ llm_subcategory       # LLM子分类
✅ llm_keywords          # LLM关键词（TEXT格式）
✅ llm_sentiment_score   # LLM情感得分（-1到1）
✅ llm_summary           # LLM总结
✅ llm_impact_markets    # 影响市场
✅ llm_is_market_relevant # 是否与金融市场相关
```

**问题**：
- ❌ **LLM 分析结果存储在 `llm_*` 字段中**
- ❌ **股票预测使用的是 `sentiment_score` 等字段，不是 `llm_*` 字段**
- ❌ **两个字段系统没有映射关系**

---

## 📊 数据流分析

### 当前数据流

```
news-analysis-system-main
    ↓
获取财联社新闻
    ↓
股票匹配（symbol, sector, industry）
    ↓
存储到 news_articles 表
    ├─ 基础字段 ✅
    ├─ 股票关联 ✅
    └─ 情感分析字段 ❌ (NULL)
    ↓
LLM分析（独立流程）
    ↓
存储到 llm_* 字段 ✅
    ↓
smart_stock_advisor 股票预测
    ↓
查询 news_articles 表
    ├─ 使用 sentiment_score ❌ (NULL，使用默认值0.0)
    ├─ 使用 is_positive/is_negative ❌ (NULL)
    └─ 使用 llm_sentiment_score ❌ (未使用)
```

### 问题总结

1. **情感分析缺失**：news-analysis-system-main 没有进行情感分析
2. **字段不匹配**：LLM分析结果在 `llm_*` 字段，但股票预测使用 `sentiment_score` 等字段
3. **数据不完整**：股票预测需要的字段大部分为 NULL

---

## 🔧 解决方案

### 方案1：在新闻获取时添加情感分析（推荐）✅

**修改 `get_cls_news.py`**：
- 添加情感分析功能
- 在存储前分析新闻情感
- 填充 `sentiment_score`, `is_positive`, `is_negative` 等字段

**优点**：
- ✅ 数据完整，股票预测可以直接使用
- ✅ 不需要修改股票预测逻辑
- ✅ 与 smart_stock_advisor 的逻辑一致

### 方案2：将 LLM 分析结果映射到预测字段

**修改 `db_handle.py` 的 `import_results()`**：
- 将 `llm_sentiment_score` 映射到 `sentiment_score`
- 根据 `llm_sentiment_score` 设置 `is_positive`/`is_negative`
- 将 `llm_keywords` 转换为 JSON 格式存储到 `keywords`

**优点**：
- ✅ 利用 LLM 的深度分析结果
- ✅ 不需要重复分析

**缺点**：
- ⚠️ LLM 分析较慢，可能延迟

### 方案3：修改股票预测逻辑使用 LLM 字段

**修改 `stock_predictor.py`**：
- 优先使用 `llm_sentiment_score`（如果存在）
- 如果 `llm_sentiment_score` 为 NULL，再使用 `sentiment_score`

**优点**：
- ✅ 充分利用 LLM 分析结果
- ✅ 向后兼容

**缺点**：
- ⚠️ 需要修改股票预测代码
