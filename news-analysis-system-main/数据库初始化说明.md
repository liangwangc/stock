# 数据库初始化说明

**问题**：数据库 `cls_news_db` 不存在

---

## 解决方案

### 方式1：使用SQL脚本创建（推荐）

```bash
mysql -u root -p < src/config/init_database.sql
```

然后执行扩展脚本添加股票关联字段：

```bash
mysql -u root -p cls_news_db < src/config/add_stock_fields.sql
```

---

### 方式2：手动创建

**步骤1**：创建数据库

```sql
CREATE DATABASE IF NOT EXISTS `cls_news_db` 
DEFAULT CHARACTER SET utf8mb4 
COLLATE utf8mb4_unicode_ci;
```

**步骤2**：执行表创建脚本

```bash
mysql -u root -p cls_news_db < src/config/sql_table_create.txt
```

**步骤3**：执行扩展脚本（添加股票关联字段）

```bash
mysql -u root -p cls_news_db < src/config/add_stock_fields.sql
```

---

### 方式3：使用已存在的数据库

如果财联社新闻数据存储在其他数据库中，修改 `src/config/config.py`：

```python
DB_CONFIG = {
    'host': 'localhost',
    'user': 'root',
    'password': 'your_password',
    'database': 'your_existing_database',  # 修改为实际数据库名
    'port': 3306
}
```

---

## 验证

创建完成后，验证数据库和表：

```sql
USE cls_news_db;
SHOW TABLES;
-- 应该看到：news, analysis_results, processed_hashes, summary, news_stock_relation

DESCRIBE news;
-- 应该看到：symbol, sector, industry, concept, source, source_url 等字段
```
