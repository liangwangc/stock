### 4. 验证数据

**查询数据库验证**：
```sql
USE cls_news_db;

-- 查看最新获取的新闻（带股票关联）
SELECT id, title, symbol, sector, industry, source, create_time
FROM news
WHERE symbol IS NOT NULL
ORDER BY create_time DESC
LIMIT 10;

-- 查看股票关联关系
SELECT nsr.news_id, nsr.symbol, nsr.relevance_score, nsr.relation_type, n.title
FROM news_stock_relation nsr
JOIN news n ON nsr.news_id = n.id
ORDER BY nsr.created_at DESC
LIMIT 10;
```

---

### 5. 如果测试失败

**常见问题**：

1. **数据库密码错误**
   - 错误：`Access denied for user 'root'@'localhost'`
   - 解决：检查 `src/config/config.py` 中的 `DB_CONFIG['password']`

2. **数据库不存在**
   - 错误：`Unknown database 'cls_news_db'`
   - 解决：创建数据库或修改配置中的数据库名

3. **表不存在**
   - 错误：`Table 'cls_news_db.news' doesn't exist`
   - 解决：执行第一步的数据库扩展脚本

4. **股票匹配失败**
   - 检查主数据库连接配置（`MAIN_DB_CONFIG`）
   - 确认 `stock_predictions` 表有数据
