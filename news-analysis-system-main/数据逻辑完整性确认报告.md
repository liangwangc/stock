## 🔄 完整数据流

### 新闻获取流程

```

   ↓

```

```
1. 查询未分析新闻（llm_analyzed_at IS NULL）
   ↓
2. LLM深度分析
   - 分类分析
   - 情感分析
   - 关键词提取
   - 生成摘要
   ↓
3. 更新LLM字段
   - llm_category, llm_subcategory
   - llm_sentiment_score
   - llm_keywords, llm_summary
   ↓
4. 映射到预测字段
   - llm_sentiment_score → sentiment_score

```
