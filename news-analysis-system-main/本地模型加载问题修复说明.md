# 本地模型加载问题修复说明

**修复日期**：2026-01-23  
**问题**：本地模型无法加载，报错 `Using a device_map requires accelerate`

---

## 一、问题分析

### 1. 主要错误
```
ValueError: Using a `device_map`, `tp_plan`, `torch.device` context manager or setting `torch.set_default_device(device)` requires `accelerate`. You can install it with `pip install accelerate`
```

### 2. 根本原因
- **缺少 `accelerate` 库**：使用 `device_map="auto"` 需要 `accelerate` 库支持
- **网络代理问题**：代理配置错误（`127.0.0.1:9`），无法从 HuggingFace 下载模型

---

## 二、修复方案

### ✅ 1. 自动检测 `accelerate` 库

**修复前**：
- 直接使用 `device_map="auto"`，如果缺少 `accelerate` 库会报错

**修复后**：
- 先检查是否有 `accelerate` 库
- 如果有，使用 `device_map="auto"`（更高效）
- 如果没有，使用传统方式加载（`model.to(device)`）

### ✅ 2. 处理无效代理配置

**修复后**：
- 检测到无效代理配置（如 `127.0.0.1:9`）时，临时禁用代理
- 优先使用本地缓存（如果模型已下载）
- 如果在线加载失败，自动回退到本地缓存模式

### ✅ 3. 多层回退机制

**加载顺序**：
1. **优先**：使用 `accelerate` + `device_map="auto"`（如果可用）
2. **回退1**：使用传统方式 + `model.to(device)`（如果没有 `accelerate`）
3. **回退2**：使用本地缓存（如果在线加载失败）

---

## 三、使用建议

### 1. 安装 `accelerate` 库（推荐）

```bash
pip install accelerate
```

**优势**：
- 更高效的模型加载
- 支持多GPU自动分配
- 更好的内存管理

### 2. 检查代理配置

如果遇到网络问题，检查环境变量：
```bash
# Windows PowerShell
echo $env:HTTP_PROXY
echo $env:HTTPS_PROXY
```

如果代理配置错误，可以临时禁用：
```bash
# Windows PowerShell
$env:HTTP_PROXY = ""
$env:HTTPS_PROXY = ""
```

### 3. 使用 API 模式（备选方案）

如果本地模型加载仍有问题，可以使用 API 模式：
- 配置 `DASHSCOPE_API_KEY` 环境变量
- 系统会自动回退到 API 模式
