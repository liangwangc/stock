## 一、数据库配置

### 1.1 财联社新闻数据库（本地数据库）

**配置项**：`DB_CONFIG`  
**用途**：存储财联社新闻和分析结果

```python

    'host': 'localhost',
    'user': 'root',
    'password': 'qwer123123',
    'database': 'cls_news_db',
    'port': 3306
}
```

**数据库表**：
- `news`：财联社新闻原始数据
- `analysis_results`：LLM分析结果

- `summary`：分类总结

**连接字符串**：`DATABASE_URL`

## 五、配置修改

### 5.1 修改主数据库配置

如果需要修改主数据库配置，编辑 `src/config/config.py`：

```python
MAIN_DB_CONFIG = {
    'host': 'your_host',      # 修改主机
    'user': 'your_user',      # 修改用户名

```

可以修改代码支持环境变量：

```python

    'host': os.getenv('MAIN_DB_HOST', 'localhost'),
```

## 六、注意事项

### 6.1 数据库连接

⚠️ **确保两个数据库都正常运行**：
- 财联社数据库（cls_news_db）：用于存储新闻和分析结果
- 主数据库（stock_data）：用于同步数据

### 6.2 数据同步

⚠️ **同步前确保**：
- `news_articles` 表已扩展LLM字段（执行 `add_llm_analysis_fields.sql`）
- `content_hash` 字段正确生成
- 数据库连接配置正确

### 6.3 权限要求

⚠️ **数据库用户权限**：
- 对 `cls_news_db` 需要有读写权限
- 对 `stock_data` 需要有写入权限（至少对 `news_articles` 表）
