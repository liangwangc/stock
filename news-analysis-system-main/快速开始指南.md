```sql
USE cls_news_db;

-- 查看有股票关联的新闻
SELECT id, title, symbol, sector, industry, source, create_time
FROM news
WHERE symbol IS NOT NULL
ORDER BY create_time DESC
LIMIT 10;

-- 查看股票关联关系
SELECT nsr.news_id, nsr.symbol, nsr.relevance_score, nsr.relation_type, n.title
FROM news_stock_relation nsr
JOIN news n ON nsr.news_id = n.id
ORDER BY nsr.created_at DESC
LIMIT 10;
```

## 六、常见问题

### 6.1 股票匹配失败

**问题**：股票匹配模块无法加载股票信息

**解决**：
1. 检查主数据库连接配置是否正确
2. 确认 `stock_predictions` 表有数据
3. 检查数据库权限

---

### 6.2 数据库连接失败

**问题**：无法连接到主数据库

**解决**：
1. 检查 `MAIN_DB_CONFIG` 配置
2. 确认数据库服务运行正常
3. 检查网络连接

---

### 6.3 同步失败

**问题**：数据同步失败

**解决**：
1. 检查两个数据库的连接配置
2. 确认 `news_articles` 表已扩展LLM字段
3. 查看同步日志中的错误信息

## 七、功能说明

### 7.1 股票匹配策略

1. **股票代码提取**：
   - 匹配6位数字（600xxx, 000xxx, 002xxx, 300xxx等）
   - 支持"代码：600519"格式

2. **股票名称匹配**：
   - 完整名称匹配
   - 去除后缀匹配（如"股份"、"有限公司"）
   - 简称匹配

3. **行业匹配**：
   - 基于行业关键词匹配
   - 相关性得分：0.5-0.7

---

### 7.2 数据存储

**news 表**：
- 存储新闻基本信息
- 包含主要股票关联（symbol, sector, industry）

**news_stock_relation 表**：
- 存储多对多关联关系
- 支持一条新闻关联多个股票
- 包含相关性得分和关联类型
