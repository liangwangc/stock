## 三、可能遇到的问题

### 3.1 模块未找到

**错误**：`ModuleNotFoundError: No module named 'sqlalchemy'`

**解决**：
```bash
py -m pip install sqlalchemy pandas pymysql
```

---

### 3.2 数据库连接失败

**错误**：`连接主数据库失败` 或 `无法加载股票信息`

**检查项**：
1. 确认 `src/config/config.py` 中的 `MAIN_DB_CONFIG` 配置正确
2. 确认主数据库（stock_data）服务运行正常
3. 确认 `stock_predictions` 表有数据

**验证数据库连接**：
```python
from src.config.config import MAIN_DATABASE_URL
from sqlalchemy import create_engine

engine = create_engine(MAIN_DATABASE_URL)
with engine.connect() as conn:
    result = conn.execute("SELECT COUNT(*) FROM stock_predictions")
    print(f"股票数量: {result.fetchone()[0]}")
```

---

### 3.3 股票信息为空

**问题**：`已加载 0 只股票信息到缓存`

**原因**：主数据库的 `stock_predictions` 表没有数据

**解决**：
1. 先运行 smart_stock_advisor 的股票预测任务
2. 确保 `stock_predictions` 表有数据后再测试
