## 🗂️ 数据库表结构

### news_articles 表（主要表）

**基础字段**：
- `id`, `title`, `content`, `publish_time`, `fetch_time`
- `source`, `source_url`, `news_type`
- `symbol`, `sector`, `industry`, `concept`
- `content_hash` (用于去重)

**LLM分析字段**：
- `llm_category` - 主分类
- `llm_subcategory` - 子分类
- `llm_keywords` - 关键词
- `llm_sentiment_score` - 情感得分（-1到1）
- `llm_summary` - 总结
- `llm_impact_markets` - 影响市场/品种
- `llm_is_market_relevant` - 是否与金融市场相关
- `llm_analyzed_at` - 分析时间

### news_stock_relation 表（可选）

- `news_id` - 新闻ID
- `symbol` - 股票代码
- `relevance_score` - 相关性得分
- `relation_type` - 关联类型（direct/related）

编辑 `src/config/config.py`，确认数据库配置正确：
```python
DB_CONFIG = {
    'host': 'localhost',
    'user': 'root',
    'password': 'root',
    'database': 'stock_data',
    'port': 3307,
    'charset': 'utf8mb4'
}
```

### 3. 测试新闻获取（单次）


## 🔍 故障排查

### 常见问题

1. **数据库连接失败**
   - 检查 `config.py` 中的数据库配置
   - 确认数据库服务是否运行
   - 检查端口是否正确（3307）

2. **新闻获取失败**
   - 检查网络连接
   - 确认 akshare 库已安装
   - 查看日志文件中的错误信息

3. **LLM分析失败**
   - 确认模型文件已下载
   - 检查内存是否充足
   - 查看日志文件中的错误信息

4. **股票匹配率低**
   - 检查股票信息是否完整
   - 优化匹配算法
   - 查看匹配日志
