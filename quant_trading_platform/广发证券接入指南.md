# 广发证券API接入指南

## 前置准备

### 1. 申请广发证券API权限

1. **联系广发证券**：
   - 访问广发证券官网或联系客服
   - 申请开放平台API访问权限
   - 获取API密钥（API Key）和应用ID（App ID）

2. **获取API密钥**：
   - API Key（API密钥）
   - API Secret（API密钥）
   - App ID（应用ID）

### 2. 安装依赖

```bash
pip install gf-api-client
```

## 配置步骤

### 1. 配置API信息

编辑 `config.py` 文件，填写您的广发证券API信息：

```python
# 广发证券API配置
GF_API_CONFIG = {
    "api_key": "您的API密钥",        # 替换为您的API Key
    "api_secret": "您的API密钥",      # 替换为您的API Secret
    "app_id": "您的应用ID",           # 替换为您的App ID
    "base_url": "https://openapi.gf.com.cn",
    "enabled": True  # 启用广发证券API
}
```

### 2. 运行实盘交易

```bash
python trading/gf_realtime_trading.py
```

## 常见问题

### Q: 如何获取广发证券API密钥？

A: 需要联系广发证券客服或访问广发证券开放平台申请API权限。

### Q: API调用失败怎么办？

A: 检查：
1. API密钥是否正确
2. 网络连接是否正常
3. API服务是否可用
4. 账户是否有足够的资金/持仓

### Q: 如何测试API连接？

A: 可以先调用 `get_balance()` 方法测试账户查询功能。

### Q: 交易费用如何计算？

A: 交易费用（手续费、印花税等）由广发证券自动计算，无需在代码中单独处理。

## API接口说明

根据实际的 `gf-api-client` 库的API，可能需要调整以下方法：

1. `place_order()`: 下单接口
2. `get_positions()`: 查询持仓
3. `get_account_info()`: 查询账户信息
4. `get_quote()`: 获取行情

如果API接口与代码中的实现不同，需要根据实际的API文档进行调整。
