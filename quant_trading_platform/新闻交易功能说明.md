  - 快速买入/卖出执行

## 核心特性

### 快速交易模式

- **快速买入**: 检测到利好新闻时，立即买入
- **快速卖出**: 检测到利空新闻时，立即卖出
- **情感阈值**: 可配置的情感分数阈值
- **置信度过滤**: 只有置信度足够高的信号才会执行

### 情感分析

使用关键词匹配分析新闻情感：

**利好关键词**：
- 上涨、增长、盈利、利好、突破、大涨、涨停、创新高
- 超预期、业绩增长、扩张、收购、合并、重组
- 订单、签约、中标、合作、投资、增持、回购
- 推荐、买入、增持评级

**利空关键词**：
- 下跌、下降、亏损、利空、跌停、创新低、破位
- 低于预期、业绩下滑、收缩、减持、退市
- 解约、违约、风险、警告、调查、处罚、违规
- 看空、减持、卖出、减持评级

## 使用方法

### 1. 运行新闻实时交易（模拟模式）

```bash
python trading/news_realtime_trading.py
```

### 2. 在代码中使用

```python
from strategies.news_strategy import NewsRealtimeStrategy
from trading.news_realtime_trading import NewsRealtimeTrading
from trading.simulated_trader import SimulatedTrader
from data_source import AkshareDataSource

# 初始化交易接口
data_source = AkshareDataSource()
trader = SimulatedTrader(
    initial_cash=1000000,
    commission=0.0003,
    slippage=0.001,
    data_source=data_source
)

# 创建新闻策略
strategy = NewsRealtimeStrategy(
    symbol="600519",  # 股票代码
    sentiment_threshold=0.3,  # 情感阈值（超过此值才交易）
    confidence_threshold=0.5,  # 置信度阈值
    news_count=5,  # 分析5条最新新闻
    fast_trade=True  # 快速交易模式
)

# 创建新闻实时交易系统
news_trading = NewsRealtimeTrading(
    trader=trader,
    strategy=strategy,
    check_interval=300,  # 每5分钟检查一次新闻
    fast_trade=True,  # 快速交易模式
    max_position_ratio=0.8  # 最大持仓80%
)

# 启动交易
news_trading.start()
```

## 策略参数说明

### NewsRealtimeStrategy 参数

- `symbol`: 股票代码（如 "600519"）
- `sentiment_threshold`: 情感分数阈值（默认0.3）
  - 超过此值触发买入，低于-此值触发卖出
- `confidence_threshold`: 置信度阈值（默认0.5）
  - 只有置信度超过此值的信号才会执行
- `news_count`: 分析的新闻数量（默认5）
- `fast_trade`: 是否快速交易模式（默认True）

### NewsRealtimeTrading 参数

- `check_interval`: 检查新闻的时间间隔（秒，默认300）
- `fast_trade`: 快速交易模式（默认True）
  - True: 买入时使用90%可用资金
  - False: 买入时使用70%可用资金
- `max_position_ratio`: 最大持仓比例（默认0.8）

## 交易逻辑

### 买入条件（全部满足才买入）

1. ✅ 新闻情感为**正面**（positive）
2. ✅ 情感分数 > `sentiment_threshold`（默认0.3）
3. ✅ 置信度 > `confidence_threshold`（默认0.5）
4. ✅ 当前**无持仓**
5. ✅ 可用资金 >= 1000元

### 卖出条件（全部满足才卖出）

1. ✅ 新闻情感为**负面**（negative）
2. ✅ 情感分数 < -`sentiment_threshold`（默认-0.3）
3. ✅ 置信度 > `confidence_threshold`（默认0.5）
4. ✅ 当前**有持仓**
