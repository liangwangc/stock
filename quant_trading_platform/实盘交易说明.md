# 实盘自动交易说明

## ⚠️ 重要提示

**当前实现的实盘交易模块使用的是模拟交易接口，不涉及真实资金！**

要进行真实的自动买卖股票，需要：

1. **接入券商API**：需要开通支持API交易的券商账户
2. **风险评估**：实盘交易存在资金损失风险
3. **合规要求**：需要遵守相关法律法规
4. **充分测试**：在模拟环境充分测试后再考虑实盘

## 当前实现

### 1. 模拟交易接口 (`SimulatedTrader`)

- 完全模拟的交易环境
- 不涉及真实资金
- 用于测试交易逻辑和策略
- 包含手续费、滑点等真实交易成本

### 2. 实时交易管理器 (`RealtimeTrader`)

- 定时检查交易信号
- 自动执行买入/卖出操作
- 账户状态监控
- 交易记录保存

## 使用方法

### 模拟交易（测试用）

```bash
python realtime_trading.py
```

这将启动模拟交易系统，每5分钟检查一次交易信号。

## 风险提示

1. **市场风险**：股票价格可能大幅波动，导致资金损失
2. **技术风险**：系统故障、网络问题可能导致交易失败
3. **策略风险**：策略可能失效，导致持续亏损
4. **流动性风险**：某些股票可能无法及时成交

## 建议

1. **充分回测**：在历史数据上充分测试策略
2. **小额测试**：先用小额资金测试真实交易
3. **设置止损**：建立完善的风险控制机制
4. **监控运行**：实时监控交易系统运行状态
5. **定期评估**：定期评估策略表现，及时调整
