# 快速配置广发证券API

## 步骤1: 获取API密钥

### 方法1: 联系广发证券客服

1. 拨打广发证券客服热线：95575
2. 说明需要申请开放平台API权限
3. 提供您的账户信息
4. 等待审核通过后获取API密钥

### 方法2: 访问广发证券官网

1. 访问广发证券官网：https://www.gf.com.cn
2. 登录您的账户
3. 查找"开放平台"或"API接口"相关页面
4. 申请API访问权限
5. 填写申请表格，说明用途

### 方法3: 访问广发证券开放平台（如果有）

1. 访问广发证券开放平台（具体URL请咨询客服）
2. 注册开发者账号
3. 创建应用获取API密钥

**需要获取的信息：**
- ✅ API Key（API密钥）
- ✅ API Secret（API密钥）
- ✅ App ID（应用ID）

## 步骤2: 配置API信息

编辑 `config.py` 文件，找到 `GF_API_CONFIG` 部分：

```python
GF_API_CONFIG = {
    "api_key": "这里填写您的API Key",
    "api_secret": "这里填写您的API Secret", 
    "app_id": "这里填写您的App ID",
    "base_url": "https://openapi.gf.com.cn",
    "enabled": True  # 设置为True启用
}
```

**示例：**
```python
GF_API_CONFIG = {
    "api_key": "GF20231224001ABC123",
    "api_secret": "Secret1234567890ABCDEF",
    "app_id": "APP123456",
    "base_url": "https://openapi.gf.com.cn",
    "enabled": True
}
```

## 步骤3: 安装依赖

```bash
pip install gf-api-client
```

如果安装失败，可以尝试：
```bash
pip install gf-api-client -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 步骤4: 测试配置

运行测试脚本验证配置：

```bash
python test_gf_api.py
```

测试脚本会检查：
- ✅ 配置是否完整
- ✅ API库是否已安装
- ✅ API连接是否正常
- ✅ 账户信息能否查询

## 步骤5: 运行实盘交易

配置测试通过后，运行实盘交易程序：

```bash
python trading/gf_realtime_trading.py
```

## 常见问题

### Q1: 找不到广发证券API申请入口？

**A:** 广发证券的API接口可能不是公开的，建议：
1. 直接联系客服咨询
2. 询问您的客户经理
3. 查看广发证券官网的"机构业务"或"量化交易"相关页面

### Q2: API密钥格式是什么样的？

**A:** 一般格式：
- API Key: 通常是字母数字组合，如 `GF20231224001ABC123`
- API Secret: 通常是较长的密钥字符串
- App ID: 应用标识符

### Q3: 测试时提示"API密钥不正确"？

**A:** 请检查：
1. 是否复制了多余的空格
2. 密钥是否完整（没有截断）
3. 是否使用了正确的密钥对

### Q4: 提示"gf-api-client未安装"？

**A:** 运行：
```bash
pip install gf-api-client
```

如果该库不存在，可能需要：
1. 使用广发证券提供的官方SDK
2. 根据广发证券API文档自行实现接口

### Q5: 如何确认API是否可用？

**A:** 可以：
1. 先用测试脚本 `test_gf_api.py` 测试
2. 尝试查询账户余额（只读操作，不涉及交易）
3. 联系广发证券技术支持确认API状态

## 注意事项

1. **安全性**：
   - 不要将API密钥提交到代码仓库
   - 建议使用环境变量存储敏感信息
   - 定期更换API密钥

2. **测试**：
   - 先用小额资金测试
   - 充分测试后再加大资金量
   - 设置止损和风险控制

3. **合规**：
   - 遵守广发证券API使用规范
   - 注意API调用频率限制
   - 确保交易行为合规

## 如果找不到官方API

如果广发证券不提供公开的API接口，可以考虑：

1. **使用第三方量化平台**：
   - 掘金量化
   - 米筐量化
   - 聚宽量化
   - 这些平台通常支持多家券商接入

2. **联系广发证券量化交易部门**：
   - 机构客户可能有专门的接口
   - 可以咨询是否有量化交易接口

3. **使用模拟交易先测试策略**：
   - 使用平台提供的模拟交易接口
   - 验证策略有效性后再考虑实盘
