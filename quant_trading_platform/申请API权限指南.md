# 广发证券API权限申请指南

## 申请方式

### 方式1: 电话申请（推荐）

**客服热线：95575**

**申请话术模板：**

```
您好，我是广发证券的客户，账户号是 [你的账户号]。
我想申请开放平台API接口权限，用于量化交易和程序化交易。
请问需要如何申请？需要准备哪些材料？
```

**可能的问题及回答：**

- **问：为什么需要API接口？**
  - 答：我需要进行量化交易和程序化交易，希望能通过API接口实现自动化交易策略。

- **问：是否有相关资质？**
  - 答：我是个人投资者，主要用于个人账户的量化交易。

- **问：资金规模是多少？**
  - 答：[如实回答你的资金规模]

- **问：用途是什么？**
  - 答：用于实现基于技术指标的自动交易策略，提高交易效率。

### 方式2: 营业部申请

1. 前往就近的广发证券营业部
2. 联系你的客户经理
3. 说明需要申请API接口权限
4. 填写相关申请表格
5. 提供身份证明和账户信息

### 方式3: 在线申请（如果有）

1. 登录广发证券官网
2. 查找"机构业务"、"量化交易"或"API接口"相关页面
3. 填写在线申请表格
4. 提交相关材料

## 申请材料准备

通常需要准备以下材料：

1. **身份证明**：身份证复印件
2. **账户信息**：证券账户号
3. **申请说明**：用途说明（见下方模板）
4. **风险评估**：风险承受能力评估

## 申请流程

1. **提交申请**
   - 通过电话、营业部或在线方式提交申请
   - 提供必要的材料和说明

2. **等待审核**
   - 广发证券会审核你的申请
   - 通常需要1-3个工作日

3. **获取权限**
   - 审核通过后，广发证券会提供：
     - API Key（API密钥）
     - API Secret（API密钥）
     - App ID（应用ID）
     - API文档和使用说明

4. **配置使用**
   - 按照提供的文档配置API
   - 在本平台的config.py中填写密钥
   - 使用test_gf_api.py测试连接

## 注意事项

1. **机构客户优先**：
   - 如果API接口主要面向机构客户，可能需要一定的资金门槛
   - 个人客户可能需要特殊申请

2. **替代方案**：
   - 如果广发证券不提供个人API接口，可以考虑：
     - 使用第三方量化平台（如掘金、米筐、聚宽）接入广发证券
     - 使用其他支持API的券商（如华泰证券、东方财富等）

3. **合规要求**：
   - 确保交易行为符合监管要求
   - 遵守API使用规范
   - 不要违反交易规则

## 常见问题

### Q1: 个人客户可以申请吗？

**A:** 这取决于广发证券的政策。建议：
- 先咨询客服了解个人客户是否可以申请
- 如果有资金门槛，了解具体要求
- 考虑使用第三方量化平台作为替代方案

### Q2: 申请需要多长时间？

**A:** 通常需要1-3个工作日审核，具体时间请咨询客服。

### Q3: 申请会被拒绝吗？

**A:** 如果申请被拒绝，可以：
- 询问拒绝原因
- 提供更详细的用途说明
- 考虑使用第三方平台接入

### Q4: 费用是多少？

**A:** 通常API接口本身不收费，但需要确认：
- 是否有接口使用费
- 交易手续费是否与普通交易相同
