# 广发证券API权限申请指南

## 📞 申请渠道

### 方式一：电话申请（推荐）

1. **拨打广发证券客服热线**：95575
2. **转接人工服务**后说明需求：
   ```
   您好，我是广发证券的客户，账户号是：[您的账户号]
   我需要申请开放平台API接口权限，用于量化交易和程序化交易。
   请问如何申请API接口？
   ```
3. **可能需要提供的信息**：
   - 账户号/客户号
   - 身份证号（用于身份验证）
   - 申请用途说明（量化交易、程序化交易）
   - 联系方式

### 方式二：在线客服

1. 访问广发证券官网：https://www.gf.com.cn
2. 登录您的账户
3. 点击"在线客服"或"智能客服"
4. 输入：`申请API接口权限` 或 `量化交易API`
5. 转人工服务后说明需求

### 方式三：客户经理

1. 如果您有专属客户经理，直接联系客户经理
2. 说明需要申请API接口权限
3. 客户经理会指导您完成申请流程

### 方式四：营业部现场申请

1. 前往您开户的广发证券营业部
2. 说明需要申请API接口权限
3. 填写相关申请表
4. 提供身份证明等材料

## 📋 申请时需要的材料

通常需要准备：

1. **身份证明**：
   - 身份证原件及复印件
   - 账户持有人身份验证

2. **账户信息**：
   - 证券账户号
   - 资金账户号
   - 开户营业部信息

3. **申请说明**：
   - 申请用途（量化交易/程序化交易）
   - 使用目的说明
   - 预计使用规模

4. **风险承诺书**（可能）：
   - 了解API交易风险
   - 承诺合规使用

## 💬 申请话术参考

### 电话申请话术

```
客服：您好，广发证券，请问有什么可以帮您？

您：您好，我是广发证券的客户，想申请开放平台API接口权限。

客服：请问您申请API接口是用于什么用途？

您：我需要进行量化交易和程序化交易，希望通过API接口实现自动化交易。

客服：好的，请问您的账户号是？

您：[提供账户号]

客服：请提供您的身份证号进行身份验证。

您：[提供身份证号]

客服：好的，我已经为您记录申请，请问您的联系方式是？

您：[提供联系方式]

客服：我们会在3-5个工作日内审核您的申请，审核通过后会通过电话/短信/邮件通知您。

您：请问审核需要多长时间？我需要提供什么材料吗？

客服：[告知审核时间和所需材料]

您：好的，谢谢。另外，我想了解一下API接口的使用文档和技术支持联系方式。

客服：[提供相关信息]
```

## ⏰ 审核流程

1. **提交申请**（当天）
   - 通过电话/在线/现场提交申请
   - 填写相关表格

2. **审核阶段**（3-5个工作日）
   - 广发证券审核您的申请
   - 可能需要进行电话回访确认

3. **审核通过**
   - 收到审核通过通知
   - 获取API密钥和文档

4. **技术对接**（如有需要）
   - 获取API文档
   - 技术对接指导
   - 测试环境接入

## 📝 申请注意事项

1. **明确用途**：说明是用于量化交易、程序化交易或自动化交易
2. **合规使用**：承诺遵守相关法律法规和交易规则
3. **风险认知**：了解API交易的风险，签署风险提示书（如有）
4. **保持联系**：确保联系方式畅通，以便接收审核结果

## 🔍 如果广发证券不提供公开API

如果广发证券客服表示不提供公开的API接口，您可以：

### 选项1：询问机构客户接口

```
"请问机构客户或者大户是否有专门的量化交易接口？
我的交易规模比较大，可能需要程序化交易接口。"
```

### 选项2：询问第三方平台接入

```
"广发证券是否支持通过第三方量化平台（如掘金、米筐、聚宽）进行接入？"
```

### 选项3：询问量化交易产品

```
"广发证券是否有针对量化交易客户的专业服务或产品？"
```
