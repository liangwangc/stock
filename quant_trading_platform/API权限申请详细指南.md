# 广发证券API权限申请详细指南

## 申请渠道

### 方式1: 电话申请（推荐）

1. **拨打客服电话**：95575
2. **转接人工服务**：按提示转接到人工客服
3. **说明需求**：告诉客服你需要申请量化交易API接口权限
4. **提供信息**：
   - 你的广发证券账户号
   - 身份证号（用于身份验证）
   - 申请用途说明（量化交易/程序化交易）
5. **记录工单号**：保存客服提供的工单号，便于后续查询进度

### 方式2: 客户经理申请

1. **联系你的客户经理**（如果你有专属客户经理）
2. **说明需求**：量化交易API接口权限
3. **提供材料**：
   - 身份证明
   - 账户信息
   - 申请用途说明

### 方式3: 营业部申请

1. **前往最近的广发证券营业部**
2. **找到柜台服务人员**
3. **填写申请表**：程序化交易接口申请
4. **提交材料**：
   - 身份证原件及复印件
   - 股东账户卡
   - 申请表

### 方式4: 官网在线申请（如果有）

1. 访问广发证券官网：https://www.gf.com.cn
2. 登录账户
3. 查找"业务办理" → "量化交易"或"API接口"
4. 在线填写申请表

## 申请时需要说明的信息

### 1. 申请用途

**标准说辞：**
> "您好，我需要申请量化交易API接口权限，用于程序化交易系统，实现自动化买卖股票。这是我个人账户，用于个人量化策略回测和交易。"

### 2. 技术需求

**可以这样说明：**
- 需要REST API接口或WebSocket接口
- 需要下单、查询持仓、查询资金等基本功能
- 需要实时行情接口（如果策略需要）

### 3. 风险声明

**广发证券可能会问：**
- Q: 是否了解程序化交易风险？
- A: "是的，我了解程序化交易存在风险，包括系统故障、策略失效等风险，我会做好风险控制。"

- Q: 是否做过充分测试？
- A: "是的，我已经在模拟环境中充分测试了策略。"

## 申请材料准备

### 必需材料

1. ✅ **身份证明**：身份证原件及复印件
2. ✅ **账户信息**：股东账户号、资金账户号
3. ✅ **申请表**：程序化交易接口申请表（营业部提供）

### 可能需要提供的材料

1. **风险揭示书**：签署程序化交易风险揭示书
2. **技术方案**：简单的技术实现方案说明
3. **测试报告**：策略回测报告（如果有）

## 申请流程时间

1. **提交申请**：1个工作日
2. **审核时间**：通常3-7个工作日
3. **获取密钥**：审核通过后1-3个工作日
4. **总计**：大约5-10个工作日

## 常见问题

### Q1: 个人投资者可以申请吗？

**A:** 可以，但可能需要满足一定条件（如资产规模、交易经验等）。建议直接咨询客服。

### Q2: 申请需要费用吗？

**A:** 通常API接口本身不收费，但可能有最低资产要求或交易量要求。具体请咨询客服。

### Q3: 申请被拒绝怎么办？

**A:** 
1. 询问拒绝原因
2. 如果是因为资产不足，可以考虑增加账户资金
3. 如果是因为风险控制，可以提供更详细的风险管理方案
4. 也可以考虑使用第三方量化平台（如掘金、米筐等）

### Q4: API接口有哪些限制？

**A:** 可能的限制包括：
- 调用频率限制（如每秒最多X次）
- 单次下单金额限制
- 持仓数量限制
- 交易时间限制（仅交易时间可用）

### Q5: 如果没有API接口怎么办？

**A:** 可以考虑：
1. **使用第三方量化平台**：如掘金量化、米筐量化、聚宽量化等
2. **使用模拟交易**：先用模拟环境测试策略
3. **其他券商**：某些券商（如华泰证券）的API接口更容易申请

## 如果广发证券不提供公开API

如果广发证券明确表示不提供个人API接口，可以考虑：

### 方案1: 使用第三方量化平台

1. **掘金量化**：https://www.myquant.cn
   - 支持多家券商
   - 提供Python SDK
   - 可以接入广发证券账户

2. **米筐量化**：https://www.ricequant.com
   - 专业量化平台
   - 支持回测和实盘

3. **聚宽量化**：https://www.joinquant.com
   - 老牌量化平台
   - 功能完善

### 方案2: 继续使用模拟交易

当前平台的模拟交易功能已经完全可用，可以：
- 测试策略有效性
- 验证交易逻辑
- 积累交易经验

等条件成熟后再考虑实盘交易。

### 方案3: 其他券商

某些券商对API接口更加开放：
