# 量化交易平台使用说明

## 快速开始

### 1. 安装依赖

```bash
cd quant_trading_platform
pip install -r requirements.txt
```

### 2. 运行程序

```bash
python main.py
```

或者使用快速启动脚本：

```bash
python run.py
```

## 配置说明

在 `config.py` 文件中可以修改以下配置：

- `START_DATE`: 回测开始日期（格式：YYYYMMDD）
- `END_DATE`: 回测结束日期（格式：YYYYMMDD）
- `DEFAULT_CASH`: 初始资金（默认100万）
- `DEFAULT_COMMISSION`: 手续费率（默认0.03%，即万三）
- `DEFAULT_SLIPPAGE`: 滑点率（默认0.1%）
- `DEFAULT_STOCKS`: 默认股票池

## 修改策略

在 `main.py` 中可以选择不同的策略：

```python
# 使用移动平均线策略
strategy = MovingAverageStrategy(short_period=5, long_period=20)

# 或使用MACD策略
strategy = MACDStrategy()
```

## 创建自定义策略

1. 在 `strategies/` 目录下创建新的策略文件
2. 继承 `BaseStrategy` 类
3. 实现 `generate_signals` 方法

示例：

```python
from strategies.base_strategy import BaseStrategy
import pandas as pd

class MyStrategy(BaseStrategy):
    def __init__(self):
        super().__init__("我的策略")
    
    def generate_signals(self, data: pd.DataFrame) -> pd.DataFrame:
        signals = pd.DataFrame(index=data.index)
        signals['signal'] = 0
        # 在这里实现你的交易逻辑
        # 1 = 买入, -1 = 卖出, 0 = 持有
        return signals
```

## 修改股票代码

在 `main.py` 中修改股票代码：

```python
symbol = "000001"  # 改为你想测试的股票代码
```

或者在 `config.py` 中修改 `DEFAULT_STOCKS` 列表。

## 注意事项

1. 首次运行需要下载数据，可能需要一些时间
2. 确保网络连接正常，数据获取需要访问互联网
3. 如果数据获取失败，请检查股票代码是否正确
4. 绘图功能需要图形界面支持，如果没有图形界面，程序仍会正常运行但不会显示图表

## 常见问题

### Q: 数据获取失败怎么办？
A: 检查网络连接，确保可以访问akshare数据源。也可以尝试更换股票代码。

### Q: 如何添加更多技术指标？
A: 在 `indicators/technical_indicators.py` 中添加新的指标函数。

### Q: 如何保存回测结果？
A: 回测结果会自动保存为CSV文件（如果修改代码），图表会保存为PNG文件。

### Q: 支持实时交易吗？
A: 当前版本仅支持回测功能，不包含实盘交易功能。
