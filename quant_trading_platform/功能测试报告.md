## 使用建议

### 1. 回测策略
```bash
python main.py
```
在 `config.py` 中修改股票代码和日期范围，在 `main.py` 中选择策略。

### 2. 模拟交易测试
```bash
python realtime_trading.py
```
使用模拟交易接口测试实时交易逻辑。

### 3. 申请API权限
查看 `申请API权限指南.md`，联系广发证券申请API权限。

### 4. 实盘交易（获取API权限后）
```bash
python trading/gf_realtime_trading.py
```

## 注意事项

1. **数据获取**: 需要网络连接，首次运行会下载数据
2. **API接入**: 广发证券API需要申请权限，可能需要一定时间
3. **实盘交易**: 存在风险，建议先用模拟交易测试
4. **策略优化**: 可以在历史数据上充分回测后再考虑实盘
