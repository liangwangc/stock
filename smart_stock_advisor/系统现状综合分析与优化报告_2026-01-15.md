## 二、股票预测系统分析

### 2.1 预测流程架构

**核心类**：`StockPredictor` (`predictor/stock_predictor.py`)

**预测流程**：
```
1. 数据准备（获取60天历史数据）
   ↓
2. 并行多因子分析（9个因子）
   ├── 第一阶段：独立分析（6个任务，并行）
   │   ├── market_overall（市场整体）
   │   ├── news（新闻情感）
   │   ├── capital_flow（资金流向）
   │   ├── valuation（估值指标）
   │   ├── us_sector（美股板块）
   │   └── sector_rotation（板块轮动）
   └── 第二阶段：数据依赖分析（3个任务，并行）
       ├── technical（技术指标）
       ├── market（市场情绪）
       └── history（历史模式）
   ↓
3. ML模型预测（如果模型已激活）
   ↓
4. 市场状态识别与权重调整
   ↓
5. 因子融合计算（加权平均）
   ↓
6. 概率转换（Sigmoid函数）
   ↓
7. 置信度计算
   ↓
8. 生成预测结果
```

### 2.2 预测因子权重配置

**当前权重分配**（总计100%）：
- 新闻情感权重：25%
- 资金流向权重：18%
- 市场情绪权重：17%
- 技术指标权重：20%
- 板块轮动权重：5%
- 历史模式权重：8%
- 美股板块权重：5%
- 估值指标权重：2%
- **ML模型权重：15%**（如果模型激活）

**权重来源**：
- 默认值：`config.py` 中的 `PREDICTION_CONFIG`
- 动态配置：数据库 `prediction_config` 表（通过 `PredictionConfigManager` 管理）
- 支持热更新：无需重启服务

## 三、实时交易策略分析

### 3.1 实时决策流程

**核心类**：`RealtimeTradingAdvisor` (`predictor/realtime_trading_advisor.py`)

**决策流程**：
```
1. 检查交易时间（集合竞价/交易时段/收盘）
   ↓
2. 获取实时行情（当前价格、涨跌幅）
   ↓
3. 执行预测分析（调用 StockPredictor.predict()）
   ↓
4. 获取实时资金流向
   ↓
5. 分析买卖盘（五档买卖盘强度）
   ↓
6. 综合计算交易信号
   ├── 预测结果权重：50%
   ├── 资金流向权重：25%
   ├── 买卖盘权重：15%
   └── 盘中调整权重：10%
   ↓
7. 生成交易决策（BUY/SELL/HOLD/ADD/REDUCE）
   ↓
8. 输出决策结果（理由、价格建议、风险警告）
```

### 3.2 决策规则

**未持仓时**：
- BUY（强烈）：signal_strength > 0.75 && confidence > 0.70
- BUY（适中）：signal_strength > 0.65 && confidence > 0.55
- WAIT：震荡行情
- AVOID：下跌概率 > 60%

**已持仓时**：
- SELL（止损）：亏损 <= -5%
- SELL（止盈）：盈利 >= +8% && 预测看跌
- SELL（强烈）：下跌概率 > 70%
- REDUCE：下跌概率 > 60%
- ADD：上涨概率 > 75% && 当前盈利
- HOLD：其他情况

## 六、问题总结

### 6.1 已发现的问题

#### 问题1：实时策略效率问题 ⚠️⚠️

**问题描述**：
- 实时策略每次刷新都执行完整的预测分析
- 预测分析耗时较长（5-10秒）
- 导致实时策略页面响应慢

**影响**：用户体验差，实时监控效率低

**解决方案**：
- ✅ 已实现预测结果缓存（10分钟）
- ⚠️ 但缓存机制可能不够完善

#### 问题2：ML模型权重固定 ⚠️

**问题描述**：
- ML模型权重固定为15%，无法根据模型表现动态调整
- 如果模型表现差，仍然占用15%权重

**影响**：可能影响预测准确性

**解决方案**：
- 建议根据模型历史准确率动态调整权重
- 模型表现差时降低权重或禁用

#### 问题3：参数优化后需要手动刷新 ⚠️

**问题描述**：
- 应用优化参数后，需要调用 `refresh_config()` 才能生效
- 或者需要重新初始化 `StockPredictor`

**影响**：用户体验不够友好

**解决方案**：
- 应用优化参数后自动刷新配置
- 或者在每次预测前检查配置是否有更新

### 8.2 实时交易策略核心逻辑

#### 8.2.1 预测结果缓存机制

**实现位置**：`predictor/realtime_trading_advisor.py` 第581-650行

**缓存策略**：
- **缓存键**：股票代码（`symbol`）
- **缓存值**：预测结果字典 + 时间戳 + 缓存时长
- **默认缓存时长**：600秒（10分钟）
- **线程安全**：使用 `threading.Lock()` 保护

**缓存逻辑**：
```python
def _get_cached_prediction(self, symbol: str, force_refresh: bool = False, 
                            cache_duration: int = None) -> Optional[Dict]:
    # 1. 检查缓存是否存在且未过期
    if not force_refresh and symbol in self._prediction_cache:
        cached_data = self._prediction_cache[symbol]
        age_seconds = (datetime.now() - cached_data['timestamp']).total_seconds()
        
        if age_seconds < cache_duration:
            # 缓存有效，返回缓存结果
            return cached_data['prediction']
        else:
            # 缓存过期，删除
            del self._prediction_cache[symbol]
    
    # 2. 执行新的预测
    prediction = self.predictor.predict(symbol)
    
    # 3. 更新缓存
    self._prediction_cache[symbol] = {
        'prediction': prediction,
        'timestamp': datetime.now(),
        'cache_duration': cache_duration
    }
    
    return prediction
```

**优点**：
- ✅ 避免重复计算，提升响应速度
- ✅ 线程安全，支持并发访问
- ✅ 可配置缓存时长

**潜在问题**：
- ⚠️ 缓存时长固定（10分钟），可能不适合所有场景
- ⚠️ 缓存没有大小限制，可能导致内存占用过高
- ⚠️ 没有缓存命中率统计，无法评估缓存效果

```python
# 1. 添加模型性能监控
class MLModelPerformanceMonitor:
    def __init__(self):
        self.model_performance = {}  # {model_id: {'accuracy': 0.65, 'last_update': ...}}
    
    def update_performance(self, model_id: int, accuracy: float):
        """更新模型性能"""
        self.model_performance[model_id] = {
            'accuracy': accuracy,
            'last_update': datetime.now()
        }
    
    def get_optimal_weight(self, model_id: int) -> float:
        """根据性能计算最优权重"""
        if model_id not in self.model_performance:
            return 0.15  # 默认权重
        
        accuracy = self.model_performance[model_id]['accuracy']
        
        # 性能好（准确率>60%）：权重15-20%
        if accuracy > 0.60:
            return 0.15 + (accuracy - 0.60) * 0.25
        # 性能一般（准确率50-60%）：权重10-15%
        elif accuracy > 0.50:
            return 0.10 + (accuracy - 0.50) * 0.50
        # 性能差（准确率<50%）：权重0-10%
        else:
            return max(0.0, accuracy * 0.20)
```
