# 股票名称获取修复说明

## 问题描述

在批量收集A股历史数据时，数据库中的股票数据没有股票名称（`name` 字段为空或NULL）。

## 问题原因

1. **批量模式下**：`get_stock_info()` 方法返回的字典中，股票名称可能不在 `'name'` 键下，而是在其他键下（如 `'股票简称'`、`'股票名称'` 等）
2. **逐日模式下**：如果 `get_stock_info()` 失败，没有备用方案获取股票名称
3. **数据源问题**：`ak.stock_individual_info_em()` 返回的数据结构可能不包含标准化的 `name` 字段

## 修复方案

### 1. 修复 `get_stock_info()` 方法 ✅

**文件**：`smart_stock_advisor/data_source/stock_data_source.py`

**修改内容**：
- 添加股票名称提取逻辑，尝试多个可能的键名
- 如果基本信息中没有名称，从实时行情获取
- 确保返回的字典中包含 `name` 字段

**代码逻辑**：
```python
# 提取股票名称（尝试多个可能的键名）
stock_name = None
for key in ['股票简称', '股票名称', '名称', 'name', '股票全称']:
    if key in info_dict:
        stock_name = str(info_dict[key]).strip()
        if stock_name and stock_name != 'nan' and stock_name != '':
            info_dict['name'] = stock_name
            break

# 如果还是没有找到名称，尝试从实时行情获取
if not stock_name or stock_name == '':
    # 从实时行情获取名称
    ...
```

### 2. 修复批量模式下的名称获取 ✅

**文件**：`smart_stock_advisor/utils/stock_history_collector.py`

**修改内容**：
- 增强股票名称获取逻辑，尝试多个来源
- 如果 `get_stock_info()` 没有返回名称，从股票列表中获取
- 如果还是没有，使用股票代码作为名称（并记录警告）

**代码逻辑**：
```python
# 提取股票名称（尝试多个来源）
stock_name = ''
if stock_info:
    stock_name = stock_info.get('name', '') or stock_info.get('股票简称', '') or stock_info.get('股票名称', '')

# 如果还是没有获取到名称，从股票列表中获取
if not stock_name or stock_name == '':
    stock_list = self.data_source.get_all_stock_list(...)
    for stock in stock_list:
        if stock.get('symbol') == symbol:
            stock_name = stock.get('name', '')
            break

# 如果还是没有，使用股票代码作为名称
if not stock_name or stock_name == '':
    stock_name = symbol
    self.logger.warning(f"{symbol} 无法获取股票名称，使用代码作为名称")
```

### 3. 修复逐日模式下的名称获取 ✅

**文件**：`smart_stock_advisor/utils/stock_history_collector.py`

**修改内容**：
- 在数据采集开始时先获取股票名称
- 如果 `get_stock_info()` 失败，从股票列表中获取
- 如果实时行情中有名称，优先使用实时行情的名称

**代码逻辑**：
```python
# 先尝试获取股票名称
stock_name = ''
try:
    stock_info = self.data_source.get_stock_info(symbol)
    if stock_info:
        stock_name = stock_info.get('name', '') or ...
except Exception as e:
    ...

# 如果还是没有获取到名称，从股票列表中获取
if not stock_name or stock_name == '':
    stock_list = self.data_source.get_all_stock_list(...)
    ...

data = {
    'symbol': symbol,
    'name': stock_name if stock_name else symbol,  # 如果获取不到名称，使用代码
    ...
}
```

## 名称获取优先级

### 优先级1：从 `get_stock_info()` 获取
- 尝试键名：`'name'` → `'股票简称'` → `'股票名称'` → `'股票全称'`

### 优先级2：从实时行情获取
- 如果 `get_stock_info()` 没有返回名称，从 `ak.stock_zh_a_spot_em()` 获取

### 优先级3：从股票列表获取
- 如果前两种方法都失败，从 `get_all_stock_list()` 获取

### 优先级4：使用股票代码
- 如果所有方法都失败，使用股票代码作为名称（并记录警告日志）

## 验证方法

### 检查数据库中的股票名称

```sql
-- 检查股票名称完整性
SELECT 
    symbol,
    name,
    COUNT(*) as record_count
FROM stock_history_data
WHERE symbol = '000001'
GROUP BY symbol, name;

-- 检查名称缺失的记录
SELECT 
    symbol,
    COUNT(*) as total_records,
    SUM(CASE WHEN name IS NULL OR name = '' OR name = symbol THEN 1 ELSE 0 END) as missing_name_count
FROM stock_history_data
GROUP BY symbol
HAVING missing_name_count > 0
LIMIT 10;
```

## 更新已有数据

如果数据库中已有数据缺少股票名称，可以运行以下SQL更新：

```sql
-- 方法1：从 stock_predictions 表更新（如果有预测记录）
UPDATE stock_history_data shd
INNER JOIN stock_predictions sp ON shd.symbol = sp.symbol
SET shd.name = sp.name
WHERE (shd.name IS NULL OR shd.name = '' OR shd.name = shd.symbol)
AND sp.name IS NOT NULL AND sp.name != '';

-- 方法2：手动更新（需要先获取股票列表）
-- 先获取股票列表，然后批量更新
```

或者使用Python脚本批量更新：

```python
from data_source.stock_data_source import StockDataSource
from utils.stock_history_storage import StockHistoryStorage

ds = StockDataSource()
storage = StockHistoryStorage()

# 获取所有股票列表
stock_list = ds.get_all_stock_list()

# 更新数据库中的名称
for stock in stock_list:
    symbol = stock['symbol']
    name = stock['name']
    
    # 更新所有该股票的历史记录
    sql = "UPDATE stock_history_data SET name = %s WHERE symbol = %s AND (name IS NULL OR name = '' OR name = symbol)"
    storage.db.execute_update(sql, (name, symbol))
```

2. `smart_stock_advisor/utils/stock_history_collector.py` - 修复批量模式和逐日模式下的名称获取逻辑

## 注意事项

1. **性能考虑**：
   - 批量模式下，每个股票只获取一次名称，不会影响性能
   - 如果从股票列表获取，可能需要一些时间（但只执行一次）

2. **数据一致性**：
   - 如果股票名称发生变化，历史数据中的名称不会自动更新
   - 如果需要更新历史数据的名称，需要手动运行更新脚本

3. **备用方案**：
   - 如果所有方法都失败，使用股票代码作为名称
   - 会记录警告日志，便于排查问题
