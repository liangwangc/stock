# 股票数据接口性能测试和优化建议

## 一、当前使用的接口

### 1. 历史数据获取：`ak.stock_zh_a_hist`

**当前实现**：
```python
df = ak.stock_zh_a_hist(
    symbol=symbol,
    period="daily",
    start_date=start_date_str_api,  # YYYYMMDD格式
    end_date=end_date_str_api,      # YYYYMMDD格式
    adjust="qfq"  # 前复权
)
```

**特点**：
- ✅ 支持获取指定日期范围的历史数据
- ✅ 支持前复权、后复权、不复权
- ✅ 数据完整，包含OHLCV和成交额
- ⚠️ 单只股票单次调用，批量获取需要循环
- ⚠️ 速度较慢（约1-2秒/股票）

## 二、可用的替代接口

### 1. `ak.stock_zh_a_spot_em()` - 实时行情批量接口

**特点**：
- ✅ **批量获取所有A股实时行情**（一次调用获取5000+只股票）
- ✅ **速度极快**（约1-2秒获取所有股票）
- ✅ 包含实时价格、涨跌幅、成交量、成交额等
- ❌ **不包含历史数据**（只有当前时刻的数据）
- ❌ 不适合获取历史K线数据

**使用场景**：
- 获取所有股票的实时行情
- 更新数据库中的最新数据
- 实时监控和筛选

**示例代码**：
```python
import akshare as ak

# 一次获取所有A股实时行情
df = ak.stock_zh_a_spot_em()
print(f"获取到 {len(df)} 只股票的实时行情")
print(df.head())
```

### 2. `ak.stock_zh_a_hist_min_em()` - 分钟级数据接口

**特点**：
- ✅ 可以获取分钟级K线数据
- ⚠️ 主要用于实时数据，不适合批量获取历史数据
- ⚠️ 数据量大，速度较慢

**使用场景**：
- 获取当日分钟级数据
- 实时分析

### 3. 其他可能的接口

- `ak.stock_zh_a_hist_pre_min_em()` - 盘前数据
- `ak.stock_zh_a_hist_sina()` - 新浪接口（可能已废弃）
- `ak.stock_zh_a_hist_163()` - 网易接口（可能已废弃）

## 三、性能优化方案

### 方案1：使用 `stock_zh_a_spot_em` 批量获取实时数据

**优势**：
- 一次调用获取所有股票数据
- 速度极快（1-2秒获取5000+只股票）
- 适合更新最新数据

**实现思路**：
```python
def update_realtime_data_batch():
    """批量更新所有股票的实时数据"""
    # 一次获取所有A股实时行情
    df = ak.stock_zh_a_spot_em()
    
    # 批量更新数据库
    for _, row in df.iterrows():
        symbol = row['代码']
        # 更新数据库中的最新数据
        update_stock_daily_data(symbol, today, row)
```

**适用场景**：
- 每日收盘后更新最新数据
- 实时数据同步

### 方案2：优化历史数据获取流程

**当前问题**：
- 每只股票需要单独调用API
- 5000只股票 × 1秒 = 约5000秒（1.4小时）

**优化策略**：

1. **数据库优先策略**（已实现）
   - 优先从数据库获取历史数据
   - 只获取缺失的数据

2. **批量处理优化**
   - 使用多线程并发获取（注意API限流）
   - 批量保存到数据库（减少数据库写入次数）

3. **缓存机制**
   - 缓存股票列表（已实现，1小时缓存）
   - 缓存实时行情数据（已实现，5分钟缓存）

4. **增量更新**
   - 只获取缺失日期的数据
   - 避免重复获取已有数据

### 方案3：混合使用策略

**策略**：
- **历史数据收集**：使用 `stock_zh_a_hist`（适合批量收集）
- **实时数据更新**：使用 `stock_zh_a_spot_em`（批量获取，速度快）
- **数据库缓存**：优先从数据库读取（最快）

**实现示例**：
```python
def get_stock_data_optimized(symbol, start_date, end_date):
    """优化的股票数据获取"""
    # 1. 优先从数据库获取
    db_data = get_from_database(symbol, start_date, end_date)
    if db_data is not None and len(db_data) > 0:
        return db_data
    
    # 2. 如果数据库没有，从API获取
    api_data = ak.stock_zh_a_hist(
        symbol=symbol,
        period="daily",
        start_date=start_date,
        end_date=end_date,
        adjust="qfq"
    )
    
    # 3. 保存到数据库
    save_to_database(symbol, api_data)
    
    return api_data

def update_realtime_data():
    """批量更新实时数据"""
    # 使用批量接口获取所有股票实时数据
    df = ak.stock_zh_a_spot_em()
    
    # 批量更新数据库
```

## 五、推荐方案

### 对于历史数据收集（批量收集10年数据）

**推荐**：继续使用 `stock_zh_a_hist`，但优化处理流程

**优化点**：
1. ✅ **数据库优先**：优先从数据库获取（已实现）
2. ✅ **增量更新**：只获取缺失的数据（已实现）
3. ✅ **批量保存**：使用批量INSERT优化（已实现）
4. ✅ **多线程**：使用多线程并发获取（已实现）
5. ⚠️ **API限流**：注意控制请求频率，避免被封

**性能提升**：
- 数据库优先：减少90%+的API调用
- 增量更新：只获取缺失数据，大幅减少API调用
- 批量保存：减少数据库写入次数，提升写入速度

### 对于实时数据更新（每日更新）

**推荐**：使用 `stock_zh_a_spot_em` 批量获取

**优势**：
- 一次调用获取所有股票
- 速度极快（1-2秒）
- 适合每日收盘后更新

**实现建议**：
```python
def update_today_data_batch():
    """批量更新今日数据"""
    today = datetime.now().strftime('%Y-%m-%d')
    
    # 批量获取所有股票实时行情
    df = ak.stock_zh_a_spot_em()
    
    # 转换为标准格式并批量保存
    batch_data = []
    for _, row in df.iterrows():
        symbol = row['代码']
        data = {
            'symbol': symbol,
            'name': row.get('名称', ''),
            'trade_date': today,
            'close_price': row.get('最新价', 0),
            'open_price': row.get('今开', 0),
            'high_price': row.get('最高', 0),
            'low_price': row.get('最低', 0),
            'volume': row.get('成交量', 0),
            'amount': row.get('成交额', 0),
            # ... 其他字段
        }
        batch_data.append((symbol, today, data))
    
    # 批量保存到数据库
    storage.save_stock_daily_data_batch(batch_data)
```
