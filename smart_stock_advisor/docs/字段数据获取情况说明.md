# 字段数据获取情况说明

## 问题分析

在批量收集A股历史数据时，以下字段显示为 `(Null)`：
- `cost_distribution`、`cost_distribution_history`、`cost_distribution_intraday`（成本分布）
- `total_market_cap`、`float_market_cap`（市值）
- `pe_ratio`、`pb_ratio`（估值指标）
- `limit_up`、`limit_down`、`limit_pct`（涨跌停）

## 字段获取情况分析

### 1. 成本分布字段

#### cost_distribution_history（历史成本分布）
- **数据来源**：`get_cost_distribution()` 方法
- **获取方式**：基于历史K线数据计算（收盘价和成交量）
- **历史数据**：✅ **可以计算**
- **批量模式**：⚠️ **之前未获取，已修复**

**计算方法**：
```python
# 基于最近60天的收盘价和成交量计算成本分布
cost_dist = self.data_source.get_cost_distribution(symbol, days=60)
```

#### cost_distribution_intraday（当日成本分布）
- **数据来源**：`get_intraday_cost_distribution()` 方法
- **获取方式**：基于当日分时数据计算
- **历史数据**：❌ **不可用**（需要当日分时数据，历史数据无法获取）
- **批量模式**：❌ **历史数据不可用**

**说明**：当日分时数据只能获取实时数据，历史分时数据通常不可用。

#### cost_distribution（合并成本分布）
- **数据来源**：合并 `cost_distribution_history` 和 `cost_distribution_intraday`
- **历史数据**：✅ **部分可用**（只有历史成本分布）

---

### 2. 市值字段

#### total_market_cap（总市值）
- **数据来源**：`get_realtime_quote()` 方法，字段 `total_value`
- **获取方式**：从实时行情API获取
- **历史数据**：❌ **通常不可用**（实时行情API只提供当前数据）
- **批量模式**：❌ **历史数据不可用**

**说明**：市值数据是实时数据，历史市值数据通常不可用。如果需要历史市值，可能需要：
1. 使用财务数据API（如TuShare）
2. 从历史财务报告中获取
3. 基于历史价格和股本计算（如果知道历史股本）

#### float_market_cap（流通市值）
- **数据来源**：`get_realtime_quote()` 方法，字段 `float_value`
- **获取方式**：从实时行情API获取
- **历史数据**：❌ **通常不可用**（实时行情API只提供当前数据）
- **批量模式**：❌ **历史数据不可用**

**说明**：同总市值，历史数据不可用。

---

### 3. 估值指标字段

#### pe_ratio（市盈率）
- **数据来源1**：`get_realtime_quote()` 方法（实时行情）
- **数据来源2**：`get_stock_info()` 方法（股票基本信息）
- **获取方式**：从API获取
- **历史数据**：⚠️ **部分可用**（股票基本信息可能包含，但历史PE通常不可用）
- **批量模式**：✅ **已修复**（从 `get_stock_info` 获取）

**说明**：
- 实时行情API通常只提供当前PE
- 股票基本信息API可能提供PE，但历史PE数据通常不可用
- 如果需要历史PE，可能需要从财务数据API获取

#### pb_ratio（市净率）
- **数据来源1**：`get_realtime_quote()` 方法（实时行情）
- **数据来源2**：`get_stock_info()` 方法（股票基本信息）
- **获取方式**：从API获取
- **历史数据**：⚠️ **部分可用**（股票基本信息可能包含，但历史PB通常不可用）
- **批量模式**：✅ **已修复**（从 `get_stock_info` 获取）

**说明**：同PE，历史PB数据通常不可用。

---

### 4. 涨跌停字段

#### limit_up（涨停价）
- **数据来源**：`get_realtime_quote()` 方法计算
- **计算公式**：`昨收价 * (1 + limit_pct)`
- **历史数据**：✅ **可以计算**（基于昨收价）
- **批量模式**：✅ **已修复**（批量计算）

**计算逻辑**：
```python
if symbol.startswith('688') or symbol.startswith('300'):
    limit_pct = 0.20  # 科创板/创业板20%
elif 'ST' in stock_name:
    limit_pct = 0.05  # ST股票5%
else:
    limit_pct = 0.10  # 普通股票10%

limit_up = pre_close * (1 + limit_pct)
```

#### limit_down（跌停价）
- **数据来源**：`get_realtime_quote()` 方法计算
- **计算公式**：`昨收价 * (1 - limit_pct)`
- **历史数据**：✅ **可以计算**（基于昨收价）
- **批量模式**：✅ **已修复**（批量计算）

#### limit_pct（涨跌停幅度）
- **数据来源**：根据股票类型确定
- **历史数据**：✅ **可以计算**（基于股票类型）
- **批量模式**：✅ **已修复**（批量计算）

---

## 解决方案

### 已修复的字段 ✅

1. **cost_distribution_history** - 批量模式下已添加计算
2. **pe_ratio, pb_ratio** - 批量模式下已从 `get_stock_info` 获取
3. **limit_up, limit_down, limit_pct** - 批量模式下已添加计算

### 无法获取的字段 ❌

1. **cost_distribution_intraday** - 历史数据不可用（需要当日分时数据）
2. **total_market_cap, float_market_cap** - 历史数据通常不可用（需要实时行情API）

### 部分可用的字段 ⚠️

1. **pe_ratio, pb_ratio** - 可以从 `get_stock_info` 获取，但历史PE/PB通常不可用
   - **当前值**：可以获取
   - **历史值**：通常不可用

---

## 字段获取优先级

### 高优先级（已修复）✅

1. **limit_up, limit_down, limit_pct** - 可以计算，已修复
2. **cost_distribution_history** - 可以计算，已修复
3. **pe_ratio, pb_ratio** - 可以从股票信息获取，已修复

### 中优先级（需要特殊处理）⚠️

1. **total_market_cap, float_market_cap** - 历史数据不可用
   - **解决方案**：如果需要历史市值，可能需要：
     - 使用财务数据API（如TuShare）获取历史股本
     - 基于历史价格和股本计算：`市值 = 价格 * 股本`

### 低优先级（历史数据不可用）❌

1. **cost_distribution_intraday** - 历史数据不可用
   - **说明**：当日成本分布需要当日分时数据，历史数据无法获取

## 验证方法

### 检查字段获取情况

```sql
-- 检查字段完整性
SELECT 
    symbol,
    COUNT(*) as total_records,
    SUM(CASE WHEN cost_distribution_history IS NOT NULL THEN 1 ELSE 0 END) as has_cost_dist,
    SUM(CASE WHEN pe_ratio IS NOT NULL THEN 1 ELSE 0 END) as has_pe,
    SUM(CASE WHEN limit_up IS NOT NULL THEN 1 ELSE 0 END) as has_limit_up,
    SUM(CASE WHEN total_market_cap IS NOT NULL THEN 1 ELSE 0 END) as has_market_cap
FROM stock_history_data
WHERE symbol = '000001'
GROUP BY symbol;
```
