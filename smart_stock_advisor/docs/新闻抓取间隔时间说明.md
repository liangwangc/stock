## 🔍 详细说明

### 1. smart_stock_advisor 的间隔时间设置

#### 前端界面

**位置**：设置页面 → 新闻抓取任务 → 创建新任务

**间隔时间设置**：
- ✅ **有间隔时间设置**，但根据"执行方式"显示不同的输入框
- ⚠️ **默认隐藏**：如果选择"每日"，间隔时间输入框是隐藏的

**三种执行方式**：

1. **每日执行**（daily）
   - 显示：每天执行时间（HH:MM）
   - 隐藏：间隔时间输入框
   - 内部：`interval_minutes` 自动设为 1440（24小时）

2. **每小时执行**（hourly）
   - 显示：间隔小时数（小数）
   - 输入框：`hourlyInterval`（默认值：1.0）
   - 内部：转换为分钟数（`interval_minutes = hourlyInterval * 60`）

3. **每N分钟执行**（interval）
   - 显示：间隔分钟数（小数）
   - 输入框：`minuteInterval`（默认值：10.0）
   - 内部：直接使用（`interval_minutes = minuteInterval`）

#### 代码实现

**前端**（`settings.html`）：
```javascript
// 根据执行方式显示不同的输入框
function updateScheduleType() {
    const scheduleType = document.getElementById('scheduleType').value;
    
    if (scheduleType === 'daily') {
        dailyTimeGroup.style.display = 'block';      // 显示时间选择
        minuteIntervalGroup.style.display = 'none';  // 隐藏分钟间隔
    } else if (scheduleType === 'hourly') {
        hourlyIntervalGroup.style.display = 'block'; // 显示小时间隔
        minuteIntervalGroup.style.display = 'none';
    } else if (scheduleType === 'interval') {
        minuteIntervalGroup.style.display = 'block'; // 显示分钟间隔
    }
}
```

**后端**（`web_app.py`）：
```python
interval_minutes = data.get('interval_minutes', 10)  # 默认10分钟
```

### 2. news-analysis-system-main 的间隔时间

#### fetch_and_store_news() 函数

**文件**：`src/data_processing/get_cls_news.py`

**特点**：
- ❌ **没有固定的间隔时间**
- ✅ **只执行一次**：函数本身不包含定时逻辑
- ✅ **由调用者控制**：间隔时间由调用者（scheduler.py 或 smart_stock_advisor）控制

#### scheduler.py 的固定间隔

**文件**：`news-analysis-system-main/scheduler.py`

**当前配置**：
```python
def setup_schedules():
    # 新闻获取：每10分钟执行一次（固定）
    schedule.every(10).minutes.do(news_fetch_job)
    
    # LLM分析：每2小时执行一次（固定）
    schedule.every(2).hours.do(llm_analysis_job_wrapper)
```

**特点**：
- ⚠️ **硬编码**：间隔时间是固定的，不能通过参数配置
- ⚠️ **需要修改代码**：如果要改变间隔时间，需要修改 `scheduler.py` 文件

## ⚠️ 问题说明

### 问题1：创建任务时看不到间隔时间

**原因**：
- 默认选择是"每日"执行方式
- "每日"方式不显示间隔时间输入框（因为固定为24小时）
- 用户需要选择"每N分钟"或"每小时"才能看到间隔时间设置

**解决方法**：
1. 选择"每N分钟"执行方式，会显示"间隔分钟数"输入框
2. 选择"每小时"执行方式，会显示"间隔小时数"输入框

### 问题2：news-analysis-system-main 的固定间隔时间

**当前情况**：
- `scheduler.py` 中硬编码为每10分钟执行一次
- 如果通过 smart_stock_advisor 的定时任务调用，间隔时间由 smart_stock_advisor 控制
- 如果直接运行 `scheduler.py`，间隔时间是固定的10分钟

**影响**：
- ✅ **通过 smart_stock_advisor 调用**：间隔时间可配置（通过Web界面）
- ⚠️ **直接运行 scheduler.py**：间隔时间固定为10分钟

## 💡 改进建议

### 方案1：改进前端界面（推荐）

**问题**：用户可能不知道需要选择"每N分钟"才能看到间隔时间设置

**改进**：
1. 默认选择"每N分钟"执行方式
2. 在"每日"和"每小时"方式下也显示间隔时间说明
3. 添加提示文字，说明间隔时间的含义

### 方案2：让 scheduler.py 支持配置

**问题**：scheduler.py 的间隔时间是硬编码的

**改进**：
```python
# 从环境变量或配置文件读取间隔时间
NEWS_FETCH_INTERVAL = int(os.getenv('NEWS_FETCH_INTERVAL', 10))  # 默认10分钟
LLM_ANALYSIS_INTERVAL = int(os.getenv('LLM_ANALYSIS_INTERVAL', 120))  # 默认2小时

schedule.every(NEWS_FETCH_INTERVAL).minutes.do(news_fetch_job)
schedule.every(LLM_ANALYSIS_INTERVAL).minutes.do(llm_analysis_job_wrapper)
```

**优点**：
- 可以通过环境变量配置
- 不需要修改代码

### 方案3：统一使用 smart_stock_advisor 的定时任务

**建议**：
- ✅ 推荐通过 smart_stock_advisor 的Web界面创建定时任务
- ✅ 间隔时间可以在Web界面配置
- ⚠️ 不需要单独运行 `scheduler.py`

## 📝 使用建议

### 推荐配置

**通过 smart_stock_advisor 创建定时任务**：

1. **执行方式**：选择"每N分钟"
2. **间隔分钟数**：推荐 10-30 分钟
   - 高频：10分钟
   - 标准：30分钟（推荐）⭐
   - 低频：60分钟

3. **任务类型**：选择"全部"（all）

### 不推荐

- ❌ 直接运行 `scheduler.py`（间隔时间固定，不够灵活）
- ❌ 选择"每日"执行方式（间隔时间太长，可能错过新闻）

### 建议

1. ✅ **使用 smart_stock_advisor 的Web界面创建定时任务**
2. ✅ **选择"每N分钟"执行方式，设置合适的间隔时间（推荐30分钟）**
