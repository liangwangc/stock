# 定时任务修改说明

**修改时间**：2026-01-23  
**修改内容**：smart_stock_advisor 的新闻抓取定时任务改为直接调用 news-analysis-system-main

---

## 📋 修改内容

### 修改文件

**文件**：`utils/scheduled_task_manager.py`  
**方法**：`_execute_news_crawl()`

### 修改前

```python
# 使用 smart_stock_advisor 自己的方法
from news.unified_news_source import UnifiedNewsSource
from utils.news_crawler import NewsCrawler

news_source = UnifiedNewsSource()
news_crawler = NewsCrawler()
result = news_crawler.crawl_all_news(...)
```

### 修改后

```python
# 直接调用 news-analysis-system-main 的方法
import sys
import os

# 获取 news-analysis-system-main 项目路径
current_dir = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
news_system_path = os.path.join(os.path.dirname(current_dir), 'news-analysis-system-main')

# 添加到 Python 路径
sys.path.insert(0, news_system_path)

# 导入并调用
from src.data_processing.get_cls_news import fetch_and_store_news
fetch_and_store_news()
```

---

## ✅ 修改效果

### 架构变化

**修改前**：
```
smart_stock_advisor 定时任务
  └─ UnifiedNewsSource() → 多源新闻获取
```

**修改后**：
```
smart_stock_advisor 定时任务（管理）
  └─ 调用 news-analysis-system-main.fetch_and_store_news()
      └─ 财联社新闻获取 + 股票匹配 + 情感分析 + 数据库存储
```

### 功能说明

1. ✅ **统一新闻处理**：所有新闻获取和处理都由 news-analysis-system-main 完成
2. ✅ **任务管理**：smart_stock_advisor 只负责任务调度和管理
3. ✅ **避免重复**：不再使用 smart_stock_advisor 自己的新闻获取方法

---

## 📊 使用方式

### 在 Web 界面创建新闻抓取任务

1. 登录 smart_stock_advisor Web 界面
2. 进入"设置"页面
3. 创建"新闻抓取任务"
4. 任务执行时会自动调用 news-analysis-system-main 的方法

### 任务配置

- **任务类型**：`all`（全部）或其他类型（都会调用 news-analysis-system-main）
- **调度方式**：间隔执行/每小时/每日
- **间隔时间**：推荐 10-30 分钟

## ⚠️ 注意事项

### 前置条件

1. ✅ **项目路径**：确保 `news-analysis-system-main` 项目与 `smart_stock_advisor` 在同一父目录下
   ```
   d:\wjw_work\
     ├─ smart_stock_advisor\
     └─ news-analysis-system-main\
   ```

2. ✅ **依赖安装**：确保 news-analysis-system-main 的依赖已安装
   ```bash
   cd news-analysis-system-main
   pip install -r requirements.txt
   ```

3. ✅ **数据库配置**：确保 news-analysis-system-main 的数据库配置正确
   - 配置文件：`news-analysis-system-main/src/config/config.py`
   - 数据库：`stock_data`
   - 表：`news_articles`

### 错误处理

如果任务执行失败，可能的原因：

1. **路径不存在**
   - 错误信息：`news-analysis-system-main 项目路径不存在`
   - 解决方法：检查项目路径是否正确

2. **导入失败**
   - 错误信息：`导入 news-analysis-system-main 模块失败`
   - 解决方法：检查依赖是否安装，路径是否正确

3. **执行失败**
   - 错误信息：`调用 news-analysis-system-main 方法失败`
   - 解决方法：查看日志，检查 news-analysis-system-main 的配置
