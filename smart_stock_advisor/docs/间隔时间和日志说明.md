## 📋 问题解答

### 问题1：smart_stock_advisor 设置的间隔时间会在 news-analysis-system-main 中使用吗？

**答案**：✅ **是的，会生效**

**原理**：
- smart_stock_advisor 的 `ScheduledTaskManager` 按照设置的 `interval_minutes` 来控制何时调用 `fetch_and_store_news()`
- `fetch_and_store_news()` 函数本身不关心间隔时间，它只是执行一次新闻获取
- **间隔时间完全由 smart_stock_advisor 控制**

**执行流程**：
```
smart_stock_advisor ScheduledTaskManager
  ├─ 按照 interval_minutes 设置的时间间隔
  └─ 调用 news-analysis-system-main.fetch_and_store_news()
      └─ 执行一次新闻获取（不关心间隔时间）
```

**代码位置**：
- `utils/scheduled_task_manager.py` → `_execute_news_crawl()` → `fetch_and_store_news()`
- 间隔时间从 `task_config.get('interval_minutes', 60)` 获取
- 通过 `schedule.every(interval_minutes).minutes.do(task_wrapper)` 控制执行频率

### 问题2：news-analysis-system-main 的日志信息能在 smart_stock_advisor 控制台看到吗？

**答案**：✅ **是的，现在可以看到了（已改进）**

## 🔍 详细分析

### 间隔时间控制流程

**1. 创建任务时设置间隔时间**：
```python
# Web界面创建任务
interval_minutes = 30  # 用户设置的间隔时间（分钟）

# 保存到数据库
task_config = {
    'task_type': 'all',
    'interval_minutes': 30
}
```

**2. 启动任务时使用间隔时间**：
```python
# scheduled_task_manager.py
def _schedule_task(self, task):
    task_config = json.loads(task.get('task_config', '{}'))
    interval_minutes = task_config.get('interval_minutes', 60)
    
    # 按照间隔时间调度
    if interval_minutes >= 60:
        hours = interval_minutes // 60
        job = schedule.every(hours).hours.do(task_wrapper)
    else:
        job = schedule.every(interval_minutes).minutes.do(task_wrapper)
```

**3. 执行任务时调用 news-analysis-system-main**：
```python
def _execute_news_crawl(self, task):
    interval_minutes = task_config.get('interval_minutes', 60)
    # 调用 news-analysis-system-main 的方法
    fetch_and_store_news()  # 不关心间隔时间，只执行一次
```

**结论**：✅ **间隔时间完全由 smart_stock_advisor 控制，news-analysis-system-main 只是被动执行**

## 💡 改进建议

### 方案1：重定向 print() 输出到 logger（推荐）

**修改 `_execute_news_crawl()` 方法**：
```python
import sys
import io
from contextlib import redirect_stdout

def _execute_news_crawl(self, task):
    # ...
    # 创建字符串缓冲区捕获 print() 输出
    stdout_buffer = io.StringIO()
    
    try:
        # 重定向 print() 输出到缓冲区
        with redirect_stdout(stdout_buffer):
            fetch_and_store_news()
        
        # 将捕获的输出写入日志
        output = stdout_buffer.getvalue()
        if output:
            for line in output.strip().split('\n'):
                if line.strip():
                    self.logger.info(f"[news-analysis-system-main] {line}")
    finally:
        stdout_buffer.close()
```

**优点**：
- ✅ 所有日志统一到 smart_stock_advisor 的日志系统
- ✅ 可以写入日志文件
- ✅ 日志格式统一

### 立即改进（方案1）

**修改文件**：`utils/scheduled_task_manager.py`

**修改位置**：`_execute_news_crawl()` 方法

**代码**：
```python
import sys
import io
from contextlib import redirect_stdout

def _execute_news_crawl(self, task):
    # ...
    # 创建字符串缓冲区捕获 print() 输出
    stdout_buffer = io.StringIO()
    stderr_buffer = io.StringIO()
    
    try:
        # 重定向 print() 输出到缓冲区
        with redirect_stdout(stdout_buffer), redirect_stderr(stderr_buffer):
            fetch_and_store_news()
        
        # 将捕获的输出写入日志
        stdout_output = stdout_buffer.getvalue()
        stderr_output = stderr_buffer.getvalue()
        
        if stdout_output:
            for line in stdout_output.strip().split('\n'):
                if line.strip():
                    self.logger.info(f"[news-analysis-system-main] {line}")
        
        if stderr_output:
            for line in stderr_output.strip().split('\n'):
                if line.strip():
                    self.logger.error(f"[news-analysis-system-main] {line}")
    finally:
        stdout_buffer.close()
        stderr_buffer.close()
```
