# 预测明日股价显示说明

## 📍 显示位置

预测的明日股价显示在**股票预测列表**中，每个股票项的**"价格"列**：

```
┌─────────────────────┐
│  股票代码           │
│  股票名称           │
│  10.50元            │  ← 当前价格（加粗显示）
│  预测: 10.75元      │  ← 预测明日收盘价（如果存在）
│  +2.38%             │  ← 预测涨跌幅（红色/绿色，加粗显示）
└─────────────────────┘
```

## 🎨 显示样式

1. **当前价格**：加粗显示，字体大小15px
2. **预测收盘价**：灰色文字，字体大小12px，加粗
3. **预测涨跌幅**：
   - 上涨：红色（#e74c3c），加粗
   - 下跌：绿色（#27ae60），加粗
   - 字体大小13px

## ✅ 显示条件

预测价格和涨幅会在以下条件下显示：

1. **预测收盘价**：`predicted_close_price` 存在且大于0
2. **预测涨跌幅**：`predicted_change_pct` 不为 null、undefined 且不为 0

如果只有预测收盘价但没有涨跌幅，会显示"（涨幅计算中）"提示。

## 🔧 数据库字段

预测价格数据存储在 `stock_predictions` 表中：

- `predicted_close_price`：明日大概收盘价格（DECIMAL(10,2)）
- `predicted_change_pct`：明日大概涨幅百分比（DECIMAL(6,2)）

## 📊 计算方式

### 预测涨跌幅计算

```python
probability_diff = up_probability - down_probability  # -1 到 1
max_change_pct = 10.0  # 最大涨跌幅 10%
predicted_change_pct = tanh(probability_diff * 3) * max_change_pct * confidence
```

### 预测收盘价计算

```python
predicted_close_price = current_price * (1 + predicted_change_pct / 100.0)
```

## 🚀 如何查看预测价格

### 方法1：查看现有预测

1. 打开股票预测列表页面
2. 切换到"📈 股票预测列表（收盘-明日）"或"⏰ 股票预测列表（未收盘-明天）"页签
3. 查看每个股票的价格列

### 方法2：重新预测

如果旧数据没有预测价格，需要重新预测：

1. 点击"🔮 预测"按钮
2. 输入股票代码（多个代码用顿号、或逗号,分隔）
3. 点击"开始预测"
4. 预测完成后，新的预测结果会包含预测价格和涨幅

## 🔍 检查数据库字段

如果看不到预测价格，可以运行检查脚本：

```bash
python scripts/check_and_add_predicted_price_fields.py
```

这个脚本会：
1. 检查 `predicted_close_price` 和 `predicted_change_pct` 字段是否存在
2. 如果不存在，自动添加这些字段
3. 添加必要的索引

## 📝 注意事项

1. **旧数据**：在添加预测价格字段之前的预测记录可能没有这些值，需要重新预测
2. **数据更新**：每次新的预测都会自动计算并保存预测价格和涨幅
3. **显示优化**：如果预测价格为0或null，不会显示预测价格行

## 🐛 故障排查

### 问题1：看不到预测价格

**可能原因**：
- 数据库字段不存在
- 旧数据没有预测价格值
- 预测价格计算失败

**解决方法**：
1. 运行检查脚本确保字段存在
2. 重新预测股票
3. 检查预测日志确认计算是否成功

### 问题2：预测价格显示为0

**可能原因**：
- 预测价格计算时出错
- 当前价格为0
- 置信度为0

**解决方法**：
- 检查预测日志
- 确认当前价格是否正确
- 检查置信度是否正常
