## 二、性能瓶颈分析

### 2.1 数据库查询优化空间

#### ⚠️ 问题1：股票名称查询重复（N+1查询）

**代码位置**：`predictor/stock_predictor.py:3002-3039`

**问题描述**：
- 每个股票预测时都要查询两次数据库获取股票名称
- 第一次查询 `stock_predictions` 表
- 如果失败，第二次查询 `stock_history_data` 表
- 5400只股票 = **10800次数据库查询**（仅股票名称）

**影响**：
- 每次查询耗时：10-50ms
- 总耗时：108-540秒（1.8-9分钟）
- 数据库连接压力大

**优化建议**：
1. ✅ **批量查询股票名称**：在任务开始前，一次性查询所有股票的名称
2. ✅ **使用缓存**：将股票名称缓存到内存中
3. ✅ **优化查询顺序**：优先从 `stock_history_data` 查询（数据更完整）

**优化效果**：
- 查询次数：从10800次降低到**2次**（批量查询）
- 耗时：从1.8-9分钟降低到**0.1-0.5秒**
- **性能提升：100-1000倍**

---

#### ⚠️ 问题2：每个线程创建独立实例

**代码位置**：`web_app.py:2228-2230`

**问题描述**：
- 每个线程都创建独立的 `StockPredictor()` 和 `PredictionVisualizer()` 实例
- 每个实例都会初始化数据源、新闻源等

**影响**：

**优化建议**：
1. ✅ **共享只读资源**：配置数据、股票列表等可以共享
2. ✅ **延迟初始化**：只在需要时初始化资源
3. ✅ **对象池**：复用预测器实例（需要确保线程安全）

**优化效果**：
- 内存占用：从1-2GB降低到**200-500MB**
- 初始化耗时：从2-4秒降低到**0.5-1秒**

## 三、优化方案

### 3.1 批量查询股票名称（高优先级）

**实现方式**：
```python
# 在任务开始前，批量查询所有股票的名称
def batch_get_stock_names(symbols: List[str]) -> Dict[str, str]:
    """批量获取股票名称"""
    from utils.db_connection import DatabaseConnection
    db = DatabaseConnection()
    
    # 批量查询stock_history_data表（数据更完整）
    placeholders = ','.join(['%s'] * len(symbols))
    sql = f"""
        SELECT DISTINCT symbol, name 
        FROM stock_history_data 
        WHERE symbol IN ({placeholders}) 
        AND name IS NOT NULL
    """
    results = db.execute_query(sql, tuple(symbols))
    
    # 构建字典
    name_map = {}
    for row in results:
        symbol = str(row.get('symbol', '')).zfill(6)
        name = row.get('name', '')
        if symbol not in name_map:
            name_map[symbol] = name
    
    # 对于没有名称的股票，查询stock_predictions表
    missing_symbols = [s for s in symbols if s not in name_map]
    if missing_symbols:
        placeholders = ','.join(['%s'] * len(missing_symbols))
        sql = f"""
            SELECT symbol, name 
            FROM stock_predictions 
            WHERE symbol IN ({placeholders})
            ORDER BY prediction_time DESC
        """
        results = db.execute_query(sql, tuple(missing_symbols))
        for row in results:
            symbol = str(row.get('symbol', '')).zfill(6)
            name = row.get('name', '')
            if symbol not in name_map:
                name_map[symbol] = name
    
    return name_map
```

**修改位置**：
- `web_app.py:2148-2160`：在获取股票列表后，批量查询股票名称
- `predictor/stock_predictor.py:3002-3039`：使用传入的股票名称，不再查询数据库

**优化效果**：
- 查询次数：从10800次降低到**2次**
- 耗时：从1.8-9分钟降低到**0.1-0.5秒**
- **性能提升：100-1000倍**

### 3.2 批量查询历史数据（中优先级）

**实现方式**：
```python
# 对于同一日期范围，批量查询多只股票的历史数据
def batch_get_stock_history(symbols: List[str], start_date: str, end_date: str) -> Dict[str, pd.DataFrame]:
    """批量获取股票历史数据"""
    from utils.stock_history_storage import StockHistoryStorage
    storage = StockHistoryStorage()
    
    # 批量查询（每批100只股票）
    batch_size = 100
    all_data = {}
    
    for i in range(0, len(symbols), batch_size):
        batch_symbols = symbols[i:i+batch_size]
        placeholders = ','.join(['%s'] * len(batch_symbols))
        sql = f"""
            SELECT symbol, trade_date, open_price, high_price, low_price, close_price, volume
            FROM stock_history_data
            WHERE symbol IN ({placeholders})
            AND trade_date >= %s
            AND trade_date <= %s
            AND period_type = 'daily'
            ORDER BY symbol, trade_date
        """
        params = [str(s).zfill(6) for s in batch_symbols] + [start_date, end_date]
        results = storage.db.execute_query(sql, tuple(params))
        
        # 按股票分组
        for row in results:
            symbol = str(row.get('symbol', '')).zfill(6)
            if symbol not in all_data:
                all_data[symbol] = []
            all_data[symbol].append(row)
    
    # 转换为DataFrame
    dataframes = {}
    for symbol, records in all_data.items():
        df = pd.DataFrame(records)
        # ... 转换为DataFrame格式
        dataframes[symbol] = df
    
    return dataframes
```

**优化效果**：
- 查询次数：从5400次降低到**54次**（每批100只）
- 查询耗时：从27-135秒降低到**2.7-13.5秒**
- **性能提升：10倍**

def get_cached_config():
    """获取缓存的配置"""
    global config_cache, config_cache_time
    
    if config_cache is None or (time.time() - config_cache_time) > config_cache_ttl:
        from utils.prediction_config_manager import PredictionConfigManager

        config_cache = manager.get_config()
