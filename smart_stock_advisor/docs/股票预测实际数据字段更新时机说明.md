## 三、更新流程

### 3.1 完整更新流程

```
1. 触发更新（保存新预测 或 查看历史页面）
   ↓
2. 查询需要更新的记录
   - target_date < 今天
   - actual_price 为空
   ↓
3. 对每条记录：
   a. 调用 get_actual_stock_change(symbol, target_date, current_price)
      ↓
   b. 从 stock_history_data 表查询目标日期的收盘价
      - 优先从数据库获取
      - 如果数据库没有，从API获取
      ↓
   c. 计算实际涨跌幅
      - actual_change_pct = (actual_price - current_price) / current_price * 100
      - current_price：预测时的价格（从 stock_predictions.current_price 获取）
      ↓
   d. 判断实际方向
      - 涨跌幅 > 0.01%：上涨
      - 涨跌幅 < -0.01%：下跌
      - 其他：平盘
      ↓
   e. 判断预测命中
      - 预测上涨 + 实际上涨 → 命中
      - 预测下跌 + 实际下跌 → 命中
      - 预测震荡 + 实际平盘（-0.5% ~ 0.5%） → 命中
      - 其他 → 未命中
      ↓
   f. 调用 update_prediction_actual() 更新数据库
      ↓
4. 更新完成，记录日志
```

---

### 3.2 数据来源

#### 3.2.1 实际价格（actual_price）

**来源**：`stock_history_data` 表的 `close_price` 字段

**查询逻辑**（`stock_data_source.py:2956-2976`）：
```python
# 优先从数据库获取
history_data = storage.get_stock_history_data(
    symbol=symbol,
    start_date=target_date,
    end_date=target_date,
    limit=1,
    period_type='daily'
)

actual_price = history_data[0].get('close_price')
```

**备用方案**：如果数据库没有数据，从API获取（`stock_data_source.py:3047-3103`）

---

#### 3.2.2 实际涨跌幅（actual_change_pct）

**计算方式**：
```python
actual_change_pct = (actual_price - current_price) / current_price * 100
```

**其中**：
- `actual_price`：目标日期的收盘价（从 `stock_history_data` 表获取）
- `current_price`：预测时的价格（从 `stock_predictions.current_price` 字段获取）

**如果 `current_price` 为空**：
- 尝试从 `stock_predictions` 表查询（`stock_data_source.py:2979-2993`）
- 如果仍然没有，使用数据库中的 `change_pct` 字段（如果有）

---

#### 3.2.3 实际方向（actual_direction）

**判断逻辑**（`stock_data_source.py:3025-3030`）：
```python
if actual_change_pct > 0.01:      # 大于0.01%算上涨
    actual_direction = '上涨'
elif actual_change_pct < -0.01:   # 小于-0.01%算下跌
    actual_direction = '下跌'
else:
    actual_direction = '平盘'
```

---

#### 3.2.4 预测命中（prediction_hit）

**判断逻辑**（`prediction_visualizer.py:2072-2080`）：
```python
hit = '未知'
if change_val is not None:
    if prediction == '上涨':
        hit = '命中' if change_val > 0 else '未命中'
    elif prediction == '下跌':
        hit = '命中' if change_val < 0 else '未命中'
    elif prediction == '震荡':
        # 震荡区间阈值：±0.5%
        hit = '命中' if -0.5 <= change_val <= 0.5 else '未命中'
```

## 五、数据更新依赖

### 5.1 数据依赖

**更新实际数据需要**：
1. ✅ `stock_history_data` 表中有目标日期的数据
   - 字段：`close_price`（收盘价）
   - 如果没有数据，无法更新

2. ✅ `stock_predictions` 表中有 `current_price` 字段
   - 用于计算涨跌幅
   - 如果没有，会尝试从数据库查询

---

### 5.2 更新失败情况

**更新失败的原因**：
1. ❌ `stock_history_data` 表中没有目标日期的数据
   - 可能原因：数据获取任务未执行、目标日期是周末/节假日
   - 处理：跳过该记录，继续更新其他记录

2. ❌ `current_price` 为空，且无法从数据库查询
   - 可能原因：预测记录保存时没有保存 `current_price`
   - 处理：跳过该记录，无法计算涨跌幅

3. ❌ API获取失败（如果数据库没有数据）
   - 可能原因：网络问题、API限制
   - 处理：跳过该记录，继续更新其他记录
