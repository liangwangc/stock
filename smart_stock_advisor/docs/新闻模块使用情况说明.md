## 🔍 详细分析

### 1. smart_stock_advisor 的定时任务（已修改）

**文件位置**：`utils/scheduled_task_manager.py` → `_execute_news_crawl()`

**修改后的调用**：
```python
import sys
import os

# 获取 news-analysis-system-main 项目路径
news_system_path = os.path.join(os.path.dirname(current_dir), 'news-analysis-system-main')

# 添加到 Python 路径
sys.path.insert(0, news_system_path)

# 导入并调用 news-analysis-system-main 的方法
from src.data_processing.get_cls_news import fetch_and_store_news

# 直接调用 news-analysis-system-main 的新闻获取方法
fetch_and_store_news()
```

**说明**：
- ✅ **现在直接调用 news-analysis-system-main 的 `fetch_and_store_news()` 方法**
- ✅ smart_stock_advisor 只负责任务管理和调度
- ✅ 新闻获取、股票匹配、情感分析、数据库存储都由 news-analysis-system-main 处理

---

### 2. news-analysis-system-main 的定时任务

**文件位置**：`news-analysis-system-main/scheduler.py`

**实际调用**：
```python
from src.data_processing.get_cls_news import fetch_and_store_news
from src.analysis.main import job as llm_analysis_job

# 调用自己的方法
fetch_and_store_news()  # ✅ news-analysis-system-main自己的财联社新闻获取
llm_analysis_job()      # ✅ news-analysis-system-main自己的LLM分析
```

**说明**：
- ✅ 使用的是 `fetch_and_store_news()` - news-analysis-system-main 自己的财联社新闻获取
- ✅ 独立运行，不依赖 smart_stock_advisor

---

### 3. 两个系统的关系

**当前状态**：**独立运行，互不调用**

| 系统 | 定时任务 | 调用的方法 | 数据存储 |
|------|---------|-----------|---------|
| **smart_stock_advisor** | `ScheduledTaskManager._execute_news_crawl()` | `UnifiedNewsSource()` + `NewsCrawler()` | `stock_data.news_articles` |
| **news-analysis-system-main** | `scheduler.py` | `fetch_and_store_news()` | `stock_data.news_articles` |

**共同点**：
- ✅ 两者都写入同一个数据库表：`stock_data.news_articles`
- ✅ 两者都支持去重（通过 `content_hash` 和唯一索引）

**不同点**：
- smart_stock_advisor：多源新闻（13个新闻源）
- news-analysis-system-main：财联社新闻（单一来源）

## 📊 新闻模块使用情况

### smart_stock_advisor 中的新闻模块

#### ✅ 正在使用的功能

1. **定时任务**（`ScheduledTaskManager._execute_news_crawl()`）
   - 使用 `UnifiedNewsSource()` 获取多源新闻
   - 使用 `NewsCrawler()` 抓取新闻
   - 使用 `NewsStorage()` 保存新闻

2. **股票预测时读取新闻**（`stock_predictor.py`）
   - 使用 `NewsStorage.get_today_news_by_symbol()` 读取股票新闻
   - 使用 `NewsStorage.get_today_market_news()` 读取市场新闻

3. **新闻存储和去重**（`NewsStorage`）
   - 保存新闻到数据库
   - 去重功能（精确匹配 + SimHash）

#### ⚠️ 可能未使用的功能

1. **手动新闻获取**（通过Web界面）
   - 如果只使用定时任务，手动获取功能可能未使用

2. **新闻同步功能**（`NewsSyncFromCls`）
   - 用于从 news-analysis-system-main 同步数据
   - 如果 news-analysis-system-main 直接写入数据库，此功能可能未使用

---

### news-analysis-system-main 中的新闻模块

#### ✅ 正在使用的功能

1. **定时任务**（`scheduler.py`）
   - 调用 `fetch_and_store_news()` 获取财联社新闻
   - 调用 `llm_analysis_job()` 进行LLM分析

2. **新闻获取**（`get_cls_news.py`）
   - 获取财联社新闻
   - 股票匹配
   - 基础情感分析
   - 直接写入 `stock_data.news_articles` 表

3. **LLM分析**（`analysis/main.py`）
   - 深度分析新闻
   - 更新LLM相关字段

## 🎯 总结

### 当前架构（修改后）

```
smart_stock_advisor (任务管理)
  ├─ 定时任务管理 → 调用 news-analysis-system-main.fetch_and_store_news()
  └─ 股票预测 → NewsStorage → 读取新闻（从数据库）

news-analysis-system-main (新闻处理中心)
  ├─ fetch_and_store_news() → 财联社新闻获取 → stock_data.news_articles
  ├─ 股票匹配 → 自动关联股票
  ├─ 基础情感分析 → 填充情感字段
  └─ LLM分析（独立调度） → 深度分析 → 更新LLM字段
```

### 关键变化

1. ✅ **smart_stock_advisor 的定时任务现在直接调用 news-analysis-system-main 的方法**
2. ✅ **统一使用 news-analysis-system-main 进行新闻获取和处理**
3. ✅ **smart_stock_advisor 只负责任务管理和调度，不执行新闻获取**
4. ✅ **所有新闻都通过 news-analysis-system-main 写入数据库**
