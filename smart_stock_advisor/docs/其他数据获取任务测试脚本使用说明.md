# 其他数据获取任务测试脚本使用说明

## 一、脚本概述

**脚本路径**: `scripts/test_other_data_collection.py`

**功能**: 测试设置页面"创建其他数据获取任务"中的6种数据类型的数据获取接口

**测试数据类型**:
1. **北向资金** (north_bound_capital)
2. **市场指数** (market_index)
3. **融资融券** (margin_trading)
4. **主力资金** (main_force_capital)
5. **股票行业信息** (stock_industry_info)
6. **板块轮动** (sector_rotation)

**测试顺序**: akshare -> tushare -> 其他接口

---

## 二、使用方法

### 2.1 直接运行

```bash
cd d:\wjw_work\smart_stock_advisor
python scripts/test_other_data_collection.py
```

### 2.2 运行单个测试

如果需要单独测试某个数据类型，可以修改脚本的 `run_all_tests()` 方法，只调用对应的测试方法：

```python
# 只测试北向资金
tester = OtherDataCollectionTester()
tester.test_north_bound_capital()
tester.generate_report()
```

## 三、测试方法说明

### 3.1 北向资金 (test_north_bound_capital)

**AkShare接口**:
- `ak.stock_connect_north_flow_em(indicator="北向资金")`
- `ak.stock_connect_north_sina()`

**Tushare接口**:
- `pro.moneyflow_hsgt()` - 沪深港通资金流向

**测试内容**: 获取北向资金净流入数据

---

### 3.2 市场指数 (test_market_index)

**AkShare接口**:
- `ak.index_zh_a_hist()` - 指数历史数据
- `ak.stock_zh_index_daily()` - 指数日线数据

**Tushare接口**:
- `pro.index_daily()` - 指数日线数据

**测试内容**: 获取上证指数(sh000001)的历史数据

---

### 3.3 融资融券 (test_margin_trading)

**AkShare接口**:
- `ak.stock_margin_underlying_info_sse()` - 上交所融资融券
- `ak.stock_margin_underlying_info_szse()` - 深交所融资融券

**Tushare接口**:
- `pro.margin()` - 融资融券数据

**测试内容**: 获取测试股票(600519)的融资融券数据

---

### 3.4 主力资金 (test_main_force_capital)

**AkShare接口**:
- `ak.stock_individual_fund_flow()` - 个股资金流向
- `ak.stock_individual_fund_flow_rank()` - 个股资金流向排名

**Tushare接口**:
- `pro.moneyflow()` - 资金流向数据

**测试内容**: 获取测试股票(600519)的主力资金流向数据

---

### 3.5 股票行业信息 (test_stock_industry_info)

**AkShare接口**:
- `ak.stock_individual_info_em()` - 个股信息
- `ak.stock_board_concept_name_em()` - 概念板块列表

**Tushare接口**:
- `pro.stock_basic()` - 股票基本信息

**测试内容**: 获取测试股票(600519)的行业和概念信息

---

### 3.6 板块轮动 (test_sector_rotation)

**AkShare接口**:
- `ak.stock_board_industry_name_em()` - 行业板块列表
- `ak.stock_board_concept_name_em()` - 概念板块列表

**Tushare接口**:
- `pro.index_classify()` - 行业分类

**测试内容**: 获取行业板块和概念板块数据

---

## 四、测试结果

### 4.1 控制台输出

脚本运行时会实时输出每个接口的测试结果：
- ✓ 表示成功
- ✗ 表示失败
- 显示获取到的数据列和数据样例

### 4.2 测试报告文件

测试完成后会自动生成测试报告文件：
- **路径**: `reports/other_data_collection_test_report.txt`
- **内容**: 包含所有6种数据类型的测试结果汇总

### 4.3 测试结果格式

每个数据类型的测试结果包含：
- **AkShare测试结果**: 成功/失败，使用的接口方法，错误信息（如果有）
- **Tushare测试结果**: 成功/失败，使用的接口方法，错误信息（如果有）
- **其他接口测试结果**: 成功/失败（当前暂未实现）

## 五、配置要求

### 5.1 依赖库

- `akshare`: 用于AkShare接口测试
- `tushare`: 用于Tushare接口测试
- `pandas`: 数据处理
- `config.py`: 需要配置 `TUSHARE_TOKEN`

### 5.2 Tushare配置

脚本会自动从 `config.py` 读取 `TUSHARE_TOKEN`，如果未配置，Tushare测试会跳过。

---

## 六、注意事项

1. **网络连接**: 测试需要网络连接，某些接口可能需要代理
2. **API限制**: 某些接口可能有调用频率限制，测试时请注意
3. **数据可用性**: 某些数据可能只在交易日可用
4. **权限要求**: Tushare的某些接口可能需要付费权限

---

## 七、扩展其他接口

如果需要添加其他数据源的测试，可以在对应的测试方法中添加：

```python
# 3. 测试其他接口
print("\n[X.3] 测试其他接口...")
try:
    # 添加其他数据源的测试代码
    other_data = other_api.get_data()
    if other_data:
        result['other'] = {'success': True, 'data': other_data, 'error': None}
except Exception as e:
    result['other'] = {'success': False, 'data': None, 'error': str(e)}
```
