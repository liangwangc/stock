# 数据获取失败导致空数据保存问题修复说明

**创建日期**：2026-01-22  
**问题**：设置页面定时任务数据获取，只有135条数据有价格信息，剩下的都没有数据（开盘价、收盘价等字段为空）

---

## 一、问题分析

### 1.1 问题现象

- **第一批次**：135条数据完整，有真实的当天收盘价格信息
- **其他数据**：没有价格数据（开盘价、收盘价等字段为空），但仍然被保存到数据库

### 1.2 问题原因

**根本原因**：当API没有返回当天数据时，`collect_stock_daily_data()` 函数仍然返回了没有价格字段的数据字典，导致空数据被保存到数据库

**具体流程**：

1. **数据获取失败**（第235-243行）：
   ```python
   if date_idx in days_data.index:
       target_row = days_data.loc[date_idx]
   else:
       # 如果找不到精确日期，返回None（不获取数据）
       self.logger.warning(f"无法找到 {symbol} {date} 的精确数据，跳过该股票该日期的数据获取")
       target_row = None
   ```

2. **价格数据未设置**（第245行）：
   ```python
   if target_row is not None:
       data['open_price'] = ...
       data['close_price'] = ...
       # 如果 target_row 为 None，这些字段不会被设置
   ```

3. **函数仍然返回数据**（第150行和第725行）：
   ```python
   data = {
       'symbol': symbol,
       'name': stock_name,
       # ... 其他字段，但没有价格字段
   }
   # ... 处理逻辑 ...
   return data  # 即使没有价格数据，仍然返回
   ```

4. **空数据被保存**（第1531-1536行）：
   ```python
   data = self.collect_stock_daily_data(symbol, date, fast_mode=True)
   if data:  # data 不为 None，即使没有价格数据
       collected_data.append((symbol, date, data))  # 空数据被添加到保存列表
   ```

---

## 二、解决方案

### 2.1 修复内容

**修复位置**：`utils/stock_history_collector.py` 第400-404行

**修复逻辑**：在返回数据前，检查是否有必要的价格字段（`close_price` 或 `open_price`），如果没有，返回 None，避免保存空数据

**修改前**：
```python
# 快速模式下不再调用get_realtime_quote（性能优化）
# 如果需要市值数据，可以后续批量获取或使用get_stock_info API

# 3. 获取买卖盘数据（快速模式：跳过，这些数据历史数据不可用）
```

**修改后**：
```python
# 快速模式下不再调用get_realtime_quote（性能优化）
# 如果需要市值数据，可以后续批量获取或使用get_stock_info API

# 检查是否有必要的价格数据（如果没有价格数据，返回None，避免保存空数据）
if not data.get('close_price') and not data.get('open_price'):
    # 如果没有收盘价和开盘价，说明没有获取到有效的K线数据
    self.logger.warning(f"{symbol} {date} 没有获取到有效的价格数据，跳过保存")
    return None

# 3. 获取买卖盘数据（快速模式：跳过，这些数据历史数据不可用）
```

---

### 2.2 修复效果

**修复前**：
- API没有返回当天数据时，函数返回没有价格字段的数据字典
- 空数据被保存到数据库，导致数据库中有很多没有价格信息的记录

**修复后**：
- API没有返回当天数据时，函数返回 None
- 空数据不会被保存到数据库，只有有价格数据的记录才会被保存
- 失败的数据会被正确统计到 `fail_count` 中

---

## 三、为什么只有135条数据有价格？

### 3.1 可能的原因

1. **API限制**：
   - 某些股票可能不在API的数据范围内
   - API可能对某些股票返回空数据

2. **非交易日**：
   - 某些股票可能当天停牌或非交易日
   - API不会返回非交易日的数据

3. **数据源问题**：
   - API可能对某些股票的数据获取失败
   - 网络问题或API限流导致部分数据获取失败

4. **股票代码问题**：
   - 某些股票代码可能无效或已退市
   - API无法识别某些股票代码

### 3.2 修复后的行为

- ✅ 只有成功获取到价格数据的股票才会被保存
- ✅ 没有价格数据的股票会被跳过，不会保存空数据
- ✅ 失败的数据会被正确统计和记录
