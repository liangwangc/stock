# 历史股票获取完整流程性能分析

## 问题描述

用户反映：API返回数据大约50秒，但存入数据库要几分钟。

## 完整流程分析

### 1. 流程步骤

```
1. 扫描缺失日期（get_missing_dates）
   ↓
2. 批量获取K线数据（get_stock_data）- API调用，约50秒
   ↓
3. 获取股票基本信息（get_stock_info）- 每个股票1次API调用
   ↓
4. 获取股票名称（可能调用get_all_stock_list）
   ↓
5. 预计算技术指标（一次性计算所有日期的技术指标）
   ↓
6. 遍历missing_dates，构建数据字典（循环处理每条数据）
   ├─ 从kline_data中查找对应日期的数据
   ├─ 计算涨跌幅（使用pre_close_series）
   ├─ 计算价格区间和振幅
   ├─ 计算涨跌停价
   ├─ 添加预计算的技术指标
   └─ 序列化JSON字段
   ↓
7. 批量保存到数据库（save_stock_daily_data_batch）
   ├─ 使用executemany批量插入
   ├─ 每批200条
   └─ 执行SQL插入
```

### 2. 代码位置

**主要方法**：`utils/stock_history_collector.py::_collect_stock_history_batch()`

**关键步骤**：
- 第532-556行：批量获取K线数据（API调用）
- 第568-593行：获取股票基本信息
- 第608-734行：预计算技术指标
- 第749-876行：遍历缺失日期，构建数据字典
- 第878-896行：批量保存到数据库

## 性能瓶颈分析

### 🔴 瓶颈1：数据构建循环（最严重）

**问题**：
- 遍历所有`missing_dates`（约2500条）
- 每条数据都要：
  - 查找`kline_data.loc[date_obj]`（约0.1-0.5ms）
  - 构建数据字典（约1-5ms）
  - 计算涨跌幅、振幅等（约0.5-2ms）
  - 序列化JSON字段（约0.5-2ms）
- 总耗时：2500条 × (1-10ms) = **2.5-25秒**

**代码位置**：`utils/stock_history_collector.py` 第749-876行

**优化方案**：
1. **向量化数据构建**：使用pandas批量处理，避免循环
2. **减少字典操作**：批量构建数据字典
3. **延迟JSON序列化**：在批量保存时统一序列化

### 🟡 瓶颈2：技术指标预计算

**问题**：
- 虽然已经优化为向量化计算，但提取指标值时仍需要遍历`missing_dates`
- 每个日期都要访问`indicators_df.loc[date_obj]`（约0.1-0.5ms）
- 总耗时：2500条 × 0.1-0.5ms = **0.25-1.25秒**

**代码位置**：`utils/stock_history_collector.py` 第702-729行

**优化方案**：
1. **批量提取指标**：一次性提取所有日期的指标值
2. **减少字典转换**：直接使用DataFrame，避免转换为字典

### 🟡 瓶颈3：数据库批量保存

**问题**：
- 虽然已使用`executemany`，但2500条数据需要分13批（每批200条）
- 每批都要：
  - 构建参数列表（约10-50ms）
  - 执行SQL插入（约0.5-1秒）
- 总耗时：13批 × (0.5-1秒) = **6.5-13秒**

**代码位置**：`utils/stock_history_storage.py` 第515-577行

**优化方案**：
1. **增大批次大小**：从200增加到500或1000
2. **减少参数构建时间**：优化参数构建逻辑

### 🟢 瓶颈4：API调用（已优化）

**问题**：
- `get_stock_info()` 每个股票调用1次（约1-2秒）
- `get_all_stock_list()` 如果名称获取失败会调用（约2-5秒）

**代码位置**：`utils/stock_history_collector.py` 第568-584行

**优化方案**：
1. **缓存股票列表**：已实现缓存（`use_cache=True`）
2. **缓存股票信息**：可以添加股票信息缓存

## 优化建议

### 1. 向量化数据构建（最重要）

**当前实现**：
```python
for date_str in missing_dates:
    date_obj = pd.to_datetime(date_str)
    if date_obj in kline_data.index:
        row = kline_data.loc[date_obj]
        data = {...}  # 构建数据字典
        batch_data.append((date_str, data))
```

**优化后**：
```python
# 批量提取所有日期的数据
missing_dates_objs = [pd.to_datetime(d) for d in missing_dates]
missing_dates_in_kline = [d for d in missing_dates_objs if d in kline_data.index]

# 批量提取K线数据
rows_df = kline_data.reindex(missing_dates_in_kline)

# 批量计算所有字段
data_df = pd.DataFrame()
data_df['symbol'] = symbol
data_df['name'] = stock_name
data_df['trade_date'] = [d.strftime('%Y-%m-%d') for d in missing_dates_in_kline]
data_df['open_price'] = rows_df['open']
data_df['close_price'] = rows_df['close']
# ... 其他字段

# 批量计算涨跌幅
data_df['pre_close'] = pre_close_series.reindex(missing_dates_in_kline)
data_df['change_amount'] = data_df['close_price'] - data_df['pre_close']
data_df['change_pct'] = (data_df['change_amount'] / data_df['pre_close']) * 100

# 转换为列表格式
batch_data = [(symbol, row['trade_date'], row.to_dict()) for _, row in data_df.iterrows()]
```

**预期效果**：
- 数据构建时间：从2.5-25秒降低到0.5-2秒
- **性能提升：5-10倍**
