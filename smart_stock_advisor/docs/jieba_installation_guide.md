# jieba 分词库安装和使用指南

## 问题说明

如果看到以下警告信息：
```
jieba分词库不可用，将使用简单分词（字符串匹配）
```

说明 `jieba` 分词库未安装或无法导入。

## 影响

- **jieba 可用时**：使用专业的中文分词，情感分析准确性更高
- **jieba 不可用时**：使用简单的字符串匹配，功能正常但准确性略低

## 解决方案

### 方案1：安装 jieba（推荐）

jieba 是最常用的中文分词库，安装简单，性能稳定。

#### 安装命令

```bash
# 使用 pip 安装
pip install jieba

# 或使用 pip3
pip3 install jieba

# 或指定版本
pip install jieba>=0.42.1
```

#### 验证安装

```python
import jieba
print(jieba.__version__)  # 应该显示版本号
```

### 方案2：使用其他中文分词库（可选）

如果 jieba 无法安装，可以考虑以下替代方案：

#### 2.1 pkuseg（北京大学分词工具）

```bash
pip install pkuseg
```

特点：
- 准确率较高
- 支持领域自适应（金融、新闻等）
- 速度较快

#### 2.2 thulac（清华大学分词工具）

```bash
pip install thulac
```

特点：
- 准确率高
- 支持词性标注
- 速度较慢

#### 2.3 使用简单分词（当前默认）

如果无法安装任何分词库，系统会自动使用简单分词（基于正则表达式和字符串匹配）。

## 代码改进

系统已经做了以下改进：

1. **更详细的错误提示**：显示具体的错误信息和安装建议
2. **改进的简单分词**：使用正则表达式进行更精确的匹配，避免部分匹配问题
3. **优雅降级**：即使 jieba 不可用，系统仍能正常工作

## 使用建议

1. **生产环境**：建议安装 jieba，以获得最佳的分词效果
2. **开发测试**：可以使用简单分词，功能完全可用
3. **特殊需求**：如果需要更高的准确率，可以考虑 pkuseg 或 thulac

## 常见问题

### Q: 安装 jieba 后仍然提示不可用？

A: 检查以下几点：
1. 确认安装的 Python 环境与运行环境一致
2. 尝试重启 Python 进程或应用程序
3. 检查是否有权限问题

### Q: 可以使用多个分词库吗？

A: 当前代码只支持 jieba，如果需要支持其他分词库，需要修改代码。

### Q: 简单分词的效果如何？

A: 简单分词使用关键词匹配，对于常见的关键词（如"上涨"、"下跌"等）效果良好，但对于复杂句子可能不如专业分词库准确。
