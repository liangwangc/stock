# 设置页面股票分析数据库模式优化说明

**创建日期**：2026-01-22  
**优化内容**：确保设置页面的股票分析完全使用数据库数据，不调用实时API

---

## 一、优化目标

### 1.1 用户需求
- **设置页面的股票分析**：不需要实时调用API获取数据，全部从数据库中获取
- **如果数据库没有数据**：则不预测，给出提示信息

### 1.2 优化原则
- ✅ 设置页面预测：完全使用数据库数据
- ✅ 数据库没有数据：返回错误提示，不调用API
- ✅ **不影响主页预测**：主页预测仍然可以使用实时API

---

- **调用方法**：`predict_before_close()` 
- **代码位置**：`predictor/stock_predictor.py:3768`
- **数据获取**：✅ **仍然使用实时API**（不受本次修改影响）

**设置页面预测**（`/api/stock/analysis`）：

## 三、已完成的修改

### 3.1 修改 `get_stock_data()` 方法

**文件**：`data_source/stock_data_source.py`

**修改内容**：
- 添加 `use_db_only` 参数（**默认值为 `False`**）
- 当 `use_db_only=True` 时，只从数据库获取数据
- 如果数据库没有数据，直接返回空DataFrame，不调用API

**代码修改**：
```python
def get_stock_data(self, symbol: str, days: int = 60, start_date: str = None, 
                   end_date: str = None, force_api: bool = False, 
                   use_db_only: bool = False) -> pd.DataFrame:  # ← 默认值 False
    """
    Args:
        use_db_only: 是否只使用数据库（True=只从数据库获取，如果数据库没有数据则返回空DataFrame）
    """
    # ... 数据库查询逻辑 ...
    
    if use_db_only:
        # 如果数据库没有数据，直接返回空DataFrame
        return pd.DataFrame()
    
    # 否则，fallback到API（原有逻辑）
```

**影响分析**：
- ✅ **主页预测**：调用 `get_stock_data()` 时**不传入** `use_db_only`，使用默认值 `False`，会fallback到API ✅
- ✅ **设置页面预测**：调用 `get_stock_data()` 时**传入** `use_db_only=True`，强制只使用数据库 ✅

## 六、ML模型使用情况

### 6.1 ML模型在预测中的使用

**✅ 确认**：股票预测**确实使用了模型训练的结果**

**使用位置**：
- `predictor/stock_predictor.py:3245-3268`（`predict()` 方法）
- `predictor/stock_predictor.py:4369-4396`（`predict_before_close()` 方法）

**调用流程**：
```python
# 1. 尝试加载激活的ML模型
from utils.ml_predictor_integration import MLPredictorIntegration
ml_integration = MLPredictorIntegration()
ml_prediction_result = ml_integration.get_ml_prediction(symbol, data)

# 2. 如果模型可用，获取ML预测得分
if ml_prediction_result and ml_prediction_result.get('available'):
    ml_score = ml_prediction_result.get('ml_score', 0.0)
    ml_weight = 0.15  # ML模型权重15%（默认）或动态权重

# 3. 融合到最终预测
final_score = (
    technical_score * technical_weight +
    news_score * news_weight +
    capital_flow_score * capital_flow_weight +
    ... +
    ml_score * ml_weight  # ← ML模型得分
)
```

---

### 6.2 ML模型权重

**默认权重**：15%

**动态权重调整**：
- 如果模型性能监控可用，会根据模型历史表现动态调整权重
- 通过 `MLModelPerformanceMonitor.get_optimal_weight()` 获取最优权重

**权重归一化**：
- ML模型权重（15%）与其他8个因子权重（85%）一起归一化
- 确保所有权重总和为100%

---

### 6.3 ML模型类型

**支持的模型类型**：
1. **XGBoost分类器**（`xgb_classifier`）- 优先使用
2. **LightGBM分类器**（`lgb_classifier`）- 次选
3. **XGBoost回归器**（`xgb_regressor`）- 备选
4. **LightGBM回归器**（`lgb_regressor`）- 备选

**模型加载顺序**：
```
1. 尝试加载 xgb_classifier（激活的模型）
   ↓
2. 如果没有，尝试加载 lgb_classifier
   ↓
3. 如果还没有，尝试加载 xgb_regressor
   ↓
4. 如果还没有，尝试加载 lgb_regressor
   ↓
5. 如果都没有，跳过ML预测（不影响主流程）
```
