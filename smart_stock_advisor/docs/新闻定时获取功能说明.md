# 新闻定时获取功能说明

**创建时间**：2026-01-23  
**功能**：设置页面 - 新闻数据定时获取功能详细说明

---

## 📋 功能确认

### ✅ 1. 是否是定时获取新闻？

**答案**：**是的，支持定时获取新闻** ✅

**功能说明**：
- ✅ 设置页面的"新闻抓取任务"功能支持定时获取新闻
- ✅ 使用 `ScheduledTaskManager` 统一调度
- ✅ 支持三种调度方式：
  - **间隔执行**（interval）：每N分钟执行一次
  - **每小时执行**（hourly）：每小时执行一次
  - **每日执行**（daily）：每天特定时间执行

**实现方式**：
- 使用 `schedule` 库进行任务调度
- 任务启动后自动按配置的时间间隔执行
- 支持启动/停止任务

## ⏰ 推荐间隔时间

### news-analysis-system-main 的配置

**当前配置**（`scheduler.py`）：
- **新闻获取**：每10分钟执行一次
- **LLM分析**：每2小时执行一次

**推荐配置**：

#### 1. 新闻获取间隔

| 场景 | 推荐间隔 | 说明 |
|------|---------|------|
| **高频获取** | 10-15分钟 | 适合需要实时新闻的场景 |
| **标准获取** | 30-60分钟 | 平衡及时性和资源占用（推荐）⭐ |
| **低频获取** | 60-120分钟 | 适合资源有限或使用频率不高的场景 |

**news-analysis-system-main 推荐**：**10分钟** ✅
- ✅ 财联社新闻更新频率较高
- ✅ 10分钟可以及时获取新新闻
- ✅ 不会触发反爬虫机制

**smart_stock_advisor 推荐**：**30-60分钟** ⭐
- ✅ 多源新闻获取，资源占用较大
- ✅ 30-60分钟平衡及时性和资源占用
- ✅ 避免频繁请求导致API限制

#### 2. LLM分析间隔

**推荐间隔**：**2小时** ✅
- ✅ LLM分析需要较多资源
- ✅ 2小时可以及时分析新获取的新闻
- ✅ 不会造成资源压力过大

**调整建议**：
- 如果资源充足：可以缩短到1小时
- 如果资源有限：可以延长到4小时或每天一次

## 🔍 去重功能

### ✅ 两个系统都有去重功能

### 1. smart_stock_advisor 去重机制

**实现位置**：`utils/news_storage.py`

**去重方式**（双重保障）：

**方式1：精确匹配**（优先）
```python
# 基于标题和来源的精确匹配
existing_id = self._check_duplicate(title, source)
```

**方式2：SimHash相似度检测**（备用）
```python
# 使用SimHash算法检测相似内容
if not existing_id and self.deduplication and content:
    duplicate_id = self.deduplication.check_duplicate_by_content(title, content, source)
```

**特点**：
- ✅ **精确匹配**：标题+来源完全一致 → 跳过
- ✅ **相似度检测**：内容相似度超过阈值 → 跳过
- ✅ **双重保障**：确保不会重复存储

**去重字段**：
- `title` + `source` - 精确匹配
- `simhash` - 相似度检测

---

### 2. news-analysis-system-main 去重机制

**实现位置**：`src/data_processing/get_cls_news.py`

**去重方式**：

**content_hash 去重**：
```python
# 生成内容哈希
news_df['content_hash'] = news_df.apply(generate_hash, axis=1)

# 过滤已存在的hash
new_news_df = filter_new_hashes(news_df)

# 插入前再次检查
check_sql = text("SELECT COUNT(*) FROM news_articles WHERE content_hash = :hash")
```

**特点**：
- ✅ **基于内容哈希**：使用MD5哈希（title + content）
- ✅ **插入前检查**：逐条检查，避免重复
- ✅ **数据库唯一索引**：`uk_title_source` 防止重复

**去重字段**：
- `content_hash` - 内容哈希（MD5）
- `uk_title_source` - 唯一索引（标题+来源）
