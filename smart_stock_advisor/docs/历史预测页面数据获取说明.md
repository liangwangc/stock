## 一、数据流程概览

```
用户访问历史预测页面
  ↓
前端调用 /api/history?symbol=股票代码
  ↓
后端API：
  1. 自动更新历史实际数据（_update_historical_actual_data）
  2. 从数据库查询预测记录（get_predictions）
  3. 返回JSON数据（包含预测价格和真实价格）
  ↓
前端渲染显示
```

### 2.2 计算时机

**计算位置**：`predictor/stock_predictor.py`

**计算方法**：`_calculate_predicted_price_optimized()`（第2611行）

**调用时机**：
- 在 `predict()` 方法中调用（第3430行）
- 在 `predict_before_close()` 方法中调用（第4489行）

**计算流程**：
```python
# 1. 获取股票特性相关的最大涨跌幅
max_change_pct = self._get_max_change_pct(symbol, stock_name)

# 2. 计算历史波动率调整系数
volatility_coefficient = self._calculate_volatility_coefficient(data)

# 3. 计算价格趋势调整因子
trend_adjustment = self._calculate_trend_adjustment(data)

# 4. 计算概率差异
probability_diff = up_probability - down_probability

# 5. 计算预测涨跌幅
predicted_change_pct = (
    tanh(probability_diff * volatility_coefficient) * 
    max_change_pct * 
    confidence * 
    trend_adjustment
)

# 6. 计算预测收盘价
predicted_close_price = current_price * (1 + predicted_change_pct / 100.0)
```

## 三、真实价格字段

### 3.1 字段说明

| 字段名 | 说明 | 数据来源 |
|--------|------|----------|
| `actual_price` | 实际价格（目标日期的收盘价） | 从 `stock_history_data` 表获取 |
| `actual_change_pct` | 实际涨跌幅 | 计算得出：`(actual_price - current_price) / current_price * 100` |
| `actual_direction` | 实际方向（上涨/下跌/平盘） | 根据涨跌幅判断 |
| `prediction_hit` | 预测命中（命中/未命中） | 根据预测方向和实际方向判断 |

---

### 3.2 更新时机

**更新方法**：`visualizer/prediction_visualizer.py` → `_update_historical_actual_data()`（第1991行）

**触发时机**：
1. ✅ **每次保存新预测时自动触发**（第1792行）
2. ✅ **查看历史页面时也会更新**（`web_app.py:3279`）

---

### 3.3 更新流程

```
1. 查询需要更新的记录
   - target_date < 今天
   - actual_price 为空
   ↓
2. 对每条记录：
   a. 调用 get_actual_stock_change(symbol, target_date, current_price)
      ↓
   b. 从 stock_history_data 表查询目标日期的收盘价
      - 优先从数据库获取
      - 如果数据库没有，从API获取
      ↓
   c. 计算实际涨跌幅
      - actual_change_pct = (actual_price - current_price) / current_price * 100
      ↓
   d. 判断实际方向和预测命中
      ↓
   e. 调用 update_prediction_actual() 更新数据库
```

---

### 3.4 获取方式

**API接口**：`web_app.py` → `/api/history`（第3259行）

**获取逻辑**（第3322-3325行）：

## 五、数据来源总结

### 5.1 预测价格

| 字段 | 计算时机 | 保存时机 | 获取方式 |
|------|---------|---------|---------|
| `predicted_close_price` | 预测时计算 | 预测后立即保存 | 从数据库读取 |
| `predicted_change_pct` | 预测时计算 | 预测后立即保存 | 从数据库读取 |

**计算公式**：
- `predicted_change_pct = tanh(概率差异 × 波动率系数) × 最大涨跌幅 × 置信度 × 趋势调整`
- `predicted_close_price = current_price × (1 + predicted_change_pct / 100)`

---

### 5.2 真实价格

| 字段 | 更新时机 | 数据来源 | 获取方式 |
|------|---------|---------|---------|
| `actual_price` | 目标日期收盘后 | `stock_history_data.close_price` | 查看历史页面时自动更新 |
| `actual_change_pct` | 目标日期收盘后 | 计算得出 | 查看历史页面时自动更新 |
| `actual_direction` | 目标日期收盘后 | 根据涨跌幅判断 | 查看历史页面时自动更新 |
| `prediction_hit` | 目标日期收盘后 | 根据预测方向和实际方向判断 | 查看历史页面时自动更新 |

**计算公式**：
- `actual_change_pct = (actual_price - current_price) / current_price × 100`
- `actual_direction`：涨跌幅 > 0.01%：上涨；< -0.01%：下跌；其他：平盘

## 六、完整数据流程

### 6.1 预测时（保存预测价格）

```
用户执行预测
  ↓
predict() 或 predict_before_close()
  ↓
计算预测价格：
  - _calculate_predicted_price_optimized()
  - predicted_change_pct
  - predicted_close_price
  ↓
保存预测结果：
  - save_stock_record()
  - save_prediction()
  - 保存到 stock_predictions 表
  - 包含 predicted_close_price 和 predicted_change_pct
```

---

### 6.2 查看历史时（更新真实价格）

```
用户访问历史预测页面
  ↓
前端调用 /api/history?symbol=股票代码
  ↓
后端API：
  1. 自动更新历史实际数据
     - _update_historical_actual_data()
     - 查询 target_date < 今天 且 actual_price 为空的记录
     - 从 stock_history_data 表获取实际价格
     - 计算实际涨跌幅、方向、命中
     - 更新到 stock_predictions 表
   ↓
  2. 从数据库查询预测记录
     - get_predictions(symbol=symbol, limit=1000)
     - 包含预测价格和真实价格
   ↓
  3. 返回JSON数据给前端
  ↓
前端渲染显示
```
