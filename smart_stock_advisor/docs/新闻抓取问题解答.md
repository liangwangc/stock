# 新闻抓取问题解答

## 问题1：为什么16个新闻来源抓不到新闻？

### 原因分析

当您选择"全量新闻（包含市场、股票所有新闻）"时，系统会调用 `crawl_all_news()` 方法。之前这个方法存在以下问题：

1. **使用了 `only_today=True` 参数**
   - 代码中使用了 `only_today=True`，这意味着只获取当天的新闻
   - 如果当天没有新闻，或者时间解析有问题，就会抓不到新闻

2. **时间解析问题**
   - 各个新闻源的时间格式不一致（有些是"今天"、"1小时前"等相对时间）
   - 时间解析可能失败，导致新闻被错误过滤

3. **时间范围过滤**
   - 即使获取到了新闻，也会按时间范围过滤
   - 如果时间范围计算有问题，可能过滤掉所有新闻

### 解决方案

**已修复并优化**：
1. ✅ 将 `crawl_all_news()` 方法中的 `only_today=True` 改为 `only_today=False`，这样就能获取所有新闻，然后按时间范围过滤
2. ✅ 添加了重试机制（默认3次），提高抓取成功率
3. ✅ 改进了时间解析逻辑，支持多种时间格式
4. ✅ 添加了详细的统计信息，包括各新闻源的贡献
5. ✅ 优化了日志输出，提供更清晰的信息

### 优化内容

1. **重试机制**：
   - 默认重试3次，每次失败后等待时间递增（2秒、4秒、6秒）
   - 提高抓取成功率，应对网络波动

2. **时间解析优化**：
   - 提取为独立方法 `_parse_news_time()`，支持多种时间格式
   - 处理相对时间（"今天"、"1小时前"等）
   - 改进错误处理，避免误过滤

3. **统计信息增强**：
   - 添加各新闻源的贡献统计
   - 记录时间范围信息
   - 统计关联到的股票数量
   - 记录时间过滤的详细信息

4. **日志优化**：
   - 更详细的日志输出，包括进度信息
   - 记录各新闻源的贡献情况
   - 提供问题诊断信息

### 如何验证

1. 查看日志：检查是否有 "未获取到新闻" 的警告，查看详细的统计信息
2. 检查数据库：查看 `news_articles` 表中是否有新数据
3. 查看任务执行历史：在设置页面查看任务的执行结果
4. 查看统计信息：日志中会显示各新闻源的贡献情况

## 问题2：限制数量是什么意思？

### 说明

**限制数量（limit）** 表示**每个新闻源最多获取多少条新闻**。

### 具体含义

1. **在 `crawl_all_news()` 方法中**：
   - `limit` 参数表示每个新闻源的限制数量
   - 实际调用时使用 `limit * 2`，是为了获取更多新闻以便后续时间过滤
   - 例如：如果 `limit=200`，实际会请求 `200 * 2 = 400` 条新闻

2. **在 `get_market_news()` 方法中**：
   - `limit` 参数表示总共需要获取多少条新闻
   - 系统会将这个数量平均分配给各个新闻源
   - 例如：如果有16个新闻源，`limit=200`，每个新闻源会获取 `200 // 16 + 1 = 13` 条新闻

3. **为什么需要限制数量？**
   - 防止一次性获取过多数据，导致内存占用过高
   - 提高抓取效率，避免超时
   - 控制数据库写入量

### 建议设置

- **市场新闻**：建议 `limit=50-100`
- **股票新闻**：建议 `limit=20-50`
- **全量新闻**：建议 `limit=200-500`

### 注意事项

- 限制数量越大，抓取时间越长
- 如果设置太大，可能导致超时或内存不足
- 如果设置太小，可能抓取不到足够的新闻

## 常见问题

### Q1: 为什么有些新闻源获取不到数据？

**可能原因**：
1. 新闻源网站结构变化，导致解析失败
2. 网络问题，无法访问新闻源网站
3. 新闻源网站有反爬虫机制
4. 新闻源网站暂时没有新新闻

**解决方法**：
- 查看日志，了解具体错误信息
- 检查网络连接
- 稍后重试

### Q2: 为什么抓取的新闻数量少于预期？

**可能原因**：
1. 去重：多个新闻源可能有重复新闻，系统会自动去重
2. 时间过滤：只保留时间范围内的新闻
3. 新闻源限制：某些新闻源可能返回的数据较少

**解决方法**：
- 增加 `limit` 参数
- 检查时间范围设置
- 查看日志了解去重情况

### Q3: 如何查看抓取任务的执行情况？

**方法**：
1. 在设置页面 -> 新闻抓取 -> 任务列表
2. 点击任务，查看执行历史
3. 查看日志文件：`logs/news_crawler.log`

### Q4: 全量新闻和增量新闻有什么区别？

**全量新闻**：
- 获取所有新闻（不限制日期）
- 然后按时间范围过滤
- 适合首次抓取或补全历史数据

**增量新闻**：
- 只获取指定时间范围内的新闻
- 基于上次抓取时间，只获取新新闻
- 适合定时抓取，避免重复
