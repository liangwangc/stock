# 字段数量说明

## 一、实际保存的字段数量

**当前版本**：**41个字段**

## 二、字段统计

### 2.1 已保存的字段（41个）

1. **基本信息**（3个）：
   - `symbol` - 股票代码
   - `name` - 股票名称
   - `trade_date` - 交易日期
   - `period_type` - 周期类型

2. **基本价格数据**（7个）：
   - `open_price` - 开盘价
   - `close_price` - 收盘价
   - `high_price` - 最高价
   - `low_price` - 最低价
   - `pre_close` - 昨收价
   - `change_amount` - 涨跌额
   - `change_pct` - 涨跌幅

3. **成交数据**（3个）：
   - `volume` - 成交量
   - `amount` - 成交额
   - `volume_ratio` - 量比

4. **成本分布**（2个）：
   - `cost_distribution` - 成本分布
   - `cost_distribution_history` - 历史成本分布

5. **估值指标**（2个）：
   - `pe_ratio` - 市盈率
   - `pb_ratio` - 市净率

6. **涨跌停信息**（5个）：
   - `limit_up` - 涨停价
   - `limit_down` - 跌停价
   - `limit_pct` - 涨跌停幅度
   - `is_limit_up` - 是否涨停
   - `is_limit_down` - 是否跌停

7. **振幅和波动**（2个）：
   - `amplitude` - 振幅
   - `price_range` - 价格区间

8. **技术指标**（10个）：
   - `ma5`, `ma10`, `ma20`, `ma60` - 均线
   - `rsi` - RSI指标
   - `macd`, `macd_signal`, `macd_hist` - MACD指标
   - `x2` - X2指标

9. **融资融券**（3个）：
   - `margin_balance` - 融资余额
   - `short_balance` - 融券余额
   - `margin_ratio` - 融资融券余额占比

10. **其他**（4个）：
    - `extra_data` - 扩展数据
    - `data_source` - 数据来源
    - `data_quality_score` - 数据质量得分
    - `is_valid` - 数据是否有效

**总计：41个字段**

### 2.2 已注释掉的字段（16个）

以下字段在历史数据收集中已注释掉，不保存到数据库：

1. **换手率**（1个）：
   - `turnover_rate` - 需要流通股本数据，历史数据通常不可用

2. **盘口数据**（3个）：
   - `outer_volume` - 外盘（实时数据）
   - `inner_volume` - 内盘（实时数据）
   - `bid_ask_ratio` - 委比（实时数据）

3. **五档买卖盘**（4个）：
   - `bid_levels` - 五档买盘（实时数据）
   - `ask_levels` - 五档卖盘（实时数据）
   - `bid_total_volume` - 买盘总手数（实时数据）
   - `ask_total_volume` - 卖盘总手数（实时数据）

4. **成本分布**（1个）：
   - `cost_distribution_intraday` - 当日成本分布（历史数据不可用）

5. **市值数据**（2个）：
   - `total_market_cap` - 总市值（历史数据通常不可用）
   - `float_market_cap` - 流通市值（历史数据通常不可用）

6. **资金流向**（5个）：
   - `main_net_inflow` - 主力净流入（实时数据）
   - `super_large_inflow` - 超大单净流入（实时数据）
   - `large_inflow` - 大单净流入（实时数据）
   - `medium_inflow` - 中单净流入（实时数据）
   - `small_inflow` - 小单净流入（实时数据）

**总计：16个字段**

## 五、注意事项

1. **数据库表结构**：保持不变，仍然包含所有58个字段
2. **历史数据**：被注释的字段在历史数据收集中保持为NULL

## 六、如果进度条显示57个字段

如果进度条或日志显示"57个字段"，可能是：

1. **旧版本的显示**：显示的是优化前的字段数量（58个减去某个字段）
2. **数据构建时的字段数量**：显示的是数据构建时的字段数量（包括被注释的字段）
3. **数据库表结构字段总数**：显示的是数据库表结构中的字段总数（58个）
