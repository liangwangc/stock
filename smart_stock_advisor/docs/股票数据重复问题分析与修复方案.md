# 股票数据重复问题分析与修复方案

**创建日期**：2026-01-22  
**问题描述**：获取的股票数据有重复的数据

---

## 一、问题分析

### 1.1 可能的原因

1. **唯一索引不完整**
   - 数据库唯一索引可能还是旧的：`uk_symbol_date` (`symbol`, `trade_date`)
   - 缺少 `period_type` 字段
   - 导致同一个股票同一天可以有多条记录

2. **period_type 字段为 NULL**
   - 如果 `period_type` 为 NULL，唯一索引可能失效
   - 导致可以插入重复数据

3. **增量更新逻辑问题**
   - `skip_existence_check=True` 时，直接使用 `ON DUPLICATE KEY UPDATE`
   - 但如果唯一索引不正确，`ON DUPLICATE KEY UPDATE` 可能不会生效

4. **并发插入问题**
   - 多线程并发插入时，如果唯一索引不正确，可能产生重复数据

### 3.3 步骤3：清理重复数据

**方法1：保留ID最小的记录**

```sql
-- 创建临时表存储需要保留的记录
CREATE TEMPORARY TABLE `temp_keep_records` AS
SELECT MIN(id) as id
FROM `stock_history_data`
GROUP BY `symbol`, `trade_date`, `period_type`;

-- 删除重复记录（执行前请先备份！）
DELETE FROM `stock_history_data`
WHERE id NOT IN (SELECT id FROM `temp_keep_records`);
```

**方法2：使用窗口函数（MySQL 8.0+）**

```sql
DELETE FROM `stock_history_data`
WHERE id IN (
    SELECT id FROM (
        SELECT id,
               ROW_NUMBER() OVER (PARTITION BY symbol, trade_date, period_type ORDER BY id) as rn
        FROM `stock_history_data`
    ) as t
    WHERE rn > 1
```
