# 技术指标批量计算说明

## 概述

为了提升数据收集速度，历史数据收集时跳过了技术指标计算。现在提供了批量计算技术指标的脚本，用于后续补充历史数据的技术指标。

## 延迟计算的指标

以下技术指标在数据收集时跳过计算，可以通过批量脚本后续计算：

- **移动平均线**：`ma5`, `ma10`, `ma20`, `ma60`
- **RSI**：`rsi`（相对强弱指标）
- **MACD**：`macd`, `macd_signal`, `macd_hist`（MACD指标）
- **X2指标**：`x2`
- **量比**：`volume_ratio`

## 脚本使用方法

### 基本用法

#### 1. 计算单只股票的技术指标

```bash
python scripts/batch_calculate_technical_indicators.py --symbol 000001
```

#### 2. 批量计算所有股票的技术指标

```bash
python scripts/batch_calculate_technical_indicators.py --all
```

#### 3. 批量计算指定股票列表的技术指标

```bash
python scripts/batch_calculate_technical_indicators.py --symbols 000001,600519,000002
```

#### 4. 计算指定日期范围的数据

```bash
python scripts/batch_calculate_technical_indicators.py --all --start-date 2024-01-01 --end-date 2024-12-31
```

#### 5. 多线程模式（推荐，提升速度）

```bash
python scripts/batch_calculate_technical_indicators.py --all --threads 5
```

#### 6. 仅扫描缺失数据，不进行计算

```bash
python scripts/batch_calculate_technical_indicators.py --all --scan-only
```

### 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--symbol` | 单只股票代码 | - |
| `--symbols` | 股票代码列表（逗号分隔） | - |
| `--all` | 处理所有股票 | False |
| `--start-date` | 开始日期（格式：YYYY-MM-DD） | 所有数据 |
| `--end-date` | 结束日期（格式：YYYY-MM-DD） | 所有数据 |
| `--threads` | 最大线程数 | 1 |
| `--scan-only` | 仅扫描缺失数据，不进行计算 | False |

### 使用示例

#### 示例1：计算单只股票最近1年的技术指标

```bash
python scripts/batch_calculate_technical_indicators.py \
    --symbol 000001 \
    --start-date 2024-01-01 \
    --end-date 2024-12-31
```

#### 示例2：批量计算所有股票的技术指标（多线程）

```bash
python scripts/batch_calculate_technical_indicators.py \
    --all \
    --threads 5
```

#### 示例3：先扫描缺失数据，再批量计算

```bash
# 1. 扫描缺失数据
python scripts/batch_calculate_technical_indicators.py --all --scan-only

# 2. 批量计算（根据扫描结果决定是否计算）
python scripts/batch_calculate_technical_indicators.py --all --threads 5
```

## 脚本功能

### 1. 扫描缺失技术指标

脚本会自动扫描数据库中缺失技术指标的数据：
- 检查 `ma5`, `rsi`, `macd` 等主要指标
- 如果主要指标都为空，则标记为缺失
- 返回缺失技术指标的股票和日期列表

### 2. 批量计算技术指标

对于每只股票：
- 获取足够的历史K线数据（前60天）
- 使用向量化计算（pandas/numpy）批量计算所有日期的指标
- 更新数据库中的技术指标字段

### 3. 多线程支持

支持多线程模式，可以并行处理多只股票：
- 每个线程处理一只股票
- 线程间互不干扰
- 大幅提升批量计算速度

### 4. 进度跟踪

脚本会实时输出进度信息：
- 每只股票的处理进度
- 成功/失败统计
- 总体进度和耗时

## 性能说明

### 计算时间估算

- **单只股票，2500天数据**：约 1-3 秒
- **1000只股票，每只2500天，单线程**：约 15-45 分钟
- **1000只股票，每只2500天，5线程**：约 3-9 分钟

### 优化建议

1. **使用多线程**：推荐使用 `--threads 5` 或更多
2. **分批处理**：如果数据量很大，可以分批处理（使用 `--start-date` 和 `--end-date`）

## 注意事项

### 1. 数据要求

- 需要确保数据库中有足够的历史K线数据
- 每个日期至少需要20天的历史数据才能计算所有指标
- 如果历史数据不足，该日期的技术指标将无法计算

### 2. 计算逻辑

- 技术指标是基于历史数据计算的
- 使用向量化计算（pandas/numpy），性能优异
- 计算顺序：MA → RSI/MACD → X2 → 量比

### 3. 数据库更新

- 脚本会更新所有技术指标字段
- 已存在的指标会被覆盖
- 缺失的指标会被补充

### 4. 错误处理

- 如果某个日期的技术指标计算失败，脚本会继续处理其他日期
- 失败的原因会记录在日志中
- 可以重新运行脚本，已计算的指标不会重复计算（但会被覆盖）

## 常见问题

### Q1: 为什么有些日期的技术指标无法计算？

**A**: 可能的原因：
- 历史数据不足（需要至少20天的历史数据）
- 价格数据异常（价格为0或负数）
- 成交量数据异常（全部为0）

### Q2: 可以重复运行脚本吗？

**A**: 可以。脚本会重新计算所有缺失的指标，已存在的指标会被覆盖。

### Q3: 如何提高计算速度？

**A**: 
- 使用多线程模式（`--threads 5`）
- 分批处理（使用 `--start-date` 和 `--end-date`）

### Q4: 技术指标数据会占用多少存储空间？

**A**: 
- 每个日期的技术指标约占用 100-200 字节
- 1000只股票，每只2500天，约占用 250-500 MB
