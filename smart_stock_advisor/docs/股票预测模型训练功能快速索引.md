## 🔧 核心模块

### 数据加载模块
- **文件**：`utils/ml_data_loader.py`
- **主要方法**：
  - `load_training_data_from_history()` - 从历史数据加载（基础模型训练）
  - `load_training_data()` - 从预测数据加载（微调训练）
  - `_extract_features_from_history()` - 提取特征
  - `check_training_data_quality()` - 检查数据质量

### 特征工程模块
- **文件**：`utils/ml_feature_engineering.py`
- **主要方法**：
  - `prepare_features()` - 准备特征和标签
  - `normalize_features()` - 特征标准化
  - `select_features()` - 特征选择

### 模型训练模块
- **文件**：`utils/ml_model_trainer.py`
- **主要方法**：
  - `train_xgb_classifier()` - 训练XGBoost分类器
  - `train_lgb_classifier()` - 训练LightGBM分类器
  - `train_xgb_regressor()` - 训练XGBoost回归器
  - `train_lgb_regressor()` - 训练LightGBM回归器

### 模型管理模块
- **文件**：`utils/ml_model_manager.py`
- **主要方法**：
  - `save_model_info()` - 保存模型信息
  - `load_model()` - 加载模型
  - `get_model_info()` - 获取模型信息
  - `list_models()` - 列出所有模型
  - `activate_model()` - 激活模型

## 🚀 快速命令

### 基础模型训练（10年数据）
```bash
py scripts/train_base_model.py \
    --train-start 2014-01-01 \
    --train-end 2022-12-31 \
    --val-start 2023-01-01 \
    --val-end 2023-12-31 \
    --models xgb_classifier lgb_classifier
```

### 小规模测试（1年数据）
```bash
py scripts/train_base_model.py \
    --train-start 2023-01-01 \
    --train-end 2023-06-30 \
    --val-start 2023-07-01 \
    --val-end 2023-12-31 \
    --models xgb_classifier
```

### 模型微调
```bash
py scripts/fine_tune_model.py --base-model xgb_classifier_base_v20240114_120000
```

## 📊 训练策略

### 两阶段训练
1. **基础模型训练**（历史数据）
   - 数据源：`stock_history_data` 表
   - 频率：首次部署必须，之后每3-6个月
   - 时间：30分钟到2小时

2. **模型微调**（预测数据）
   - 数据源：`stock_predictions` 表
   - 频率：每周1-2次
   - 时间：10-30分钟

### 模型权重
- ML模型权重：**15%**
- 其他8个因子权重：**85%**

## 🔍 关键信息速查

### 支持的模型类型
- `xgb_classifier` - XGBoost分类器 ⭐⭐⭐⭐⭐
- `lgb_classifier` - LightGBM分类器 ⭐⭐⭐⭐
- `xgb_regressor` - XGBoost回归器 ⭐⭐⭐
- `lgb_regressor` - LightGBM回归器 ⭐⭐⭐

### 特征数量
- 约50+个特征
- 包括：价格特征、技术指标、资金流向、估值、融资融券、衍生特征、时间序列特征

### 数据库表
- `trained_models` - 存储模型元数据
- `stock_history_data` - 历史数据（基础模型训练）
- `stock_predictions` - 预测数据（微调训练）

### 模型文件位置
- `models/xgb_classifier/` - XGBoost分类器模型
- `models/lgb_classifier/` - LightGBM分类器模型
- `models/xgb_regressor/` - XGBoost回归器模型
- `models/lgb_regressor/` - LightGBM回归器模型
