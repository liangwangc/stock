## 🚀 快速安装

### 方法1：使用 requirements.txt（推荐）

```bash
# 进入项目目录
cd smart_stock_advisor

# 安装所有依赖
pip install -r requirements.txt
```

如果 `requirements.txt` 不可用，可以按照下面的分类逐个安装。

## 📦 必需依赖

这些包是项目运行的核心依赖，必须安装。

```bash

```bash

```bash

## 🔧 可选依赖

这些包用于增强功能，如果不需要相关功能可以不安装。

### 技术指标计算（与证券公司算法一致）

```bash
# Windows系统（推荐使用预编译wheel文件）
pip install TA-Lib>=0.4.28

# 如果上述命令失败，Windows系统可以：
# 1. 下载预编译wheel文件：https://www.lfd.uci.edu/~gohlke/pythonlibs/#ta-lib
# 2. 根据Python版本选择对应文件（如：TA_Lib-0.4.28-cp313-win_amd64.whl）
# 3. 安装：pip install TA_Lib-0.4.28-cp313-win_amd64.whl

# Linux系统
sudo apt-get install ta-lib  # Ubuntu/Debian
pip install TA-Lib>=0.4.28

# macOS系统
brew install ta-lib
pip install TA-Lib>=0.4.28
```

**注意**：talib是技术指标计算库，用于确保计算值与证券公司一致。如果未安装，系统会回退到pandas计算（可能与证券公司值不一致）。

## ✅ 安装验证

安装完成后，可以使用以下命令验证关键包是否安装成功：

```python
# 验证脚本
python -c "
import sys
packages = [
    'pandas', 'numpy', 'akshare', 'requests', 'bs4', 'lxml',
    'pymysql', 'flask', 'flask_socketio', 'schedule', 'tqdm',
    'sklearn', 'matplotlib', 'seaborn', 'plotly', 'yfinance',
    'jieba', 'psutil', 'pytest'
]

print('检查依赖包安装状态：')
print('=' * 50)
missing = []
for pkg in packages:
    try:
        if pkg == 'bs4':
            import bs4
            version = getattr(bs4, '__version__', '未知')
        elif pkg == 'flask_socketio':
            import flask_socketio
            version = getattr(flask_socketio, '__version__', '未知')
        elif pkg == 'sklearn':
            import sklearn
            version = sklearn.__version__
        else:
            mod = __import__(pkg)
            version = getattr(mod, '__version__', '未知')
        print(f'✓ {pkg:20s} - 版本: {version}')
    except ImportError:
        print(f'✗ {pkg:20s} - 未安装')
        missing.append(pkg)

print('=' * 50)
if missing:
    print(f'\n缺失的包: {", ".join(missing)}')
    print('请运行: pip install ' + ' '.join(missing))
else:
    print('\n所有依赖包已安装！')
"
```

或者创建一个验证脚本 `check_dependencies.py`：

```python
#!/usr/bin/env python
# -*- coding: utf-8 -*-
"""检查项目依赖是否安装"""

import sys

REQUIRED_PACKAGES = {
    'pandas': 'pandas',
    'numpy': 'numpy',
    'akshare': 'akshare',
    'requests': 'requests',
    'beautifulsoup4': 'bs4',
    'lxml': 'lxml',
    'pymysql': 'pymysql',
    'flask': 'flask',
    'flask-socketio': 'flask_socketio',
    'schedule': 'schedule',
    'tqdm': 'tqdm',
    'python-dateutil': 'dateutil',
}

OPTIONAL_PACKAGES = {
    'TA-Lib': 'talib',  # 技术指标计算（与证券公司算法一致）
    'scikit-learn': 'sklearn',
    'xgboost': 'xgboost',
    'lightgbm': 'lightgbm',
    'matplotlib': 'matplotlib',
    'seaborn': 'seaborn',
    'plotly': 'plotly',
    'dash': 'dash',
    'yfinance': 'yfinance',
    'jieba': 'jieba',
    'psutil': 'psutil',
    'pytest': 'pytest',
    'openpyxl': 'openpyxl',
}

def check_package(package_name, import_name):
    """检查包是否安装"""
    try:
        mod = __import__(import_name)
        version = getattr(mod, '__version__', '未知')
        return True, version
    except ImportError:
        return False, None

def main():
    print('=' * 60)
    print('项目依赖检查')
    print('=' * 60)
    
    print('\n【必需依赖】')
    print('-' * 60)
    missing_required = []
    for pkg_name, import_name in REQUIRED_PACKAGES.items():
        installed, version = check_package(pkg_name, import_name)
        if installed:
            print(f'✓ {pkg_name:25s} - 版本: {version}')
        else:
            print(f'✗ {pkg_name:25s} - 未安装')
            missing_required.append(pkg_name)
    
    print('\n【可选依赖】')
    print('-' * 60)
    missing_optional = []
    for pkg_name, import_name in OPTIONAL_PACKAGES.items():
        installed, version = check_package(pkg_name, import_name)
        if installed:
            print(f'✓ {pkg_name:25s} - 版本: {version}')
        else:
            print(f'○ {pkg_name:25s} - 未安装（可选）')
            missing_optional.append(pkg_name)
    
    print('\n' + '=' * 60)
    if missing_required:
        print(f'\n❌ 缺失必需依赖: {", ".join(missing_required)}')
        print(f'请运行: pip install {" ".join(missing_required)}')
        return 1
    else:
        print('\n✅ 所有必需依赖已安装！')
        if missing_optional:
            print(f'\n💡 可选依赖未安装: {", ".join(missing_optional)}')
            print('这些包用于增强功能，不影响核心功能运行。')
        return 0

if __name__ == '__main__':
    sys.exit(main())
```

运行验证：

```bash
python check_dependencies.py
```

## 🔍 常见问题

### Q1: 安装 akshare 时出错

**问题**：`akshare` 安装失败或导入错误

**解决方案**：
```bash
# 升级 pip
pip install --upgrade pip

# 重新安装 akshare
pip install akshare --upgrade

# 如果仍有问题，尝试安装依赖
pip install requests lxml pandas pyexecjs
```

### Q2: 安装 pymysql 时出错

**问题**：`pymysql` 安装失败

**解决方案**：
```bash
# Windows
pip install pymysql

# Linux/Mac（可能需要编译工具）
sudo apt-get install python3-dev default-libmysqlclient-dev  # Ubuntu/Debian
pip install pymysql
```

### Q3: flask-socketio 安装失败

**问题**：`flask-socketio` 安装失败

**解决方案**：
```bash
# 确保已安装 flask
pip install flask>=2.3.0

# 安装 flask-socketio
pip install flask-socketio

# 如果使用 Python 3.11+，可能需要指定版本
pip install "flask-socketio>=5.0.0"
```

### Q4: jieba 安装后仍提示不可用

**问题**：安装 `jieba` 后仍然提示不可用

**解决方案**：
1. 确认安装的 Python 环境与运行环境一致
2. 尝试重启 Python 进程或应用程序
3. 检查是否有权限问题
4. 验证安装：`python -c "import jieba; print(jieba.__version__)"`

### Q5: 依赖冲突

**问题**：安装时出现依赖版本冲突

**解决方案**：
```bash
# 使用虚拟环境（推荐）
python -m venv venv
source venv/bin/activate  # Linux/Mac
# 或
venv\Scripts\activate  # Windows

# 在虚拟环境中安装依赖
pip install -r requirements.txt

# 如果仍有冲突，可以尝试不指定版本
pip install pandas numpy akshare flask pymysql ...
```

### Q6: 网络问题导致安装失败

**问题**：下载包时网络超时或连接失败

**解决方案**：
```bash
# 使用国内镜像源（推荐）
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 或使用阿里云镜像
pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/

# 或使用豆瓣镜像
pip install -r requirements.txt -i https://pypi.douban.com/simple/
```

### Q7: TA-Lib (talib) 安装失败

**问题**：`pip install TA-Lib` 安装失败，特别是Windows系统

**解决方案**：

**Windows系统**：
```bash
# 方法1：直接安装（推荐，如果可用）
pip install TA-Lib>=0.4.28

# 方法2：如果方法1失败，使用预编译wheel文件
# 1. 访问：https://www.lfd.uci.edu/~gohlke/pythonlibs/#ta-lib
# 2. 根据Python版本下载对应文件（如：TA_Lib-0.4.28-cp313-win_amd64.whl）
# 3. 安装：pip install TA_Lib-0.4.28-cp313-win_amd64.whl

# 方法3：使用conda（如果使用conda环境）
conda install -c conda-forge ta-lib
```

**Linux系统**：
```bash
# Ubuntu/Debian
sudo apt-get install ta-lib
pip install TA-Lib>=0.4.28

# CentOS/RHEL
sudo yum install ta-lib-devel
pip install TA-Lib>=0.4.28
```

**macOS系统**：
```bash
brew install ta-lib
pip install TA-Lib>=0.4.28
```

**验证安装**：
```bash
python -c "import talib; print('talib安装成功，版本:', talib.__version__)"
```

**注意**：如果talib安装失败，系统会自动回退到pandas计算技术指标，但可能与证券公司看到的值不一致。
