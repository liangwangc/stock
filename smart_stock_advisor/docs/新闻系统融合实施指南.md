def _execute_cls_news_sync(self, task: Dict):
    """执行财联社新闻同步任务"""
    try:
        from utils.news_sync_from_cls import NewsSyncFromCls
        sync = NewsSyncFromCls()
        since = datetime.now() - timedelta(hours=1)
        result = sync.sync_all(news_limit=500, analysis_limit=500)
        return {
            'success': True,
            'message': f"同步完成: 新闻={result['news']['synced']}, 分析={result['analysis']['synced']}"
        }
    except Exception as e:
        self.logger.error(f"同步失败: {str(e)}")
        return {'success': False, 'error': str(e)}

## 三、使用融合后的数据

### 3.1 在股票预测中使用LLM分析结果

编辑 `predictor/stock_predictor.py`，优先使用LLM分析结果：

```python
def _get_news_sentiment(self, symbol: str, news_list: List[Dict]) -> float:
    """获取新闻情感得分（优先使用LLM分析）"""
    sentiment_scores = []
    
    for news in news_list:
        # 优先使用LLM情感得分
        if news.get('llm_sentiment_score') is not None:
            sentiment_scores.append(news['llm_sentiment_score'])
        # 降级使用关键词分析
        elif news.get('sentiment_score') is not None:
            sentiment_scores.append(news['sentiment_score'])
    
    if sentiment_scores:
        return sum(sentiment_scores) / len(sentiment_scores)
    return 0.0
```

### 4.2 处理同步失败

**常见问题**：

1. **数据库连接失败**
   - 检查财联社数据库配置
   - 确认数据库服务运行正常
   - 检查网络连接

2. **同步数据重复**
   - 确认 `content_hash` 字段已正确生成
   - 检查唯一索引是否生效

3. **分析结果未同步**
   - 确认 `analysis_results` 表中有数据
   - 检查 `content_hash` 是否匹配
   - 查看同步日志中的错误信息

## 六、故障排查

### 6.1 同步脚本无法运行

**检查项**：
- Python环境是否正确
- 依赖包是否安装（pandas, sqlalchemy, pymysql）
- 数据库连接配置是否正确

### 6.2 数据未同步

**检查项**：
- 财联社数据库是否有新数据
- `content_hash` 是否匹配
- 同步日志是否有错误信息

### 6.3 LLM分析结果缺失

**检查项**：
- `analysis_results` 表中是否有数据
- `news_index` 是否对应正确的 `news.id`
- `content_hash` 是否匹配
