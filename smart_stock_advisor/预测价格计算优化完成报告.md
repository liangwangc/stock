## 一、优化概述

### 1.1 优化目标

优化预测明日收盘价和涨幅的计算逻辑，使其更实用、更准确，考虑股票特性、历史波动率和价格趋势。

### 1.2 优化前的问题

1. ❌ **固定最大涨跌幅10%**：所有股票都使用10%，不符合实际规则
2. ❌ **固定tanh系数3**：不考虑股票的历史波动率
3. ❌ **没有考虑价格趋势**：只基于当前价格，没有考虑趋势
4. ❌ **计算过于简单**：不实用，预测价格不够准确

## 二、优化内容

### 2.1 根据股票特性调整最大涨跌幅

**新增函数**：`_get_max_change_pct()`

**逻辑**：
- **ST股票**：5%（涨跌停限制）
- **创业板（300开头）**：20%（涨跌停限制）
- **科创板（688开头）**：20%（涨跌停限制）
- **主板（600/000/001开头）**：10%（涨跌停限制）
- **默认**：10%

**代码位置**：`predictor/stock_predictor.py` 第2474-2502行

---

### 2.2 根据历史波动率调整tanh系数

**新增函数**：`_calculate_volatility_coefficient()`

**逻辑**：
- 计算最近20天的日收益率标准差（波动率）
- 基准波动率：2%（A股平均日波动率）
- 系数范围：1.5（低波动）到 4.5（高波动）
- 公式：`coefficient = 1.5 + (volatility / 0.02) * 1.0`

**效果**：
- 高波动股票：使用更大的系数（如4.0），预测涨跌幅范围更大
- 低波动股票：使用更小的系数（如2.0），预测涨跌幅范围更小

**代码位置**：`predictor/stock_predictor.py` 第2504-2550行

---

### 2.3 考虑价格趋势

**新增函数**：`_calculate_trend_adjustment()`

**逻辑**：
- 计算短期趋势（最近5天）
- 计算中期趋势（最近20天）
- 综合趋势：短期权重60% + 中期权重40%
- 调整因子：`1.0 + combined_trend * 0.5`
- 限制范围：0.9-1.1

**效果**：
- **上涨趋势**：调整因子 > 1.0，预测更乐观（涨跌幅更大）
- **下跌趋势**：调整因子 < 1.0，预测更保守（涨跌幅更小）

**代码位置**：`predictor/stock_predictor.py` 第2552-2595行

---

### 2.4 优化后的价格计算

**新增函数**：`_calculate_predicted_price_optimized()`

**计算公式**：
```python
# 1. 获取股票特性相关的最大涨跌幅
max_change_pct = _get_max_change_pct(symbol, stock_name)

# 2. 计算历史波动率调整系数
volatility_coefficient = _calculate_volatility_coefficient(data)

# 3. 计算价格趋势调整因子
trend_adjustment = _calculate_trend_adjustment(data)

# 4. 计算概率差异
probability_diff = up_probability - down_probability

# 5. 使用调整后的系数计算涨跌幅
predicted_change_pct = (
    tanh(probability_diff * volatility_coefficient) * 
    max_change_pct * 
    confidence * 
    trend_adjustment
)

# 6. 计算预测收盘价
predicted_close_price = current_price * (1 + predicted_change_pct / 100.0)
```

**代码位置**：`predictor/stock_predictor.py` 第2597-2645行
