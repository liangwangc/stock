# 错误修复说明

## 修复内容

### 1. 修复 `scheduled_tasks` 表不存在的错误

**错误信息**：
```
Table 'stock_data.scheduled_tasks' doesn't exist
```

**问题原因**：
- `news_task_manager.py` 中查询 `scheduled_tasks` 表时，如果表不存在会抛出错误
- 需要添加错误处理，如果表不存在则回退到使用 `news_crawl_tasks` 表

**修复方案**：
- 在 `news_task_manager.py` 的所有 `scheduled_tasks` 表查询处添加 `try-except` 错误处理
- 如果表不存在（错误代码1146或包含"doesn't exist"），记录日志并回退到使用 `news_crawl_tasks` 表
- 修改位置：
  - `start_task()` 方法（第236行）
  - `stop_task()` 方法（第312行）
  - `get_task()` 方法（第370行）
  - `get_all_tasks()` 方法（第416行）

### 2. 修复 `importance_score` 字段不存在的错误

**错误信息**：
```
Unknown column 'na.importance_score' in 'field list'
```

**问题原因**：
- `news_notification.py` 中的 `get_user_notifications()` 和 `get_notification_history()` 方法使用了 `importance_score` 字段
- 但 `news_articles` 表中可能不存在这个字段

**修复方案**：
- 在查询前动态检查 `importance_score` 字段是否存在
- 如果字段不存在，使用 `NULL as importance_score` 替代
- 修改位置：
  - `get_user_notifications()` 方法（第308-330行）
  - `get_notification_history()` 方法（第364-390行）
