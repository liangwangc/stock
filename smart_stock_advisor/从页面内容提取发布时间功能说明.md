# 从页面内容提取发布时间功能说明

## 功能概述

新增了从新闻页面内容（HTML/文本）中自动提取发布时间的功能。当新闻数据中没有提供 `time`、`publish_time` 或 `pub_time` 字段时，系统会尝试从新闻的标题和内容中提取发布时间。

## 实现方案

### 1. 创建时间提取工具类

创建了 `smart_stock_advisor/utils/news_time_extractor.py` 文件，包含 `NewsTimeExtractor` 类，提供以下功能：

#### 提取方法

1. **从HTML meta标签提取**
   - 查找常见的meta标签：`article:published_time`、`publishdate`、`pubdate`、`date`、`datePublished`
   - 查找HTML5的 `<time>` 标签

2. **从常见位置提取**
   - 从内容开头500字符和结尾500字符中查找时间（时间通常在开头或结尾）

3. **使用正则表达式匹配**
   - 支持多种时间格式：
     - `2026-01-14 15:30:00`
     - `2026-01-14 15:30`
     - `2026-01-14`
     - `2026年1月14日 15:30:00`
     - `2026年1月14日 15:30`
     - `2026年1月14日`
     - `2026/01/14 15:30:00`
     - `2026.01.14 15:30:00`
     - 等等

4. **解析相对时间**
   - 支持相对时间关键词：
     - `刚刚`、`刚才` → 当前时间
     - `1分钟前`、`10分钟前`、`30分钟前` → 计算相对时间
     - `1小时前`、`2小时前`、`3小时前` → 计算相对时间
     - `今天`、`今日` → 当前时间
     - `昨天`、`昨日` → 24小时前
     - `前天` → 48小时前

### 2. 集成到新闻存储模块

修改了 `smart_stock_advisor/utils/news_storage.py` 的 `save_news_article` 方法：

```python
# 优化：如果从字段中没有获取到时间，尝试从内容中提取
if not publish_time and (content or title):
    try:
        from utils.news_time_extractor import NewsTimeExtractor
        extracted_time = NewsTimeExtractor.extract_from_content(content, title)
        if extracted_time:
            publish_time = extracted_time
            self.logger.debug(f"从内容中提取到发布时间: {title[:50]}... -> {extracted_time}")
    except Exception as e:
        self.logger.debug(f"从内容提取时间失败: {str(e)}")
```

## 工作流程

1. **优先从字段获取**
   - 首先尝试从 `time`、`publish_time`、`pub_time` 字段获取时间

2. **从内容提取（如果字段中没有）**
   - 如果字段中没有时间，且新闻有内容或标题，则尝试从内容中提取

3. **提取策略**
   - 先尝试从HTML meta标签提取（最准确）
   - 然后从常见位置提取（开头/结尾）
   - 再使用正则表达式匹配时间模式
   - 最后尝试解析相对时间

4. **时间验证**
   - 验证提取的时间是否合理（不能是未来时间，不能早于2000年）
   - 如果提取失败，使用当前时间作为默认值

## 支持的时间格式

### 标准格式
- `2026-01-14 15:30:00`
- `2026-01-14 15:30`
- `2026-01-14`

### 中文格式
- `2026年1月14日 15:30:00`
- `2026年1月14日 15:30`
- `2026年1月14日`

### 斜杠格式
- `2026/01/14 15:30:00`
- `2026/01/14 15:30`

### 点格式
- `2026.01.14 15:30:00`
- `2026.01.14 15:30`

### 相对时间
- `刚刚`、`刚才`
- `1分钟前`、`10分钟前`、`30分钟前`
- `1小时前`、`2小时前`、`3小时前`
- `今天`、`今日`
- `昨天`、`昨日`
- `前天`

## 使用示例

```python
from utils.news_time_extractor import NewsTimeExtractor

# 示例1: 从HTML内容中提取
html_content = """
<html>
<head>
    <meta property="article:published_time" content="2026-01-14 15:30:00">
</head>
<body>
    <h1>新闻标题</h1>
    <p>新闻内容...</p>
</body>
</html>
"""
publish_time = NewsTimeExtractor.extract_from_content(html_content)
# 结果: datetime(2026, 1, 14, 15, 30, 0)

# 示例2: 从文本内容中提取
text_content = "发布时间：2026年1月14日 15:30:00\n新闻内容..."
publish_time = NewsTimeExtractor.extract_from_content(text_content)
# 结果: datetime(2026, 1, 14, 15, 30, 0)

# 示例3: 相对时间
text_content = "1小时前发布的新闻..."
publish_time = NewsTimeExtractor.extract_from_content(text_content)
# 结果: 当前时间 - 1小时
```

## 优势

1. **提高时间获取率**：即使新闻源没有提供时间字段，也能从内容中提取
2. **支持多种格式**：支持标准格式、中文格式、相对时间等多种时间表示方式
3. **智能提取**：优先从最准确的位置（meta标签）提取，然后尝试其他方法
4. **容错性强**：如果提取失败，使用当前时间作为默认值，不会影响新闻保存

## 注意事项

1. **性能考虑**：从内容中提取时间需要解析文本，可能影响性能。建议只在字段中没有时间时才使用。

2. **准确性**：从内容中提取的时间可能不如直接从字段获取准确，但总比没有时间好。

3. **日志记录**：成功提取时间时会记录日志，便于调试和监控。
