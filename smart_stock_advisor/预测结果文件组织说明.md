# 预测结果文件组织说明

## 文件目录结构

所有预测相关的结果文件现在都统一存放在 `reports/` 目录下：

```
smart_stock_advisor/
├── reports/                          # 预测结果文件目录（新建）
│   ├── prediction_600362_*.png       # PNG图形报告
│   ├── prediction_600362_*_interactive.html    # 交互式图表
│   ├── prediction_600362_*_full_report.html    # 完整HTML报告
│   └── history_*.html                # 历史预测页面
├── stock_list.html                   # 股票列表页面（根目录）
└── stock_predictions.csv             # 预测记录CSV文件（根目录）
```

## 文件说明

### 1. `reports/` 目录
- **PNG图形报告** (`prediction_{symbol}_{timestamp}.png`)
  - 包含涨跌概率饼图、雷达图、柱状图、技术分析图表等
  
- **交互式图表** (`prediction_{symbol}_{timestamp}_interactive.html`)
  - 可交互的30天价格走势图
  - 支持鼠标悬停查看详细信息
  
- **完整HTML报告** (`prediction_{symbol}_{timestamp}_full_report.html`)
  - 包含所有预测分析的完整报告
  - 包含可滚动的个股预测分析部分

### 2. 根目录文件
- **`stock_list.html`**
  - 股票预测列表主页面
  - 所有链接已自动指向 `reports/` 目录下的文件
  
- **`history_{symbol}.html`**（已移至reports目录）
  - 单个股票的历史预测记录页面
  - 保存在 `reports/` 目录下
  - 包含返回 `stock_list.html` 的链接（使用相对路径 `../stock_list.html`）

## 路径引用说明

### HTML文件中的路径
- **`stock_list.html`**（根目录）：
  - 使用相对路径指向 `reports/` 目录：`reports/prediction_*.png`、`reports/prediction_*_full_report.html`
  - 历史预测链接：`reports/history_{symbol}.html`
  
- **`history_{symbol}.html`**（在 `reports/` 目录下）：
  - 返回列表链接：`../stock_list.html`（指向上一级目录的stock_list.html）
  - 图形报告和文字详情链接：使用相对于reports目录的路径（因为都在同一目录下）

### CSV文件中的路径
- `stock_predictions.csv` 中保存的是绝对路径或相对于项目根目录的路径
- 在生成HTML时，会自动转换为相对路径

## 迁移旧文件（可选）

如果您之前已经在根目录生成了预测结果文件，可以：

1. **手动迁移**（推荐）：
   ```bash
   # 创建reports目录
   mkdir reports
   
   # 移动PNG文件
   move prediction_*.png reports/
   
   # 移动HTML文件
   move prediction_*.html reports/
   ```

2. **保持现状**：
   - 旧文件可以保留在根目录
   - 新生成的文件会自动保存到 `reports/` 目录
   - 不影响系统运行

## 优势

1. **文件组织清晰**：所有预测结果文件集中在一个目录
2. **易于管理**：方便备份、删除或归档历史预测结果
3. **目录整洁**：根目录更加清爽，只保留主要的HTML列表文件
4. **路径统一**：所有文件路径引用都使用相对路径，便于部署

## 注意事项

1. **浏览器打开**：
   - 使用浏览器打开 `stock_list.html` 时，需要确保文件结构完整
   - 如果通过 `file://` 协议打开，相对路径应该是正确的
   - 如果部署到Web服务器，路径同样适用

2. **备份**：
   - 备份时建议同时备份 `reports/` 目录和 `stock_predictions.csv` 以及 `stock_list.html`
   - 这样恢复时可以保持文件关联关系

3. **清理**：
   - 可以定期清理 `reports/` 目录中的旧预测结果文件（PNG、HTML报告）
   - 历史预测页面（`history_*.html`）也保存在 `reports/` 目录，可以一起管理
   - 但注意不要删除 `stock_list.html` 中仍在引用的文件
