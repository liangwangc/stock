## 一、前置条件

### 1.1 安装talib库（必需）

**Windows系统**：
```bash
# 方法1：直接安装（推荐）
pip install TA-Lib>=0.4.28

# 方法2：如果方法1失败，使用预编译wheel文件
# 1. 访问：https://www.lfd.uci.edu/~gohlke/pythonlibs/#ta-lib
# 2. 根据Python版本下载对应文件（如：TA_Lib-0.4.28-cp313-win_amd64.whl）
# 3. 安装：pip install TA_Lib-0.4.28-cp313-win_amd64.whl
```

**Linux系统**：
```bash
sudo apt-get install ta-lib  # Ubuntu/Debian
pip install TA-Lib>=0.4.28
```

**macOS系统**：
```bash
brew install ta-lib
pip install TA-Lib>=0.4.28
```

**验证安装**：
```bash
python -c "import talib; print('talib安装成功，版本:', talib.__version__)"
```

**注意**：如果talib未安装，脚本会回退到pandas计算（可能与证券公司值不一致）。

## 二、性能估算

假设数据库中有：
- 5500只股票
- 每只股票平均200个交易日
- 总共约110万条记录

**预计耗时**：
- 单只股票（如000019）：约10-30秒
- 100只股票：约10-30分钟
- 所有股票（5500只）：约1-3小时

**优化建议**：
- 可以先更新最近的数据（如最近30天）
- 然后逐步更新历史数据
- 或者按日期范围分批更新
