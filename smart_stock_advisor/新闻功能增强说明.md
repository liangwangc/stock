# 新闻功能增强说明

## 改进概述

针对用户反馈"新闻指标没有很好地用起来"的问题，进行了以下增强：

1. **添加更多财经新闻源**
2. **改进新闻筛选逻辑，纳入行业/产业相关新闻**
3. **优化新闻情感分析的使用**

## 详细改进

### 1. 新增财经新闻源

#### 东方财富新闻源 (`eastmoney_news_source.py`)
- 获取股票相关新闻
- 获取市场新闻
- 支持HTML解析

#### 雪球新闻源 (`xueqiu_news_source.py`)
- 通过API获取股票相关新闻
- 获取热门话题和市场新闻
- 支持股票代码转换（如000001 -> SZ000001）

### 2. 行业相关新闻筛选

#### 新增功能：`get_stock_industry_info()`
- 位置：`smart_stock_advisor/data_source/stock_data_source.py`
- 功能：获取股票的行业和概念板块信息
- 返回：
  ```python
  {
      'industry': '行业名称',
      'concepts': ['概念1', '概念2', ...],
      'industry_keywords': ['行业关键词1', ...]
  }
  ```

#### 改进的新闻获取逻辑
- **位置**：`quant_trading_platform/news/unified_news_source.py`
- **改进点**：
  1. `get_stock_news()` 方法新增 `industry_keywords` 参数
  2. 不仅获取直接提到股票的新闻，还筛选包含行业/概念关键词的市场新闻
  3. 新闻标记相关性：`direct`（直接相关）、`industry`（行业相关）
  4. 按相关性排序：直接相关 > 行业相关 > 其他

#### 改进的新闻评分计算
- **位置**：`smart_stock_advisor/predictor/stock_predictor.py`
- **改进点**：
  1. 自动获取股票行业信息
  2. 使用行业关键词筛选相关新闻
  3. 统计直接相关和行业相关的新闻数量
  4. 日志输出更详细的新闻分析信息

### 3. 配置更新

#### `smart_stock_advisor/config.py`
```python
# 新增新闻源
NEWS_SOURCES = [
    "jin10",      # 金十数据
    "caixin",     # 财新
    "securities", # 证券公司
    "tonghuashun", # 同花顺
    "eastmoney",  # 东方财富（新增）
    "xueqiu"      # 雪球（新增）

# 新闻分析配置优化

    "news_count": 15,             # 增加新闻数量
    "include_industry_news": True, # 包含行业相关新闻

```

### 4. 依赖更新

#### `quant_trading_platform/requirements.txt`
新增依赖：
- `requests>=2.28.0` - HTTP请求库
- `beautifulsoup4>=4.11.0` - HTML解析库

## 使用效果

### 改进前
- 只获取直接提到股票代码的新闻
- 新闻源较少（4个）
- 行业相关风险新闻可能被忽略

### 改进后
- ✅ 获取直接提到股票的新闻
- ✅ 自动获取行业/概念相关新闻（即使不直接提到股票）
- ✅ 新闻源增加到6个
- ✅ 更全面的新闻覆盖，提高预测准确性

## 示例

假设分析股票 `000001`（平安银行）：

1. **获取行业信息**：
   - 行业：银行
   - 概念：金融科技、数字货币等

2. **获取新闻**：
   - 直接相关：包含"000001"或"平安银行"的新闻
   - 行业相关：包含"银行"、"金融科技"等关键词的市场新闻

3. **情感分析**：
   - 综合直接相关和行业相关新闻的情感
   - 行业相关新闻权重为0.7（相对于直接相关新闻）

## 注意事项

1. **新闻源可用性**：
   - 部分新闻源可能需要处理反爬虫机制
   - 如果某个新闻源初始化失败，会自动跳过，不影响其他新闻源

2. **行业信息获取**：
   - 依赖 akshare 的接口
   - 如果获取失败，会降级为仅使用直接相关新闻

3. **性能考虑**：
   - 行业相关新闻筛选会增加一些计算时间
   - 已优化为只筛选必要的新闻

## 后续优化建议

1. **缓存机制**：对行业信息进行缓存，避免重复查询
2. **新闻权重调整**：根据新闻来源和时效性调整权重
3. **更多新闻源**：可以继续添加证券时报、中国证券报等权威媒体
4. **智能关键词扩展**：自动扩展行业相关关键词（如同义词、上下游产业等）
