# 美股板块行情功能说明

## 功能概述

新增了**美股板块行情**作为预测因子，通过分析美股各板块的走势来影响A股相应板块的预测。由于美股比A股早一天收盘，可以利用美股前一天的收盘数据来预测A股当天的走势。

## 实现细节

### 1. 美股板块与A股板块映射

建立了美股板块与A股行业/概念的映射关系：

| 美股板块 | A股对应行业/概念 |
|---------|----------------|
| 科技 | 计算机、电子、通信、软件、互联网、人工智能、芯片、半导体 |
| 金融 | 银行、证券、保险、金融、信托 |
| 医疗 | 医药、医疗、生物、医疗器械、生物医药 |
| 能源 | 石油、天然气、煤炭、能源、电力 |
| 消费 | 消费、零售、商贸、电商、消费电子 |
| 工业 | 机械、工业、制造、装备、自动化 |
| 材料 | 化工、钢铁、有色金属、材料、建材 |
| 公用事业 | 公用事业、水务、燃气、环保 |
| 房地产 | 房地产、地产、建筑、基建 |
| 通信 | 通信、5G、通信设备、电信 |
| 消费必需品 | 食品、饮料、农业、食品饮料 |

### 2. 数据获取

- **位置**：`smart_stock_advisor/data_source/stock_data_source.py`
- **函数**：`get_us_sector_data()`
- **数据源**：使用akshare获取美股ETF数据
  - 科技板块：XLK (Technology Select Sector SPDR Fund)
  - 金融板块：XLF (Financial Select Sector SPDR Fund)
  - 医疗板块：XLV (Health Care Select Sector SPDR Fund)
  - 能源板块：XLE (Energy Select Sector SPDR Fund)
  - 消费板块：XLY (Consumer Discretionary Select Sector SPDR Fund)
  - 工业板块：XLI (Industrial Select Sector SPDR Fund)
  - 材料板块：XLB (Materials Select Sector SPDR Fund)
  - 公用事业：XLU (Utilities Select Sector SPDR Fund)
  - 房地产：XLRE (Real Estate Select Sector SPDR Fund)
  - 通信：XLC (Communication Services Select Sector SPDR Fund)
  - 消费必需品：XLP (Consumer Staples Select Sector SPDR Fund)
  - 整体市场：SPY (SPDR S&P 500 ETF)

### 3. 得分计算

- **位置**：`smart_stock_advisor/predictor/stock_predictor.py`
- **函数**：`calculate_us_sector_score()`
- **逻辑**：
  1. 根据股票的行业/概念信息，找到对应的美股板块
  2. 获取美股板块最近5天的数据
  3. 计算最近一天的涨跌幅和平均涨跌幅
  4. 使用加权平均计算得分（归一化到-1到1之间）
  5. 如果找不到对应板块，使用标普500（SPY）作为整体市场参考

### 4. 权重配置

- **位置**：`smart_stock_advisor/config.py`
- **配置项**：`us_sector_weight: 0.10`（10%权重）
- **调整**：技术指标权重从0.35调整为0.30，为美股板块让出5%权重

### 5. 最终得分计算

最终得分公式更新为：
```python
final_score = (
    technical_score * 0.30 +      # 技术指标（30%）
    news_score * 0.25 +           # 新闻情感（25%）
    market_score * 0.15 +         # 市场情绪（15%）
    history_score * 0.10 +        # 历史模式（10%）
    valuation_score * 0.05 +      # 估值指标（5%）
    us_sector_score * 0.10        # 美股板块（10%，新增）
)
```

### 6. 可视化更新

- **雷达图**：新增"美股板块"维度，显示5个因素（技术指标、新闻情感、市场情绪、历史模式、美股板块）
- **总结文本**：在预测总结中加入美股板块信息，包括板块名称、涨跌幅和得分

## 使用效果

### 优势

1. **提前预警**：美股比A股早一天收盘，可以利用美股走势提前判断A股板块走势
2. **全球联动**：考虑全球市场对A股的影响，提高预测准确性
3. **板块映射**：通过行业映射，精准匹配美股板块与A股板块

### 示例

假设分析一只科技股（如000001）：

1. **识别板块**：系统识别该股票属于"计算机"行业
2. **匹配美股板块**：找到对应的美股板块为"科技"（XLK）
3. **获取数据**：获取XLK最近5天的收盘数据
4. **计算得分**：如果XLK上涨2%，则美股板块得分为正，有利于A股科技股上涨
5. **综合预测**：将美股板块得分（10%权重）纳入最终预测

## 配置说明

### 修改权重

在 `config.py` 中修改：
```python
PREDICTION_CONFIG = {
    "us_sector_weight": 0.10,  # 可以调整这个值（0-1之间）
    ...
}
```

### 修改板块映射

在 `stock_data_source.py` 的 `get_us_sector_mapping()` 函数中修改映射关系。

### 添加新板块

1. 在 `get_us_sector_data()` 的 `sector_etf_map` 中添加新的ETF映射
2. 在 `get_us_sector_mapping()` 中添加A股行业映射

## 注意事项

1. **数据可用性**：依赖akshare的美股数据接口，如果接口不可用，会返回空数据，得分默认为0
2. **时差影响**：美股收盘时间比A股早，需要考虑时差因素
3. **映射准确性**：板块映射关系可能需要根据实际情况调整
4. **权重平衡**：美股板块权重不宜过高，建议保持在5-15%之间

## 后续优化建议

1. **更多板块**：可以添加更多细分板块（如新能源、半导体等）
2. **相关性分析**：分析历史数据，计算美股板块与A股板块的相关性系数
3. **动态权重**：根据相关性动态调整权重
4. **其他市场**：可以考虑加入港股、欧洲股市等作为参考
