# 两阶段训练策略方案

**创建日期**：2026-01-14  
**策略**：先用历史数据训练基础模型，后期用预测数据微调

---

## 一、策略分析

### ✅ 1.1 方案可行性

**阶段1：基础模型训练（使用stock_history_data表）**
- ✅ **数据量充足**：10年历史数据，数百万条记录
- ✅ **数据完整**：价格、技术指标、资金流向等特征齐全
- ✅ **标签清晰**：使用未来1天的涨跌幅作为标签
- ✅ **训练稳定**：数据量大，模型泛化能力强

**阶段2：增量微调（使用stock_predictions表）**
- ✅ **数据真实**：基于实际预测结果，更贴近实际应用
- ✅ **持续更新**：可以定期使用新的预测数据微调
- ✅ **适应变化**：适应市场环境变化和模型性能变化

**结论**：✅ **完全可行，这是业界常用的预训练+微调策略**

---

### ✅ 1.2 优势分析

**优势1：充分利用数据**
- 历史数据量大，训练基础模型效果好
- 预测数据真实，微调后更贴近实际应用

**优势2：模型稳定性**
- 基础模型在大数据上训练，泛化能力强
- 微调时只需要少量数据，避免过拟合

**优势3：持续优化**
- 可以定期使用新的预测数据微调
- 模型可以适应市场环境变化

**优势4：风险控制**
- 基础模型作为保底，即使微调失败也有基础模型可用
- 可以对比基础模型和微调模型的性能

---

## 二、实施方案

### 2.1 阶段1：基础模型训练

**数据源**：`stock_history_data` 表（全量历史数据）

**训练流程**：
```
1. 加载历史数据（2014-2024，10年）
   ↓
2. 构建训练样本
   - 特征：当前日期前60天的历史数据
   - 标签：未来1天的涨跌幅（从历史数据中获取）
   ↓
3. 数据划分
   - 训练集：2014-2022（9年）
   - 验证集：2023（1年）
   - 测试集：2024（1年）
   ↓
4. 训练模型
   - XGBoost分类器
   - LightGBM分类器
   ↓
5. 保存基础模型
   - 模型文件：models/base/xgb_classifier_base.pkl
   - 模型信息：标记为base模型
```

**预期效果**：
- 训练样本数：100万+条
- 方向准确率：55-65%
- 模型稳定性：高

---

### 2.2 阶段2：增量微调

**数据源**：`stock_predictions` 表（有实际结果的预测记录）

**微调流程**：
```
1. 加载基础模型
   ↓
2. 加载新的预测数据（最近30-90天）
   ↓
3. 构建微调样本
   - 特征：从stock_history_data表获取
   - 标签：actual_change_pct（实际涨跌幅）
   ↓
4. 微调模型
   - 方法1：继续训练（warm start）
   - 方法2：调整学习率后训练
   - 方法3：只训练最后几层（如果使用神经网络）
   ↓
5. 保存微调模型
   - 模型文件：models/finetuned/xgb_classifier_finetuned_v1.pkl
   - 模型信息：标记为finetuned模型，关联base模型
```

**预期效果**：
- 微调样本数：1000-10000条
- 方向准确率：60-70%（相比基础模型提升5-10%）
- 训练时间：5-30分钟

    base_model_name='xgb_classifier_base',
    fine_tune_start_date=None,  # None表示使用最近90天
    fine_tune_end_date=None,
    learning_rate_multiplier=0.1,  # 降低学习率
    n_estimators=50  # 微调时使用较少的树
):
    """
    微调基础模型（使用stock_predictions表）
    """
    # 1. 加载基础模型
    base_model = model_manager.load_model(base_model_name)
    
    # 2. 加载微调数据
    fine_tune_df = data_loader.load_training_data(
        start_date=fine_tune_start_date,
        end_date=fine_tune_end_date
    )
    
    # 3. 准备特征和标签
    X_finetune, y_finetune, _ = feature_engineering.prepare_features(
        fine_tune_df, label_column='label_up'
    )
    
    # 4. 微调模型（warm start）
    if hasattr(base_model, 'fit'):
        # XGBoost/LightGBM支持warm start
        base_model.set_params(
            learning_rate=base_model.learning_rate * learning_rate_multiplier,
            n_estimators=n_estimators
        )
        base_model.fit(
            X_finetune, y_finetune,
            xgb_model=base_model.get_booster()  # warm start
