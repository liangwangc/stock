## 一、设置页面功能说明

**功能路径**：设置页面 → 股票数据获取 → 增量获取当日数据

**功能描述**：通过Web界面创建定时任务，自动获取股票收盘后的当日数据

---

## 二、执行流程

### 2.1 Web界面操作流程

1. **创建任务**：
   - 用户点击"创建数据获取任务"
   - 选择"中国股票"（market_type: 'cn'）
   - 选择"增量更新"（collection_type: 'incremental'）
   - 设置定时参数（schedule_type, schedule_time等）
   - 提交创建任务

2. **启动任务**：
   - 用户点击任务列表中的"启动"按钮
   - 系统调用启动API

3. **自动执行**：
   - 定时任务管理器在指定时间自动执行
   - 或手动触发立即执行

### 2.2 后端执行流程

```
Web界面
  ↓
POST /api/stock-data/tasks (创建任务)
  ↓
POST /api/scheduled/tasks/<task_id>/start (启动任务)
  ↓
ScheduledTaskManager.start_task()
  ↓
定时执行或立即执行
  ↓
_execute_cn_stock_data_collection()
  ↓
StockHistoryCollector().incremental_update_today()
```

## 四、执行参数说明

### 4.1 默认参数

**Web界面默认参数**（在 `scheduled_task_manager.py` 中）：
- `max_workers`（线程数）：**10**（从任务配置读取，默认10）
- `batch_size`（批次大小）：**1000**（从任务配置读取，默认1000）
- `delay`（延迟时间）：**1.0秒**（从任务配置读取，默认1.0）

**命令行默认参数**（在 `update_stock_history_daily.py` 中）：
- `max_workers`（线程数）：**10**
- `batch_size`（批次大小）：**100**

### 4.2 参数配置位置

**Web界面任务配置**（JSON格式）：
```json
{
  "collection_type": "incremental",
  "threads": 10,           // 线程数
  "batch_size": 1000,      // 批次大小
  "delay": 1.0            // 延迟时间（秒）
}
```

**配置位置**：
- 创建任务时在任务配置中设置
- 存储在 `scheduled_tasks` 表的 `task_config` 字段（JSON格式）

## 五、执行逻辑详解

### 5.1 增量更新逻辑

1. **获取股票列表**：
   - 如果任务配置中指定了股票列表，使用指定的列表
   - 如果未指定，从数据库 `stock_history_data` 表获取所有已有数据的股票

2. **批量查询已存在数据**：
   - 批量查询今日数据已存在的股票（每批1000只）
   - 过滤出需要处理的股票

3. **多线程采集数据**：
   - 使用线程池并发采集股票数据
   - 默认10个线程同时处理

4. **批量保存数据**：
   - 收集所有采集到的数据
   - 使用批量插入方法保存到数据库

### 5.2 执行时间

**处理时间预估**（5000只股票）：
- **原版本（单线程）**：约42分钟
- **优化版本（10线程）**：约5分钟
- **性能提升**：8-10倍
