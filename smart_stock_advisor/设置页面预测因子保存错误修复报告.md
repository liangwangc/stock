# 设置页面预测因子保存错误修复报告

## 一、问题描述

**错误信息**：
```
2026-01-27 11:13:24 - utils.db_storage - ERROR - 保存预测因子数据失败: 'list' object has no attribute 'get'
```

**问题位置**：`utils/db_storage.py` 第307行

**问题原因**：`factors.get('technical', {})` 返回的不是字典，而是列表，导致调用 `.get()` 方法失败。

## 二、问题根源

### 2.1 错误发生位置

**位置**：`utils/db_storage.py` 第307行
```python
technical = factors.get('technical', {})
```

**错误**：`factors.get('technical', {})` 返回的是列表而不是字典，导致后续调用 `technical.get('score')` 失败。

### 2.2 可能的原因

1. **结果变量类型错误**：`results.get('technical', ...)` 可能返回列表而不是字典
2. **并行任务返回格式不一致**：某些并行任务可能返回了错误的数据格式
3. **异常处理中的默认值设置错误**：在异常处理中可能设置了列表作为默认值
