# 新闻抓取优化完成总结

## 优化内容

### 1. 改进 `only_today` 参数处理

**问题**：
- 各个新闻源获取到的新闻时间字段不一致（`time`、`publish_time`、`pub_time`）
- 时间解析不准确，导致当天新闻被错误过滤

**优化**：
- 在 `unified_news_source.py` 中改进时间解析逻辑
- 尝试多个时间字段（`time`、`publish_time`、`pub_time`）
- 改进日期解析，处理各种时间格式
- 如果无法解析日期或没有时间信息，默认保留新闻（而不是过滤掉）

**修改文件**：
- `quant_trading_platform/news/unified_news_source.py`
  - `get_stock_news()` 方法（第286-304行）
  - `get_market_news()` 方法（第362-380行）

### 2. 实现"全部"新闻抓取功能

**功能**：
- 创建新方法 `crawl_all_news()`，获取所有新闻（不限制日期）
- 使用 `NewsStockMapper` 分析每条新闻，关联到股票、板块、行业
- 识别大盘相关新闻（包含"大盘"、"指数"、"A股"等关键词）
- 保存新闻时自动关联股票、板块、行业信息

**修改文件**：
- `smart_stock_advisor/utils/news_crawler.py`
  - 新增 `crawl_all_news()` 方法
  - 修改 `start_crawl_task()` 方法，当 `task_type='all'` 时，调用 `crawl_all_news()`

## 使用方法

### 创建"全部"新闻抓取任务

1. 在设置页面 -> 新闻数据获取
2. 点击"创建新任务"
3. 选择任务类型：**全部（全量新闻）**
4. 设置执行时间和间隔
5. 创建并启动任务

### 功能说明

- **全部新闻抓取**：
  - 不限制日期，获取所有新闻源的最新新闻
  - 自动分析每条新闻，关联到相关股票、板块、行业
  - 识别大盘相关新闻

- **关联分析**：
  - 使用 `NewsStockMapper` 分析新闻内容
  - 自动提取股票代码、名称
  - 关联到板块、行业
  - 识别大盘相关关键词

## 注意事项

1. **时间解析改进**：
   - 改进后的时间解析逻辑更加健壮
   - 如果新闻源没有提供时间信息，默认保留新闻
   - 这可能导致 `only_today=True` 时，包含一些非当天新闻（但数量很少）

2. **全部新闻抓取**：
   - 不限制日期，可能获取到大量新闻
   - 建议设置合理的 `limit` 参数
   - 关联分析可能耗时较长，建议在后台执行

3. **关联分析**：
   - 依赖 `NewsStockMapper` 的准确性
   - 如果新闻内容不清晰，可能无法正确关联
   - 大盘相关新闻如果未关联到具体股票，`symbol` 为 `None`（表示市场新闻）
