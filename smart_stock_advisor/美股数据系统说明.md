# 美股数据系统说明

## 概述

本系统用于收集和存储美股市场数据，包括股票基本信息、历史价格数据、板块和行业分类信息，参考A股数据库模式设计。

## 数据库表结构

### 1. us_sectors（美股板块表）
- 存储GICS板块分类信息
- 包含11个标准板块（能源、材料、工业等）
- 字段：sector_code, sector_name_en, sector_name_cn, gics_level等

### 2. us_industries（美股行业表）
- 存储GICS行业分类信息
- 关联到板块
- 字段：industry_code, industry_name_en, sector_code等

### 3. us_stock_info（美股股票基本信息表）
- 存储股票基本信息
- 包含所属板块、行业、交易所等信息
- 字段：symbol, name_en, exchange, sector_code, industry_code等

### 4. us_stock_history_data（美股历史数据表）
- 存储近10年的详细历史数据
- 参考A股stock_history_data表结构
- 包含：价格、成交量、技术指标、估值指标等
- 字段：symbol, trade_date, open_price, close_price, volume, ma5, rsi, macd等

### 5. us_sector_stock_map（板块股票映射表）
- 多对多关系表
- 记录股票所属的板块

### 6. us_industry_stock_map（行业股票映射表）
- 多对多关系表
- 记录股票所属的行业

### 7. us_sector_index_history（板块指数历史数据表）
- 存储板块ETF/指数的历史数据

## 使用方法

### 1. 创建数据库表

```bash
# 创建所有美股相关的数据库表
python scripts/create_us_stock_tables.py
```

### 2. 初始化板块数据

```bash
# 初始化GICS板块分类数据
python scripts/collect_us_stock_data.py --init-sectors
```

### 3. 获取股票列表

```bash
# 获取S&P 500成分股列表
python scripts/get_us_stock_list.py --index sp500 --output sp500_stocks.csv

# 获取NASDAQ 100成分股列表
python scripts/get_us_stock_list.py --index nasdaq100 --output nasdaq100_stocks.csv
```

### 4. 收集历史数据

#### 收集指定股票（10年数据）

```bash
# 收集单个或多个股票的历史数据
python scripts/collect_us_stock_data.py --symbols AAPL MSFT GOOGL

# 收集S&P 500所有成分股（需要较长时间）
python scripts/collect_us_stock_data.py --sp500
```

#### 使用Python代码

```python
from utils.us_stock_collector import USStockCollector

collector = USStockCollector()

# 收集单只股票
result = collector.collect_stock_history('AAPL', period='10y')
print(result)

# 批量收集
symbols = ['AAPL', 'MSFT', 'GOOGL']
result = collector.collect_batch_stocks(symbols, period='10y', delay=0.5)
print(result)
```

## 数据来源

### 主要数据源
- **yfinance**: 用于获取美股历史价格数据、股票基本信息
- **Wikipedia**: 用于获取S&P 500、NASDAQ 100等指数成分股列表
- **GICS分类**: 标准板块和行业分类

### 数据获取方式
- 股票历史数据：通过yfinance的Ticker.history()方法
- 股票基本信息：通过yfinance的Ticker.info属性
- 成分股列表：从Wikipedia页面解析HTML表格

## 数据字段说明

### 价格数据
- `open_price`: 开盘价（美元）
- `close_price`: 收盘价（美元）
- `high_price`: 最高价（美元）
- `low_price`: 最低价（美元）
- `adj_close_price`: 调整后收盘价（复权价格）

### 成交数据
- `volume`: 成交量（股）
- `amount`: 成交额（美元）
- `turnover_rate`: 换手率（%）

### 技术指标
- `ma5/ma10/ma20/ma50/ma200`: 移动平均线
- `rsi`: RSI指标
- `macd/macd_signal/macd_hist`: MACD指标
- `volatility`: 波动率（%）

### 估值指标
- `pe_ratio`: 市盈率（TTM）
- `forward_pe`: 前瞻市盈率
- `pb_ratio`: 市净率
- `ps_ratio`: 市销率
- `dividend_yield`: 股息率（%）

## 注意事项

### 1. 数据获取限制
- yfinance有请求频率限制，建议每只股票之间延迟0.5-1秒
- 批量收集大量股票时，建议分批进行

### 2. 数据完整性
- 某些字段可能为空（如期权数据、资金流向等），取决于数据源是否提供
- 技术指标会根据可用数据自动计算

### 3. 增量更新
- 系统支持增量更新，默认不会重复下载已存在的数据
- 使用`update_existing=True`参数可以强制更新已有数据
