# 数据库字段检查说明

## 📋 检查预测价格字段是否存在

### 方法1：使用Python脚本检查（推荐）

运行检查脚本：
```bash
python scripts/check_and_add_predicted_price_fields.py
```

这个脚本会：
1. ✅ 检查 `predicted_close_price` 和 `predicted_change_pct` 字段是否存在
2. ✅ 如果不存在，自动添加这些字段
3. ✅ 添加必要的索引

### 方法2：手动检查SQL

#### 1. 检查字段是否存在

```sql
-- 查看所有字段
SHOW COLUMNS FROM stock_predictions;

-- 或者只检查特定字段
SHOW COLUMNS FROM stock_predictions LIKE 'predicted_close_price';
SHOW COLUMNS FROM stock_predictions LIKE 'predicted_change_pct';
```

#### 2. 如果字段不存在，执行以下SQL添加

```sql
-- 添加 predicted_close_price 字段（明日大概收盘价格）
ALTER TABLE `stock_predictions` 
ADD COLUMN `predicted_close_price` DECIMAL(10,2) DEFAULT NULL 
COMMENT '明日大概收盘价格' 
AFTER `current_price`;

-- 添加 predicted_change_pct 字段（明日大概涨幅百分比）
ALTER TABLE `stock_predictions` 
ADD COLUMN `predicted_change_pct` DECIMAL(6,2) DEFAULT NULL 
COMMENT '明日大概涨幅百分比' 
AFTER `predicted_close_price`;

-- 添加索引（用于查询和排序）
ALTER TABLE `stock_predictions` 
ADD INDEX `idx_predicted_change_pct` (`predicted_change_pct`);
```

### 方法3：使用SQL文件

直接执行SQL文件：
```bash
# 如果使用MySQL命令行
mysql -u用户名 -p数据库名 < database/add_predicted_price_fields.sql

# 或者使用Python脚本执行
python database/add_predicted_price_fields.py
```

## ✅ 验证字段已添加

执行以下SQL验证：

```sql
-- 检查字段是否存在
SELECT 
    COLUMN_NAME, 
    DATA_TYPE, 
    COLUMN_TYPE,
    COLUMN_COMMENT
FROM INFORMATION_SCHEMA.COLUMNS 
WHERE TABLE_SCHEMA = DATABASE() 
  AND TABLE_NAME = 'stock_predictions' 
  AND COLUMN_NAME IN ('predicted_close_price', 'predicted_change_pct');

-- 检查索引是否存在
SHOW INDEXES FROM stock_predictions WHERE Key_name = 'idx_predicted_change_pct';
```

## 📊 字段说明

| 字段名 | 类型 | 说明 | 位置 |
|--------|------|------|------|
| `predicted_close_price` | DECIMAL(10,2) | 明日大概收盘价格 | 在 `current_price` 之后 |
| `predicted_change_pct` | DECIMAL(6,2) | 明日大概涨幅百分比 | 在 `predicted_close_price` 之后 |

## 🔍 检查现有数据

查看是否有数据：

```sql
-- 查看有预测价格的记录数量
SELECT 
    COUNT(*) as total,
    COUNT(predicted_close_price) as has_price,
    COUNT(predicted_change_pct) as has_change_pct
FROM stock_predictions;

-- 查看最近的预测记录（包含预测价格）
SELECT 
    symbol,
    name,
    current_price,
    predicted_close_price,
    predicted_change_pct,
    prediction_date,
    target_date
FROM stock_predictions
WHERE predicted_close_price IS NOT NULL
ORDER BY prediction_time DESC
LIMIT 10;
```

## ⚠️ 注意事项

1. **旧数据**：在添加字段之前的预测记录可能没有这些值（为NULL）
2. **重新预测**：如果需要为旧数据填充预测价格，需要重新运行预测
3. **数据完整性**：新预测会自动计算并保存这两个字段的值
