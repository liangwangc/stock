# 定时任务内存优化方案

**日期**：2026-01-16  
**问题**：新闻抓取任务占用大量内存

---

## 一、问题分析

### 1.1 发现的问题

1. **新闻抓取limit设置过大**
   - `news_crawler.py` 第288行：`effective_limit = max(limit * 5, 100)` 
   - 即使limit=15，实际也会获取至少100条新闻
   - 对于多个新闻源，总数据量会非常大

2. **内存未及时释放**
   - 新闻列表处理完后没有显式清理
   - 没有使用 `del` 或 `gc.collect()` 释放内存
   - 对象引用可能未正确释放

3. **定时任务实例管理**
   - 每次执行可能创建新的实例
   - 旧实例可能未正确清理
   - 线程资源可能未释放

4. **数据累积**
   - 如果任务执行频繁，数据可能累积
   - 没有批量处理限制

---

## 二、优化方案

### 2.1 降低新闻抓取limit

**问题代码**（`news_crawler.py` 第288行）：
```python
effective_limit = max(limit * 5, 100)  # 至少100条
```

**优化方案**：
```python
# 根据实际需求设置合理的limit
effective_limit = limit * 2  # 只获取limit*2条，用于时间过滤
# 或者根据时间范围动态计算
if interval_minutes <= 60:
    effective_limit = limit * 2  # 1小时内，获取limit*2条
elif interval_minutes <= 240:
    effective_limit = limit * 3  # 4小时内，获取limit*3条
else:
    effective_limit = limit * 5  # 更长时间，获取limit*5条
```

### 2.2 及时释放内存

**在新闻处理完成后添加清理代码**：
```python
# 处理完新闻后
try:
    # ... 处理新闻 ...
finally:
    # 清理内存
    del news_list
    del filtered_news
    import gc
    gc.collect()  # 强制垃圾回收
```

### 2.3 批量处理限制

**分批处理新闻，避免一次性加载过多数据**：
```python
BATCH_SIZE = 50  # 每批处理50条新闻

for i in range(0, len(news_list), BATCH_SIZE):
    batch = news_list[i:i+BATCH_SIZE]
    # 处理这一批
    process_batch(batch)
    # 立即清理
    del batch
    gc.collect()
```

### 2.4 优化定时任务执行

**确保任务执行完后清理资源**：
```python
def _execute_news_crawl(self, task: Dict) -> Dict:
    news_source = None
    news_storage = None
    news_crawler = None
    news_list = []
    
    try:
        # ... 执行任务 ...
        return result
    finally:
        # 清理资源
        del news_list
        if news_source:
            del news_source
        if news_storage:
            del news_storage
        if news_crawler:
            del news_crawler
        import gc
        gc.collect()
```

### 2.5 限制非增量抓取的limit

**对于非'all'类型的任务，降低limit**：
```python
# scheduled_task_manager.py 第1423行
# 原代码：limit=100
# 优化后：
news_list = news_source.get_market_news(limit=30, only_today=False)  # 降低到30条

# 第1427行
news_list = news_source.get_stock_news(symbol, limit=30, only_today=False)  # 降低到30条
```

**在关键位置添加内存使用监控**：
```python
import psutil
import os

def get_memory_usage():
    process = psutil.Process(os.getpid())
    return process.memory_info().rss / 1024 / 1024  # MB

# 在任务执行前后记录内存使用
before_memory = get_memory_usage()
# ... 执行任务 ...
after_memory = get_memory_usage()
self.logger.info(f"内存使用: {before_memory:.2f}MB -> {after_memory:.2f}MB (增加: {after_memory-before_memory:.2f}MB)")
```
