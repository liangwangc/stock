# 美股数据源问题解决方案

## 当前问题诊断

根据测试结果，当前遇到以下问题：

1. **akshare 接口问题**：
   - 错误：`'NoneType' object is not subscriptable`
   - 可能原因：接口返回 None 或接口变更

2. **yfinance 接口限制**：
   - 错误：`Too Many Requests. Rate limited. Try after a while.`
   - 原因：API 速率限制，请求过于频繁

## 解决方案

### 方案1：使用增强版数据源（推荐）⭐

系统已提供增强版数据源，支持多个备用接口，自动切换。

#### 步骤1：注册免费API密钥

**Alpha Vantage**（推荐，免费版限制较宽松）：
- 注册地址：https://www.alphavantage.co/support/#api-key
- 免费版限制：每分钟5次请求，每天500次
- 注册后立即可用

**Polygon.io**：
- 注册地址：https://polygon.io/
- 免费版限制：每分钟5次请求

**Finnhub**：
- 注册地址：https://finnhub.io/
- 免费版限制：每分钟60次请求

#### 步骤2：配置API密钥

**方式1：使用环境变量（推荐）**

在 Windows PowerShell 中：
```powershell
# 设置环境变量（当前会话）
$env:ALPHA_VANTAGE_API_KEY = "your_api_key_here"
$env:POLYGON_API_KEY = "your_api_key_here"
$env:FINNHUB_API_KEY = "your_api_key_here"
```

**方式2：创建配置文件**

创建 `smart_stock_advisor/config_us_stock.py`：
```python
# 美股数据源API密钥配置
ALPHA_VANTAGE_API_KEY = "your_api_key_here"
POLYGON_API_KEY = "your_api_key_here"
FINNHUB_API_KEY = "your_api_key_here"
```

#### 步骤3：修改代码使用增强版数据源

修改 `data_source/us_stock_data_source.py` 或相关调用代码：

```python
# 方式1：直接使用增强版
from data_source.us_stock_data_source_enhanced import EnhancedUSStockDataSource

ds = EnhancedUSStockDataSource()
df = ds.get_stock_data('AAPL', start_date='2024-01-01', end_date='2024-12-31')
```

或者修改现有代码，在 `USStockDataSource` 类中集成增强版功能。

- 使用 Alpha Vantage（免费版足够）
- 设置合理的请求间隔

### 对于大量股票（> 50只）：
- 使用增强版数据源，配置多个API密钥
- 系统会自动在接口间切换
- 考虑付费版本（如果需要）

## 注意事项

1. **API密钥安全**：
   - 不要将密钥提交到代码仓库
   - 使用环境变量或配置文件（已加入.gitignore）

2. **速率限制**：
   - 每个接口都有速率限制
   - 增强版会自动处理，在接口间切换

3. **数据一致性**：
   - 不同接口返回的数据格式可能略有不同
   - 系统会自动标准化
