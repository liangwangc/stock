## 需要手动修复的问题

### 问题1：training_metrics解析不够安全

**位置**：`templates/settings.html` 第2988行

**当前代码**：
```javascript
const trainMetrics = model.training_metrics ? JSON.parse(model.training_metrics) : {};
```

**修复为**：
```javascript
// 安全解析training_metrics（可能是字符串或对象）
let trainMetrics = {};
try {
    if (model.training_metrics) {
        if (typeof model.training_metrics === 'string') {
            trainMetrics = JSON.parse(model.training_metrics);
        } else {
            trainMetrics = model.training_metrics;
        }
    }
} catch (e) {
    console.warn('解析training_metrics失败:', e);
    trainMetrics = {};
}
```

**原因**：`training_metrics`字段可能是字符串（需要JSON.parse）或对象（直接使用），需要安全处理。
