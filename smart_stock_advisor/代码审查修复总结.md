## 二、修复详情

### 2.1 SQL注入防护

**修复前**:
```python
sql += f" LIMIT {limit}"
sql = f"UPDATE scheduled_tasks SET {', '.join(updates)} WHERE id = %s"
ORDER BY {order_by}
```

**修复后**:
```python
# 验证limit
try:
    limit_int = int(limit)
    if limit_int > 0 and limit_int <= 10000:
        sql += " LIMIT %s"
        params.append(limit_int)
except (ValueError, TypeError):
    pass

# 验证字段名
allowed_fields = {'status', 'next_run_time', ...}
if key in allowed_fields:
    updates.append(f"{key} = %s")

# 验证order_by
allowed_fields = {'prediction_time', 'prediction_date', ...}
if field in allowed_fields and direction in allowed_directions:
    safe_order_by = f"{field} {direction}"
```

### 2.2 密钥管理

**修复前**:
```python
app.config['SECRET_KEY'] = 'your-secret-key-here-change-in-production'
```

**修复后**:
```python
SECRET_KEY = os.getenv('FLASK_SECRET_KEY')
if not SECRET_KEY:
    SECRET_KEY = secrets.token_hex(32)
    logger.warning("⚠️  使用随机生成的SECRET_KEY，生产环境请设置FLASK_SECRET_KEY环境变量")
app.config['SECRET_KEY'] = SECRET_KEY
```

### 2.3 CORS配置

**修复前**:
```python
socketio = SocketIO(app, cors_allowed_origins="*", async_mode='threading')
```

**修复后**:
```python
cors_origins_env = os.getenv('CORS_ALLOWED_ORIGINS', '*')
if cors_origins_env == '*':
    logger.warning("⚠️  CORS允许所有来源，生产环境请设置CORS_ALLOWED_ORIGINS环境变量")
    allowed_origins = '*'
else:
    allowed_origins = [origin.strip() for origin in cors_origins_env.split(',')]
socketio = SocketIO(app, cors_allowed_origins=allowed_origins, async_mode='threading')
```

## 四、环境变量配置

### 生产环境必须设置

```bash
# Flask密钥（必须）
export FLASK_SECRET_KEY="your-strong-secret-key-here"

# CORS允许的来源（推荐）
export CORS_ALLOWED_ORIGINS="https://yourdomain.com,https://www.yourdomain.com"

# Alpha Vantage API密钥（可选）
export ALPHA_VANTAGE_API_KEY="your-api-key"
```

### Windows PowerShell

```powershell
# 设置环境变量（当前会话）
$env:FLASK_SECRET_KEY = "your-strong-secret-key-here"
$env:CORS_ALLOWED_ORIGINS = "https://yourdomain.com"
$env:ALPHA_VANTAGE_API_KEY = "your-api-key"

# 永久设置（需要管理员权限）
[System.Environment]::SetEnvironmentVariable('FLASK_SECRET_KEY', 'your-strong-secret-key-here', 'User')
```
