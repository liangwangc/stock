# 新闻抓取增量逻辑检查与修复说明

## 一、问题分析

### 1. 用户反馈的问题

日志显示：
```
开始增量抓取全部新闻，时间范围: 2026-01-14 16:30:04 到 2026-01-14 16:30:03
```

**问题**：
- 开始时间（16:30:04）比结束时间（16:30:03）还晚1秒，时间范围不正确
- 用户想确认：是否启动后获取当前时间往前在定时任务设置的分钟数的新闻，下一次循环又往前推
- 用户想确认：抓取的新闻是否全部存储到数据库中

### 2. 代码分析

**当前实现**（`scheduled_task_manager.py` 的 `_execute_news_crawl` 方法）：
- ❌ **没有使用增量抓取逻辑**
- ❌ **没有调用 `NewsCrawler.crawl_all_news()`**
- ❌ **没有传递 `last_fetch_time` 和 `interval_minutes`**
- ❌ **直接调用 `get_market_news(limit=200, only_today=False)`，获取所有新闻，不限制时间范围**

**正确的实现应该**（`news_crawler.py` 的 `crawl_all_news` 方法）：
- ✅ 使用 `_calculate_time_range()` 计算时间范围
- ✅ 从 `last_fetch_time` 到当前时间
- ✅ 首次获取：从当天00:00开始
- ✅ 后续获取：从上次执行时间开始
- ✅ 按时间范围过滤新闻

## 三、修复方案

### 1. 修改 `_execute_news_crawl` 方法

**需要修改**：
- 当 `task_type == 'all'` 时，使用 `NewsCrawler.crawl_all_news()` 方法
- 传递 `last_fetch_time`（从 `task.get('last_run_time')` 获取）
- 传递 `interval_minutes`（从 `task_config.get('interval_minutes')` 获取）
- 使用增量抓取逻辑

### 2. 确保新闻全部存储到数据库

**当前实现**（第1390-1406行）：

## 四、修复代码

### 修改 `_execute_news_crawl` 方法

```python
def _execute_news_crawl(self, task: Dict) -> Dict:
    """执行新闻抓取任务"""
    try:
        task_config = json.loads(task.get('task_config', '{}')) if task.get('task_config') else {}
        task_type = task_config.get('task_type', 'market')
        symbol = task_config.get('symbol', None)
        interval_minutes = task_config.get('interval_minutes', 60)
        
        try:
            from news.unified_news_source import UnifiedNewsSource
            from utils.news_storage import NewsStorage
            from utils.news_crawler import NewsCrawler
            
            news_source = UnifiedNewsSource()
            news_storage = NewsStorage()
            news_crawler = NewsCrawler()
            
            success_count = 0
            fail_count = 0
            duplicate_count = 0
            
            self.logger.info(f"开始执行新闻抓取任务，类型: {task_type}, 股票: {symbol}")
            
            if task_type == 'all':
                # 抓取全部新闻（使用增量抓取）
                # 获取上次执行时间
                last_fetch_time = None
                if task.get('last_run_time'):
                    last_run_time_str = task.get('last_run_time')
                    if isinstance(last_run_time_str, str):
                        try:
                            last_fetch_time = datetime.strptime(last_run_time_str, '%Y-%m-%d %H:%M:%S')
                        except:
                            try:
                                last_fetch_time = datetime.strptime(last_run_time_str, '%Y-%m-%d %H:%M:%S.%f')
                            except:
                                self.logger.warning(f"无法解析last_run_time: {last_run_time_str}")
                    elif isinstance(last_run_time_str, datetime):
                        last_fetch_time = last_run_time_str
                
                # 使用增量抓取
                result = news_crawler.crawl_all_news(
                    limit=task_config.get('limit', 15),  # 每个新闻源的限制数量
                    last_fetch_time=last_fetch_time,
                    interval_minutes=interval_minutes,
                    max_retries=task_config.get('max_retries', 3)
                )
                
                # crawl_all_news 内部已经保存了新闻，直接返回结果
                return {
                    'success': True,
                    'message': f"抓取完成: 成功 {result.get('success', 0)}, 重复 {result.get('duplicate', 0)}, 失败 {result.get('failed', 0)}",
                    'data': {
                        'success_count': result.get('success', 0),
                        'fail_count': result.get('failed', 0),
                        'duplicate_count': result.get('duplicate', 0),
                        'total': result.get('success', 0) + result.get('failed', 0) + result.get('duplicate', 0),
                        'time_range': result.get('time_range', {})
                    }
                }
            elif task_type == 'market':
                # 抓取市场新闻（不限制日期，获取更多新闻）
                news_list = news_source.get_market_news(limit=100, only_today=False)
                self.logger.info(f"获取到 {len(news_list)} 条市场新闻")
            elif task_type == 'stock' and symbol:
                # 抓取股票新闻（不限制日期）
                news_list = news_source.get_stock_news(symbol, limit=100, only_today=False)
                self.logger.info(f"获取到 {len(news_list)} 条股票新闻（{symbol}）")
            else:
                # 默认抓取市场新闻
                news_list = news_source.get_market_news(limit=100, only_today=False)
                self.logger.info(f"获取到 {len(news_list)} 条市场新闻（默认）")
            
            # 对于非'all'类型，保存新闻
            if task_type != 'all':
                if not news_list:
                    self.logger.warning("未获取到任何新闻")
                    return {
                        'success': False,
                        'message': '未获取到任何新闻',
                        'data': {
                            'success_count': 0,
                            'fail_count': 0,
                            'duplicate_count': 0,
                            'total': 0
                        }
                    }
                
                # 保存新闻
                for news_item in news_list:
                    try:
                        news_id = news_storage.save_news_article(news_item)
                        if news_id:
                            success_count += 1
                        else:
                            # 检查是否是重复新闻
                            title = news_item.get('title', '')
                            source = news_item.get('source', '')
                            if news_storage._check_duplicate(title, source):
                                duplicate_count += 1
                            else:
                                fail_count += 1
                    except Exception as e:
                        self.logger.error(f"保存新闻失败: {str(e)}, 标题: {news_item.get('title', '')[:50]}")
                        fail_count += 1
                
                self.logger.info(f"新闻抓取完成: 成功 {success_count}, 重复 {duplicate_count}, 失败 {fail_count}, 总计 {len(news_list)}")
                
                return {
                    'success': True,
                    'message': f"抓取完成: 成功 {success_count}, 重复 {duplicate_count}, 失败 {fail_count}",
                    'data': {
                        'success_count': success_count,
                        'fail_count': fail_count,
                        'duplicate_count': duplicate_count,
                        'total': len(news_list)
                    }
                }
```

## 五、时间范围计算逻辑

### `_calculate_time_range` 方法逻辑

1. **首次获取**（`last_fetch_time` 为 `None`）：
   - 如果当前时间是凌晨00:00-00:10，从前一天23:50开始
   - 否则从当天00:00开始
   - 结束时间：当前时间

2. **后续获取**（`last_fetch_time` 不为 `None`）：
   - 开始时间：`last_fetch_time`
   - 如果 `last_fetch_time` 是凌晨00:00，往前推10分钟
   - 结束时间：当前时间

3. **时间范围过滤**：
   - 只保留 `start_time <= 新闻时间 <= end_time` 的新闻
   - 确保增量获取，不重复获取旧新闻

## 六、新闻存储确认

### 存储流程

1. **`crawl_all_news()` 方法**：
   - 获取新闻列表
   - 按时间范围过滤
   - 调用 `news_storage.save_news_article()` 保存每条新闻
   - 返回保存结果统计

2. **`save_news_article()` 方法**：
   - 检查重复（基于标题+来源，以及SimHash）
   - 如果重复，返回 `None`
   - 如果不重复，保存到数据库，返回新闻ID

3. **存储确认**：
   - ✅ 所有新闻都会尝试保存
   - ✅ 重复新闻会被过滤（返回 `None`，计入 `duplicate_count`）
   - ✅ 保存失败的新闻会被记录（计入 `failed_count`）
   - ✅ 只有成功保存的新闻才会计入 `success_count`

## 七、修复后的行为

### 1. 首次执行

- **时间范围**：从当天00:00（或前一天23:50，如果是凌晨）到当前时间
- **获取新闻**：获取时间范围内的所有新闻
- **保存新闻**：所有新闻都会尝试保存到数据库

### 2. 后续执行

- **时间范围**：从上次执行时间（`last_run_time`）到当前时间
- **获取新闻**：获取时间范围内的所有新闻（增量）
- **保存新闻**：所有新闻都会尝试保存到数据库（重复的会被过滤）

### 3. 时间范围显示

- **日志格式**：`开始增量抓取全部新闻，时间范围: {start_time} 到 {end_time}`
- **时间格式**：`YYYY-MM-DD HH:MM:SS`
- **确保**：`start_time <= end_time`
