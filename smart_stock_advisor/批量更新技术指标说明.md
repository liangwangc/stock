# 批量更新技术指标说明

**日期**：2026-01-16  
**脚本**：`scripts/batch_update_technical_indicators.py`

---

## 一、功能说明

批量重新计算并更新数据库中的技术指标字段：
- ma5、ma10、ma20、ma60（移动平均线）
- rsi（相对强弱指标）
- macd、macd_signal、macd_hist（MACD指标）
- x2（自定义指标）

---

## 三、使用方法

### 2.1 更新所有股票的所有日期

```bash
python scripts/batch_update_technical_indicators.py
```

### 2.2 更新指定股票

```bash
python scripts/batch_update_technical_indicators.py --symbol 000019
```

### 2.3 更新指定日期范围

```bash
# 更新2026年1月的数据
python scripts/batch_update_technical_indicators.py --start-date 2026-01-01 --end-date 2026-01-31

# 更新指定股票指定日期范围
python scripts/batch_update_technical_indicators.py --symbol 000019 --start-date 2026-01-01 --end-date 2026-01-16
```

### 2.4 调整批量大小

```bash
# 批量大小500（默认）
python scripts/batch_update_technical_indicators.py --batch-size 500

# 批量大小1000（更快，但可能占用更多内存）
python scripts/batch_update_technical_indicators.py --batch-size 1000
```

### 2.5 不使用talib（即使已安装）

```bash
python scripts/batch_update_technical_indicators.py --no-talib
```

## 四、参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--symbol`, `-s` | 股票代码（如果为None，则更新所有股票） | None |
| `--start-date` | 开始日期（YYYY-MM-DD） | None（从最早的数据开始） |
| `--end-date` | 结束日期（YYYY-MM-DD） | None（到最新的数据） |
| `--batch-size` | 批量更新大小 | 500 |
| `--no-talib` | 不使用talib库（即使已安装） | False |

---

## 四、计算方式

### 4.1 优先使用talib

如果talib库已安装且未使用`--no-talib`参数：
- ✅ **MA**：使用talib.MA（标准SMA）
- ✅ **RSI**：使用talib.RSI（Wilder平滑，与证券公司一致）
- ✅ **MACD**：使用talib.MACD（标准参数：12, 26, 9）
- ⚠️ **X2**：talib没有，使用pandas计算

### 4.2 回退到pandas

如果talib库未安装或使用了`--no-talib`参数：
- ⚠️ **MA**：使用pandas rolling().mean()
- ⚠️ **RSI**：使用pandas计算（可能与证券公司值不一致）
- ⚠️ **MACD**：使用pandas ewm()计算
- ✅ **X2**：使用pandas计算

## 六、性能说明

### 5.1 批量处理

- 按股票分组处理，每只股票获取一次历史数据
- 批量更新数据库（默认500条/批）
- 使用进度条显示处理进度

### 5.2 数据要求

- **MA5**：需要至少5天数据
- **MA10**：需要至少10天数据
- **MA20**：需要至少20天数据
- **MA60**：需要至少60天数据
- **RSI**：需要至少14天数据
- **MACD**：需要至少26天数据
- **X2**：需要至少20天数据

如果数据不足，对应字段设置为NULL。

## 八、注意事项

1. **数据完整性**：脚本会为每只股票获取足够的历史数据（至少90天）来计算所有指标
2. **talib安装**：强烈建议安装talib库以确保与证券公司值一致（见"前置条件"部分）
3. **批量大小**：批量大小越大，更新越快，但可能占用更多内存
4. **数据不足**：如果某条记录的历史数据不足，对应字段会设置为NULL
5. **回退机制**：如果talib未安装，会自动回退到pandas计算（可能与证券公司值不一致）
