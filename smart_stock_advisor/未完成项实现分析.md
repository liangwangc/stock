## 二、实现方案

### 1. 夏普比率（backtest_engine.py）

**公式**：`Sharpe = (μ - rf) / σ × √annualization`

- μ：日收益率均值  
- σ：日收益率标准差  
- rf：无风险利率（日化，可简化为 0）  
- annualization：252（交易日）

**数据来源**：已有 `daily_values`，每项含 `total_value`。

**实现步骤**：

1. 从 `daily_values` 计算日收益率序列：
   ```text
   returns[i] = (V[i] - V[i-1]) / V[i-1]
   ```
2. 计算 `mean_r = mean(returns)`，`std_r = std(returns)`。
3. 若 `std_r <= 0`：返回 0。
4. 否则：`sharpe = (mean_r - 0) / std_r * sqrt(252)`。
5. 边界：`daily_values` 少于 2 条时返回 0。

**改动位置**：`utils/backtest_engine.py` 中 `_calculate_metrics`，约 5–10 行。

### 2. max_drawdown（model_performance_evaluator + web_app）

**evaluate_trading_performance** 已有 `returns` 列表（每笔交易收益率），按时间顺序。

**实现步骤**：

1. 用 `returns` 构造累计净值曲线：
   ```text
   equity[0] = 1.0
   equity[i] = equity[i-1] * (1 + returns[i]/100)
   ```
2. 求最大回撤：
   ```text
   peak = equity[0]
   max_dd = 0
   for e in equity:
       peak = max(peak, e)
       dd = (peak - e) / peak
       max_dd = max(max_dd, dd)
   max_drawdown = max_dd * 100  # 转为百分比
   ```
3. 在 `performance_result` 中新增 `max_drawdown`。

**web_app 修改**：

将 `'max_drawdown': 0` 改为 `'max_drawdown': trading_result.get('max_drawdown', 0)`。

**改动位置**：

- `utils/model_performance_evaluator.py`：`evaluate_trading_performance` 中增加 max_drawdown 计算，约 10–15 行。
- `web_app.py`：1 行替换。

### 3. 夏普比率（model_performance_evaluator）

**evaluate_trading_performance** 中的 `returns` 是“每笔交易收益率”，不是日收益率，不能直接按日化夏普公式。

**两种做法**：

**方案 A（推荐）**：按交易序列计算“交易夏普”

- 把每笔交易视为一个样本，计算：
  - `mean_r = mean(returns)`  
  - `std_r = std(returns)`  
- 若 `std_r <= 0`：sharpe = 0。
- 否则：`sharpe = mean_r / std_r * sqrt(len(returns))`（年化因子用 √N 近似）。
- 含义：单位风险的超额收益，可与其他策略做横向比较。

**方案 B**：按时间展开为日收益率

- 需要每笔交易对应的持有天数，按日拆分收益率再年化。
- 实现复杂，且 `evaluate_trading_performance` 当前结构未提供日级序列，暂不推荐。

**改动位置**：`utils/model_performance_evaluator.py` 中 `evaluate_trading_performance` 内，在已有 `returns` 后增加 sharpe 计算，约 5–8 行；并在 `performance_result` 中增加 `sharpe_ratio`。
