# 用户管理功能说明

## 功能概述

用户管理功能提供了完整的用户账户管理系统，包括用户创建、编辑、删除，以及单点登录（SSO）支持。

## 数据库设计

### 1. 用户表（users）

存储用户基本信息：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键，自增 |
| username | VARCHAR(50) | 用户名（唯一） |
| password_hash | VARCHAR(255) | 密码哈希值 |
| role | VARCHAR(20) | 角色（admin/user） |
| email | VARCHAR(100) | 邮箱（可选） |
| is_active | TINYINT(1) | 是否激活（1=激活，0=禁用） |
| last_login | DATETIME | 最后登录时间 |
| last_login_ip | VARCHAR(50) | 最后登录IP |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |

### 2. 用户会话表（user_sessions）

存储用户登录会话信息，用于实现单点登录：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键，自增 |
| user_id | BIGINT | 用户ID（外键） |
| session_id | VARCHAR(255) | 会话ID（唯一） |
| ip_address | VARCHAR(50) | IP地址 |
| user_agent | VARCHAR(500) | 用户代理 |
| login_time | DATETIME | 登录时间 |
| last_activity | DATETIME | 最后活动时间 |
| is_active | TINYINT(1) | 是否活跃（1=活跃，0=已退出） |

## 功能特性

### 1. 单点登录（SSO）

**实现原理**：
- 用户登录时，系统生成唯一的 `session_id` 并存储到数据库
- 新登录会自动使该用户的所有其他会话失效
- 每个请求前通过 `@app.before_request` 验证会话有效性
- 如果会话无效，自动清除session并重定向到登录页

**使用效果**：
- 一个账户只能在一个地方登录
- 如果用户在A处登录，然后在B处登录，A处的会话会自动失效
- A处用户需要重新登录才能继续使用

### 2. 用户管理

**管理员权限**：
- 查看所有用户列表
- 创建新用户
- 编辑用户信息（密码、角色、邮箱、激活状态）
- 删除用户（软删除，设置为非激活状态）

**安全限制**：
- 不能删除自己的账户
- 不能删除最后一个管理员账户
- 密码长度至少6位
- 密码使用哈希存储，不会明文保存

### 3. 会话管理

**自动清理**：
- 系统可以自动清理过期的会话（超过24小时未活动）
- 通过 `UserManager.cleanup_expired_sessions()` 方法实现

**会话验证**：
- 每次请求自动验证会话有效性
- 无效会话自动清除并重定向登录

## 使用说明

### 1. 初始化数据库

首次使用前，需要初始化数据库表：

```bash
cd D:\wjw_work\smart_stock_advisor
py database/init_database.py
```

这会自动创建：
- `users` 表
- `user_sessions` 表
- 默认admin用户（用户名：admin，密码：admin123）

### 2. 访问用户管理

1. 启动Web应用：
   ```bash
   py web_app.py
   ```

2. 使用管理员账户登录（默认：admin / admin123）

3. 点击导航栏的"设置"按钮

4. 在设置页面点击"用户管理"标签页

### 3. 添加用户

1. 在用户管理页面点击"➕ 添加用户"按钮
2. 填写用户信息：
   - 用户名（必填，唯一）
   - 密码（必填，至少6位）
   - 角色（admin 或 user）
   - 邮箱（可选）
3. 点击"创建"按钮

### 4. 编辑用户

1. 在用户列表中找到要编辑的用户
2. 点击"✏️ 编辑"按钮
3. 修改用户信息：
   - 新密码（留空则不修改）
   - 角色
   - 邮箱
   - 激活状态
4. 点击"保存"按钮

### 5. 删除用户

1. 在用户列表中找到要删除的用户
2. 点击"🗑️ 删除"按钮
3. 确认删除

**注意**：
- 删除是软删除，用户会被设置为非激活状态
- 不能删除自己的账户
- 不能删除最后一个管理员账户

## API接口

### 获取用户列表
```
GET /api/users
权限：仅管理员
返回：用户列表（不包含密码哈希）
```

### 创建用户
```
POST /api/users
权限：仅管理员
请求体：
{
    "username": "用户名",
    "password": "密码",
    "role": "admin|user",
    "email": "邮箱（可选）"
}
```

### 更新用户
```
PUT /api/users/<user_id>
权限：仅管理员
请求体：
{
    "password": "新密码（可选）",
    "role": "admin|user",
    "email": "邮箱",
    "is_active": 1|0
}
```

### 删除用户
```
DELETE /api/users/<user_id>
权限：仅管理员
注意：不能删除自己，不能删除最后一个管理员
```

## 技术实现

### 密码安全

- 使用 `werkzeug.security.generate_password_hash()` 生成密码哈希
- 使用 `werkzeug.security.check_password_hash()` 验证密码
- 密码永远不会以明文形式存储或传输

### 会话管理

- 使用 `secrets.token_urlsafe()` 生成唯一的会话ID
- 会话ID存储在Flask session中
- 数据库会话表记录所有活跃会话
- 通过外键关联用户表，支持级联删除

### 单点登录实现

```python
@app.before_request
def check_session():
    """在每个请求前检查会话有效性"""
    if 'user_id' in session and 'session_id' in session:
        um = get_user_manager()
        if um and USE_DATABASE:
            session_info = um.validate_session(session.get('session_id'))
            if not session_info:
                # 会话无效，清除并重定向
                session.clear()
                if request.endpoint and request.endpoint != 'login':
                    return redirect(url_for('login'))
```

## 注意事项

1. **数据库依赖**：
   - 用户管理功能需要数据库支持
   - 如果 `USE_DATABASE = False`，系统会回退到内存用户字典

2. **默认用户**：
   - 首次启动时，如果数据库中没有admin用户，会自动创建
   - 默认用户名：admin，密码：admin123
   - **建议首次登录后立即修改密码**

3. **会话过期**：
   - 默认会话有效期为24小时
   - 可以通过 `UserManager.cleanup_expired_sessions()` 清理过期会话

4. **权限控制**：
   - 只有管理员可以访问用户管理功能
   - 普通用户无法查看或修改其他用户信息

5. **单点登录限制**：
   - 如果用户在其他地方登录，当前会话会立即失效
   - 需要重新登录才能继续使用

## 故障排除

### 问题1：无法创建用户

**可能原因**：
- 用户名已存在
- 密码长度不足6位
- 数据库连接失败

**解决方法**：
- 检查用户名是否唯一
- 确保密码至少6位
- 检查数据库配置和连接

### 问题2：登录后立即被退出

**可能原因**：
- 会话验证失败
- 数据库会话表未正确创建
- 会话ID不匹配

**解决方法**：
- 检查数据库表是否正确创建
- 查看日志中的错误信息
- 清除浏览器cookie后重新登录

### 问题3：无法访问用户管理

**可能原因**：
- 当前用户不是管理员
- API接口权限检查失败

**解决方法**：
- 使用管理员账户登录
- 检查session中的role字段是否为'admin'
