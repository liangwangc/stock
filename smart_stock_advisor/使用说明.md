# Smart Stock Advisor 使用说明

## 功能概述

Smart Stock Advisor 是一个智能股票预测系统，通过综合分析技术指标、新闻情感、市场情绪和历史模式等多个维度，预测股票明天的涨跌概率。

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行预测

#### 方式1：命令行参数

```bash
python main.py --symbol 600519
```

#### 方式2：交互式输入

```bash
python main.py
```

然后输入股票代码（如：600519）

#### 方式3：简化版可视化

```bash
python main.py --symbol 600519 --simple
```

## 预测维度说明

系统从以下四个维度进行分析：

### 1. 技术指标分析（权重：40%）

- **MACD指标**：判断趋势和买卖信号
- **RSI指标**：判断超买超卖状态
- **移动平均线**：判断趋势方向
- **价格动量**：分析价格变化速度
- **成交量分析**：判断资金流向

### 2. 新闻情感分析（权重：30%）

- **新闻来源**：金十数据、财新、各大证券公司
- **情感分析**：利好/利空/中性判断
- **影响力评估**：根据新闻重要性加权

### 3. 市场情绪分析（权重：20%）

- **整体走势**：最近20天的涨跌情况
- **波动率**：市场波动程度
- **趋势判断**：上涨/下跌/震荡

### 4. 历史模式分析（权重：10%）

- **涨跌概率**：历史涨跌天数统计
- **连续涨跌**：连续上涨/下跌天数
- **模式识别**：识别历史相似走势

## 输出结果说明

### 1. 预测概率

- **上涨概率**：0-100%，表示明天上涨的可能性
- **下跌概率**：0-100%，表示明天下跌的可能性
- **置信度**：预测的可靠程度（0-100%）

### 2. 可视化图表

系统会生成包含以下内容的可视化图表：

1. **涨跌概率饼图**：直观显示上涨和下跌的概率
2. **概率柱状图**：对比上涨和下跌概率
3. **各因素得分雷达图**：展示技术指标、新闻情感、市场情绪、历史模式的得分
4. **价格走势图**：显示最近30天的价格走势

### 3. 详细分析报告

- 各因素得分和趋势
- 技术指标信号
- 新闻情感分析结果
- 市场情绪判断
- 历史模式识别

## 配置说明

可以在 `config.py` 中调整以下参数：

### 预测权重配置

```python
PREDICTION_CONFIG = {
    "technical_weight": 0.4,      # 技术指标权重
    "news_weight": 0.3,           # 新闻情感权重
    "market_weight": 0.2,         # 市场情绪权重
    "history_weight": 0.1,        # 历史模式权重
    "min_confidence": 0.5,        # 最小置信度
    "lookback_days": 60           # 回看天数
}
```

### 技术指标参数

```python
INDICATOR_CONFIG = {
    "ma_short": 5,        # 短期均线
    "ma_long": 20,        # 长期均线
    "rsi_period": 14,     # RSI周期
    "macd_fast": 12,      # MACD快线
    "macd_slow": 26,      # MACD慢线
    "macd_signal": 9      # MACD信号线
}
```

## 注意事项

1. **预测仅供参考**：预测结果不构成投资建议，股市有风险，投资需谨慎
2. **数据获取**：需要网络连接获取股票数据和新闻数据
3. **新闻源限制**：部分新闻源可能需要API密钥或受反爬虫限制
4. **预测准确性**：预测准确性受多种因素影响，建议结合其他分析方法
5. **市场环境**：在极端市场环境下，预测准确性可能降低

## 常见问题

### Q: 为什么新闻数据获取失败？

A: 可能的原因：
- 网络连接问题
- 新闻源API限制
- 反爬虫机制

系统会在新闻数据不可用时自动降级，仅使用技术指标进行预测。

### Q: 如何提高预测准确性？

A: 建议：
- 结合多个时间周期的分析
- 关注市场整体趋势
- 参考多个数据源
- 不要过度依赖单一指标

### Q: 预测结果如何解读？

A: 
- **上涨概率 > 60%**：较强的上涨信号
- **下跌概率 > 60%**：较强的下跌信号
- **概率在 40%-60%**：震荡可能性较大
- **置信度 > 70%**：预测可靠性较高

### Q: 可以预测多只股票吗？

A: 可以，多次运行程序，每次输入不同的股票代码即可。
