# 股票数据获取功能说明

## 一、功能概述

股票数据获取功能允许用户在设置页面创建定时任务，自动获取中国股票和美股的历史数据，并存储到数据库中。

## 二、功能特点

### 1. 支持两种市场
- ✅ **中国股票**：支持A股市场的股票数据获取
- ✅ **美国股票**：支持美股市场的股票数据获取

### 2. 支持两种收集方式
- ✅ **增量更新**：每日收盘后更新最新的交易数据
- ✅ **全量收集**：收集股票的历史数据（可指定时间范围）

### 3. 定时任务管理
- ✅ 支持每日、每周、每月定时执行
- ✅ 支持启动/停止任务
- ✅ 任务状态实时显示
- ✅ 执行历史记录查询

### 4. 列表展示与分页
- ✅ 任务列表支持分页显示（每页20条）
- ✅ 历史记录支持分页显示（每页20条）
- ✅ 数据量大时自动分页，提高加载速度

## 三、使用方法

### 1. 创建中国股票数据获取任务

**步骤**：
1. 进入设置页面 → "股票数据获取"页签
2. 点击"创建数据获取任务"按钮
3. 填写任务信息：
   - 任务名称：例如"每日中国股票数据更新"
   - 市场类型：选择"中国股票"
   - 收集类型：
     - 增量更新：每日收盘后更新最新数据
     - 全量收集：收集历史数据（可指定年数，默认10年）
   - 股票列表（可选）：输入股票代码，多个用逗号分隔，如：`600519,000001,600000`
   - 执行时间：选择执行频率和执行时间，如：每日 18:00
4. 点击"创建任务"

**任务配置示例**：
```json
{
  "task_name": "每日中国股票数据更新",
  "market_type": "cn",
  "collection_type": "incremental",
  "schedule_type": "daily",
  "schedule_time": "18:00",
  "symbols": null  // 为空则处理所有股票
}
```

### 2. 创建美国股票数据获取任务

**步骤**：
1. 进入设置页面 → "股票数据获取"页签
2. 点击"创建数据获取任务"按钮
3. 填写任务信息：
   - 任务名称：例如"S&P 500历史数据收集"
   - 市场类型：选择"美国股票"
   - 收集类型：
     - 增量更新：获取最近30天的数据（需要指定股票列表）
     - 全量收集：收集历史数据（可指定周期：1y/5y/10y）
   - 指数类型（全量收集时）：可选择"S&P 500"或"NASDAQ 100"，或指定股票列表
   - 股票列表（可选）：输入股票代码，多个用逗号分隔，如：`AAPL,MSFT,GOOGL`
   - 执行时间：选择执行频率和执行时间
4. 点击"创建任务"

**任务配置示例**：
```json
{
  "task_name": "S&P 500历史数据收集",
  "market_type": "us",
  "collection_type": "full",
  "schedule_type": "daily",
  "schedule_time": "02:00",
  "index_type": "sp500",
  "period": "10y"
}
```

### 3. 管理任务

**启动任务**：
- 在任务列表中找到要启动的任务
- 点击"启动"按钮
- 任务将按照设定的时间自动执行

**停止任务**：
- 在任务列表中找到正在运行的任务
- 点击"停止"按钮
- 确认后任务将停止执行

**删除任务**：
- 在任务列表中找到要删除的任务
- 点击"删除"按钮
- 确认后任务将被删除（无法恢复）

### 4. 查看历史记录

- 点击"查看历史记录"按钮
- 系统会显示所有任务的历史执行记录
- 历史记录按时间倒序排列
- 支持分页浏览（每页20条）

## 四、数据存储

### 中国股票数据
- **表名**：`stock_history_data`
- **字段**：包括股票代码、名称、交易日期、开盘价、收盘价、最高价、最低价、成交量、成交额、外盘、内盘、成本分布、委比等技术指标

### 美国股票数据
- **表名**：`us_stock_history_data`
- **字段**：包括股票代码、名称、交易日期、开盘价、收盘价、最高价、最低价、成交量、MA5/10/20/50/200、RSI、MACD等技术指标

## 五、API接口

### 1. 获取任务列表
```
GET /api/stock-data/tasks?page=1&page_size=20&task_type=stock_data_collection_cn
```

**参数**：
- `page`：页码（默认1）
- `page_size`：每页数量（默认20）
- `task_type`：任务类型（可选，`stock_data_collection_cn` 或 `stock_data_collection_us`）

**返回**：
```json
{
  "success": true,
  "data": [...],
  "total": 10,
  "page": 1,
  "page_size": 20,
  "total_pages": 1
}
```

### 2. 创建任务
```
POST /api/stock-data/tasks
Content-Type: application/json

{
  "task_name": "每日中国股票数据更新",
  "market_type": "cn",
  "collection_type": "incremental",
  "schedule_type": "daily",
  "schedule_time": "18:00",
  "symbols": ["600519", "000001"]
}
```

### 3. 获取历史记录
```
GET /api/stock-data/tasks/<task_id>/history?page=1&page_size=20
```

**返回**：
```json
{
  "success": true,
  "data": [...],
  "total": 50,
  "page": 1,
  "page_size": 20,
  "total_pages": 3
}
```

## 六、注意事项

1. **执行时间建议**：
   - 增量更新：建议在收盘后执行（如：18:00）
   - 全量收集：建议在非交易时间执行（如：凌晨2:00）

2. **资源消耗**：
   - 全量收集可能会消耗大量时间和资源
   - 建议分批执行，避免一次性处理过多股票

3. **网络要求**：
   - 美股数据获取需要稳定的网络连接
   - 建议在网络稳定的环境下执行

4. **数据完整性**：
   - 增量更新会跳过已存在的数据（默认）
   - 全量收集支持覆盖已存在的数据

5. **任务状态**：
   - 任务状态实时更新
   - 运行中的任务可以随时停止
   - 停止的任务可以重新启动

## 七、故障排查

### 问题1：任务创建失败
- 检查任务名称是否为空
- 检查市场类型和收集类型是否选择正确
- 检查执行时间配置是否正确

### 问题2：任务执行失败
- 查看任务历史记录，查看错误信息
- 检查网络连接是否正常
- 检查股票代码是否正确
- 检查数据库连接是否正常

### 问题3：数据未更新
- 检查任务是否已启动（is_active = 1）
- 检查任务执行时间是否已到
- 查看任务历史记录，确认是否执行成功
- 检查数据库中是否有数据

### 问题4：分页显示不正确
- 检查分页参数是否正确
- 检查返回数据总数是否正确
- 检查前端分页逻辑是否正确
