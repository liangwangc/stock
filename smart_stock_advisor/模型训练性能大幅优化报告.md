## 二、性能瓶颈分析

### 2.1 主要瓶颈：重复创建DataFrame

**问题**：
- `_extract_features_from_history()` 函数为每个样本都创建DataFrame
- 对于每只股票，如果有几百个样本，就要创建几百次DataFrame
- 每次创建DataFrame都要：
  1. 转换字典列表为DataFrame（慢）
  2. 检查日期排序（慢）
  3. 填充技术指标（慢）
  4. 计算估值指标中位数（慢）

**代码位置**：
- `utils/ml_data_loader.py` 第549行：`features = self._extract_features_from_history(history_records)`
- `utils/ml_data_loader.py` 第179行：`df = pd.DataFrame(history_data)`

**性能影响**：
- 假设每只股票有400个样本
- 每个样本创建DataFrame耗时约10-50ms
- 单只股票：400 × 20ms = 8秒
- 5336只股票：5336 × 8秒 = 42688秒（约12小时）

---

## 三、优化方案

### 3.1 批量特征提取（核心优化）

**优化策略**：
1. **为每只股票创建一次DataFrame**：避免为每个样本都创建
2. **预先填充技术指标**：一次性填充所有缺失值
3. **预先计算估值指标中位数**：一次性计算，避免重复计算
4. **使用DataFrame切片**：使用`iloc`切片提取历史数据，而不是创建新的DataFrame

**优化代码位置**：
- `utils/ml_data_loader.py` 第713-792行：`process_single_stock`函数

**优化前**：
```python
for i in range(min_history_days, len(records_sorted) - lookahead_days + 1):
    history_records = records_sorted[i - min_history_days:i]
    # 每次调用都创建DataFrame
    features = self._extract_features_from_history(history_records)
```

**优化后**：
```python
# 为整只股票创建一次DataFrame
df_all = pd.DataFrame(records_sorted)
# 预先填充技术指标（一次性）
for field in technical_fields:
    df_all[field] = df_all[field].ffill()
# 预先计算估值指标中位数（一次性）
valuation_medians = {...}

# 遍历样本时，使用DataFrame切片
for i in range(min_history_days, len(records_sorted) - lookahead_days + 1):
    df_history = df_all.iloc[history_start_idx:history_end_idx]
    df_current = df_all.iloc[i:i+1]
    # 使用快速函数，避免重复创建DataFrame
    features = self._extract_features_from_history_fast(df_history, df_current, valuation_medians)
```
