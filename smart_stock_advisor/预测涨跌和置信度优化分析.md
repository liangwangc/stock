## 一、当前实现分析

### 1.1 涨跌概率计算

#### 当前实现
```python
# 代码位置：predictor/stock_predictor.py 第4192行
up_probability = 1 / (1 + np.exp(-final_score * 3))  # 放大系数为3

```

#### 问题分析

**问题1：固定放大系数**
- 放大系数 `3` 是固定值，可能不适合所有情况
- 不同股票、不同市场状态可能需要不同的放大系数
- 如果 `final_score` 分布不均匀，固定系数可能导致概率映射不准确

**问题2：未考虑市场状态**
- 牛市、熊市、震荡市可能需要不同的概率映射方式
- 当前实现没有根据市场状态动态调整

**问题3：未考虑历史准确率**
- 如果历史预测准确率较低，应该降低概率的置信度
- 当前实现没有考虑历史表现

## 二、优化建议

### 2.1 优化涨跌概率计算

#### 建议1：动态调整Sigmoid放大系数

**措施**：
1. **根据市场状态调整**：牛市使用更大的系数，熊市使用更小的系数
2. **根据股票特性调整**：高波动股票使用更大的系数，低波动股票使用更小的系数
3. **根据历史准确率调整**：如果历史准确率低，使用更保守的系数

**实现方案**：
```python
def _calculate_dynamic_sigmoid_coefficient(self, final_score: float, 
                                          market_state: Dict,
                                          volatility_coefficient: float,
                                          historical_accuracy: float = None) -> float:
    """
    动态计算Sigmoid放大系数
    
    Args:
        final_score: 最终得分
        market_state: 市场状态
        volatility_coefficient: 波动率系数
        historical_accuracy: 历史准确率（可选）
    
    Returns:
        动态放大系数
    """
    base_coefficient = 3.0  # 基础系数
    
    # 1. 根据市场状态调整
    market_state_name = market_state.get('state', 'sideways')
    if market_state_name == 'bull_market':
        market_multiplier = 1.2  # 牛市，增加系数
    elif market_state_name == 'bear_market':
        market_multiplier = 0.8  # 熊市，降低系数
    else:
        market_multiplier = 1.0  # 震荡市，不变
    
    # 2. 根据波动率调整（高波动股票使用更大系数）
    volatility_multiplier = 0.8 + (volatility_coefficient - 1.5) / (4.5 - 1.5) * 0.4
    volatility_multiplier = max(0.8, min(1.2, volatility_multiplier))
    
    # 3. 根据历史准确率调整（如果可用）
    accuracy_multiplier = 1.0
    if historical_accuracy is not None:
        # 如果历史准确率低于50%，降低系数（更保守）
        if historical_accuracy < 0.5:
            accuracy_multiplier = 0.7 + historical_accuracy * 0.6
        else:
            accuracy_multiplier = 1.0
    
    # 综合调整
    dynamic_coefficient = base_coefficient * market_multiplier * volatility_multiplier * accuracy_multiplier
    
    # 限制范围：2.0-5.0
    dynamic_coefficient = max(2.0, min(5.0, dynamic_coefficient))
    
    return dynamic_coefficient
```

#### 建议2：使用校准的概率映射

**措施**：
1. **概率校准**：根据历史预测准确率校准概率
2. **校准曲线**：使用校准曲线调整概率，使其更接近实际准确率

**实现方案**：
```python
def _calibrate_probability(self, raw_probability: float, 
                          symbol: str = None,
                          historical_accuracy: float = None) -> float:
    """
    校准概率，使其更接近实际准确率
    
    Args:
        raw_probability: 原始概率
        symbol: 股票代码（用于获取历史准确率）
        historical_accuracy: 历史准确率（可选）
    
    Returns:
        校准后的概率
    """
    if historical_accuracy is None:
        # 如果没有历史准确率，使用默认校准
        # 假设原始概率普遍偏高，需要降低
        calibrated = raw_probability * 0.9 + 0.05  # 稍微降低，但不要过度
    else:
        # 根据历史准确率校准
        # 如果历史准确率低，说明原始概率偏高，需要降低
        calibration_factor = historical_accuracy / 0.6  # 假设60%是基准
        calibration_factor = max(0.7, min(1.3, calibration_factor))
        calibrated = raw_probability * calibration_factor
    
    # 限制范围：0.1-0.9（避免极端概率）
    calibrated = max(0.1, min(0.9, calibrated))
    
    return calibrated
```

### 2.2 优化置信度计算

#### 建议1：改进基础置信度计算

**措施**：
1. **考虑得分分布**：根据 `final_score` 的分布调整置信度
2. **考虑得分强度**：得分越极端（接近±1），置信度越高
3. **考虑得分稳定性**：如果得分波动大，降低置信度

**实现方案**：
```python
def _calculate_base_confidence_enhanced(self, final_score: float,
                                       factor_scores: Dict,
                                       recent_scores: List[float] = None) -> float:
    """
    增强版基础置信度计算
    
    Args:
        final_score: 最终得分
        factor_scores: 各因子得分
        recent_scores: 最近几次的得分（用于计算稳定性）
    
    Returns:
        基础置信度（0-1）
    """
    # 1. 基于得分绝对值（原有方法）
    score_based = min(abs(final_score) * 0.5 + 0.5, 1.0)
    
    # 2. 基于得分强度（得分越极端，置信度越高）
    score_strength = abs(final_score)
    strength_based = score_strength * 0.8 + 0.2  # 0.2-1.0
    
    # 3. 基于得分稳定性（如果最近得分波动大，降低置信度）
    stability_based = 1.0
    if recent_scores and len(recent_scores) >= 3:
        score_std = np.std(recent_scores)
        # 如果标准差大，说明不稳定，降低置信度
        stability_based = max(0.5, 1.0 - score_std * 2)
    
    # 4. 综合计算
    base_confidence = (
        score_based * 0.40 +
        strength_based * 0.30 +
        stability_based * 0.30
    )
    
    return base_confidence
```

#### 建议2：改进因子一致性计算

**措施**：
1. **考虑因子相关性**：如果因子之间高度相关，一致性应该更高
2. **考虑因子权重**：根据因子权重加权计算一致性
3. **考虑因子方向**：如果所有因子方向一致，提高一致性

**实现方案**：
```python
def _calculate_factor_consistency_enhanced(self, final_score: float,
                                          factor_scores: Dict,
                                          factor_weights: Dict = None) -> float:
    """
    增强版因子一致性计算
    
    Args:
        final_score: 最终得分
        factor_scores: 各因子得分
        factor_weights: 各因子权重（可选）
    
    Returns:
        因子一致性（0-1）
    """
    if not factor_scores:
        return 0.5
    
    # 1. 计算因子方向一致性
    positive_factors = sum(1 for score in factor_scores.values() if score > 0.01)
    negative_factors = sum(1 for score in factor_scores.values() if score < -0.01)
    neutral_factors = len(factor_scores) - positive_factors - negative_factors
    
    # 如果大部分因子方向一致，一致性高
    max_direction_count = max(positive_factors, negative_factors)
    direction_consistency = max_direction_count / len(factor_scores)
    
    # 2. 计算因子得分一致性（使用标准差）
    scores_array = np.array(list(factor_scores.values()))
    score_std = np.std(scores_array)
    # 标准差越小，一致性越高
    score_consistency = max(0.0, 1.0 - score_std * 2)
    
    # 3. 如果提供了权重，使用加权一致性
    if factor_weights:
        weighted_scores = []
        for factor_name, score in factor_scores.items():
            weight = factor_weights.get(factor_name, 1.0)
            weighted_scores.append(score * weight)
        weighted_std = np.std(weighted_scores)
        weighted_consistency = max(0.0, 1.0 - weighted_std * 2)
    else:
        weighted_consistency = score_consistency
    
    # 4. 综合一致性
    consistency = (
        direction_consistency * 0.50 +
        score_consistency * 0.25 +
        weighted_consistency * 0.25
    )
    
    return consistency
```

#### 建议3：增加市场波动性因子

**措施**：
1. **市场波动性**：如果市场波动大，降低置信度
2. **个股波动性**：如果个股波动大，降低置信度
3. **相关性**：如果个股与市场相关性低，降低置信度

**实现方案**：
```python
def _calculate_market_volatility_factor(self, market_state: Dict,
                                       data: pd.DataFrame) -> float:
    """
    计算市场波动性因子
    
    Args:
        market_state: 市场状态
        data: 股票历史数据
    
    Returns:
        波动性因子（0-1），1表示低波动，0表示高波动
    """
    # 1. 市场状态波动性
    market_volatility = 1.0
    if market_state.get('state') == 'bear_market':
        market_volatility = 0.7  # 熊市波动大
    elif market_state.get('state') == 'bull_market':
        market_volatility = 0.9  # 牛市波动较小
    else:
        market_volatility = 0.8  # 震荡市波动中等
    
    # 2. 个股波动性（如果数据可用）
    stock_volatility = 1.0
    if not data.empty and len(data) >= 20:
        if 'change_pct' in data.columns:
            returns = data['change_pct'].tail(20).values / 100.0
            volatility = np.std(returns)
            # 波动率越高，因子越低
            stock_volatility = max(0.5, 1.0 - volatility * 10)
    
    # 3. 综合波动性因子
    volatility_factor = (market_volatility + stock_volatility) / 2
    
    return volatility_factor
```
