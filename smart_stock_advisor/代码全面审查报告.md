## 一、安全漏洞检查

### 🔴 高危问题

#### 1.1 SQL注入风险

**问题1**: `utils/stock_prediction_db.py` 第387行
```python
if limit:
    sql += f" LIMIT {limit}"
```
**风险**: 虽然`limit`通常是数字，但直接拼接存在SQL注入风险  
**影响**: 如果`limit`来自用户输入且未验证，可能导致SQL注入  
**修复建议**:
```python
if limit:
    # 验证limit是正整数
    try:
        limit_int = int(limit)
        if limit_int > 0:
            sql += " LIMIT %s"
            params.append(limit_int)
    except (ValueError, TypeError):
        pass  # 忽略无效的limit
```

**问题2**: `utils/scheduled_task_manager.py` 第886行
```python
sql = f"UPDATE scheduled_tasks SET {', '.join(updates)} WHERE id = %s"
```
**风险**: `updates`中的字段名直接拼接，如果字段名来自用户输入可能被注入  
**影响**: 如果字段名未验证，可能导致SQL注入  
**修复建议**:
```python
# 验证字段名只包含字母、数字和下划线
allowed_fields = {'status', 'next_run_time', 'last_run_time', 'run_count', 'error_count'}
updates = []
params = []
for key, value in kwargs.items():
    if key in allowed_fields and value is not None:
        updates.append(f"{key} = %s")
        params.append(value)
```

# 验证order_by只包含允许的字段名和排序方向
allowed_order_fields = {'prediction_time', 'prediction_date', 'target_date', 'confidence', 'final_score'}

### 8.1 SQL注入修复

**文件**: `utils/stock_prediction_db.py`

```python
def get_predictions(self, symbol: str = None, limit: int = None, 
                   order_by: str = 'prediction_time DESC', 
                   prediction_type: str = None) -> List[Dict]:
    # 验证limit
    if limit is not None:
        try:
            limit_int = int(limit)
            if limit_int <= 0 or limit_int > 10000:  # 设置上限
                limit_int = None
        except (ValueError, TypeError):
            limit_int = None
    else:
        limit_int = None
    
    # 验证order_by（只允许特定字段和方向）
    allowed_fields = {'prediction_time', 'prediction_date', 'target_date', 
                     'confidence', 'final_score', 'current_price'}
    allowed_directions = {'ASC', 'DESC'}
    
    # 解析order_by
    order_parts = order_by.strip().split()
    if len(order_parts) == 2:
        field, direction = order_parts
        if field in allowed_fields and direction.upper() in allowed_directions:
            safe_order_by = f"{field} {direction.upper()}"
        else:
            safe_order_by = "prediction_time DESC"  # 默认
    else:
        safe_order_by = "prediction_time DESC"  # 默认
    
    # 构建SQL
    sql = f"""
        SELECT * FROM stock_predictions 
        {where_clause}
        ORDER BY {safe_order_by}
    """
    
    params = list(params) if params else []
    if limit_int:
        sql += " LIMIT %s"
        params.append(limit_int)
    
    results = self.db.execute_query(sql, tuple(params) if params else None)
```
