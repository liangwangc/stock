# 设置页面页签切换修复说明

**创建日期**：2026-01-15

---

## 一、问题描述

设置页面的页签点击后无法切换到对应的页面内容。

---

## 二、问题原因

1. **`event.target` 未定义**：原代码使用 `event.target.classList.add('active')`，但通过 `onclick` 属性调用时，`event` 对象可能未正确传递。

2. **菜单项查找逻辑不可靠**：通过解析 `onclick` 属性来查找对应的菜单项，容易出错。

---

## 三、修复方案

### 3.1 使用 `data-panel` 属性

**修改前**：
```html
<button class="menu-item" onclick="switchPanel('task')">股票分析任务管理</button>
```

**修改后**：
```html
<button class="menu-item active" data-panel="task">股票分析任务管理</button>
```

### 3.2 使用事件监听器

**修改前**：依赖 `onclick` 属性

**修改后**：使用 `addEventListener` 绑定点击事件，更可靠

```javascript
document.addEventListener('DOMContentLoaded', function() {
    const menuItems = document.querySelectorAll('.menu-item');
    menuItems.forEach(item => {
        item.addEventListener('click', function(e) {
            e.preventDefault();
            e.stopPropagation();
            const panelName = this.getAttribute('data-panel');
            if (panelName) {
                switchPanel(panelName);
            }
        });
    });
});
```

### 3.3 优化 `switchPanel` 函数

**修改前**：
```javascript
event.target.classList.add('active');
```

**修改后**：
```javascript
// 找到对应的菜单项并添加active状态（优先使用data-panel属性）
const menuItems = document.querySelectorAll('.menu-item');
menuItems.forEach(item => {
    const dataPanel = item.getAttribute('data-panel');
    if (dataPanel === panelName) {
        item.classList.add('active');
    }
});
```
