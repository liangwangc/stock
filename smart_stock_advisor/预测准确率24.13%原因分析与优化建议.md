## 一、准确率计算依据

### 1.1 数据来源

**数据表**：`stock_predictions`  
**时间范围**：最近30天  
**计算字段**：`prediction_hit`（预测命中）

**SQL查询**：
```sql
SELECT 
    COUNT(*) as total,
    SUM(CASE WHEN prediction_hit = '命中' THEN 1 ELSE 0 END) as hit_count
FROM stock_predictions
WHERE target_date >= DATE_SUB(NOW(), INTERVAL 30 DAY)
  AND prediction_hit IS NOT NULL
```

**计算公式**：
```
准确率 = (命中数 / 总数) × 100%
```

**代码位置**：`utils/system_monitor.py` 第104-116行

### 1.2 命中判断标准

**判断逻辑**：
- 预测方向 = 实际方向 → `prediction_hit = '命中'`
- 预测方向 ≠ 实际方向 → `prediction_hit = '未命中'`

**方向定义**：
- **上涨**：`actual_change_pct > 0`
- **下跌**：`actual_change_pct < 0`
- **震荡**：`actual_change_pct = 0` 或接近0

## 二、准确率低的主要原因分析

### 2.1 因子过多导致偏差（可能原因之一）✅

#### 问题描述

当前系统使用了**9个因子**：
1. **技术指标**（technical）
2. **新闻情感**（news）
3. **资金流向**（capital_flow）
4. **市场情绪**（market）
5. **历史模式**（history）
6. **估值指标**（valuation）
7. **美股板块**（us_sector）
8. **板块轮动**（sector_rotation）
9. **ML模型**（ml）

#### 因子过多的问题

1. **因子冲突**：
   - 不同因子可能给出相反信号
   - 例如：技术指标看涨，但新闻情感看跌
   - 加权平均后，信号可能被稀释

2. **因子相关性**：
   - 某些因子可能高度相关（如市场情绪和市场指数）
   - 重复计算导致过度拟合

3. **因子权重分配**：
   - 9个因子需要合理分配权重
   - 权重分配不当会导致预测偏差

4. **因子数据质量**：
   - 某些因子数据可能不完整或不准确
   - 低质量因子会影响整体预测

#### 影响分析

**24.13%准确率意味着**：
- 100次预测中，只有24次方向正确
- **低于随机猜测水平（50%）**
- 说明预测模型存在系统性偏差

### 2.2 其他可能原因

#### 原因1：因子权重不合理 ⚠️

**问题**：
- 权重可能基于历史数据优化，不适应当前市场
- 某些因子权重过高或过低
- 权重调整过于频繁，导致预测不稳定

**检查方法**：
```sql
-- 查看最近预测的因子权重分布
SELECT 
    symbol,
    prediction_date,
    JSON_EXTRACT(factor_weights, '$.technical') as technical_weight,
    JSON_EXTRACT(factor_weights, '$.news') as news_weight,
    JSON_EXTRACT(factor_weights, '$.capital_flow') as capital_flow_weight,
    prediction_hit
FROM stock_predictions
WHERE target_date >= DATE_SUB(NOW(), INTERVAL 30 DAY)
  AND prediction_hit IS NOT NULL
LIMIT 100;
```

#### 原因2：概率校准问题 ⚠️

**问题**：
- 上涨/下跌概率可能不够准确
- 概率校准机制可能不够完善
- 极端概率（接近0或1）可能过度自信

**检查方法**：
```sql
-- 查看预测概率分布
SELECT 
    CASE 
        WHEN up_probability > 0.7 THEN '高概率上涨'
        WHEN up_probability < 0.3 THEN '高概率下跌'
        ELSE '震荡'
    END as probability_range,
    COUNT(*) as count,
    SUM(CASE WHEN prediction_hit = '命中' THEN 1 ELSE 0 END) as hit_count,
    SUM(CASE WHEN prediction_hit = '命中' THEN 1 ELSE 0 END) * 100.0 / COUNT(*) as accuracy
FROM stock_predictions
WHERE target_date >= DATE_SUB(NOW(), INTERVAL 30 DAY)
  AND prediction_hit IS NOT NULL
GROUP BY probability_range;
```

#### 原因3：市场环境变化 ⚠️

**问题**：
- 市场可能处于异常波动期
- 预测模型不适应当前市场状态
- 市场风格切换（从牛市到熊市）

**检查方法**：
```sql
-- 查看不同市场状态下的准确率
SELECT 
    DATE(target_date) as date,
    COUNT(*) as total,
    SUM(CASE WHEN prediction_hit = '命中' THEN 1 ELSE 0 END) as hit_count,
    SUM(CASE WHEN prediction_hit = '命中' THEN 1 ELSE 0 END) * 100.0 / COUNT(*) as accuracy
FROM stock_predictions
WHERE target_date >= DATE_SUB(NOW(), INTERVAL 30 DAY)
  AND prediction_hit IS NOT NULL
GROUP BY DATE(target_date)
ORDER BY date DESC;
```

#### 原因4：数据质量问题 ⚠️

**问题**：
- 历史数据不完整
- 实时数据获取异常
- 新闻数据质量下降

**检查方法**：

## 三、优化建议

### 3.1 因子优化（针对因子过多问题）

#### 建议1：减少因子数量 ⭐⭐⭐

**措施**：
1. **保留核心因子**（5-6个）：
   - 技术指标（technical）
   - 新闻情感（news）
   - 资金流向（capital_flow）
   - 市场情绪（market）
   - ML模型（ml）

2. **移除或降低权重**：
   - 估值指标（valuation）：权重很低（2%），影响小
   - 美股板块（us_sector）：相关性可能不高
   - 板块轮动（sector_rotation）：数据可能不稳定

**实现方式**：
- 在设置页面调整因子权重
- 将低价值因子权重设为0或接近0

#### 建议2：优化因子权重分配 ⭐⭐⭐

**措施**：
1. **执行权重优化**：
   - 使用模型学习功能优化权重
   - 基于历史准确率调整权重

2. **动态调整权重**：
   - 根据市场状态调整权重
   - 根据数据质量调整权重

**实现方式**：
- 设置页面 → 模型学习 → 权重优化
- 使用最近30天的预测数据优化权重

#### 建议3：提高因子数据质量 ⭐⭐

**措施**：
1. **数据完整性检查**：
   - 确保各因子数据完整
   - 缺失数据时降低权重

2. **数据时效性**：
   - 确保使用最新数据
   - 避免使用过期数据

**实现方式**：
- 系统已实现数据质量评分
- 根据数据质量自动调整权重

### 3.2 概率校准优化

#### 建议1：改进概率校准 ⭐⭐

**措施**：
1. **根据历史准确率校准**：
   - 如果历史准确率低，降低概率
   - 如果历史准确率高，提高概率

2. **过滤极端概率**：
   - 限制概率范围在0.1-0.9
   - 避免过度自信

**实现方式**：
- 系统已实现概率校准（`_calibrate_probability`）
- 可以调整校准参数

#### 建议2：动态调整Sigmoid系数 ⭐⭐

**措施**：
1. **根据市场状态调整**：
   - 牛市：使用更大系数
   - 熊市：使用更小系数

2. **根据波动率调整**：
   - 高波动股票：使用更大系数
   - 低波动股票：使用更小系数

**实现方式**：
- 系统已实现动态Sigmoid系数（`_calculate_dynamic_sigmoid_coefficient`）
- 可以调整系数范围

### 3.3 置信度优化

#### 建议1：提高置信度阈值 ⭐⭐

**措施**：
1. **只预测高置信度股票**：
   - 提高最小置信度阈值（从0.5提高到0.6或0.7）
   - 低置信度股票不预测或标记为"震荡"

2. **根据置信度过滤**：
   - 只统计高置信度预测的准确率
   - 低置信度预测不计入准确率

**实现方式**：
- 设置页面 → 预测参数配置 → 最小置信度

#### 建议2：优化置信度计算 ⭐

**措施**：
1. **考虑因子一致性**：
   - 如果因子方向一致，提高置信度
   - 如果因子方向冲突，降低置信度

2. **考虑市场波动性**：
   - 市场波动大时，降低置信度
   - 市场稳定时，提高置信度

**实现方式**：
- 系统已实现因子一致性和市场波动性计算
- 可以调整权重

### 3.4 模型学习优化

#### 建议1：执行权重优化 ⭐⭐⭐

**措施**：
1. **使用模型学习功能**：
   - 设置页面 → 模型学习 → 权重优化
   - 基于最近30天的预测数据优化权重

2. **应用优化后的权重**：
   - 保存优化后的权重配置
   - 激活优化后的配置

**实现方式**：
- 设置页面 → 模型学习 → 权重优化
