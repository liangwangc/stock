# 股票分析任务从数据库获取股票列表优化完成报告

## 一、问题描述

**错误信息**：
```
调用 stock_zh_a_spot_em 失败（已重试 3 次）: ('Connection aborted.', RemoteDisconnected('Remote end closed connection without response'))
获取股票列表失败: ('Connection aborted.', RemoteDisconnected('Remote end closed connection without response'))
【获取股票列表】成功获取 0 只股票
【错误】未获取到任何股票，任务终止
```

**问题原因**：
- 股票分析任务在执行时，仍然从API（`ak.stock_zh_a_spot_em()`）获取股票列表
- 网络连接失败导致无法获取股票列表
- 用户希望直接从数据库 `stock_history_data` 表获取股票数据，不需要从API获取

## 二、优化方案

### 2.1 优化策略

**改为从数据库获取股票列表**：
- 不再调用 `predictor.data_source.get_all_stock_list()`（会调用API）
- 直接从 `stock_history_data` 表查询股票列表
- 根据 `data_date` 或 `target_date` 过滤有数据的股票

### 2.2 实现逻辑

1. **优先使用 `data_date`**：如果指定了 `data_date`，获取该日期有数据的股票
2. **其次使用 `target_date`**：如果没有 `data_date`，使用 `target_date`
3. **最后使用所有日期**：如果都没有指定，获取所有有数据的股票
4. **支持按成交额排序**：如果指定了 `sort_type='turnover'`，从数据库获取成交额数据并排序

## 三、代码修改

### 3.1 修改位置

**文件**：`utils/scheduled_task_manager.py`
**方法**：`_execute_stock_analysis()`（第668-760行）

### 3.2 修改内容

**修改前**：
```python
# 全量分析：使用predictor内部的data_source
stock_list = predictor.data_source.get_all_stock_list(limit=limit, sort_by_turnover=(sort_type == 'turnover'))
```

**修改后**：
```python
# 全量分析：直接从数据库获取股票列表（避免API调用）
self.logger.info("从数据库获取股票列表（避免API调用）...")
try:
    from utils.db_connection import DatabaseConnection
    db = DatabaseConnection()
    
    # 根据data_date获取有数据的股票列表（优先使用data_date，如果没有则使用target_date）
    filter_date = data_date if data_date else target_date
    if filter_date:
        # 获取指定日期有数据的股票列表
        sql = """
            SELECT DISTINCT symbol, name
            FROM stock_history_data
            WHERE trade_date = %s AND period_type = 'daily'
            ORDER BY symbol
        """
        results = db.execute_query(sql, (filter_date,))
        stock_list = [{'symbol': str(row['symbol']).zfill(6), 'name': row.get('name', '')} for row in results]
        self.logger.info(f"从数据库获取到 {len(stock_list)} 只股票（日期: {filter_date}）")
    else:
        # 如果没有指定日期，获取所有有数据的股票
        sql = """
            SELECT DISTINCT symbol, name
            FROM stock_history_data
            WHERE period_type = 'daily'
            ORDER BY symbol
        """
        results = db.execute_query(sql)
        stock_list = [{'symbol': str(row['symbol']).zfill(6), 'name': row.get('name', '')} for row in results]
        self.logger.info(f"从数据库获取到 {len(stock_list)} 只股票（所有日期）")
    
    if not stock_list:
        return {
            'success': False,
            'message': '数据库中暂无股票数据',
            'error': '数据库中没有股票数据'
        }
    
    # 如果指定了limit，限制数量
    if limit and limit > 0:
        stock_list = stock_list[:limit]
    
    # 如果指定了按成交额排序，需要从数据库获取成交额数据
    if sort_type == 'turnover':
        self.logger.info("按成交额排序（从数据库获取成交额数据）...")
        # 获取成交额数据并排序
        if filter_date:
            sql = """
                SELECT symbol, amount
                FROM stock_history_data
                WHERE trade_date = %s AND period_type = 'daily'
                ORDER BY amount DESC
            """
            turnover_results = db.execute_query(sql, (filter_date,))
        else:
            # 获取最新日期的成交额数据
            sql = """
                SELECT symbol, amount
                FROM stock_history_data
                WHERE period_type = 'daily'
                AND trade_date = (SELECT MAX(trade_date) FROM stock_history_data WHERE period_type = 'daily')
                ORDER BY amount DESC
            """
            turnover_results = db.execute_query(sql)
        
        # 构建成交额映射
        turnover_map = {str(row['symbol']).zfill(6): row.get('amount', 0) or 0 for row in turnover_results}
        
        # 按成交额排序
        stock_list.sort(key=lambda x: turnover_map.get(x['symbol'], 0), reverse=True)
    
    # 分析股票...
except Exception as e:
    self.logger.error(f"从数据库获取股票列表失败: {str(e)}")
    return {
        'success': False,
        'message': f'从数据库获取股票列表失败: {str(e)}',
        'error': str(e)
    }
```

## 四、功能说明

### 4.1 日期过滤逻辑

1. **优先使用 `data_date`**：如果任务配置中指定了 `data_date`，获取该日期有数据的股票
2. **其次使用 `target_date`**：如果没有 `data_date`，使用 `target_date`
3. **最后使用所有日期**：如果都没有指定，获取所有有数据的股票

### 4.2 排序支持

- **默认排序**：按股票代码排序
- **按成交额排序**：如果 `sort_type='turnover'`，从数据库获取成交额数据并排序

### 4.3 限制数量

- 如果指定了 `limit`，限制返回的股票数量

## 五、优势

## 六、注意事项

3. **错误处理**：如果数据库查询失败，会返回错误信息，不会继续执行
