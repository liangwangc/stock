- `min_samples`: 10（最少样本数）

**使用示例**：
```python

    new_weights = batch_result['new_weights']
```

## 三、核心功能说明

### 3.1 自适应学习频率

**原理**：
- 根据市场波动率动态调整学习频率
- 波动率高（>0.7）：频率提高2倍（天数减半）
- 波动率中等（0.4-0.7）：使用基础频率
- 波动率低（<0.4）：频率降低（天数增加50%）

**实现**：
```python
volatility = calculate_market_volatility(days=30)
if volatility > 0.7:
    frequency_days = base_frequency_days * 0.5  # 高波动，提高频率
elif volatility > 0.4:
    frequency_days = base_frequency_days  # 中等波动，基础频率
else:
    frequency_days = base_frequency_days * 1.5  # 低波动，降低频率
```

### 3.2 触发式学习

**触发条件**：
1. **预测准确率下降**：最近7天准确率比之前7天下降超过5%
2. **市场状态变化**：市场状态从牛市/熊市/震荡市发生变化

**实现**：
```python
# 检查准确率趋势
accuracy_trend = calculate_prediction_accuracy_trend(days=30)
if accuracy_trend['accuracy_diff'] < -0.05:
    should_trigger = True  # 准确率下降超过5%

# 检查市场状态变化
market_state_change = check_market_state_change(days=7)
if market_state_change['has_changed']:
    should_trigger = True  # 市场状态变化
```

### 3.3 动态学习范围

**原理**：
- 牛市/熊市：使用较长历史（90天）
- 震荡市：使用较短历史（30天）

**实现**：
```python
market_state = identify_market_state()
if market_state in ['bull_market', 'bear_market']:
    learning_days = 90  # 牛市/熊市使用较长历史
else:
    learning_days = 30  # 震荡市使用较短历史
```

### 3.4 增量权重更新

**原理**：
- 每次预测后，根据预测结果（命中/未命中）调整权重
- 如果命中：增加与预测方向一致的因子的权重
- 如果未命中：降低与预测方向一致的因子的权重

**更新公式**：
```
if is_hit and is_consistent:
    adjustment = learning_rate * |factor_score| * current_weight
elif not is_hit and is_consistent:
    adjustment = -learning_rate * |factor_score| * current_weight
else:
    adjustment = 0

new_weight = current_weight + adjustment
```

### 3.5 在线梯度下降

**原理**：
- 使用批量数据计算梯度
- 根据梯度更新权重
- 梯度 = 损失函数的负梯度

**更新公式**：
```
gradient = Σ(损失函数对权重的偏导数) / sample_count
new_weight = current_weight - learning_rate * gradient
```

### 3.6 多指标综合评估

**评估指标**：
1. **方向准确率**（权重40%）：预测方向是否正确
2. **幅度准确率**（权重30%）：预测涨跌幅的误差
3. **置信度校准**（权重30%）：高置信度是否对应高准确率

**综合得分**：
```
comprehensive_score = 
    direction_accuracy * 0.4 +
    magnitude_score * 0.3 +
    calibration_score * 0.3
```

### 3.7 分市场状态评估

**评估内容**：
- 按市场状态（牛市/熊市/震荡市）分别统计：
  - 样本数
  - 方向准确率
  - 幅度误差（MAE）
  - 平均置信度
  - 命中数/未命中数

**用途**：
- 识别模型在不同市场状态下的表现差异
- 针对性地优化不同市场状态下的权重配置

### 3.8 置信度校准评估

**评估方法**：
- 将置信度分成N个箱（默认10个）
- 计算每个箱的平均置信度和实际准确率
- 计算校准误差 = |平均置信度 - 实际准确率|

**评估指标**：
- **ECE (Expected Calibration Error)**：期望校准误差
- **MCE (Maximum Calibration Error)**：最大校准误差

**校准质量**：
- excellent: ECE < 0.05
- good: ECE < 0.1
- fair: ECE < 0.2
- poor: ECE >= 0.2

### 6.1 定时任务配置

**建议配置**：

2. **每周综合评估**：每周执行一次综合评估

### 6.2 增量更新时机

**建议时机**：
- 每次预测保存后，如果已有实际结果，调用增量更新
- 但需要设置一个阈值，避免频繁更新（如每天最多更新一次）

### 6.3 权重应用策略

**建议策略**：
1. **增量更新**：可以实时应用（影响较小）
2. **批量在线学习**：建议先评估效果，再决定是否应用
3. **自适应优化**：建议先查看优化结果，再决定是否应用

## 七、注意事项

### 7.1 数据要求

- **增量更新**：需要至少10个样本才能更新
- **批量在线学习**：需要至少10个样本才能学习
- **自适应优化**：需要至少30天的历史数据

### 7.2 性能考虑

- **增量更新**：每次预测后调用，影响较小
- **批量在线学习**：建议在非交易时间执行
- **自适应优化**：可能需要较长时间，建议在非交易时间执行

### 7.3 权重限制

- 权重范围限制在0.01-0.5之间
- 更新后会自动归一化，确保权重总和为1
