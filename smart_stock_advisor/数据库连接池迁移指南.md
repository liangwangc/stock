# 数据库连接池迁移指南

**日期**：2026-01-21  
**目的**：从线程本地连接迁移到连接池，避免连接泄漏，提升并发性能

---

## 一、当前问题

### 1.1 当前实现

- **使用**：`utils/db_connection.py` 的 `DatabaseConnection` 类
- **方式**：使用 `threading.local()`，每个线程一个连接
- **问题**：
  - 高并发时可能创建过多连接
  - 线程结束时连接可能未正确关闭
  - 连接泄漏风险

### 1.2 已有连接池实现

- **位置**：`utils/db_pool.py`
- **类名**：`DatabaseConnectionPool`
- **功能**：完整的连接池实现，支持连接复用、超时管理

---

## 二、迁移方案

### 2.1 方案选择

**方案1：完全替换（推荐）**
- 将所有 `DatabaseConnection` 替换为 `DatabaseConnectionPool`
- 优点：统一管理，避免连接泄漏
- 缺点：需要修改所有使用数据库的代码

**方案2：渐进式迁移**
- 新代码使用连接池
- 旧代码逐步迁移
- 优点：风险低
- 缺点：两套代码并存

**推荐**：采用方案1，但分阶段实施

---

## 2.2 迁移步骤

### 阶段1：修改 `DatabaseConnection` 类（向后兼容）

在 `utils/db_connection.py` 中，让 `DatabaseConnection` 内部使用连接池：

```python
from utils.db_pool import get_connection_pool

class DatabaseConnection:
    """数据库连接管理器（使用连接池）"""
    
    _pool = None
    
    @classmethod
    def _get_pool(cls):
        """获取连接池实例"""
        if cls._pool is None:
            cls._pool = get_connection_pool()
        return cls._pool
    
    @classmethod
    def get_connection(cls):
        """获取数据库连接（从连接池）"""
        if not USE_DATABASE:
            return None
        
        pool = cls._get_pool()
        return pool.get_connection()
    
    @classmethod
    def close_connection(cls, conn):
        """归还连接到连接池"""
        if conn and USE_DATABASE:
            pool = cls._get_pool()
            pool.return_connection(conn)
    
    @classmethod
    def execute_query(cls, sql: str, params: tuple = None) -> List[Dict[str, Any]]:
        """执行查询SQL"""
        if not USE_DATABASE:
            return []
        
        conn = None
        try:
            conn = cls.get_connection()
            if conn is None:
                return []
            
            with conn.cursor() as cursor:
                cursor.execute(sql, params)
                return cursor.fetchall()
        except Exception as e:
            logger.error(f"执行查询失败: {sql[:100]}... 错误: {str(e)}")
            raise
        finally:
            if conn:
                cls.close_connection(conn)
    
    @classmethod
    def execute_update(cls, sql: str, params: tuple = None, commit_immediately: bool = True) -> int:
        """执行更新SQL"""
        if not USE_DATABASE:
            return 0
        
        conn = None
        try:
            conn = cls.get_connection()
            if conn is None:
                return 0
            
            with conn.cursor() as cursor:
                affected_rows = cursor.execute(sql, params)
                if not DB_CONFIG.get('autocommit', True):
                    conn.commit()
                return affected_rows
        except Exception as e:
            logger.error(f"执行更新失败: {sql[:100]}... 错误: {str(e)}")
            raise
        finally:
            if conn:
                cls.close_connection(conn)
```

## 四、注意事项

### 4.1 连接归还

**重要**：使用连接后必须归还到连接池！

```python
# ✅ 正确：使用上下文管理器或try-finally
conn = DatabaseConnection.get_connection()
try:
    # 使用连接
    pass
finally:
    DatabaseConnection.close_connection(conn)

# ✅ 正确：使用execute_query/execute_update（自动归还）
results = DatabaseConnection.execute_query(sql, params)

# ❌ 错误：获取连接后不归还
conn = DatabaseConnection.get_connection()
# 使用连接...
# 忘记归还！
```

### 4.2 事务处理

如果使用事务，需要确保在整个事务期间使用同一个连接：

```python
conn = DatabaseConnection.get_connection()
try:
    conn.begin()
    # 执行多个操作
    conn.commit()
except:
    conn.rollback()
finally:
    DatabaseConnection.close_connection(conn)
```

### 4.3 性能监控

监控连接池状态：

```python
from utils.db_pool import get_connection_pool

pool = get_connection_pool()
stats = pool.get_stats()
print(f"连接池大小: {stats['pool_size']}")
print(f"已创建连接: {stats['created_connections']}")
```
