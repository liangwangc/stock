## 二、高优先级优化建议

### 2.1 回测结果可视化 ✅ 必须实现

#### 问题描述
- 回测引擎返回JSON结果，但没有可视化展示
- 用户无法直观查看回测收益曲线、最大回撤、交易记录等

#### 建议方案

**1. 创建回测结果可视化模块**
- 新建文件：`visualizer/backtest_visualizer.py`
- 实现方法：
  - `visualize_backtest_result(backtest_result: Dict) -> str`：生成HTML报告
  - `create_profit_curve(backtest_result: Dict) -> str`：收益曲线图
  - `create_drawdown_chart(backtest_result: Dict) -> str`：最大回撤图
  - `create_trades_table(backtest_result: Dict) -> str`：交易记录表格

**2. 图表类型**
- **收益曲线图**（Plotly折线图）：
  - X轴：日期
  - Y轴：资产价值（累计收益）
  - 标记：买入点、卖出点
- **最大回撤图**（Plotly面积图）：
  - X轴：日期
  - Y轴：回撤百分比
  - 填充区域显示回撤
- **交易记录表格**（HTML表格）：
  - 日期、股票代码、操作（买入/卖出）、价格、数量、收益、收益率
- **绩效指标图表**（Plotly柱状图/饼图）：
  - 总收益率、年化收益率、最大回撤、胜率、盈亏比等

**3. Web界面集成**
- 在设置页面的模型学习面板中，添加"查看回测结果"按钮
- 点击后跳转到回测结果页面，显示交互式图表
- 新增API接口：`/api/backtest/result/<backtest_id>`

**4. 实现步骤**
1. 创建 `visualizer/backtest_visualizer.py`
2. 实现可视化方法（使用Plotly）
3. 修改 `BacktestEngine`，保存回测结果ID
4. 在Web界面添加回测结果展示页面
5. 添加API接口

**预计工作量**：2-3天

### 2.4 实时策略权重动态调整 ✅ 建议实现

#### 问题描述
- 实时交易策略的权重配置固定（预测50%、资金25%、买卖盘15%、盘中10%）
- 无法根据市场状态动态调整权重

#### 建议方案

**1. 实现动态权重调整**
- 在 `RealtimeTradingAdvisor.get_realtime_decision()` 方法中
- 根据市场状态调整权重：
  - 牛市：提高预测权重，降低盘中调整权重
  - 熊市：提高资金流向权重，降低预测权重
  - 震荡市：平衡权重

**2. 实现细节**
```python
# 获取市场状态
market_state = prediction_result.get('market_state', {}).get('state', 'sideways')

# 根据市场状态调整权重
if market_state == 'bull_market':
    prediction_weight = 0.6
    capital_flow_weight = 0.20
    bid_ask_weight = 0.12
    intraday_weight = 0.08
elif market_state == 'bear_market':
    prediction_weight = 0.40
    capital_flow_weight = 0.30
    bid_ask_weight = 0.20
    intraday_weight = 0.10
else:
    # 使用默认权重
    ...
```

**3. 实现步骤**
1. 修改 `predictor/realtime_trading_advisor.py`
2. 在 `get_realtime_decision()` 方法中添加权重调整逻辑
3. 从配置中读取基础权重，然后根据市场状态调整
4. 测试验证

### 3.2 数据一致性改进 ✅ 建议改进

#### 问题描述
- PNG/HTML图表直接从预测结果生成（不依赖数据库）
- Web页面从数据库读取数据
- 可能存在数据不一致的情况

#### 建议方案

**1. 统一数据来源**
- 可视化模块优先从数据库读取数据
- 如果数据库数据不可用，再使用传入的参数

**2. 数据版本管理**
- 在数据库中添加数据版本字段
- 确保图表和数据的一致性

**预计工作量**：1-2天

---

### 3.3 新股票/数据不足时的处理优化 ✅ 建议优化

#### 问题描述
- 新股票无历史准确率数据，权重优化可能不准确
- 数据不足时，置信度计算可能不准确

#### 建议方案

**1. 新股票处理**
- 使用行业/板块的平均权重
- 使用默认权重配置
- 标记为新股票，使用保守策略

**2. 数据不足处理**
- 降低置信度阈值
- 使用更保守的预测策略
- 提示用户数据不足

**预计工作量**：1-2天

---

### 3.4 实时数据完整性处理 ✅ 建议改进

#### 问题描述
- 某些实时数据字段可能为None（如资金流向、买卖盘）
- 数据不完整时，决策可能不准确

#### 建议方案

**1. 数据完整性检查**
- 在决策前检查数据完整性
- 如果关键数据缺失，降低置信度或使用默认值

**2. 数据质量评分**
- 计算数据质量评分
- 根据数据质量调整决策权重

**预计工作量**：1天
