### 2. 修复 `importance_score` 字段不存在的错误

**错误信息**：
```
Unknown column 'na.importance_score' in 'field list'
```

**问题原因**：
- `news_notification.py` 中的 `get_user_notifications()` 和 `get_notification_history()` 方法使用了 `importance_score` 字段
- 但 `news_articles` 表中可能不存在这个字段

**修复方案**：
- 在查询前动态检查 `importance_score` 字段是否存在
- 如果字段不存在，使用 `NULL as importance_score` 和 `NULL as importance_level` 替代
- 修改位置：
  - `get_user_notifications()` 方法（第323-351行）：已修复
  - `get_notification_history()` 方法（第395-409行）：已修复

### importance_score 字段动态检查

```python
# 动态检查importance_score字段是否存在
try:
    check_sql = "SHOW COLUMNS FROM news_articles LIKE 'importance_score'"
    has_importance_score = len(self.db.execute_query(check_sql)) > 0
except:
    has_importance_score = False

if has_importance_score:
    sql = """
        SELECT n.*, na.content, ..., na.importance_score, na.importance_level
        FROM news_notifications n
        JOIN news_articles na ON n.news_id = na.id
        ...
    """
else:
    sql = """
        SELECT n.*, na.content, ..., NULL as importance_score, NULL as importance_level
        FROM news_notifications n
        JOIN news_articles na ON n.news_id = na.id
        ...
    """
```
