## 二、当前计算方式分析

### 2.1 MA（移动平均线）

**当前实现**：`stock_history_collector.py` 第509-512行
```python
data['ma5'] = float(closes.tail(5).mean()) if len(closes) >= 5 else None
data['ma10'] = float(closes.tail(10).mean()) if len(closes) >= 10 else None
data['ma20'] = float(closes.tail(20).mean()) if len(closes) >= 20 else None
data['ma60'] = float(closes.tail(60).mean()) if len(closes) >= 60 else None
```

**计算方式**：简单移动平均（SMA）
- ✅ **标准算法**：使用pandas `rolling().mean()`，这是标准的SMA
- ⚠️ **可能差异**：如果证券公司使用加权移动平均（WMA）或指数移动平均（EMA），会有差异

**与证券公司差异原因**：
1. **数据范围不同**：我们使用的是数据库中已有的历史数据，如果数据不完整或包含停牌日，会导致差异
2. **复权处理**：如果证券公司使用复权价格，而我们使用不复权价格，会有差异
3. **MA类型不同**：如果证券公司使用EMA或WMA，而我们使用SMA，会有差异

---

### 2.2 RSI（相对强弱指标）

**当前实现**：`stock_history_collector.py` 第514-521行
```python
if len(closes) >= 14:
    delta = closes.diff()
    gain = (delta.where(delta > 0, 0)).rolling(window=14).mean()
    loss = (-delta.where(delta < 0, 0)).rolling(window(14).mean()
    rs = gain / loss
    rsi = 100 - (100 / (1 + rs))
    data['rsi'] = float(rsi.iloc[-1]) if pd.notna(rsi.iloc[-1]) else None
```

**计算方式**：**简单移动平均（SMA）方式**

**问题**：❌ **这是最大的问题！**

**标准RSI计算方式（Wilder's Smoothing）**：
1. **初始14天**：使用SMA计算平均涨跌幅
2. **第15天起**：使用Wilder平滑公式（类似EMA，但平滑系数α=1/N）
   ```
   AvgU_t = (AvgU_{t-1} × (N-1) + U_t) / N
   AvgD_t = (AvgD_{t-1} × (N-1) + D_t) / N
   ```

**我们的实现**：
- ❌ **每次都使用SMA**：每次都重新计算最近14天的SMA
- ❌ **没有使用Wilder平滑**：导致RSI值波动更大，与证券公司标准值不一致

**与证券公司差异原因**：
1. **算法不同**：证券公司使用Wilder平滑（SMMA/RMA），我们使用纯SMA
2. **平滑效果**：Wilder平滑更平滑，对历史数据有累积影响；SMA只考虑最近N天
3. **这是最常见的差异原因**！

### 2.3 MACD

**当前实现**：`stock_history_collector.py` 第523-532行
```python
if len(closes) >= 26:
    ema12 = closes.ewm(span=12, adjust=False).mean()
    ema26 = closes.ewm(span=26, adjust=False).mean()
    macd = ema12 - ema26
    signal = macd.ewm(span=9, adjust=False).mean()
    histogram = macd - signal
```

**计算方式**：标准MACD算法
- ✅ **EMA计算**：使用 `ewm(span=12, adjust=False)`，这是标准的EMA
- ✅ **Signal计算**：MACD的9日EMA
- ✅ **Histogram计算**：MACD - Signal

**与证券公司差异原因**：
1. **数据范围**：如果历史数据不完整，EMA的初始值会有差异
2. **复权处理**：如果使用复权价格，会有差异
3. **EMA平滑系数**：`adjust=False` 是标准EMA，但某些软件可能使用 `adjust=True`

### 2.4 X2（自定义指标）

**当前实现**：`stock_history_collector.py` 第534-552行
```python
if len(days_data) >= 20:
    highs = days_data['high']
    lows = days_data['low']
    current_close = data.get('close_price')
    if current_close is not None:
        llv_low = lows.tail(20).min()
        hhv_high = highs.tail(20).max()
        range_width = hhv_high - llv_low
        if range_width > 0:
            x2_value = (current_close - llv_low) / range_width * 100
            data['x2'] = float(round(x2_value, 4))
        else:
            data['x2'] = 50.0
```

**计算方式**：收盘价在20日价格区间中的相对位置（0-100）
- ✅ **自定义指标**：这是我们的自定义指标，证券公司可能没有这个指标
- ⚠️ **如果证券公司有类似指标**：可能使用不同的周期或计算方法

## 三、问题总结

### 3.1 主要问题

1. **RSI计算方式不正确**（最重要）
   - ❌ 当前使用SMA方式
   - ✅ 应该使用Wilder平滑方式
   - 📊 这是导致与证券公司值不一致的主要原因

2. **数据范围可能不同**
   - 如果历史数据不完整（缺少停牌日、节假日等）
   - 如果使用了不同的复权方式

3. **MA/MACD可能的数据差异**
   - 数据范围不同
   - 复权处理不同

## 四、优化方案

### 4.1 修复RSI计算（优先级：最高）

**修改位置**：`stock_history_collector.py` 第514-521行

**修改前**：
```python
# 计算RSI（需要至少14日数据）
if len(closes) >= 14:
    delta = closes.diff()
    gain = (delta.where(delta > 0, 0)).rolling(window=14).mean()
    loss = (-delta.where(delta < 0, 0)).rolling(window=14).mean()
    rs = gain / loss
    rsi = 100 - (100 / (1 + rs))
    data['rsi'] = float(rsi.iloc[-1]) if pd.notna(rsi.iloc[-1]) else None
```

**修改后**（使用Wilder平滑）：
```python
# 计算RSI（使用Wilder平滑，与证券公司标准一致）
if len(closes) >= 14:
    delta = closes.diff()
    gain = delta.where(delta > 0, 0.0)
    loss = -delta.where(delta < 0, 0.0)
    
    # 初始14天使用SMA
    avg_gain = gain.rolling(window=14, min_periods=14).mean()
    avg_loss = loss.rolling(window=14, min_periods=14).mean()
    
    # 从第15天起使用Wilder平滑
    for i in range(14, len(closes)):
        if pd.notna(avg_gain.iloc[i-1]) and pd.notna(avg_loss.iloc[i-1]):
            avg_gain.iloc[i] = (avg_gain.iloc[i-1] * 13 + gain.iloc[i]) / 14
            avg_loss.iloc[i] = (avg_loss.iloc[i-1] * 13 + loss.iloc[i]) / 14
    
    rs = avg_gain / avg_loss.replace(0, np.nan)
    rsi = 100 - (100 / (1 + rs))
    data['rsi'] = float(rsi.iloc[-1]) if pd.notna(rsi.iloc[-1]) else None
```

**或者使用更简洁的向量化方式**：
```python
# 计算RSI（使用Wilder平滑，与证券公司标准一致）
if len(closes) >= 14:
    delta = closes.diff()
    gain = delta.where(delta > 0, 0.0)
    loss = -delta.where(delta < 0, 0.0)
    
    # 使用Wilder平滑（RMA/SMMA）
    # RMA = EMA with alpha = 1/N
    avg_gain = gain.ewm(alpha=1/14, adjust=False).mean()
    avg_loss = loss.ewm(alpha=1/14, adjust=False).mean()
    
    rs = avg_gain / avg_loss.replace(0, np.nan)
    rsi = 100 - (100 / (1 + rs))
    data['rsi'] = float(rsi.iloc[-1]) if pd.notna(rsi.iloc[-1]) else None
```
