## 详细分析

### 1. 股票分析任务执行方式

**函数位置**：`smart_stock_advisor/web_app.py` → `run_stock_analysis_task()`

**执行方式**：
- ✅ **一次性任务**：任务启动后，分析所有指定的股票，完成后立即结束
- ❌ **无定时循环**：没有 `while True`、`for` 循环或定时器
- ❌ **无调度器**：没有使用 `schedule`、`APScheduler`、`Celery` 等调度框架
- ❌ **无自动重启**：任务完成后不会自动重新启动

### 2. 任务执行流程

```
用户点击"开始分析"按钮
    ↓
API调用：/api/tasks/start
    ↓
创建后台线程（threading.Thread）
    ↓
执行 run_stock_analysis_task()
    ↓
获取股票列表
    ↓
多线程/单线程分析所有股票
    ↓
任务完成，状态更新为 'completed'
    ↓
任务结束（线程退出）
```

### 6. 任务管理

**任务状态**：
- `running`：正在执行
- `completed`：已完成（一次性任务）
- `cancelled`：已取消
- `failed`：执行失败

**任务历史**：
- 所有任务记录保存在 `analysis_tasks` 表中
- 每个任务只执行一次，不会重复执行

## 总结

### 批量股票分析任务特点：
1. ✅ **一次性执行**：启动后分析所有股票，完成后结束
2. ❌ **无定时功能**：不会定时重复执行
3. ❌ **无自动重启**：完成后不会自动重新启动
4. ✅ **手动触发**：必须通过Web界面手动启动

### 如果需要定时任务：
如果需要定时执行批量股票分析，可以考虑以下方案：

1. **使用外部调度器**：
   - Linux Cron
   - Windows 任务计划程序
   - 定时调用 `/api/tasks/start` API

2. **添加定时任务功能**（需要开发）：
   - 参考新闻抓取任务的实现方式
   - 在 `run_stock_analysis_task` 外层添加循环和定时等待
   - 在任务管理界面添加"定时任务"配置

3. **使用任务队列**（推荐）：
   - 集成 Celery + Redis
   - 使用 Celery Beat 实现定时任务
   - 参考 `产品化优化详细方案.md` 中的建议
