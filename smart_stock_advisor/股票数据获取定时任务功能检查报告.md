## 三、功能可用性检查

### 3.1 创建定时任务 ✅ 可用

**流程**：
1. 用户点击"创建数据获取任务"
2. 填写任务信息：
   - 任务名称：例如"每日中国股票数据更新"
   - 市场类型：中国股票
   - 收集类型：增量更新
   - 执行时间：每日 18:00（收盘后）
   - 股票列表：留空（更新所有股票）
3. 调用 `POST /api/stock-data/tasks` 创建任务
4. 任务创建成功，但默认状态为 `is_active=0`（未激活）

**注意**：
- ⚠️ 创建后任务默认未激活，需要手动点击"启动"按钮

### 3.2 启动任务 ✅ 可用

**流程**：
1. 用户点击任务列表中的"启动"按钮
2. 调用 `POST /api/scheduled/tasks/<task_id>/start?source=scheduled_tasks`
3. 任务状态变为 `is_active=1`
4. 任务会按照设定的时间自动执行

**代码位置**：
- 前端：`startStockDataTask()` 函数（第6283-6299行）
- 后端：`api_start_scheduled_task()` 函数

### 3.3 停止任务 ✅ 可用

**流程**：
1. 用户点击任务列表中的"停止"按钮
2. 确认对话框
3. 调用 `POST /api/scheduled/tasks/<task_id>/stop?source=scheduled_tasks`
4. 任务状态变为 `is_active=0`
5. 任务停止执行

**代码位置**：
- 前端：`stopStockDataTask()` 函数（第6302-6322行）
- 后端：`api_stop_scheduled_task()` 函数

### 3.4 删除任务 ✅ 可用

**流程**：
1. 用户点击任务列表中的"删除"按钮
2. 确认对话框（"确定要删除此任务吗？删除后无法恢复！"）
3. 调用 `DELETE /api/scheduled/tasks/<task_id>?source=scheduled_tasks`
4. 任务从数据库删除

**代码位置**：
- 前端：`deleteStockDataTask()` 函数（第6325-6345行）
- 后端：`api_delete_scheduled_task()` 函数

### 3.5 定时执行 ✅ 可用

**流程**：
1. 任务启动后（`is_active=1`），定时任务管理器会检查执行时间
2. 到达执行时间后，调用 `_execute_cn_stock_data_collection` 或 `_execute_us_stock_data_collection`
3. 如果是增量更新，调用 `incremental_update_today()` 获取今日数据
4. 执行结果保存到 `scheduled_task_history` 表

**关键点**：
- ✅ 增量更新只获取今日数据（`today = datetime.now().strftime('%Y-%m-%d')`）
- ✅ 会检查数据是否已存在，避免重复采集
- ✅ 支持指定股票列表或获取所有股票
- ✅ 执行结果会记录到历史表

## 四、使用步骤（每天收盘后定时获取当天数据）

### 步骤1：创建任务

1. 进入设置页面 → "股票数据获取"
2. 点击"创建数据获取任务"
3. 填写信息：
   - **任务名称**：`每日中国股票数据更新`
   - **市场类型**：`中国股票`
   - **收集类型**：`增量更新（每日收盘后更新最新数据）`
   - **执行时间**：`每日`
   - **执行时间（24小时制）**：`18:00`（A股收盘后）
   - **股票列表**：留空（更新所有股票）
4. 点击"创建任务"

### 步骤2：启动任务

1. 创建成功后，任务会显示在任务列表中
2. 任务状态显示为"未激活"（灰色）
3. **重要**：点击"启动"按钮（▶️ 启动）
4. 任务状态变为"运行中"（绿色）

### 步骤3：验证任务

1. **检查任务状态**：
   - 任务列表中查看任务状态
   - 确认状态为"运行中"（绿色）

2. **检查执行历史**：
   - 点击"查看历史记录"
   - 等待到执行时间（18:00）后查看
   - 查看任务是否按时执行
   - 查看执行结果（成功/失败）

3. **检查数据**：
   - 查询 `stock_history_data` 表
   - 确认今日数据已保存
