## 二、逻辑流程说明

### 实时交易决策流程

```
1. 检查交易时间
   ↓
2. 获取实时行情（当前价格、涨跌幅等）
   ↓
3. 执行预测分析（预测明天走势）
   ↓
4. 获取实时资金流向（主力净流入/流出）
   ↓
5. 分析买卖盘（五档买卖盘强度）
   ↓
6. 综合计算交易信号
   ├── 基础预测得分（预测权重）
   ├── 资金流向调整（25%权重）
   ├── 买卖盘调整（15%权重）
   └── 盘中涨跌调整（10%权重）
   ↓
7. 生成交易决策
   ├── 未持仓：BUY / WAIT / AVOID
   └── 已持仓：SELL / REDUCE / HOLD / ADD
   ↓
8. 输出决策结果（包含理由、价格建议、风险警告）
   ↓
9. 保存决策快照到CSV（供后续学习）
```

### 决策规则总结

#### 未持仓时的决策规则：

| 条件 | 决策 | 说明 |
|------|------|------|
| 上涨概率 > 75% && 置信度 > 70% | **BUY（强烈）** | 强烈买入信号 |
| 上涨概率 > 65% && 置信度 > 55% | **BUY（适中）** | 可以买入 |
| 预测方向 = 震荡 | **WAIT** | 建议观望 |
| 下跌概率 > 60% | **AVOID** | 不建议买入 |

#### 已持仓时的决策规则：

| 条件 | 决策 | 说明 |
|------|------|------|
| 亏损 <= -5% | **SELL（止损）** | 触发止损线 |
| 盈利 >= +8% && 预测看跌 | **SELL（止盈）** | 达到止盈目标 |
| 盈利 >= +8% && 预测看涨 | **HOLD** | 继续持有，设置移动止损 |
| 下跌概率 > 70% && 置信度 > 55% | **SELL（强烈）** | 建议卖出 |
| 下跌概率 > 60% && 置信度 > 55% | **REDUCE** | 建议减仓50% |
| 上涨概率 > 75% && 置信度 > 70% && 当前盈利 | **ADD** | 可以加仓 |
| 其他情况 | **HOLD** | 持有观望 |

## 三、使用方法

### 1. 实时决策（单次）

**未持仓：**
```bash
py main.py --realtime --symbol 600519
```

**已持仓：**
```bash
py main.py --realtime --symbol 600519 --holding --cost 1800
```

**输出内容：**
- 实时行情数据（当前价、涨跌幅）
- 明日预测（方向、概率、置信度）
- 交易决策（操作建议、强度）
- 决策理由
- 价格建议（买入价、止损价、目标价）
- 仓位建议
- 风险警告

### 2. 实时监控（持续运行）

```bash
# 每30秒更新一次
py main.py --monitor --symbol 600519 --interval 30

# 已持仓监控
py main.py --monitor --symbol 600519 --interval 30 --holding --cost 1800
```

**特点：**
- 持续循环更新，直到收盘或手动停止
- 信号变化时自动提醒（如 HOLD → BUY）
- 非交易时间自动退出

### 3. 批量扫描（寻找买入机会）

```bash
# 扫描成交额最高的50只股票
py main.py --scan --limit 50
```

**特点：**
- 扫描多只股票，找出 BUY/ADD 信号
- 按信号强度和上涨概率排序
- 返回前10个最佳机会

### 4. 独立脚本运行

```bash
# 单次决策
py predictor/realtime_trading_advisor.py --symbol 600519

# 监控模式
py predictor/realtime_trading_advisor.py --symbol 600519 --monitor --interval 30

# 批量扫描
py predictor/realtime_trading_advisor.py --scan --limit 50
```

## 六、注意事项

### ⚠️ 逻辑潜在问题检查

1. **权重总和**：
   - ✅ 预测权重动态计算：`1 - 资金流向权重 - 买卖盘权重 - 盘中调整权重`
   - ✅ 确保权重总和为 1

2. **止损止盈逻辑**：
   - ✅ 止损检查在止盈检查之前（优先级正确）
   - ✅ 止损无条件执行（亏损超过-5%立即卖出）
   - ✅ 止盈需要结合预测（达到+8%且预测看跌才卖出）

3. **价格建议计算**：
   - ⚠️ 止损价计算公式检查：`ideal_buy * (1 + stop_loss_pct / 100)`
     - 如果 `stop_loss_pct = -5%`，则 `1 + (-5) / 100 = 0.95`，正确
   - ⚠️ 目标价计算公式检查：`ideal_buy * (1 + take_profit_pct / 100)`
     - 如果 `take_profit_pct = 8%`，则 `1 + 8 / 100 = 1.08`，正确

4. **信号强度范围**：
   - ✅ 使用 `max(0, min(1, signal_strength))` 限制在 0-1 范围内

### ✅ 已修复的问题

1. **配置读取**：现在从 `config.py` 读取 `TRADING_CONFIG`，不再硬编码
2. **权重使用**：信号计算中的权重现在从配置读取，不再硬编码

1. **实时决策模式**：适合盘中快速查看单只股票的交易建议

3. **批量扫描模式**：适合寻找新的买入机会，在热门股票中筛选

   - 如果追求更高收益，可以提高 `take_profit_pct`（如 10%）
