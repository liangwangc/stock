# 数据收集错误修复说明

## 错误1: NameError: name 'pd' is not defined

### 错误位置
`scripts/batch_collect_10years_data.py` 第286行

### 错误原因
在 `CNStockBatchCollector.get_stock_list` 方法中使用了 `pd.DataFrame`，但没有导入 `pandas` 模块。

### 修复方法
在文件开头添加 `import pandas as pd`

**修复前**：
```python
import os
import sys
import argparse
import json
import time
from datetime import datetime
from typing import List, Dict, Optional
```

**修复后**：
```python
import os
import sys
import argparse
import json
import time
from datetime import datetime
from typing import List, Dict, Optional
import pandas as pd
```

## 错误2: NameError: name 'period_type' is not defined

### 错误位置
`utils/stock_history_storage.py` 第373行

### 错误原因
在 `get_missing_dates` 方法中使用了 `period_type` 变量，但该方法没有 `period_type` 参数。

### 修复方法
在 `get_missing_dates` 方法签名中添加 `period_type` 参数，默认值为 `'daily'`。

**修复前**：
```python
def get_missing_dates(self, symbol: str, start_date: str, end_date: str) -> List[str]:
    ...
    sql = "SELECT trade_date FROM stock_history_data WHERE symbol = %s AND trade_date BETWEEN %s AND %s AND period_type = %s"
    existing_results = self.db.execute_query(sql, (symbol, start_date, end_date, period_type))
```

**修复后**：
```python
def get_missing_dates(self, symbol: str, start_date: str, end_date: str, period_type: str = 'daily') -> List[str]:
    """
    获取缺失的日期列表
    
    Args:
        symbol: 股票代码
        start_date: 开始日期（格式：YYYY-MM-DD）
        end_date: 结束日期（格式：YYYY-MM-DD）
        period_type: K线周期类型（daily/weekly/monthly/yearly），默认为'daily'
    """
    ...
    sql = "SELECT trade_date FROM stock_history_data WHERE symbol = %s AND trade_date BETWEEN %s AND %s AND period_type = %s"
    existing_results = self.db.execute_query(sql, (symbol, start_date, end_date, period_type))
```
