# 新闻模块优化说明

## 一、优化内容

### 1. 新闻数据库表设计 ✅

创建了两个新的数据库表：

#### `news_articles` 表
存储详细的新闻文章信息，包含以下字段：

**基本信息**：
- `title`: 新闻标题
- `content`: 新闻内容
- `summary`: 新闻摘要
- `publish_time`: 发布时间
- `fetch_time`: 抓取时间
- `source`: 新闻来源（如：金十数据、财新等）
- `source_url`: 新闻原始URL
- `news_type`: 新闻类型（stock/market/policy/industry）

**关联信息**：
- `symbol`: 关联股票代码
- `sector`: 关联板块
- `industry`: 关联行业
- `concept`: 关联概念

**情感分析结果**：
- `sentiment`: 情感倾向（positive/negative/neutral）
- `sentiment_score`: 情感得分（-1到1）
- `sentiment_confidence`: 情感分析置信度（0到1）
- `is_positive`: 是否利好（1/0）
- `is_negative`: 是否利空（1/0）
- `is_policy`: 是否政策新闻（1/0）
- `keywords`: 匹配的关键词（JSON格式）

**相关性**：
- `relevance_type`: 相关性类型（direct/industry/market）
- `relevance_score`: 相关性得分（0到1）

**其他**：
- `author`: 作者
- `tags`: 标签（JSON格式）
- `is_duplicate`: 是否重复新闻
- `duplicate_of`: 重复新闻的原始ID

**索引**：
- 为常用查询字段创建了索引（symbol、publish_time、source、sentiment等）
- 唯一索引：`(title, source)` 防止重复抓取

#### `news_crawl_tasks` 表
存储新闻抓取任务信息，包含以下字段：

- `task_name`: 任务名称
- `task_type`: 任务类型（market/stock/all）
- `symbol`: 股票代码（如果是股票任务）
- `sources`: 新闻源列表（JSON格式）
- `interval_minutes`: 抓取间隔（分钟）
- `is_active`: 是否激活（1/0）
- `last_run_time`: 最后运行时间
- `next_run_time`: 下次运行时间
- `run_count`: 运行次数
- `success_count`: 成功次数
- `fail_count`: 失败次数
- `last_error`: 最后错误信息

### 2. 新闻存储模块 ✅

创建了 `utils/news_storage.py` 模块，提供以下功能：

- **`save_news_article()`**: 保存单条新闻到数据库
  - 自动进行情感分析
  - 标记利好/利空
  - 检查重复新闻
  - 关联股票、板块、行业信息

- **`save_news_batch()`**: 批量保存新闻
  - 返回成功/失败/重复数量统计

- **`get_news_by_symbol()`**: 获取股票相关新闻
  - 支持按情感筛选
  - 支持限制数量

- **`get_news_statistics()`**: 获取新闻统计信息
  - 总数量、利好数量、利空数量
  - 平均情感得分

### 3. 新闻情感分析 ✅

集成了现有的 `NewsSentimentAnalyzer`，自动分析每条新闻：

- **情感分类**：positive（利好）/ negative（利空）/ neutral（中性）
- **情感得分**：-1到1之间的数值
- **置信度**：0到1之间的置信度
- **关键词匹配**：记录匹配到的关键词
- **自动标记**：
  - `is_positive = 1` 当 sentiment='positive' 且 score > 0.1
  - `is_negative = 1` 当 sentiment='negative' 且 score < -0.1

### 4. 定时任务系统 ✅

创建了 `utils/news_crawler.py` 和 `utils/news_task_manager.py` 模块：

#### NewsCrawler（新闻抓取器）
- **`crawl_market_news()`**: 抓取市场新闻
- **`crawl_stock_news()`**: 抓取股票新闻
- **`start_crawl_task()`**: 启动定时抓取任务（使用线程）
- **`stop_crawl_task()`**: 停止抓取任务

#### NewsTaskManager（任务管理器）
- **`create_task()`**: 创建新闻抓取任务
- **`start_task()`**: 启动任务
- **`stop_task()`**: 停止任务
- **`get_task()`**: 获取任务信息
- **`get_all_tasks()`**: 获取所有任务
- **`update_task()`**: 更新任务配置
- **`delete_task()`**: 删除任务
- **`get_task_statistics()`**: 获取任务统计信息

### 5. 设置页面集成 ✅

在设置页面（`templates/settings.html`）中添加了"新闻抓取"标签页：

**功能**：
- 创建新闻抓取任务
  - 任务名称
  - 任务类型（市场新闻/股票新闻/全部）
  - 股票代码（股票新闻需要）
  - 抓取间隔（分钟，10-1440）
  
- 任务列表显示
  - 任务状态（运行中/已停止）
  - 运行统计（运行次数、成功次数、失败次数）
  - 最后运行时间、下次运行时间
  - 最后错误信息

- 任务操作
  - 启动任务
  - 停止任务
  - 编辑任务（开发中）
  - 删除任务

### 6. API接口 ✅

新增以下API接口：

- `GET /api/news/tasks` - 获取所有新闻抓取任务
- `POST /api/news/tasks` - 创建新闻抓取任务
- `GET /api/news/tasks/<task_id>` - 获取任务信息
- `PUT /api/news/tasks/<task_id>` - 更新任务
- `DELETE /api/news/tasks/<task_id>` - 删除任务
- `POST /api/news/tasks/<task_id>/start` - 启动任务
- `POST /api/news/tasks/<task_id>/stop` - 停止任务
- `GET /api/news/articles` - 获取新闻文章列表
- `GET /api/news/statistics` - 获取新闻统计信息

## 二、使用方法

### 1. 初始化数据库表

```bash
# 运行数据库初始化脚本（会自动包含新闻表）
py database/init_database.py
```

### 2. 在设置页面创建任务

1. 启动Web应用：`py web_app.py`
2. 访问设置页面：http://localhost:5000/settings
3. 点击"新闻抓取"标签页
4. 点击"创建新任务"按钮
5. 填写任务信息：
   - 任务名称：如"市场新闻抓取"
   - 任务类型：选择"市场新闻"、"股票新闻"或"全部"
   - 股票代码：如果是股票新闻，输入股票代码（如：600519）
   - 抓取间隔：设置抓取间隔（分钟，建议60-120分钟）
6. 点击"创建"按钮
7. 创建成功后，点击"启动"按钮开始抓取

### 3. 查看抓取结果

- 任务列表会显示运行统计信息
- 可以通过API接口查询新闻文章：
  ```javascript
  fetch('/api/news/articles?symbol=600519&limit=20')
  ```

## 三、技术实现

### 1. 数据库表创建

SQL脚本位置：`database/news_table.sql`

### 2. 模块文件

- `utils/news_storage.py` - 新闻存储模块
- `utils/news_crawler.py` - 新闻抓取模块
- `utils/news_task_manager.py` - 任务管理模块

### 3. 定时任务实现

使用Python的 `threading` 模块实现定时任务：
- 每个任务运行在独立的线程中
- 使用 `threading.Event` 控制任务停止
- 任务状态持久化到数据库

### 4. 情感分析集成

自动调用 `NewsSentimentAnalyzer` 进行情感分析：
- 分析新闻标题和内容
- 匹配利好/利空关键词
- 计算情感得分和置信度
- 自动标记利好/利空

## 四、注意事项

1. **数据库必须启用**：新闻存储功能需要数据库支持，确保 `config_db.py` 中 `USE_DATABASE = True`

2. **新闻源可用性**：确保新闻源模块可用（`quant_trading_platform/news` 或本地 `news` 模块）

3. **抓取间隔建议**：
   - 市场新闻：建议60-120分钟
   - 股票新闻：建议30-60分钟
   - 避免设置过短（<10分钟），可能触发反爬虫机制

4. **任务管理**：
   - 任务创建后默认不激活，需要手动启动
   - 停止任务会立即停止当前抓取循环
   - 删除任务前会自动停止任务

5. **重复新闻处理**：
   - 基于标题和来源的唯一索引防止重复
   - 如果新闻已存在，会跳过保存
