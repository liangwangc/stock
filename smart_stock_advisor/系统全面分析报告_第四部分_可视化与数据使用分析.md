# 系统全面分析报告 - 第四部分：可视化与数据使用分析

**分析日期**：2026-01-11  
**分析范围**：可视化功能、数据展示、Web界面集成、数据使用情况

---

## 一、可视化系统概述

### 1.1 可视化模块结构

**核心模块**：`visualizer/prediction_visualizer.py`

**主要功能**：
1. 预测结果可视化（PNG图片）
2. HTML交互式报告生成
3. 图表生成（饼图、雷达图、柱状图、趋势图等）
4. 实时数据展示

**技术栈**：
- **Matplotlib**：静态图表（PNG）
- **Plotly**：交互式图表（HTML）
- **Pandas**：数据处理

---

## 二、可视化功能详细分析

### 2.1 图表类型

#### 1. 涨跌概率饼图

**位置**：第一行左（gs[0, 0]）

**展示内容**：
- 上涨概率（绿色）
- 下跌概率（红色）
- 其他概率（灰色）

**数据来源**：`prediction_result['up_probability']`、`prediction_result['down_probability']`

#### 2. 各因素得分雷达图

**位置**：第一行中左（gs[0, 1]）

**展示内容**：
- 技术指标得分
- 新闻情感得分
- 市场情绪得分
- 历史模式得分
- 美股板块得分

**数据来源**：`prediction_result['factors']`

**得分范围**：-1 到 1（转换为 0-1 用于雷达图显示）

#### 3. 涨跌概率对比柱状图

**位置**：第一行中右（gs[0, 2]）

**展示内容**：
- 上涨概率百分比（绿色柱）
- 下跌概率百分比（红色柱）

**数据来源**：`prediction_result['up_probability']`、`prediction_result['down_probability']`

#### 4. 实时交易决策面板

**位置**：第一行右（gs[0, 3]）

**展示内容**（如果提供实时数据）：
- 操作建议（BUY/SELL/HOLD/ADD/REDUCE）
- 建议强度（强烈/适中/中性）
- 决策理由（最多显示3条）
- 价格建议（买入价、卖出价、止损价、目标价）
- 仓位建议
- 风险警告

**数据来源**：`realtime_data.get('decision', {})`

#### 5. 市场行情预测

**位置**：第二行左（gs[1, 0:2]）

**展示内容**：
- 市场整体预测
- 市场状态信息
- 市场趋势分析

**数据来源**：`prediction_result['factors']['market']`

#### 6. 个股预测分析

**位置**：第二行右（gs[1, 2:4]）

**展示内容**：
- 预测方向
- 上涨/下跌概率
- 置信度
- 各因子得分和权重
- 预测总结

**数据来源**：`prediction_result`

#### 7. 实时数据面板

**位置**：第三行全宽（gs[2, :]）

**展示内容**（如果提供实时数据）：
- **实时行情**：
  - 当前价格
  - 涨跌幅
  - 开盘/最高/最低/收盘价
  - 换手率
  - 振幅
- **资金流向**：
  - 主力净流入
  - 总净流入
  - 资金流向趋势
- **交易时段**：
  - 当前交易时段信息

**数据来源**：`realtime_data.get('quote', {})`、`realtime_data.get('capital_flow', {})`、`realtime_data.get('trading_time', {})`

#### 8. 30天价格趋势图

**位置**：第四行全宽（gs[3, :]）

**展示内容**：
- 30天价格走势（K线图或折线图）
- 技术指标（MA、MACD等，如果可用）
- 预测价格点（如果可用）

**数据来源**：`stock_data`（历史价格数据）

**图表类型**：
- PNG静态图：使用Matplotlib
- HTML交互式图：使用Plotly（支持鼠标悬停、缩放、平移）

### 2.2 可视化方法

#### 1. `visualize()` 方法

**功能**：生成PNG静态图表并显示

**参数**：
- `prediction_result: Dict`：预测结果
- `stock_data: pd.DataFrame`：股票历史数据（可选）
- `realtime_data: Dict`：实时交易决策数据（可选）

**输出**：
- PNG图片文件（保存到 `reports/` 目录）
- 图表显示（如果环境支持）

#### 2. `visualize_no_display_v2()` 方法

**功能**：生成PNG静态图表但不显示（适用于服务器环境）

**参数**：同 `visualize()`

**输出**：
- PNG图片文件路径

#### 3. `_create_interactive_html_report()` 方法

**功能**：生成HTML交互式报告

**参数**：
- `prediction_result: Dict`：预测结果
- `stock_data: pd.DataFrame`：股票历史数据（可选）
- `realtime_data: Dict`：实时交易决策数据（可选）

**输出**：
- HTML文件路径（保存到 `reports/` 目录）
- 使用Plotly生成交互式图表

**报告内容**：
- 涨跌概率饼图（Plotly）
- 各因素得分雷达图（Plotly）
- 涨跌概率对比柱状图（Plotly）
- 30天价格趋势图（Plotly，交互式）
- 实时行情与交易决策（如果可用）
- 预测总结文字

## 四、数据使用分析

### 4.1 预测结果数据的可视化使用

#### 数据流程

```
预测系统 (StockPredictor.predict())
    ↓
预测结果 {
    prediction: '上涨'/'下跌'/'震荡',
    up_probability: 0.75,
    down_probability: 0.25,
    confidence: 0.70,
    factors: {...}
}
    ↓
数据存储
    ├── stock_predictions 表（预测结果）
    ├── prediction_factors 表（因子数据）
    └── CSV文件（可选）
    ↓
可视化系统 (PredictionVisualizer)
    ├── PNG静态图表
    ├── HTML交互式报告
    └── Web页面展示
```

#### 数据使用方式

1. **PNG静态图表**
   - 使用Matplotlib生成
   - 保存到 `reports/` 目录
   - 文件名格式：`{symbol}_prediction.png`

2. **HTML交互式报告**
   - 使用Plotly生成交互式图表
   - 保存到 `reports/` 目录
   - 文件名格式：`{symbol}_prediction.html`

3. **Web页面展示**
   - 从数据库读取预测数据
   - 使用Plotly/Chart.js在浏览器中渲染
   - 动态更新

### 4.2 实时数据可视化使用

#### 数据流程

```
实时交易策略 (RealtimeTradingAdvisor.get_realtime_decision())
    ↓
实时决策 {
    action: 'BUY'/'SELL'/'HOLD',
    strength: 'STRONG'/'MODERATE',
    reasons: [...],
    price_suggestions: {...}
}
    ↓
实时数据 {
    quote: {...},        # 实时行情
    capital_flow: {...}, # 资金流向
    trading_time: {...}  # 交易时段
}
    ↓
可视化系统 (PredictionVisualizer.visualize(realtime_data=...))
    ├── PNG图表中的实时决策面板
    ├── HTML报告中的实时数据部分
    └── Web页面实时展示
```

#### 数据使用方式

1. **PNG图表中的实时决策面板**
   - 在第一行右侧显示实时交易决策
   - 在第三行全宽显示实时数据面板

2. **HTML报告中的实时数据**
   - 在 `【实时行情与交易决策】` 区块展示
   - 包含实时行情、资金流向、交易决策

3. **Web页面实时展示**
   - 实时模式（`--monitor`）：HTML页面自动刷新
   - 监控模式：固定文件名，每次更新覆盖

## 七、关键问题分析

### 7.1 可视化问题

**问题1：回测结果可视化缺失**
- 回测引擎返回JSON结果，但没有可视化
- 用户无法直观查看回测收益曲线、最大回撤等

**问题2：模型性能可视化缺失**
- 性能评估结果只有文字展示，没有图表
- 无法直观查看准确率趋势、因子贡献度等

**问题3：实时决策可视化**
- PNG图表中已实现
- HTML报告中已实现
- Web页面中的实时展示需要确认

### 7.2 数据使用问题

**问题1：数据一致性**
- PNG/HTML图表直接从预测结果生成（不依赖数据库）
- Web页面从数据库读取数据
- 可能存在数据不一致的情况

**问题2：实时数据传递**
- 实时数据需要通过参数传递
- 如果未传递实时数据，图表中不显示实时信息
- Web页面需要单独获取实时数据
