## 数据流总结

### 预测系统数据流

```
股票代码 → 获取历史数据 → 并行多因子分析 → 市场状态识别 → 权重优化 → 
因子融合计算 → 概率转换 → 置信度计算 → 预测结果 → 数据存储 → 可视化
```

### 实时交易策略数据流

```
股票代码 + 持仓信息 → 获取实时行情 → 执行预测分析 → 获取实时资金流向 → 
分析买卖盘 → 综合计算交易信号 → 生成交易决策 → 保存决策记录
```

### 回测系统数据流

```
历史预测数据 → 模拟交易 → 计算交易成本 → 计算资产价值 → 
计算回测指标 → 回测结果 → （缺失：可视化）
```
