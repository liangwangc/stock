## 二、预测系统（StockPredictor）分析

### 2.1 预测流程

**核心方法**：`predict(symbol: str) -> Dict`

**流程步骤**：

1. **获取股票数据**（历史数据，默认60天）
2. **并行执行多因子分析**（使用线程池加速）
   - **独立任务**（6个，并行执行）：
     - 市场整体预测 (`market_overall`)
     - 新闻情感分析 (`news`)
     - 资金流向分析 (`capital_flow`)
     - 估值指标分析 (`valuation`)
     - 美股板块分析 (`us_sector`)
     - 板块轮动分析 (`sector_rotation`)
   - **数据依赖任务**（3个，并行执行）：
     - 技术指标分析 (`technical`) - 需要历史价格数据
     - 市场情绪分析 (`market`) - 需要历史数据
     - 历史模式分析 (`history`) - 需要历史数据
3. **市场状态识别**（动态调整权重）
4. **权重优化**（基于历史准确率）
5. **因子融合计算**
6. **置信度计算**
7. **生成预测结果**

### 2.2 8个预测因子

| 因子名称 | 默认权重 | 数据来源 | 计算方式 |
|---------|---------|---------|---------|
| **新闻情感** | 25% | 新闻源（TuShare等） | 情感分析、关键词匹配 |
| **资金流向** | 18% | AkShare实时数据 | 北向资金、融资融券、主力资金 |
| **市场情绪** | 17% | 大盘指数、个股数据 | 指数趋势、个股情绪 |
| **技术指标** | 20% | 历史价格数据 | MA、RSI、MACD、KDJ、CCI等 |
| **板块轮动** | 5% | 板块数据 | 热门板块识别 |
| **历史模式** | 8% | 历史价格数据 | 相似模式匹配 |
| **美股板块** | 5% | 美股数据 | 相关板块表现 |
| **估值指标** | 2% | 财务数据 | PE、PB、ROE等 |

**权重总和**：100%

### 2.3 因子融合算法

**代码位置**：`predictor/stock_predictor.py` 第2368-2377行

```python
final_score = (
    technical_score * adjusted_technical_weight +
    news_score * adjusted_news_weight +
    capital_flow_score * adjusted_capital_flow_weight +
    market_score * adjusted_market_weight +
    sector_rotation_score * adjusted_sector_rotation_weight +
    history_score * adjusted_history_weight +
    valuation_score * adjusted_valuation_weight +
    us_sector_score * adjusted_us_sector_weight
)
```

**权重动态调整机制**：
- 基于市场状态调整（牛市/熊市/震荡市）
- 基于历史准确率优化（`weight_optimizer`）
- 新闻权重倍数调整（根据新闻数量和质量）

**概率转换**：
```python
up_probability = 1 / (1 + np.exp(-final_score * 3))  # Sigmoid函数
down_probability = 1 - up_probability
```

### 2.4 置信度计算

**代码位置**：`predictor/stock_predictor.py` `_calculate_confidence()` 方法

**影响因素**：
- 因子一致性（各因子得分方向一致性）
- 数据质量（数据完整性、时效性）
- 历史准确率（该股票历史预测准确率）
- 市场状态（市场稳定性）

**增强置信度计算**：
- 使用 `ConfidenceCalculator` 模块
- 考虑历史准确率反馈
- 一致性检查
- 数据时效性评估

## 三、实时交易策略（RealtimeTradingAdvisor）分析

### 3.1 实时决策流程

**核心方法**：`get_realtime_decision(symbol, holding, cost_price) -> Dict`

**流程步骤**：

1. **获取实时行情**（当前价格、涨跌幅等）
2. **执行预测分析**（调用 `StockPredictor.predict()`）
3. **获取实时资金流向**（主力净流入/流出）
4. **分析买卖盘**（五档买卖盘强度）
5. **综合计算交易信号**
6. **生成交易决策**

### 3.2 信号生成算法

**代码位置**：`predictor/realtime_trading_advisor.py` 第268-306行

**综合信号计算公式**：

```python
# 基础预测得分（-0.5 到 0.5）
base_score = prediction_result['up_probability'] - 0.5

# 实时资金流向调整
capital_adjustment = min(total_inflow / 100000000, 0.1)  # 最多±0.1

# 买卖盘调整
bid_ask_adjustment = bid_ask_score * 0.05  # 范围 -0.05 到 0.05

# 盘中涨跌调整（追涨杀跌风险控制）
intraday_adjustment = -0.05 if change_pct > 5 else 0.05 if change_pct < -5 else 0

# 权重配置
prediction_weight = 1.0 - capital_flow_weight - bid_ask_weight - intraday_weight
# 默认：prediction_weight = 0.5, capital_flow_weight = 0.25, bid_ask_weight = 0.15, intraday_weight = 0.10

# 最终信号得分
final_signal_score = (
    base_score * prediction_weight +           # 预测权重 50%
    capital_adjustment * capital_flow_weight + # 资金流向权重 25%
    bid_ask_adjustment * bid_ask_weight +      # 买卖盘权重 15%
    intraday_adjustment * intraday_weight      # 盘中调整权重 10%
)

# 转换为信号强度（0-1）
signal_strength = 0.5 + final_signal_score
```

### 3.3 交易决策规则

**未持仓时的决策**：

| 条件 | 决策 | 信号强度要求 |
|------|------|------------|
| 上涨概率 > 75% && 置信度 > 70% | **BUY（强烈买入）** | STRONG |
| 上涨概率 > 65% && 置信度 > 55% | **BUY（买入）** | MODERATE |
| 震荡行情 | **WAIT（观望）** | NEUTRAL |
| 下跌概率 > 60% | **AVOID（避免买入）** | - |

**已持仓时的决策**：

| 条件 | 决策 |
|------|------|
| 亏损 <= -5% | **SELL（止损）** |
| 盈利 >= +8% && 预测看跌 | **SELL（止盈）** |
| 盈利 >= +8% && 预测看涨 | **HOLD（继续持有，移动止损）** |
| 下跌概率 > 70% && 置信度 > 55% | **SELL（强烈卖出）** |
| 下跌概率 > 60% && 置信度 > 55% | **REDUCE（减仓50%）** |
| 上涨概率 > 75% && 置信度 > 70% && 当前盈利 | **ADD（加仓）** |
| 其他情况 | **HOLD（持有观望）** |

### 3.4 动态止损止盈

**代码位置**：`predictor/realtime_trading_advisor.py` 第511-569行

**调整机制**：
1. **基于市场状态调整**：
   - 牛市：提高止盈目标（+20%），放宽止损（+20%）
   - 熊市：降低止盈目标（-20%），收紧止损（-20%）
   - 震荡市：使用默认值
2. **基于波动率调整**（如果 `RiskManager` 可用）：
   - 高波动率：收紧止损/止盈
   - 低波动率：放宽止损/止盈

## 四、数据流分析

### 4.1 预测系统数据流

```
股票代码 (symbol)
    ↓
获取历史数据 (60天)
    ↓
┌─────────────────────────────────────────┐
│  并行执行多因子分析（ThreadPoolExecutor） │
├─────────────────────────────────────────┤
│ 1. 市场整体预测                         │
│ 2. 新闻情感分析 ← 新闻数据源            │
│ 3. 资金流向分析 ← 实时资金数据          │
│ 4. 估值指标分析 ← 财务数据              │
│ 5. 美股板块分析 ← 美股数据              │
│ 6. 板块轮动分析 ← 板块数据              │
│ 7. 技术指标分析 ← 历史价格数据          │
│ 8. 市场情绪分析 ← 大盘指数数据          │
│ 9. 历史模式分析 ← 历史价格数据          │
└─────────────────────────────────────────┘
    ↓
市场状态识别 + 权重优化
    ↓
因子融合计算 (加权平均)
    ↓
概率转换 (Sigmoid函数)
    ↓
置信度计算
    ↓
预测结果 {
    prediction: '上涨'/'下跌'/'震荡',
    up_probability: float,
    down_probability: float,
    confidence: float,
    factors: {...}
}
```

### 4.2 实时交易策略数据流

```
股票代码 + 持仓信息 (holding, cost_price)
    ↓
获取实时行情 (当前价格、涨跌幅)
    ↓
执行预测分析 (调用 StockPredictor.predict())
    ↓
获取实时资金流向 (主力净流入/流出)
    ↓
分析买卖盘 (五档买卖盘强度)
    ↓
综合计算交易信号 {
    预测结果权重: 50%,
    资金流向权重: 25%,
    买卖盘权重: 15%,
    盘中调整权重: 10%
}
    ↓
生成交易决策 {
    action: 'BUY'/'SELL'/'HOLD'/'REDUCE'/'ADD',
    strength: 'STRONG'/'MODERATE'/'WEAK',
    reasons: [...],
    price_suggestions: {...},
    risk_warnings: [...]
}
```

### 4.3 数据存储流程

**预测结果存储**：

- `prediction_factors` 表：各因子得分、权重、趋势
- `stock_history_data` 表：历史价格、技术指标

**实时决策存储**：
- `realtime_trading_decisions` 表：决策记录、信号强度、理由

**配置存储**：

- `prediction_config_values` 表：配置值（JSON格式）

## 五、数据结合使用分析

### 5.1 预测系统中的数据结合

**结合方式**：加权平均融合

1. **技术指标 + 历史价格数据**
   - 技术指标分析需要历史价格数据（OHLCV）
   - 计算MA、RSI、MACD、KDJ、CCI等指标
   - 输出技术得分（-1到1）

2. **新闻情感 + 股票关联**
   - 新闻数据与股票代码关联
   - 直接关联 + 行业关联 + 市场关联
   - 输出新闻得分（-1到1）

3. **资金流向 + 实时数据**
   - 北向资金 + 融资融券 + 主力资金
   - 综合计算资金流向得分
   - 输出资金流向得分（-1到1）

4. **市场情绪 + 大盘指数**
   - 大盘指数数据 + 个股价格数据
   - 计算市场情绪得分
   - 输出市场情绪得分（-1到1）

5. **8个因子加权融合**
   - 每个因子得分 × 对应权重
   - 权重归一化（确保总和为1）
   - 输出最终得分（-1到1）

6. **最终概率转换**
   - Sigmoid函数转换得分到概率
   - 输出上涨概率和下跌概率

### 5.2 实时交易策略中的数据结合

**结合方式**：多层次权重融合

1. **预测结果（50%权重）**
   - 使用 `StockPredictor.predict()` 的结果
   - 提取上涨概率作为基础得分

2. **实时资金流向（25%权重）**
   - 实时获取主力资金净流入/流出
   - 转换为调整值（±0.1范围内）

3. **买卖盘强度（15%权重）**
   - 分析五档买卖盘数据
   - 计算买卖盘强度得分

4. **盘中涨跌调整（10%权重）**
   - 基于今日涨跌幅
   - 追涨杀跌风险控制

5. **综合信号计算**
   - 加权平均所有调整项
   - 输出信号强度（0-1）

6. **交易决策生成**
   - 根据信号强度和阈值
   - 考虑持仓状态和成本价
   - 输出交易建议

## 七、关键发现

### 7.1 优势

1. ✅ **多因子融合模型**：8个因子全面覆盖
2. ✅ **并行处理**：使用线程池加速分析
3. ✅ **动态权重调整**：基于市场状态和历史准确率
4. ✅ **实时决策**：结合预测和实时数据
5. ✅ **风险控制**：动态止损止盈、仓位管理

### 7.2 潜在问题

1. ⚠️ **预测系统与实时策略的数据结合**
   - 预测系统使用历史数据
   - 实时策略需要实时数据
   - **问题**：预测结果可能滞后，实时数据可能不完整

2. ⚠️ **权重调整机制**
   - 权重优化器依赖于历史数据
   - **问题**：新股票或数据不足时，优化可能不准确

3. ⚠️ **置信度计算**
   - 依赖历史准确率反馈
   - **问题**：新股票无历史准确率数据

### 7.3 数据依赖关系

```
预测系统依赖：
- 历史价格数据（必需）
- 新闻数据（可选，但影响新闻因子）
- 资金流向数据（可选，但影响资金因子）
- 财务数据（可选，但影响估值因子）

实时策略依赖：
- 预测结果（必需）
- 实时行情（必需）
- 实时资金流向（可选，但影响决策）
- 买卖盘数据（可选，但影响决策）
```
