## 使用说明

### 1. 手动运行性能评估

```python
from utils.model_performance_evaluator import ModelPerformanceEvaluator

evaluator = ModelPerformanceEvaluator()

# 评估过去30天的预测性能
result = evaluator.evaluate_prediction_performance(days=30)
print(result)

# 评估过去30天的交易性能
result2 = evaluator.evaluate_trading_performance(days=30)
print(result2)
```

### 2. 查看性能记录

```sql
-- 查看最近的性能评估记录
SELECT * FROM model_performance 
ORDER BY evaluation_date DESC 
LIMIT 10;

-- 查看预测性能趋势
SELECT 
    evaluation_date,
    time_period,
    direction_accuracy,
    sample_count
FROM model_performance
WHERE evaluation_type = 'prediction'
ORDER BY evaluation_date DESC;
```

## 注意事项

1. **数据质量**：确保 `stock_predictions` 表中的 `actual_price` 和 `prediction_hit` 字段已正确更新
2. **性能考虑**：回测和优化可能耗时较长，建议在非交易时间运行
3. **参数稳定性**：避免参数变化过于频繁，建议每周最多优化一次
4. **A/B测试**：新参数应先进行A/B测试，确认改进后再全面应用
