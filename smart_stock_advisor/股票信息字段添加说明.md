# 股票信息字段添加说明

## 修改时间
2026-01-09

## 修改内容

### 1. 数据库表结构更新

为 `stock_predictions` 表添加了以下字段：

- **`industry`** (VARCHAR(100)): 所属行业
- **`concepts`** (TEXT): 概念板块（JSON数组格式）
- **`main_concept`** (VARCHAR(100)): 主要概念板块
- **`market`** (VARCHAR(20)): 所属市场（A股/港股/美股），默认值为 'A股'

### 2. 索引添加

为新增字段添加了索引，提高查询性能：

- `idx_industry` on `industry`
- `idx_main_concept` on `main_concept`
- `idx_market` on `market`

### 3. 代码修改

#### 3.1 `predictor/stock_predictor.py`

在 `predict()` 方法的返回结果中添加了行业和板块信息：

```python
result = {
    'symbol': symbol,
    'name': stock_name,
    'industry': industry,  # 所属行业
    'concepts': concepts,  # 概念板块列表
    'main_concept': main_concept,  # 主要概念板块
    'market': market,  # 所属市场
    ...
}
```

这些信息从 `sector_rotation_result` 中提取，来源是 `data_source.get_stock_industry_info(symbol)` 方法。

#### 3.2 `utils/stock_prediction_db.py`

修改了 `save_prediction()` 方法：

1. 从 `prediction_result` 中提取行业和板块信息
2. 将 `concepts` 列表转换为JSON字符串保存
3. 自动从 `concepts` 中提取第一个作为 `main_concept`（如果未提供）
4. 自动判断所属市场（A股/港股/美股）
5. 支持向后兼容：如果数据库表还没有新字段，使用原来的SQL语句

#### 3.3 数据来源

行业和板块信息通过 `StockDataSource.get_stock_industry_info(symbol)` 方法获取：

- **行业信息**: 从 `ak.stock_individual_info_em()` 获取
- **概念板块**: 从股票基本信息中提取，可能包含多个概念
- **主要概念**: 取概念列表的第一个，或从板块轮动结果中提取

## 使用方法

### 运行脚本添加字段

```bash
python scripts/add_stock_info_fields.py
```

或者直接在MySQL中执行：

```sql
ALTER TABLE stock_predictions ADD COLUMN `industry` VARCHAR(100) DEFAULT NULL COMMENT '所属行业' AFTER `name`;
ALTER TABLE stock_predictions ADD COLUMN `concepts` TEXT DEFAULT NULL COMMENT '概念板块（JSON数组格式）' AFTER `industry`;
ALTER TABLE stock_predictions ADD COLUMN `main_concept` VARCHAR(100) DEFAULT NULL COMMENT '主要概念板块' AFTER `concepts`;
ALTER TABLE stock_predictions ADD COLUMN `market` VARCHAR(20) DEFAULT 'A股' COMMENT '所属市场（A股/港股/美股）' AFTER `main_concept`;

-- 添加索引
ALTER TABLE stock_predictions ADD INDEX `idx_industry` (`industry`);
ALTER TABLE stock_predictions ADD INDEX `idx_main_concept` (`main_concept`);
ALTER TABLE stock_predictions ADD INDEX `idx_market` (`market`);
```

### 自动保存

当执行股票预测分析时，这些信息会自动获取并保存到数据库：

```python
from predictor.stock_predictor import StockPredictor

predictor = StockPredictor()
result = predictor.predict('600519')  # 预测时会自动获取行业和板块信息

# 保存时会自动包含行业和板块信息
from visualizer.prediction_visualizer import PredictionVisualizer
visualizer = PredictionVisualizer()
visualizer.save_stock_record('600519', result, None, None, None)
```

### 查询使用

```sql
-- 按行业查询
SELECT * FROM stock_predictions WHERE industry = '白酒' ORDER BY prediction_date DESC;

-- 按概念板块查询
SELECT * FROM stock_predictions WHERE main_concept LIKE '%新能源%' ORDER BY prediction_date DESC;

-- 按市场查询
SELECT * FROM stock_predictions WHERE market = 'A股' ORDER BY prediction_date DESC;

-- 查询所有包含某个概念的股票
SELECT * FROM stock_predictions WHERE JSON_CONTAINS(concepts, '"新能源"') ORDER BY prediction_date DESC;
```

## 数据格式

### concepts 字段

`concepts` 字段存储为JSON数组格式，例如：

```json
["新能源", "锂电池", "新能源汽车", "充电桩"]
```

### 示例数据

```python
{
    'symbol': '600519',
    'name': '贵州茅台',
    'industry': '白酒',
    'concepts': ['白酒', '消费', '蓝筹股'],
    'main_concept': '白酒',
    'market': 'A股',
    ...
}
```

## 注意事项

1. **向后兼容**: 如果数据库表还没有新字段，代码会自动检测并使用兼容的SQL语句
2. **数据来源**: 行业和板块信息来源于AkShare的数据接口，可能因数据源变化而有所不同
3. **市场判断**: 市场类型的判断基于股票代码后缀（.HK为港股，其他为A股/美股）
4. **主要概念**: 如果未明确提供 `main_concept`，会自动从 `concepts` 列表中取第一个

## 测试

字段添加脚本已包含自动检测逻辑，运行后会：
1. 检查字段是否已存在
2. 只添加不存在的字段
3. 创建必要的索引
4. 输出操作结果

可以安全地多次运行，不会重复添加已存在的字段。
