# 参数调优说明文档

## 什么是"组合调参"？

**组合调参**是指：在功能已经实现的基础上，通过调整参数数值来提升预测准确性和系统表现。

### 简单理解

想象一下：
- **功能实现** = 建造了一辆车（有引擎、方向盘、刹车等）
- **参数调优** = 调整引擎转速、方向盘灵敏度、刹车力度等参数，让车开得更好

### 具体到我们的系统

1. **X2指标**：功能已实现（能计算X2值），但需要调优：
   - 当前：X2 > 80 算超买，得分 -0.15
   - 调优：可能 X2 > 75 更准确？或者得分应该是 -0.20？

2. **异常检测**：功能已实现（能检测ST股票），但需要调优：
   - 当前：ST股票降低置信度20%
   - 调优：可能降低15%或25%更合适？

3. **ML动态权重**：功能已实现（能动态调整权重），但需要调优：
   - 当前：准确率>60%时权重15-25%
   - 调优：可能权重范围应该是10-30%？

**位置**：`utils/ml_model_performance_monitor.py` 第29-31行、第104-113行

**当前值**：
```python
ml_default_weight = 0.15       # 默认权重15%
ml_min_weight = 0.0            # 最小权重0%
ml_max_weight = 0.25            # 最大权重25%

# 权重计算阈值
ml_high_accuracy_threshold = 0.60    # 高准确率阈值60%
ml_medium_accuracy_threshold = 0.50  # 中等准确率阈值50%

# 权重计算方式
# 准确率>60%: 权重 = 0.15 + (accuracy - 0.60) * 0.25
# 准确率50-60%: 权重 = 0.10 + (accuracy - 0.50) * 0.50
# 准确率<50%: 权重 = max(0.0, accuracy * 0.20)
```

**调优方向**：
- 权重范围更保守（10-20%）还是更激进（18-30%）？
- 阈值是否需要调整（比如55%/45%）？

## 如何调优？

### 方法1：手动调优（简单但耗时）

1. **修改参数值**：在代码中修改参数
2. **运行回测**：使用 `scripts/test_anomaly_detection.py` 或自动化回测
3. **记录结果**：记录准确率、收益率等指标
4. **对比分析**：找到最优参数组合

### 方法2：使用调优工具（推荐）

我们创建了 `scripts/parameter_tuning_tool.py` 工具：

1. **自动生成参数组合**：生成多个参数组合
2. **批量回测评估**：对每个组合进行回测
3. **找到最优组合**：自动选择准确率最高的组合
4. **生成配置代码**：自动生成最优参数的配置代码

**使用方法**：
```bash
cd smart_stock_advisor
python scripts/parameter_tuning_tool.py
```

## 调优流程

### 步骤1：准备回测数据

确保有足够的历史预测数据用于评估：
```bash
# 运行一段时间，积累预测数据
# 或者使用历史数据进行回测
```

### 步骤2：运行调优工具

```bash
python scripts/parameter_tuning_tool.py
```

工具会：
1. 生成多个参数组合（例如：3×3×3×3 = 81个组合）
2. 对每个组合进行回测评估
3. 找到准确率最高的组合

### 步骤3：应用最优参数

调优工具会生成：
1. **JSON配置文件**：`config/optimal_parameters_YYYYMMDD_HHMMSS.json`
2. **Python配置代码**：`config/optimal_parameters_code_YYYYMMDD_HHMMSS.py`

你可以：
- 手动将参数值更新到代码中
- 或者创建配置类，从配置文件读取参数

### 步骤4：验证效果

应用新参数后，运行一段时间，观察：
- 预测准确率是否提升
- 收益率是否改善
- 是否有其他副作用

---

## 注意事项

### 1. 调优需要时间

- 参数组合数量可能很多（例如：81个组合）
- 每个组合需要回测评估（可能需要几分钟）
- 总时间可能几小时到几天

### 2. 避免过拟合

- 不要只在一个时间段调优
- 应该在多个时间段验证
- 使用交叉验证或滚动窗口验证

### 3. 参数相互影响

- X2参数、异常检测参数、ML权重参数可能相互影响
- 需要综合考虑，不能单独调优

### 4. 市场环境变化

- 不同市场环境（牛市/熊市/震荡市）可能需要不同参数
- 考虑根据市场状态动态调整参数

## 总结

**组合调参**就是：
1. ✅ 功能已经实现（X2、异常检测、ML权重）
2. 🔧 调整参数数值（阈值、得分、权重范围）
3. 📊 通过回测验证效果
4. 🎯 找到最优参数组合
5. 💾 应用最优参数，提升系统表现

**关键点**：
- 不是修改功能代码，而是调整参数数值
- 需要大量回测验证
- 需要避免过拟合
- 需要根据市场环境动态调整
