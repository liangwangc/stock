## 一、发现的性能问题

### 1. 线程数限制过低 ⚠️

**问题**：
- 特征提取最多只使用8个线程
- 如果CPU核心数更多，无法充分利用多核CPU

**优化前**：
```python
max_workers = min(os.cpu_count() or 4, 8)  # 最多8个线程
```

**优化后**：
```python
cpu_count = os.cpu_count() or 4
max_workers = min(cpu_count, 16)  # 最多16个线程
if total_stocks < 100:
    max_workers = min(max_workers, 4)
elif total_stocks < 500:
    max_workers = min(max_workers, 8)
# 大量股票时使用更多线程（最多16个）
```

**预期提升**：2倍（从8线程提升到16线程）

---

### 2. 技术指标前向填充效率低 ⚠️

**问题**：
- 每次调用`get_technical_indicator`时，都会执行`reversed(df.iloc[:-1].to_dict('records'))`
- 这会创建DataFrame切片、转换为字典列表，然后反向遍历
- 对于每只股票的每个样本，都要执行多次这样的操作

**优化前**：
```python
def get_technical_indicator(field_name: str, default_value: float = 0.0) -> float:
    value = latest.get(field_name)
    if value is not None and pd.notna(value):
        return float(value)
    
    # 尝试从历史数据中查找前值（前向填充）
    for prev_record in reversed(df.iloc[:-1].to_dict('records')):
        prev_value = prev_record.get(field_name)
        if prev_value is not None and pd.notna(prev_value):
            return float(prev_value)
    
    return default_value
```

**优化后**：
```python
def get_technical_indicator(field_name: str, default_value: float = 0.0) -> float:
    value = latest.get(field_name)
    if value is not None and pd.notna(value):
        return float(value)
    
    # 性能优化：直接使用DataFrame的ffill方法，避免循环遍历
    if field_name in df.columns:
        try:
            filled_series = df[field_name].ffill()  # 新版本pandas
        except AttributeError:
            filled_series = df[field_name].fillna(method='ffill')  # 旧版本pandas
        if len(filled_series) > 0:
            last_filled = filled_series.iloc[-1]
            if pd.notna(last_filled):
                return float(last_filled)
    
    return default_value
```

**预期提升**：5-10倍（避免重复的DataFrame转换和循环）

### 3. 估值指标中位数重复计算 ⚠️

**问题**：
- 每次调用`get_valuation_indicator`时，都会遍历所有历史数据计算中位数
- 对于每只股票的每个样本，都要重复计算4次（PE、PB、总市值、流通市值）

**优化前**：
```python
def get_valuation_indicator(field_name: str) -> float:
    value = latest.get(field_name)
    if value is not None and pd.notna(value) and float(value) > 0:
        return float(value)
    
    # 尝试从历史数据中计算中位数（排除0值和NULL）
    try:
        field_values = []
        for record in df.to_dict('records'):  # 每次都要转换整个DataFrame
            val = record.get(field_name)
            if val is not None and pd.notna(val):
                val_float = float(val)
                if val_float > 0:
                    field_values.append(val_float)
        
        if field_values:
            median_val = np.median(field_values)
            return float(median_val)
    except Exception:
        pass
    
    return 0.0
```

**优化后**：
```python
# 预先计算所有估值指标的中位数（只计算一次）
valuation_medians = {}
valuation_fields = ['pe_ratio', 'pb_ratio', 'total_market_cap', 'float_market_cap']
for field_name in valuation_fields:
    if field_name in df.columns:
        try:
            # 使用DataFrame直接计算中位数（排除0值和NULL）
            valid_values = df[field_name].dropna()
            valid_values = valid_values[valid_values > 0]  # 排除0值
            if len(valid_values) > 0:
                valuation_medians[field_name] = float(valid_values.median())
            else:
                valuation_medians[field_name] = 0.0
        except Exception:
            valuation_medians[field_name] = 0.0
    else:
        valuation_medians[field_name] = 0.0

def get_valuation_indicator(field_name: str) -> float:
    value = latest.get(field_name)
    if value is not None and pd.notna(value) and float(value) > 0:
        return float(value)
    
    # 使用预先计算的中位数
    return valuation_medians.get(field_name, 0.0)
```

**预期提升**：10-20倍（避免重复的DataFrame转换和中位数计算）

### 4. DataFrame排序重复执行 ⚠️

**问题**：
- 每次调用`_extract_features_from_history`时，都会检查并可能排序DataFrame
- 但实际上数据可能已经排序

**优化后**：
```python
# 性能优化：检查是否已经排序，避免不必要的排序
if 'trade_date' in df.columns:
    try:
        # 检查是否已经排序（性能优化：避免不必要的排序）
        if not df['trade_date'].is_monotonic_increasing:
            df['trade_date'] = pd.to_datetime(df['trade_date'])
            df = df.sort_values('trade_date')
        else:
            # 如果已经排序，只需要转换日期格式（如果需要）
            if df['trade_date'].dtype != 'datetime64[ns]':
                try:
                    df['trade_date'] = pd.to_datetime(df['trade_date'])
                except Exception:
                    pass
    except Exception:
        pass
```

**预期提升**：1.5-2倍（避免不必要的排序操作）

## 五、注意事项

### 5.1 CPU和内存使用

- ⚠️ **CPU使用**：优化后会充分利用多核CPU，可能达到100%利用率
- ⚠️ **内存使用**：多线程会增加内存使用（每个线程需要数据副本）
- ⚠️ **数据库连接**：确保数据库连接池足够大

### 5.2 兼容性

- ✅ **向后兼容**：所有优化都保持向后兼容
- ✅ **错误处理**：单个线程失败不影响其他线程
- ✅ **日志输出**：保持原有的日志格式
