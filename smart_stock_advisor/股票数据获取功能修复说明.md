# 股票数据获取功能修复说明

## 一、问题描述

设置页面 → 股票数据获取 → "刷新列表" 和 "查看历史记录" 功能无法使用。

## 二、问题原因

### 1. JSON序列化错误
- 任务列表和历史记录数据中包含 `datetime` 和 `timedelta` 对象
- 这些对象无法直接被JSON序列化，导致API返回失败
- 错误信息：`Object of type timedelta is not JSON serializable`

### 2. 历史记录获取逻辑问题
- `refreshStockDataHistory()` 函数只获取第一页的任务（`page_size=1000`）
- 如果任务数量超过1000，会遗漏部分任务的历史记录
- 没有进度提示，用户体验不佳

### 3. 错误处理不完善
- 刷新列表失败时没有隐藏分页控件
- 错误信息不够详细

## 三、修复内容

### 1. 修复历史记录API序列化（`web_app.py`）

**修改位置**：第3775-3810行

**修改内容**：
- 在 `api_get_stock_data_task_history()` 中添加序列化处理
- 使用 `_serialize_task_for_json()` 函数转换历史记录数据

**修改前**：
```python

    'data': paginated_history,  # 包含datetime对象
    ...

```

**修改后**：
```python

    'success': True,

    ...
})
```
