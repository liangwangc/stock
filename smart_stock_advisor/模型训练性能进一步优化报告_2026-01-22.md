## 二、性能瓶颈分析

### 2.1 主要瓶颈

1. **排序检查开销**：每只股票都要检查是否已排序
2. **字典访问开销**：大量的 `latest.get()` 操作
3. **函数调用开销**：特征提取函数中的多次函数调用
4. **DataFrame访问开销**：重复访问DataFrame列
5. **类型转换开销**：重复的类型转换操作

## 三、优化方案

### 3.1 优化排序检查

**优化前**：
```python
# 每只股票都要排序
records_sorted = sorted(records, key=lambda x: x.get('trade_date'))
```

**优化后**：
```python
# 快速检查是否已排序，避免不必要的排序
records_sorted = records
if len(records) > 1:
    first_date = records[0].get('trade_date')
    last_date = records[-1].get('trade_date')
    if first_date and last_date and first_date > last_date:
        records_sorted = sorted(records, key=lambda x: x.get('trade_date'))
```

**预期提升**：10-20%（如果大部分数据已排序）

## 九、第三轮优化（2026-01-22 关键性能优化）

### 9.1 问题分析

**用户反馈**：
- 100只股票：42.3秒（第一轮优化后）
- 预计总时间：2215.2秒（约37分钟）
- **之前版本**：不到800秒就能跑完该流程

**根本原因**：
1. **每次循环都创建DataFrame切片**：`df_all.iloc[history_start_idx:history_end_idx]` 和 `df_all.iloc[i:i+1]`
2. **每次循环都调用特征提取函数**：`_extract_features_from_history_fast()` 函数内部有很多操作
3. **函数调用开销**：每次调用都要访问DataFrame，创建Series等

### 9.2 关键优化：完全避免DataFrame切片和函数调用

**优化策略**：
1. **预先提取所有列到numpy数组**：一次性提取所有需要的列，避免循环中重复访问DataFrame
2. **直接在循环中构建特征**：使用numpy数组索引，完全避免DataFrame切片和函数调用
3. **使用numpy数组切片**：时间序列特征使用numpy数组切片，比DataFrame切片快得多

**优化代码**：
```python
# 优化前：每次循环都创建DataFrame切片和调用函数
for i in range(...):
    df_history = df_all.iloc[history_start_idx:history_end_idx]  # 创建DataFrame切片
    df_current = df_all.iloc[i:i+1]  # 创建单行DataFrame
    features = self._extract_features_from_history_fast(df_history, df_current, ...)  # 函数调用

# 优化后：预先提取所有列到numpy数组，直接在循环中构建特征
# 预先提取（只执行一次）
close_prices = df_all['close_price'].fillna(0).astype(float).values
ma5s = df_all['ma5'].fillna(0).astype(float).values
# ... 其他列

# 循环中直接使用numpy数组
for i in range(...):
    features = {}
    features['close_price'] = close_prices[i]  # 直接数组索引
    features['ma5'] = ma5s[i]  # 直接数组索引
    # ... 其他特征
    hist_close = close_prices[history_start_idx:i]  # numpy数组切片
    features['close_price_lag_1'] = float(hist_close[-2])
```

### 9.4 优化原理

1. **避免DataFrame切片开销**：
   - DataFrame切片虽然不复制数据，但仍有索引查找、类型检查等开销
   - numpy数组切片是纯内存操作，速度快得多

2. **避免函数调用开销**：
   - 函数调用有栈帧创建、参数传递等开销
   - 直接在循环中构建特征，减少函数调用

3. **减少DataFrame访问**：
   - DataFrame访问需要索引查找、类型检查等
   - numpy数组访问是直接内存访问，速度快得多
