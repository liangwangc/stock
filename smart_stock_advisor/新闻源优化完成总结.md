## 使用说明

### 1. 新新闻源自动加载

新添加的新闻源会在 `UnifiedNewsSource` 初始化时自动加载：

```python
from quant_trading_platform.news import UnifiedNewsSource

# 初始化时会自动加载所有可用的新闻源，包括新增的财联社
news_source = UnifiedNewsSource(tushare_token="your_token")

# 查看所有新闻源
print(f"已初始化 {len(news_source.sources)} 个新闻源")
for name, source in news_source.sources:
    print(f"  - {name}")

# 获取市场新闻（会从所有可用新闻源聚合，包括新添加的，只获取当天）
news_list = news_source.get_market_news(limit=50, only_today=True)
```

### 2. 优化后的新闻源

优化后的东方财富和腾讯财经新闻源会自动使用新的解析逻辑：

```python

# 腾讯财经会自动尝试多个URL
from quant_trading_platform.news.tencent_news_source import TencentNewsSource

```

## 注意事项

1. **网站结构变化**: 网页爬虫可能因为网站结构变化而失效，需要定期检查和更新
2. **反爬虫机制**: 部分网站可能有反爬虫机制，需要添加延迟、User-Agent轮换等
3. **API限制**: 使用API的新闻源（如TuShare、财联社）需要注意API调用频率限制
4. **日期解析**: 不同网站的时间格式可能不同，需要不断优化时间解析逻辑
5. **备用URL**: 已为多个新闻源添加了备用URL，提高了容错性
