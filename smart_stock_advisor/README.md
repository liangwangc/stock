# Smart Stock Advisor - 智能股票预测系统

一个基于多数据源融合的股票涨跌预测系统，结合技术指标、新闻情感分析、市场情绪等多维度数据，预测股票明天的涨跌概率。

## 功能特性

- 📈 **多数据源接入**：股票市场数据、财经新闻、市场情绪
- 🤖 **智能预测模型**：结合技术指标、新闻情感、历史表现
- 📊 **可视化展示**：直观的图表展示预测结果和各项指标
- 🔍 **综合分析**：多维度分析，提高预测准确率
- 📰 **实时新闻**：接入金十数据、财新、各大证券公司新闻源

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行预测

```bash
python main.py
```

然后输入股票代码（如：600519），系统会自动分析并展示预测结果。

## 使用方法

### 命令行使用

```bash
python main.py --symbol 600519
```

### Python代码使用

```python
from predictor import StockPredictor

predictor = StockPredictor()
result = predictor.predict("600519")
predictor.visualize(result)
```

## 预测维度

系统从以下维度进行分析：

1. **技术指标分析**
   - MACD、RSI、MA等指标
   - 趋势判断
   - 支撑阻力位

2. **新闻情感分析**
   - 利好/利空新闻统计
   - 情感分数
   - 新闻影响力

3. **市场情绪**
   - 整体市场走势
   - 行业表现
   - 资金流向

4. **历史模式**
   - 相似历史走势
   - 统计概率
   - 季节性因素

## 输出结果

- **上涨概率**：0-100%
- **下跌概率**：0-100%
- **置信度**：预测的可靠程度
- **关键因素**：影响预测的主要因素
- **可视化图表**：直观展示各项指标
