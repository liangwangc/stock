# 实时交易决策功能说明

## 功能概述

实时交易决策系统在开盘时间实时获取市场数据，结合预测分析，给出买入/卖出/持有的交易建议，帮助投资者做出当天的交易决策。

## 核心特性

### 1. 实时数据获取
- **实时行情**: 当前价格、涨跌幅、换手率、振幅
- **资金流向**: 主力净流入、超大单/大单/中单/小单流向
- **买卖盘**: 五档买卖盘数据，分析买卖力量对比
- **交易时段**: 自动识别集合竞价、上午交易、午休、下午交易、收盘

### 2. 综合决策分析
系统综合以下因素计算交易信号：

| 因素 | 权重 | 说明 |
|------|------|------|
| 预测结果 | 60% | 基于技术指标、新闻情感、资金流向等的明日预测 |
| 实时资金流向 | 25% | 当日实时主力资金净流入/流出 |
| 买卖盘强度 | 5% | 五档买卖盘力量对比 |
| 盘中涨跌调整 | 10% | 防止追高杀跌的风险控制 |

### 3. 智能交易建议

#### 未持仓时的建议：
- **建议买入 (强烈)**: 上涨概率 > 75%，置信度 > 70%
- **可以买入 (适中)**: 上涨概率 > 65%，置信度 > 55%
- **建议观望**: 震荡行情，方向不明确
- **不建议买入**: 下跌概率 > 60%

#### 已持仓时的建议：
- **止损卖出**: 亏损超过止损线（默认-5%）
- **止盈卖出**: 盈利达到目标（默认+8%）且预测看跌
- **建议卖出**: 下跌概率 > 70%
- **建议减仓**: 下跌概率 > 60%
- **可以加仓**: 上涨概率 > 75%，当前盈利中
- **继续持有**: 设置移动止损继续持有

## 使用方法

### 命令行参数

```bash
# 基本参数
--symbol, -s    股票代码（如：600519）
--realtime, -r  实时交易决策模式
--monitor, -m   实时监控模式（持续运行）
--scan          批量扫描模式
--interval, -i  监控更新间隔（秒），默认60秒
--holding       是否持有该股票
--cost          持仓成本价
--limit         扫描股票数量限制
```

### 使用示例

#### 1. 实时决策（未持仓）
```bash
py main.py --realtime --symbol 600519
```
输出示例：
```
【实时交易决策结果】
股票代码: 600519
当前价格: 1850.00元
今日涨跌: 1.25%

【明日预测】
预测方向: 上涨
上涨概率: 72.5%
置信度: 68.0%

【交易决策】
操作建议: 可以买入 (适中)

决策理由:
  1. 预测明天上涨概率72.5%
  2. 实时资金净流入，买盘活跃

价格建议:
  理想买入价: 1831.50元
  最高买入价: 1887.00元
  止损价: 1740.00元
  目标价: 1978.00元

仓位建议: 建议轻仓试探: 10%
```

#### 2. 实时决策（已持仓）
```bash
py main.py --realtime --symbol 600519 --holding --cost 1800
```
系统会根据持仓成本计算当前盈亏，并给出相应建议。

#### 3. 持续监控
```bash
py main.py --monitor --symbol 600519 --interval 30
```
每30秒更新一次，当交易信号发生变化时会提醒。

#### 4. 批量扫描
```bash
py main.py --scan --limit 50
```
扫描成交额最高的50只股票，找出最佳买入机会。

## 配置说明

在 `config.py` 中可以调整以下参数：

```python
TRADING_CONFIG = {
    # 买入信号阈值
    "buy_signal_threshold": 0.65,      # 上涨概率超过此值考虑买入
    "strong_buy_threshold": 0.75,      # 强烈买入信号阈值
    
    # 卖出信号阈值
    "sell_signal_threshold": 0.60,     # 下跌概率超过此值考虑卖出
    "strong_sell_threshold": 0.70,     # 强烈卖出信号阈值
    
    # 置信度要求
    "min_confidence": 0.55,            # 最低置信度要求
    "high_confidence": 0.70,           # 高置信度
    
    # 止损止盈设置
    "stop_loss_pct": -5.0,             # 止损比例（%）
    "take_profit_pct": 8.0,            # 止盈比例（%）
    "trailing_stop_pct": 3.0,          # 移动止损比例（%）
    
    # 仓位控制
    "max_position_pct": 30.0,          # 单只股票最大仓位（%）
    "position_step": 10.0,             # 建仓步进（%）
}
```

## 交易时段说明

| 时段 | 时间 | 系统行为 |
|------|------|----------|
| 盘前 | < 09:15 | 等待集合竞价 |
| 集合竞价 | 09:15-09:25 | 可获取竞价数据 |
| 竞价结束 | 09:25-09:30 | 等待开盘 |
| 上午交易 | 09:30-11:30 | 正常交易决策 |
| 午间休市 | 11:30-13:00 | 暂停监控 |
| 下午交易 | 13:00-15:00 | 正常交易决策 |
| 收盘后 | > 15:00 | 监控结束 |

## 风险提示

1. **本系统仅供参考**，不构成投资建议
2. 股市有风险，投资需谨慎
3. 建议结合自身风险承受能力和投资经验做出决策
4. 历史数据和预测不代表未来表现
5. 建议设置合理的止损止盈，控制风险

## 技术架构

```
main.py
    ├── --realtime/--monitor/--scan
    │       ↓
    └── RealtimeTradingAdvisor
            ├── StockDataSource.get_realtime_quote()     # 实时行情
            ├── StockDataSource.get_realtime_capital_flow()  # 资金流向
            ├── StockDataSource.get_bid_ask_data()       # 买卖盘
            ├── StockPredictor.predict()                 # 预测分析
            └── _make_trading_decision()                 # 生成决策
```
