# 美股数据源使用说明

## 当前状态

系统目前支持两个主要数据源获取美股数据：
1. **akshare**（优先使用）
2. **yfinance**（备用）

## 接口限制问题

如果遇到以下错误，说明接口有限制：
- `Too Many Requests`
- `Rate limited`
- `429` 错误
- `YFRateLimitError`

## 解决方案

### 方案1：使用增强版数据源（推荐）

系统已提供增强版数据源 `us_stock_data_source_enhanced.py`，支持多个备用接口：

#### 支持的接口：
1. **akshare** - 免费，无API密钥
2. **yfinance** - 免费，无API密钥
3. **Alpha Vantage** - 免费注册，每分钟5次请求，每天500次
4. **Polygon.io** - 免费注册，每分钟5次请求
5. **Finnhub** - 免费注册，每分钟60次请求

#### 使用方法：

```python
from data_source.us_stock_data_source_enhanced import EnhancedUSStockDataSource

# 方式1: 使用环境变量设置API密钥
import os
os.environ['ALPHA_VANTAGE_API_KEY'] = 'your_api_key'
os.environ['POLYGON_API_KEY'] = 'your_api_key'
os.environ['FINNHUB_API_KEY'] = 'your_api_key'

# 方式2: 直接传入API密钥
ds = EnhancedUSStockDataSource(
    alpha_vantage_api_key='your_alpha_vantage_key',
    polygon_api_key='your_polygon_key',
    finnhub_api_key='your_finnhub_key'
)

# 获取数据（自动尝试所有可用接口）
df = ds.get_stock_data('AAPL', start_date='2024-01-01', end_date='2024-12-31')
```

#### 获取免费API密钥：

1. **Alpha Vantage**:
   - 注册地址: https://www.alphavantage.co/support/#api-key
   - 免费版限制: 每分钟5次请求，每天500次

2. **Polygon.io**:
   - 注册地址: https://polygon.io/
   - 免费版限制: 每分钟5次请求

3. **Finnhub**:
   - 注册地址: https://finnhub.io/
   - 免费版限制: 每分钟60次请求

```bash

```

这个脚本会：
1. 检查各个数据源是否可用
2. 测试获取数据（AAPL, MSFT, GOOGL）
3. 显示成功/失败统计

## 推荐配置

### 对于少量股票（< 100只）：
- 使用现有的 `USStockDataSource`（akshare + yfinance）
- 设置合理的延迟和重试

### 对于大量股票（> 100只）：
- 使用增强版 `EnhancedUSStockDataSource`
- 注册多个免费API密钥（Alpha Vantage, Polygon, Finnhub）
- 系统会自动在多个接口间切换

## 注意事项

1. **API密钥安全**：
   - 不要将API密钥提交到代码仓库
   - 使用环境变量或配置文件存储

2. **速率限制**：
   - 每个接口都有速率限制
   - 增强版会自动处理速率限制，在接口间切换

3. **数据质量**：
   - 不同接口返回的数据格式可能略有不同
   - 系统会自动标准化数据格式

4. **成本考虑**：
   - 免费版通常有请求次数限制
   - 如需大量数据，考虑付费版本

## 故障排查

如果所有数据源都失败：

1. **检查网络连接**
   ```bash
   ping api.polygon.io
   ```

2. **检查API密钥**
   - 确认密钥是否正确
   - 确认密钥是否过期

3. **查看日志**
   - 检查日志文件中的详细错误信息
   - 确认是哪个接口失败

4. **联系支持**
   - 如果问题持续，可能需要联系API提供商
