## 二、判断逻辑

### 2.1 数据来源

**数据表**: `stock_predictions`  
**查询时间范围**: 最近30天  
**查询字段**: 
- `prediction_hit`: 预测是否命中（值为"命中"或NULL）

**SQL查询**:
```sql
SELECT 
    COUNT(*) as total,
    SUM(CASE WHEN prediction_hit = '命中' THEN 1 ELSE 0 END) as hit_count
FROM stock_predictions
WHERE target_date >= DATE_SUB(NOW(), INTERVAL 30 DAY)
  AND prediction_hit IS NOT NULL
```

**代码位置**: `utils/system_monitor.py` 第104-111行

---

### 2.2 准确率计算

**计算公式**:
```
准确率 = (命中数 / 总数) × 100%
```

**示例**:
- 最近30天有100条预测记录
- 其中20条命中（prediction_hit = '命中'）
- 准确率 = (20 / 100) × 100% = 20%

**代码位置**: `utils/system_monitor.py` 第116行

---

### 2.3 告警阈值

**告警条件**:
```python
if accuracy > 0 and accuracy < 50:
    # 触发告警
```

**判断逻辑**:
- ✅ **准确率 > 0**: 有预测记录且已评估
- ✅ **准确率 < 50%**: 准确率低于50%（低于随机猜测水平）

**代码位置**: `utils/system_monitor.py` 第335行

## 三、告警含义

### 3.1 告警级别

**级别**: `warning`（警告）  
**类型**: `business`（业务指标）  
**指标**: `prediction_accuracy`（预测准确率）

### 3.2 告警含义

**19.64% 准确率的含义**:
- 最近30天内，系统进行了预测
- 预测结果已与实际走势对比（`prediction_hit` 字段有值）

### 3.3 告警原因分析

**可能原因**:
1. **预测模型参数需要优化**
   - 因子权重配置不合理

   - ML模型权重过高或过低

2. **市场环境变化**
   - 市场处于异常波动期
   - 预测模型不适应当前市场状态

3. **数据质量问题**
   - 历史数据不完整
   - 实时数据获取异常
   - 新闻数据质量下降

4. **预测逻辑问题**
   - 预测算法存在bug
   - 置信度计算有误
   - 异常检测过于严格

## 四、数据验证

### 4.1 检查预测记录

**查询最近30天的预测记录**:
```sql
SELECT 
    COUNT(*) as total,
    SUM(CASE WHEN prediction_hit = '命中' THEN 1 ELSE 0 END) as hit_count,
    SUM(CASE WHEN prediction_hit = '命中' THEN 1 ELSE 0 END) * 100.0 / COUNT(*) as accuracy_percent
FROM stock_predictions
WHERE target_date >= DATE_SUB(NOW(), INTERVAL 30 DAY)
  AND prediction_hit IS NOT NULL;
```

### 4.2 检查预测分布

**按日期查看预测准确率趋势**:
```sql
SELECT 
    DATE(target_date) as date,
    COUNT(*) as total,
    SUM(CASE WHEN prediction_hit = '命中' THEN 1 ELSE 0 END) as hit_count,
    SUM(CASE WHEN prediction_hit = '命中' THEN 1 ELSE 0 END) * 100.0 / COUNT(*) as accuracy_percent
FROM stock_predictions
WHERE target_date >= DATE_SUB(NOW(), INTERVAL 30 DAY)
  AND prediction_hit IS NOT NULL
GROUP BY DATE(target_date)
ORDER BY date DESC;
```

### 4.3 检查未评估的预测

**查看有多少预测还未评估**:
```sql
SELECT 
    COUNT(*) as total,
    SUM(CASE WHEN prediction_hit IS NULL THEN 1 ELSE 0 END) as not_evaluated
FROM stock_predictions
WHERE target_date >= DATE_SUB(NOW(), INTERVAL 30 DAY);
```
