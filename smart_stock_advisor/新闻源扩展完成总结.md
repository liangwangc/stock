## 使用说明

### 1. 当天新闻过滤

现在每次抓取新闻时，默认只抓取当天的新闻：

```python
from utils.news_crawler import NewsCrawler

crawler = NewsCrawler()

# 市场新闻（只抓取当天）
result = crawler.crawl_market_news(limit=50, only_today=True)

# 股票新闻（只抓取当天）
result = crawler.crawl_stock_news(symbol='000001', limit=20, only_today=True)
```

### 2. 新新闻源自动加载

新添加的新闻源会在 `UnifiedNewsSource` 初始化时自动加载：

```python
from quant_trading_platform.news import UnifiedNewsSource

# 初始化时会自动加载所有可用的新闻源，包括新增的证券时报和中国证券报
news_source = UnifiedNewsSource(tushare_token="your_token")

# 获取市场新闻（会从所有可用新闻源聚合，包括新添加的）
news_list = news_source.get_market_news(limit=50, only_today=True)
```

## 注意事项

1. **网站结构变化**: 网页爬虫可能因为网站结构变化而失效，需要定期检查和更新
2. **反爬虫机制**: 部分网站可能有反爬虫机制，需要添加延迟、User-Agent轮换等
3. **API限制**: 使用API的新闻源（如TuShare）需要注意API调用频率限制
4. **日期解析**: 不同网站的时间格式可能不同，需要不断优化时间解析逻辑
