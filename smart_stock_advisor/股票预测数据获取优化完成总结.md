# 股票预测数据获取优化完成总结

## 一、优化目标

优化股票预测的数据获取机制，确保：
1. **优先从数据库获取数据**（根据时间判断）
2. **如果数据库中没有相关数据，再实时获取数据**

## 二、优化内容

### 1. `get_stock_data()` 方法（`data_source/stock_data_source.py`）

**现状**：✅ 已经实现了优先从数据库获取的逻辑

**逻辑**：
- 优先从数据库 `stock_history_data` 表获取指定日期范围的数据
- 如果数据库中有数据，直接返回
- 如果数据库中没有数据，才从API（akshare）获取

**时间判断**：
- 支持 `start_date` 和 `end_date` 参数
- 如果未指定日期，默认获取最近 `days` 天的数据
- 日期格式支持 `YYYY-MM-DD` 和 `YYYYMMDD`

### 2. `get_realtime_quote()` 方法（`data_source/stock_data_source.py`）

**优化前**：直接调用API获取实时行情数据

**优化后**：
1. **优先从数据库获取今天的数据**
   - 查询 `stock_history_data` 表中今天（`trade_date = today`）的数据
   - 如果数据库中有今天的数据，构建实时行情数据并返回
   - 计算涨跌幅、涨跌额、换手率、振幅等指标

2. **如果数据库没有今天的数据，才从API获取**
   - 调用 `ak.stock_zh_a_spot_em()` 获取实时行情
   - 保持原有逻辑不变

**代码位置**：`data_source/stock_data_source.py` 第 1622-1701 行

### 3. `predict()` 方法中的当前价格获取逻辑（`predictor/stock_predictor.py`）

**优化前**：
- 优先使用实时API获取价格
- 如果实时API失败，才使用历史数据最新价格

**优化后**：
1. **优先从数据库获取今天的数据**
   - 查询 `stock_history_data` 表中今天的数据
   - 如果数据库中有今天的数据，使用数据库中的收盘价

2. **如果数据库没有今天的数据**
   - 尝试从实时API获取（如果市场未收盘）
   - 如果实时API失败，使用历史数据最新价格

3. **记录价格来源**
   - 记录价格来源（数据库今天数据 / 实时API价格 / 历史数据最新价格）
   - 便于调试和追踪

**代码位置**：`predictor/stock_predictor.py` 第 2348-2380 行

## 三、优化效果

### 1. 性能提升
- ✅ **减少API调用**：如果数据库中有今天的数据，不再调用实时API
- ✅ **提高响应速度**：数据库查询比API调用更快
- ✅ **降低API限流风险**：减少对第三方API的依赖

### 2. 数据一致性
- ✅ **优先使用数据库数据**：确保使用定时任务更新的最新数据
- ✅ **时间判断准确**：根据日期判断是否需要实时获取
- ✅ **降级策略完善**：数据库 → 实时API → 历史数据

### 3. 日志记录
- ✅ **记录数据来源**：明确记录价格来源，便于调试
- ✅ **记录获取过程**：记录从数据库获取或从API获取的过程

## 四、数据获取流程

### 股票历史数据获取流程
```
1. 调用 get_stock_data(symbol, days=60)
   ↓
2. 计算日期范围（start_date, end_date）
   ↓
3. 查询数据库 stock_history_data 表
   ↓
4. 数据库有数据？
   ├─ 是 → 返回数据库数据 ✅
   └─ 否 → 调用API获取 → 返回API数据
```

### 当前价格获取流程
```
1. 调用 predict(symbol)
   ↓
2. 获取历史数据（get_stock_data）
   ↓
3. 获取当前价格
   ├─ 优先：查询数据库今天的数据
   │   ├─ 有数据 → 使用数据库价格 ✅
   │   └─ 无数据 → 继续下一步
   ├─ 其次：调用实时API（get_realtime_quote）
   │   ├─ API成功 → 使用实时价格
   │   └─ API失败 → 继续下一步
   └─ 最后：使用历史数据最新价格
```

### 实时行情获取流程
```
1. 调用 get_realtime_quote(symbol)
   ↓
2. 查询数据库今天的数据
   ↓
3. 数据库有今天的数据？
   ├─ 是 → 构建实时行情数据 → 返回 ✅
   └─ 否 → 调用API获取 → 返回API数据
```

## 五、注意事项

### 1. 数据库数据更新
- 确保定时任务每天收盘后更新 `stock_history_data` 表
- 如果定时任务未执行，系统会自动降级到API获取

### 2. 时间判断
- 使用 `datetime.now().strftime('%Y-%m-%d')` 获取今天的日期
- 数据库查询使用 `trade_date = today` 条件

### 3. 数据完整性
- 数据库中的数据可能不包含实时行情字段（如买一价、卖一价）
- 如果数据库没有这些字段，会返回空值，但不影响基本价格数据

## 六、测试建议

1. **测试数据库有今天数据的情况**
   - 确保定时任务已更新今天的数据
   - 验证预测时是否从数据库获取价格

2. **测试数据库没有今天数据的情况**
   - 删除今天的数据或使用未更新的股票
   - 验证是否降级到API获取

3. **测试API失败的情况**
   - 模拟API调用失败
   - 验证是否使用历史数据最新价格
