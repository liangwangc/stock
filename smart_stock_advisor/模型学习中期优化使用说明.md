# 模型学习中期优化使用说明

## 一、功能概述

本次中期优化新增了以下功能：

1. **自适应学习策略**：根据市场波动自动调整学习频率
2. **触发式学习**：预测准确率下降时自动触发学习
3. **在线学习机制**：增量权重更新和批量在线学习
4. **增强评估指标**：多指标综合评估、分市场状态评估、置信度校准评估

## 二、使用方式

### 2.1 方式一：通过设置页面创建定时任务（推荐）✅

**步骤**：
1. 打开"设置页面" → "模型学习" → "定时学习任务"
2. 点击"创建定时学习任务"按钮
3. 选择任务类型：
   - **模型评估任务** (`model_evaluation`)：定期评估模型性能
   - **参数优化任务** (`model_optimization`)：定期优化权重参数
   - **自适应优化任务** (`adaptive_optimization`)：**新增**，根据市场状态自动优化
   - **综合评估任务** (`comprehensive_evaluation`)：**新增**，多指标综合评估
   - **在线学习任务** (`online_learning`)：**新增**，批量更新权重
4. 设置调度方式：
   - **每日**：每天固定时间执行
   - **每周**：每周固定时间执行
   - **每月**：每月固定时间执行
5. 设置执行时间（如：15:30）
6. 点击"创建"并"启动"任务

**推荐配置**：

| 任务类型 | 调度方式 | 执行时间 | 说明 |
|---------|---------|---------|------|
| 模型评估任务 | 每日 | 15:30 | 每天收盘后评估模型性能 |
| 自适应优化任务 | 每周 | 20:00 | 每周日晚上根据市场状态自动优化 |
| 综合评估任务 | 每周 | 21:00 | 每周日晚上进行综合评估 |
| 在线学习任务 | 每日 | 16:00 | 每天收盘后批量更新权重 |

### 2.2 方式二：后端代码自动触发（已集成）✅

**自动触发场景**：

1. **定时任务自动执行**：
   - 系统启动时会自动加载并启动所有启用的定时任务
   - 定时任务会在设定的时间自动执行
   - 执行结果会自动记录到数据库

2. **预测保存后增量更新**（可选，需要配置）：
   - 在预测保存后，如果已有实际结果，可以自动调用增量更新
   - 需要在代码中启用（见下方说明）

### 2.3 方式三：手动调用API（高级用户）✅

**API接口**：

1. **检查是否触发学习**：
   ```python
   GET /api/model/learning/check_trigger
   ```

2. **执行自适应优化**：
   ```python
   POST /api/model/learning/adaptive_optimization
   {
       "base_frequency_days": 7
   }
   ```

3. **执行综合评估**：
   ```python
   POST /api/model/learning/comprehensive_evaluation
   {
       "days": 30
   }
   ```

4. **执行在线学习**：
   ```python
   POST /api/model/learning/online_learning
   {
       "days": 7
   }
   ```

## 三、详细配置说明

### 3.1 自适应优化任务配置

**任务类型**：`adaptive_optimization`

**配置参数**（在"任务配置"中设置）：
```json
{
    "base_frequency_days": 7  // 基础学习频率（天数），默认7天
}
```

**工作原理**：
- 根据市场波动率自动调整学习频率
- 高波动（>0.7）：频率提高2倍
- 中等波动（0.4-0.7）：基础频率
- 低波动（<0.4）：频率降低
- 根据市场状态（牛市/熊市/震荡市）调整学习范围

### 3.2 综合评估任务配置

**任务类型**：`comprehensive_evaluation`

**配置参数**（在"任务配置"中设置）：
```json
{
    "days": 30  // 评估时间范围（天数），默认30天
}
```

**评估内容**：
- 多指标综合评估（方向准确率、幅度准确率、置信度校准）
- 分市场状态评估（牛市/熊市/震荡市分别评估）
- 置信度校准评估（ECE/MCE）

### 3.3 在线学习任务配置

**任务类型**：`online_learning`

**配置参数**（在"任务配置"中设置）：
```json
{
    "days": 7  // 使用最近N天的数据，默认7天
}
```

**工作原理**：
- 使用最近N天的预测结果和实际结果
- 使用在线梯度下降算法批量更新权重
- 更新后的权重需要手动确认应用（不会自动应用）

### 3.4 触发式学习（自动检查）

**触发条件**：
1. **预测准确率下降**：最近7天准确率比之前7天下降超过5%
2. **市场状态变化**：市场状态从牛市/熊市/震荡市发生变化

**如何启用**：
- 可以创建一个定时任务，每天检查是否触发学习
- 如果触发，自动执行自适应优化

**示例配置**：
```json
{
    "task_type": "adaptive_optimization",
    "schedule_type": "daily",
    "schedule_time": "16:00",
    "task_config": {
        "base_frequency_days": 7,
        "auto_trigger": true  // 自动检查触发条件
    }
}
```

## 四、增量更新（预测后自动更新）

### 4.1 启用方式

在预测保存后自动调用增量更新，需要在代码中启用：

**位置**：`utils/stock_prediction_db.py` 的 `save_prediction` 方法

**添加代码**：
```python
# 在保存预测后，如果有实际结果，调用增量更新
if prediction_result.get('prediction_hit') in ['命中', '未命中']:
    try:
        from utils.online_learning import OnlineLearning
        online_learning = OnlineLearning()
        
        # 准备实际结果
        actual_result = {
            'actual_price': prediction_result.get('actual_price'),
            'actual_change_pct': prediction_result.get('actual_change_pct'),
            'actual_direction': prediction_result.get('actual_direction'),
            'prediction_hit': prediction_result.get('prediction_hit')
        }
        
        # 增量更新权重（如果更新成功，可以选择应用）
        updated_config = online_learning.update_weights_incremental(
            prediction_result,
            actual_result
        )
        
        # 可选：自动应用新权重（需要谨慎）
        # if updated_config:
        #     from utils.prediction_config_manager import PredictionConfigManager
        #     config_manager = PredictionConfigManager()
        #     config_manager.save_config(updated_config)
    except Exception as e:
        logger.warning(f"增量更新权重失败: {str(e)}")
```

**注意**：
- 增量更新影响较小，可以实时应用
- 但建议先观察一段时间，确认效果后再启用自动应用

### 4.2 限制条件

- 需要至少10个样本才能更新
- 更新幅度有限制（单次更新不超过10%）
- 权重范围限制在0.01-0.5之间

## 五、任务执行流程

### 5.1 定时任务执行流程

```
1. 系统启动
   ↓
2. 加载所有启用的定时任务
   ↓
3. 根据调度方式设置执行时间
   ↓
4. 定时检查是否到达执行时间
   ↓
5. 到达时间后执行任务
   ↓
6. 记录执行结果到数据库
   ↓
7. 更新下次执行时间
```

### 5.2 自适应优化执行流程

```
1. 检查市场波动率
   ↓
2. 确定学习频率
   ↓
3. 识别市场状态
   ↓
4. 确定学习范围
   ↓
5. 执行优化（网格搜索或贝叶斯优化）
   ↓
6. 评估优化结果
   ↓
7. 如果改进超过阈值，自动应用新权重
```

### 5.3 在线学习执行流程

```
1. 获取最近N天的预测结果和实际结果
   ↓
2. 检查样本数是否足够（≥10）
   ↓
3. 计算权重梯度
   ↓
4. 更新权重
   ↓
5. 归一化权重
   ↓
6. 返回新权重配置（需要手动确认应用）
```

## 七、注意事项

### 7.1 数据要求

- **自适应优化**：需要至少30天的历史数据
- **综合评估**：需要至少30天的历史数据
- **在线学习**：需要至少10个样本

### 7.2 执行时间建议

- **模型评估**：每天收盘后（15:30）
- **自适应优化**：每周日晚上（20:00），非交易时间
- **综合评估**：每周日晚上（21:00），非交易时间
- **在线学习**：每天收盘后（16:00）

### 7.3 性能考虑

- **自适应优化**：可能需要较长时间（10-30分钟），建议在非交易时间执行
- **综合评估**：可能需要较长时间（5-15分钟），建议在非交易时间执行
- **在线学习**：执行时间较短（1-5分钟），可以实时执行

### 7.4 权重应用策略

- **增量更新**：可以实时应用（影响较小）
- **批量在线学习**：建议先评估效果，再决定是否应用
- **自适应优化**：如果改进超过阈值（默认5%），会自动应用

## 八、常见问题

### Q1: 如何知道任务是否执行成功？

A: 在"设置页面" → "模型学习" → "定时学习任务"中查看任务状态和执行结果。

### Q2: 权重更新后如何查看效果？

A: 可以通过"模型评估任务"评估更新后的权重效果，或者查看预测准确率的变化。

### Q3: 可以同时运行多个学习任务吗？

A: 可以，但建议错开执行时间，避免资源竞争。

### Q4: 如何停止自动应用优化结果？

A: 在任务配置中设置 `auto_apply_threshold` 为一个很大的值（如100%），这样就不会自动应用。

### Q5: 增量更新会影响当前预测吗？

A: 不会立即影响，需要应用新权重后才会影响后续预测。

## 九、总结

本次中期优化提供了三种使用方式：

1. **设置页面创建定时任务**（推荐）：最简单，适合大多数用户
2. **后端代码自动触发**：已集成到定时任务系统，自动执行
3. **手动调用API**：适合高级用户和自定义场景

**推荐配置**：
- 每天收盘后执行模型评估和在线学习
- 每周日晚上执行自适应优化和综合评估
- 根据实际需求调整执行频率和时间
