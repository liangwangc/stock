# 新闻模块优化完成总结

## 一、优化完成情况

### ✅ 已完成优化

#### 1. 新闻去重优化 ✅
- **新增模块**：`utils/news_deduplication.py`
- **功能**：
  - 实现SimHash算法进行内容相似度检测
  - 支持64位SimHash值计算
  - 支持汉明距离计算和相似度判断（阈值可配置，默认3）
  - 基于内容相似度检测重复新闻（不仅限于标题和来源）
- **数据库**：
  - 在 `news_articles` 表添加 `simhash` 字段（BIGINT UNSIGNED）
  - 添加 `simhash` 索引，提高查询速度
- **集成**：已集成到 `NewsStorage`，保存新闻时自动计算并保存SimHash值

#### 2. 新闻搜索功能 ✅
- **新增模块**：`utils/news_search.py`
- **功能**：
  - 支持关键词搜索（标题和内容）
  - 支持多种筛选条件（股票代码、情感倾向、时间范围、板块、行业、新闻类型等）
  - 支持排序（按发布时间、相关性得分、情感得分等）
  - 支持分页（page、page_size）
  - 支持搜索建议（自动补全）
- **API接口**：
  - `GET /api/news/search`：搜索新闻接口
  - `GET /api/news/search/suggestions`：获取搜索建议接口

#### 3. 新闻推送功能 ✅
- **新增模块**：`utils/news_notification.py`
- **功能**：
  - 判断是否需要推送（重要新闻自动识别）
  - 创建通知记录
  - 获取待发送通知
  - 标记通知为已发送
  - 获取用户通知列表
- **推送条件**：
  - 直接关联的利好/利空新闻（relevance_type='direct'）
  - 高置信度的情感分析结果（sentiment_confidence > 0.7）
  - 高强度的情感得分（|sentiment_score| > 0.5）
  - 政策新闻（重大新闻）
- **数据库**：
  - 创建 `news_notifications` 表
  - 包含通知类型、发送状态、阅读状态等字段
- **集成**：已集成到 `NewsStorage`，保存新闻时自动检查是否需要推送

#### 4. 情感分析优化 ✅
- **优化模块**：`quant_trading_platform/news/sentiment_analyzer.py`
- **改进**：
  - 改进否定词处理逻辑：检查否定词与关键词的上下文关系（前后10个字符）
  - 改进置信度计算：考虑关键词权重、强度关键词和上下文
  - 如果否定词在关键词前面，反转情感（更准确）
  - 如果有高强度关键词或关键词较多，提高置信度

### ⚠️ 部分完成/待完成优化

#### 5. 任务调度优化 ⚠️ 部分完成
- **现状分析**：
  - 新闻抓取任务使用 `threading.Event` + `time.sleep`，功能有限
  - 其他定时任务使用 `schedule` 库，支持更灵活的调度
  - 问题：两种调度方式不一致，新闻任务不支持cron表达式
- **优化方案**（后续实现）：
  - 统一使用 `schedule` 库（轻量级，已在使用）
  - 将新闻抓取任务迁移到 `scheduled_task_manager` 统一管理
  - 支持更灵活的时间配置（daily、hourly、weekly、custom）
  - 保留对cron表达式的扩展支持（后续可集成APScheduler）
- **原因**：任务调度优化需要较大的重构工作，建议在后续版本中实现

## 四、使用说明

### 1. SimHash去重

- **自动启用**：保存新闻时自动计算SimHash值
- **去重检测**：先检查精确匹配（标题+来源），再使用SimHash相似度检测
- **相似度阈值**：默认汉明距离 < 3（可在 `NewsDeduplication` 初始化时配置）

### 2. 新闻搜索

**API调用示例**：
```bash
# 搜索关键词
GET /api/news/search?keyword=茅台&page=1&page_size=20

# 搜索利好新闻
GET /api/news/search?sentiment=positive&date_from=2026-01-01&page=1

# 搜索指定股票的新闻
GET /api/news/search?symbol=600519&sentiment=positive&page=1

# 获取搜索建议
GET /api/news/search/suggestions?keyword=茅&limit=10
```

### 3. 新闻推送

- **自动启用**：保存新闻时自动检查是否需要推送
- **推送条件**：直接关联的利好/利空新闻、高置信度情感分析、政策新闻
- **查看通知**：通过 `NewsNotification.get_user_notifications()` 获取用户通知列表
