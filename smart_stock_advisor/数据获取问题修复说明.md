# 数据获取问题修复说明

## 问题描述

执行 `py scripts\batch_collect_10years_data.py --market cn --batch-size 50 --delay 1.0` 命令后，没有获取到数据。

## 问题分析

经过检查，发现了一个关键问题：

### 原问题：无法获取历史数据

**问题代码**：`utils/stock_history_collector.py:61`
```python
# 原代码：只获取最近10天的数据
days_data = self.data_source.get_stock_data(symbol, days=10)
```

**问题原因**：
- `collect_stock_daily_data` 方法只获取最近10天的数据
- 如果要收集历史数据（比如1年前的数据），这个方法无法获取到
- 因为 `get_stock_data(symbol, days=10)` 只会获取从今天往前推10天的数据

### 测试结果

使用测试脚本验证数据获取功能：
```python
# 测试获取2024年1月的数据
ds.get_stock_data('000001', start_date='2024-01-01', end_date='2024-01-31')
# 结果：成功获取 22 条记录
```

**结论**：数据源本身是可以获取历史数据的，但 `collect_stock_daily_data` 方法的实现有问题。

## 修复方案

### 1. 修改 `get_stock_data` 方法

**文件**：`data_source/stock_data_source.py`

**修改内容**：
- 添加 `start_date` 和 `end_date` 参数
- 支持指定日期范围获取数据
- 保持向后兼容（如果不提供日期，使用 `days` 参数）

```python
def get_stock_data(self, symbol: str, days: int = 60, start_date: str = None, end_date: str = None) -> pd.DataFrame:
    """
    获取股票历史数据
    
    Args:
        symbol: 股票代码
        days: 获取最近多少天的数据（当start_date和end_date为None时使用）
        start_date: 开始日期（格式：YYYY-MM-DD 或 YYYYMMDD），如果提供，则忽略days参数
        end_date: 结束日期（格式：YYYY-MM-DD 或 YYYYMMDD），如果为None，则使用今天
    """
```

### 2. 修改 `collect_stock_daily_data` 方法

**文件**：`utils/stock_history_collector.py`

**修改内容**：
- 根据目标日期计算日期范围（前后各10天）
- 使用 `start_date` 和 `end_date` 参数获取数据
- 确保能够获取到历史数据

```python
# 修改后的代码
date_obj = datetime.strptime(date, '%Y-%m-%d')
start_date = (date_obj - timedelta(days=10)).strftime('%Y-%m-%d')
end_date = (date_obj + timedelta(days=10)).strftime('%Y-%m-%d')

# 使用指定的日期范围获取数据
days_data = self.data_source.get_stock_data(symbol, start_date=start_date, end_date=end_date)
```

## 其他可能的问题

### 1. 数据库连接问题

如果数据获取成功但保存失败，检查：
- 数据库是否正常运行
- `config_db.py` 中的数据库配置是否正确
- 数据库表是否已创建

### 2. 数据源API限制

如果出现API限制错误：
- 增加延迟时间（`--delay 2.0`）
- 减小批次大小（`--batch-size 30`）
- 等待一段时间后重试

### 3. 数据字段不匹配

如果出现SQL错误：
- 检查数据库表结构是否与代码匹配
- 确保已执行 `add_period_type_safe.py` 添加 `period_type` 字段
- 检查是否有其他字段缺失
