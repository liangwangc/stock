# 模型学习功能历史数据需求分析

## 分析日期
2026-01-14

## 一、功能概览

设置页面--模型学习部分包含以下功能：

1. **性能评估** - 评估模型的历史预测准确率和交易收益
2. **参数优化** - 基于历史表现自动优化权重参数
3. **综合评估** - 多指标、分市场状态、置信度校准的综合评估
4. **在线学习** - 批量更新权重
5. **自适应优化** - 根据市场波动自动调整学习频率和范围
6. **定时学习任务** - 自动定期评估和优化

## 二、各功能历史数据需求分析

### 1. 性能评估 ✅ **需要历史股票数据**

**功能位置**：`设置页面 -> 模型学习 -> 性能评估`

**数据需求**：
- **必需数据表**：
  - `stock_predictions` 表：包含预测值和实际值
    - `prediction`（预测方向）
    - `up_probability`、`down_probability`（预测概率）
    - `confidence`（置信度）
    - `actual_direction`（实际方向）**必需**
    - `actual_price`（实际价格）**必需**
    - `prediction_hit`（预测命中）**必需**
    - `target_date`、`prediction_date`（时间范围）
  - `prediction_factors` 表：因子得分数据
    - `technical_score`、`news_score`、`capital_flow_score` 等因子得分
    - 用于计算因子贡献度

**数据用途**：
- 计算方向准确率：`prediction` vs `actual_direction`
- 计算幅度误差：`predicted_change_pct` vs `actual_change_pct`
- 计算置信度校准度：`confidence` vs `prediction_hit`
- 分析因子贡献度：各因子得分与预测准确率的关系
- 识别市场状态：根据历史数据识别牛市/熊市/震荡市

**数据量要求**：
- 最少需要 **50-100条** 有实际结果的预测记录
- 建议时间范围：**最近30-90天**

**代码位置**：
- `utils/model_performance_evaluator.py` - `evaluate_performance()` 方法
- 查询SQL：从 `stock_predictions` 和 `prediction_factors` 表获取数据

## 五、数据获取建议

### 1. 确保预测数据有实际结果

**问题**：如果 `stock_predictions` 表中的 `actual_direction`、`actual_price`、`prediction_hit` 字段为空，则无法进行模型学习。

**解决方案**：
- 定期更新预测记录的实际结果
- 使用 `StockDataSource.get_actual_stock_change()` 方法获取实际数据
- 在预测后1-2天更新实际结果

### 2. 确保因子数据完整

**问题**：如果 `prediction_factors` 表中缺少因子得分，则无法进行因子贡献度分析。

**解决方案**：
- 确保每次预测都保存因子得分
- 检查 `prediction_factors` 表的数据完整性

### 3. 确保历史价格数据完整

**问题**：回测分析和市场状态识别需要历史价格数据。

**解决方案**：
- 定期收集股票历史价格数据
- 使用 `stock_history_data` 表存储历史数据
- 确保数据覆盖足够的时间范围

## 八、数据检查SQL

### 检查预测数据完整性

```sql
-- 1. 检查有实际结果的预测记录数
SELECT 
    COUNT(*) as total_predictions,
    COUNT(actual_direction) as has_direction,
    COUNT(actual_price) as has_price,
    COUNT(prediction_hit) as has_hit,
    COUNT(CASE WHEN actual_direction IS NOT NULL 
               AND actual_price IS NOT NULL 
               AND prediction_hit IS NOT NULL THEN 1 END) as complete_records
FROM stock_predictions
WHERE prediction_date >= DATE_SUB(NOW(), INTERVAL 90 DAY);

-- 2. 检查因子数据完整性
SELECT 
    COUNT(*) as total_factors,
    COUNT(technical_score) as has_technical,
    COUNT(news_score) as has_news,
    COUNT(capital_flow_score) as has_capital_flow,
    COUNT(market_score) as has_market
FROM prediction_factors
WHERE date >= DATE_SUB(NOW(), INTERVAL 90 DAY);

-- 3. 检查数据关联性
SELECT 
    COUNT(DISTINCT sp.symbol) as prediction_stocks,
    COUNT(DISTINCT pf.symbol) as factor_stocks,
    COUNT(*) as joined_records
FROM stock_predictions sp
LEFT JOIN prediction_factors pf 
    ON sp.symbol = pf.symbol 
    AND sp.prediction_date = pf.date
WHERE sp.prediction_date >= DATE_SUB(NOW(), INTERVAL 90 DAY)
  AND sp.actual_direction IS NOT NULL;
```
