## 三、当天新闻过滤功能

### 1. 已实现功能

✅ **`UnifiedNewsSource.get_market_news()`**
- 添加了 `only_today` 参数（默认True）
- 自动过滤非当天的新闻
- 支持datetime对象和字符串日期解析

✅ **`UnifiedNewsSource.get_stock_news()`**
- 添加了 `only_today` 参数（默认True）
- 自动过滤非当天的新闻

✅ **`NewsCrawler.crawl_market_news()`**
- 添加了 `only_today` 参数（默认True）
- 调用统一新闻源时传递该参数

✅ **`NewsCrawler.crawl_stock_news()`**
- 添加了 `only_today` 参数（默认True）
- 调用统一新闻源时传递该参数

### 2. 过滤逻辑

```python
# 只保留当天的新闻
if only_today:
    news_time = news.get('time')
    if news_time:
        if isinstance(news_time, datetime):
            news_date = news_time.date()
        elif isinstance(news_time, str):
            news_date = datetime.strptime(news_time[:10], '%Y-%m-%d').date()
        else:
            news_date = today
        
        if news_date != today:
            continue  # 跳过非当天新闻
```

### 3. 日期解析支持

- ✅ 标准日期格式：`YYYY-MM-DD`, `YYYY-MM-DD HH:MM:SS`
- ✅ 相对时间：`今天`、`今日`、`昨天`、`X分钟前`、`X小时前`
- ✅ 无法解析的日期：默认保留（可能是相对时间）

class STCNNewsSource(BaseNewsSource):
    """证券时报新闻源"""
    
    def __init__(self):
        self.logger = logger
        self.base_url = "http://www.stcn.com"
        self.headers = {
            'User-Agent': 'Mozilla/5.0 ...'
        }
    
    def get_market_news(self, limit: int = 20) -> List[Dict]:
        """获取市场新闻（只返回当天新闻）"""
        news_list = []
        today = datetime.now().date()
        
        try:
            url = f"{self.base_url}/stock/"
            response = requests.get(url, headers=self.headers, timeout=10)
            # ... 解析逻辑 ...
            
            # 过滤当天新闻
            filtered_news = []
            for news in news_list:
                news_time = news.get('time')
                if isinstance(news_time, datetime) and news_time.date() == today:
                    filtered_news.append(news)
            
            return filtered_news[:limit]
