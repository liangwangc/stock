## 三、关键代码修改

### 3.1 StockPredictor 配置加载优化

```python
# 优化前：分别加载，重复查询
self.config = self._load_prediction_config()  # 查询1次
self.indicator_config = self._load_indicator_config()  # 查询2次

# 优化后：统一加载，只查询1次
self._config_manager = PredictionConfigManager()
self._active_config = self._config_manager.get_config()  # 只查询1次
self.config, self.indicator_config = self._load_all_configs()
```

### 3.2 X2参数读取优化

```python
# 优化前：从prediction配置读取（重复存储）
x2_overbought_threshold = self.config.get('x2_overbought_threshold', 80)

# 优化后：从indicator_config读取（单一存储）
x2_overbought_threshold = self.indicator_config.get('x2_overbought_threshold', 80)
```

### 3.3 ML权重配置热更新

```python
# 优化前：每次创建新实例，配置不更新
performance_monitor = MLModelPerformanceMonitor()

# 优化后：传递配置管理器，支持热更新
performance_monitor = MLModelPerformanceMonitor(config_manager=self._config_manager)
# 在get_optimal_weight()中自动检查配置更新
```

### 3.4 配置变更通知

```python
# 优化前：需要手动清除缓存
config_manager.clear_cache()

# 优化后：自动通知订阅者
config_manager.clear_cache()  # 自动调用_notify_subscribers()
# 订阅者可以自动刷新配置
```
