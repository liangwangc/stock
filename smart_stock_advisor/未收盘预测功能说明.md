# 未收盘预测功能说明

## 一、功能概述

在 `stock_list.html` 页面新增了"股票预测列表（未收盘-明天）"页签，支持在交易时间内实时预测明天的股票走势。

## 二、功能特点

### 1. 页签切换
- **收盘-明日**：显示收盘后预测的明日走势（原有功能）
- **未收盘-明天**：显示未收盘时预测的明天走势（新功能）

### 2. 预测功能
- **输入方式**：点击"预测"按钮，弹出输入框
- **股票代码**：支持输入多个股票代码（最多10个），用顿号、或逗号,分隔
- **数据来源**：
  - **新闻数据**：使用数据库中的当天新闻（通过定时任务抓取）
  - **当天股票数据**：实时获取（使用 `get_realtime_quote`）
  - **历史股票数据**：使用数据库中的数据（通过定时任务收集）

### 3. 数据区分
- 预测结果保存时，会标记 `prediction_type` 字段：
  - `after_close`：收盘-明日（原有预测）
  - `before_close`：未收盘-明天（新预测）
- 两个页签分别显示对应类型的预测结果

## 三、使用方法

### 1. 切换到"未收盘-明天"页签
1. 打开 `stock_list.html` 页面
2. 点击"⏰ 股票预测列表（未收盘-明天）"页签

### 2. 执行预测
1. 点击"🔮 预测"按钮
2. 在弹窗中输入股票代码，例如：`000001、600519、000858`
3. 点击"开始预测"按钮
4. 等待预测完成（会显示进度和结果）

### 3. 查看预测结果
- 预测完成后，结果会自动显示在列表中
- 可以查看预测方向、上涨/下跌概率、置信度等信息

## 四、技术实现

### 1. 数据库字段
- 在 `stock_predictions` 表中添加 `prediction_type` 字段
- 字段类型：`VARCHAR(20)`
- 默认值：`'after_close'`
- 可选值：`'after_close'`（收盘-明日）、`'before_close'`（未收盘-明天）

### 2. 前端实现
- **页签切换**：`switchTab(tabType)` 函数
- **预测弹窗**：`showPredictModal()` 函数
- **预测执行**：`startPredict()` 函数
- **数据加载**：`loadStockDataBeforeClose()` 函数

### 3. 后端实现
- **API端点**：`/api/predict/before_close` (POST)
- **预测逻辑**：使用 `StockPredictor.predict()` 方法
- **数据获取**：
  - 新闻：自动使用数据库中的当天新闻（`StockPredictor.calculate_news_score()` 已优化）
  - 历史数据：自动使用数据库中的数据（`StockDataSource.get_stock_data()` 已优化）
  - 实时数据：使用 `StockDataSource.get_realtime_quote()` 获取当天实时价格
- **保存逻辑**：通过 `PredictionVisualizer.save_stock_record()` 保存，自动设置 `prediction_type='before_close'`

### 4. 数据流程
1. 用户输入股票代码 → 前端验证格式
2. 调用 `/api/predict/before_close` API
3. 后端执行预测：
   - 获取历史数据（从数据库）
   - 获取实时价格（从API）
   - 获取新闻数据（从数据库）
   - 执行预测计算
4. 保存预测结果（标记 `prediction_type='before_close'`）
5. 返回结果给前端
6. 前端刷新列表显示

## 五、注意事项

### 1. 数据库字段
- 首次使用前，需要执行 `database/add_prediction_type_field.sql` 添加字段
- 如果字段不存在，系统会自动兼容（使用默认值 `'after_close'`）

### 2. 数据准备
- **新闻数据**：确保定时任务已抓取当天新闻
- **历史数据**：确保定时任务已收集股票历史数据
- **实时数据**：需要网络连接，能够访问股票API

### 3. 预测限制
- 最多同时预测10只股票
- 股票代码必须是6位数字
- 需要登录后才能使用

### 4. 性能考虑
- 预测过程可能需要几秒到几十秒（取决于股票数量）
- 建议在交易时间内使用，实时数据更准确
- 如果预测失败，会显示错误信息

## 七、常见问题

### Q1: 预测失败怎么办？
A: 检查：
- 股票代码格式是否正确（6位数字）
- 网络连接是否正常
- 数据库是否有当天新闻和历史数据
- 查看浏览器控制台和服务器日志

### Q2: 为什么看不到预测结果？
A: 检查：
- 是否切换到正确的页签（"未收盘-明天"）
- 预测是否成功完成
- 刷新页面或重新加载数据

### Q3: 预测结果和"收盘-明日"有什么区别？
A: 
- **收盘-明日**：使用收盘后的完整数据，预测更准确
- **未收盘-明天**：使用交易时间内的实时数据，可以提前预测

### Q4: 可以同时预测多少只股票？
A: 最多10只股票。如果需要预测更多，可以分批进行。
