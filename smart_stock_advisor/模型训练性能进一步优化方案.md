### 1. 避免不必要的DataFrame复制 ⚠️

**问题**：
- `prepare_features()` 中使用 `df[feature_columns].copy()` 创建副本
- 如果数据量很大，复制操作会消耗时间和内存

**优化方案**：
```python
# 优化前
X = df[feature_columns].copy()

# 优化后：只在需要修改时才复制
X = df[feature_columns]
# 如果需要修改，使用视图或延迟复制
```

**预期提升**：5-10%（减少内存分配和复制时间）

---

### 2. 批量处理缺失值 ⚠️

**问题**：
- `_handle_missing_values()` 逐列处理缺失值
- 对于每列都要检查字段类型，效率较低

**优化方案**：
```python
# 优化前：逐列处理
for col in X.columns:
    if X[col].isna().sum() == 0:
        continue
    # 处理缺失值...

# 优化后：批量处理
# 1. 一次性识别所有需要处理的列
cols_with_na = X.columns[X.isna().any()].tolist()
# 2. 按字段类型分组处理
technical_cols = [col for col in cols_with_na if col in technical_fields]
valuation_cols = [col for col in cols_with_na if col in valuation_fields]
# 3. 批量填充
X[technical_cols] = X[technical_cols].fillna(method='ffill').fillna(method='bfill')
```

**预期提升**：10-20%（减少循环开销）

### 3. 优化数据类型 ⚠️

**问题**：
- DataFrame可能使用较大的数据类型（如float64）
- 如果数据范围较小，可以使用float32节省内存和计算时间

**优化方案**：
```python
# 优化后：在转换为DataFrame时指定数据类型
df = pd.DataFrame(all_samples, dtype={
    'close_price': 'float32',
    'open_price': 'float32',
    'volume': 'int64',  # 成交量可能很大，保持int64
    'rsi': 'float32',
    # ...
})
```

**预期提升**：
- 内存使用：减少50%（float64 → float32）
- 计算速度：提升10-20%（float32计算更快）

### 4. 优化数据过滤操作 ⚠️

**问题**：
- `_filter_fields_by_completeness()` 逐列计算完整率
- 使用 `df[col].isna().sum()` 可能较慢

**优化方案**：
```python
# 优化前：逐列计算
for col in feature_columns:
    missing_count = df[col].isna().sum()
    completeness = 1.0 - (missing_count / len(df))

# 优化后：批量计算
missing_counts = df[feature_columns].isna().sum()
completeness_series = 1.0 - (missing_counts / len(df))
for col in feature_columns:
    completeness = completeness_series[col]
    # ...
```

**预期提升**：20-30%（批量计算比逐列计算快）

### 9. 使用更高效的缺失值填充方法 ⚠️

**问题**：
- `fillna(method='ffill')` 在某些pandas版本中已弃用
- 可以使用 `ffill()` 方法

**优化方案**：
```python
# 优化前
X[col] = X[col].fillna(method='ffill')

# 优化后
X[col] = X[col].ffill()  # 更高效
```

**预期提升**：5-10%（新方法更高效）

### 10. 优化特征工程中的循环 ⚠️

**问题**：
- `_handle_missing_values()` 中有多个循环
- 可以合并或向量化

**优化方案**：
```python
# 优化前：多个循环
for col in X.columns:
    if col in technical_fields:
        # 处理技术指标
    elif col in valuation_fields:
        # 处理估值指标
```
