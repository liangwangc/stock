# 服务频繁重启问题修复说明

## 一、问题描述

启动项目后，服务老是重新启动，导致登录失败。

## 二、问题原因

### 1. Flask Debug模式自动重载
- `web_app.py` 中 `socketio.run(app, debug=True)` 启用了Flask的调试模式
- Flask的调试模式会监控所有Python文件的变化
- 任何文件被修改（包括日志文件、临时文件、报告文件等）都会触发自动重载
- 服务重启会导致Session失效，从而出现登录失败

### 2. 可能触发重载的文件/目录
- `reports/` 目录：预测报告文件生成
- `data/` 目录：数据文件写入
- `logs/` 目录：日志文件写入
- `__pycache__/` 目录：Python缓存文件
- `*.pyc` 文件：Python编译文件
- `*.log` 文件：日志文件
- `*.tmp` 文件：临时文件

## 三、解决方案

### 1. 禁用Debug模式（推荐）

**修改前**：
```python
socketio.run(app, host='0.0.0.0', port=5000, debug=True)
```

**修改后**：
```python
# 从环境变量读取debug模式，默认False
debug_mode = os.getenv('FLASK_DEBUG', 'False').lower() == 'true'

socketio.run(
    app, 
    host='0.0.0.0', 
    port=5000, 
    debug=debug_mode,
    use_reloader=False if not debug_mode else True
)
```

### 2. 使用环境变量控制

**Windows**：
```batch
# 禁用自动重载（生产模式）
set FLASK_DEBUG=False
python web_app.py

# 启用自动重载（调试模式）
set FLASK_DEBUG=True
python web_app.py
```

**Linux/Mac**：
```bash
# 禁用自动重载（生产模式）
export FLASK_DEBUG=False
python web_app.py

# 启用自动重载（调试模式）
export FLASK_DEBUG=True
python web_app.py
```

### 3. 修改启动脚本

**修改 `run_web_app.bat`**：
```batch
@echo off
chcp 65001 >nul
set FLASK_DEBUG=False
echo ========================================
echo 启动 Web 应用（生产模式）
echo ========================================
cd /d %~dp0
python web_app.py
pause
```

## 四、修复内容

### 1. 代码修改（`web_app.py`）

- ✅ 添加环境变量 `FLASK_DEBUG` 控制debug模式
- ✅ 默认禁用debug模式（`debug=False`）
- ✅ 禁用自动重载器（`use_reloader=False`）
- ✅ 添加日志提示当前模式

### 2. 配置说明

- **生产模式**（默认）：
  - `debug=False`
  - `use_reloader=False`
  - 不会自动重载，服务稳定
  - 适合日常使用

- **调试模式**（需要时启用）：
  - `debug=True`
  - `use_reloader=True`
  - 代码修改后自动重载
  - 适合开发调试

## 五、使用建议

### 1. 日常使用
- 使用默认配置（生产模式）
- 服务不会自动重启，登录状态保持稳定

### 2. 开发调试
- 设置环境变量 `FLASK_DEBUG=True`
- 代码修改后自动重载，方便开发

### 3. 排查问题
- 如果遇到问题需要调试，临时启用debug模式
- 调试完成后恢复生产模式

## 六、验证方法

### 1. 检查服务是否稳定
1. 启动服务：`python web_app.py`
2. 登录系统
3. 等待一段时间，观察服务是否重启
4. 检查登录状态是否保持

### 2. 检查日志
- 查看启动日志，确认当前模式：
  - `✅ 生产模式（自动重载功能已禁用）` - 正常
  - `⚠️  调试模式已启用（自动重载功能已开启）` - 调试模式

## 七、注意事项

1. **生产环境**：必须禁用debug模式
   - Debug模式会暴露错误信息
   - 自动重载会影响服务稳定性

2. **开发环境**：可以启用debug模式
   - 方便代码调试
   - 自动重载提高开发效率

3. **Session失效**：
   - 服务重启会导致Session失效
   - 禁用自动重载可以避免此问题
