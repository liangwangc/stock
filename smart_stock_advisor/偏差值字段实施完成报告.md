### 1.4 性能评估优化 ✅

**文件**: `utils/model_performance_evaluator.py`

**修改内容**（第76-102行）:

**优先级**:
1. ✅ 优先使用 `absolute_deviation_pct`（如果存在）
2. ✅ 其次使用 `deviation_pct`（如果存在）
3. ✅ 再次使用 `predicted_change_pct` 和 `actual_change_pct` 计算
4. ⚠️ 最后才使用简化的估算方法（向后兼容）

**代码逻辑**:
```python
# 优先使用存储的绝对偏差值
if r.get('absolute_deviation_pct') is not None:
    error = float(r.get('absolute_deviation_pct', 0))
# 其次使用存储的偏差值
elif r.get('deviation_pct') is not None:
    error = abs(float(r.get('deviation_pct', 0)))
# 如果都没有，使用实际的predicted_change_pct计算
elif r.get('predicted_change_pct') is not None:
    predicted_change = float(r.get('predicted_change_pct', 0))
    actual_change = float(r.get('actual_change_pct', 0))
    error = abs(predicted_change - actual_change)
```

### 2.2 查询偏差值

**查询偏差值最大的10条预测**:
```sql
SELECT symbol, target_date, 
       predicted_change_pct, actual_change_pct,
       deviation_pct, absolute_deviation_pct
FROM stock_predictions
WHERE actual_change_pct IS NOT NULL
ORDER BY absolute_deviation_pct DESC
LIMIT 10;
```

**统计偏差分布**:
```sql
SELECT 
    AVG(deviation_pct) as avg_deviation,
    STDDEV(deviation_pct) as std_deviation,
    MIN(deviation_pct) as min_deviation,
    MAX(deviation_pct) as max_deviation,
    AVG(absolute_deviation_pct) as avg_absolute_deviation
FROM stock_predictions
WHERE deviation_pct IS NOT NULL;
```

**按股票统计偏差**:
```sql
SELECT 
    symbol,
    COUNT(*) as prediction_count,
    AVG(absolute_deviation_pct) as avg_absolute_deviation,
    STDDEV(absolute_deviation_pct) as std_absolute_deviation
FROM stock_predictions
WHERE absolute_deviation_pct IS NOT NULL
GROUP BY symbol
ORDER BY avg_absolute_deviation DESC
LIMIT 20;
```
