# A股数据存储结构说明

## 数据存储方式

### 存储规则：每天一条记录

**10年数据的存储方式是：每个交易日的每条股票数据存储为一条记录。**

### 具体说明

1. **存储单位**：**每个交易日 × 每只股票 = 1条记录**
   - 例如：股票000001在2024-01-01的数据 = 1条记录
   - 例如：股票000001在2024-01-02的数据 = 1条记录
   - 例如：股票000001在2024-01-03的数据 = 1条记录

2. **10年数据量估算**：
   - **一年约250个交易日**（扣除周末和节假日）
   - **10年约2500个交易日**
   - **一只股票10年数据 ≈ 2500条记录**
   - **5000只A股 × 2500条记录 = 约1250万条记录**

3. **唯一性约束**：
   - 数据库表有唯一索引：`(symbol, trade_date, period_type)`
   - 确保：**同一只股票 + 同一交易日期 + 同一周期类型 = 唯一记录**
   - 如果重复采集，会使用 `ON DUPLICATE KEY UPDATE` 更新数据

4. **数据字段**：
   每条记录包含该交易日的完整数据，包括：
   - 基本信息：股票代码、名称、交易日期、周期类型
   - 价格数据：开盘价、收盘价、最高价、最低价、昨收价、涨跌额、涨跌幅
   - 成交数据：成交量、成交额、换手率、量比
   - 盘口数据：外盘、内盘、委比、五档买卖盘（JSON格式）
   - 成本分布：成本分布数据（JSON格式）
   - 市值和估值：总市值、流通市值、市盈率、市净率
   - 技术指标：MA5/MA10/MA20/MA60、RSI、MACD等
   - 资金流向：主力净流入、超大单、大单、中单、小单净流入
   - 融资融券：融资余额、融券余额等
   - 其他：数据来源、数据质量得分等

### 数据库表结构

**表名**：`stock_history_data`

**唯一索引**：`(symbol, trade_date, period_type)`
- `symbol`: 股票代码（6位，如'000001'）
- `trade_date`: 交易日期（DATE类型，如'2024-01-02'）
- `period_type`: 周期类型（'daily'=日线, 'weekly'=周线, 'monthly'=月线, 'yearly'=年线）

**说明**：
- 同一只股票在同一天只能有一条日线数据
- 如果支持多周期（周线、月线、年线），同一只股票在同一天可以有不同周期的数据
- 目前默认只采集日线数据（period_type='daily'）

## 数据量估算

### 单只股票
- **10年数据 ≈ 2500条记录**（每个交易日1条）

### 全部A股（假设5000只）
- **总记录数 ≈ 5000只 × 2500条 = 1250万条记录**
- **数据大小估算**：每条记录约1-2KB，总计约12-25GB

### 存储时间
- **3线程模式**：约20-40小时
- **单线程模式**：约60-120小时

## 查询示例

### 查询单只股票的所有数据
```sql
SELECT * FROM stock_history_data 
WHERE symbol = '000001' 
ORDER BY trade_date DESC;
```

### 查询单只股票最近10年的数据量
```sql
SELECT COUNT(*) as record_count 
FROM stock_history_data 
WHERE symbol = '000001';
-- 结果：约2500条（10年数据）
```

### 查询所有股票的统计信息
```sql
SELECT 
    COUNT(DISTINCT symbol) as stock_count,
    COUNT(*) as total_records,
    MIN(trade_date) as earliest_date,
    MAX(trade_date) as latest_date
FROM stock_history_data;
```

### 查询某只股票某个时间段的数据
```sql
SELECT * FROM stock_history_data 
WHERE symbol = '000001' 
  AND trade_date >= '2024-01-01' 
  AND trade_date <= '2024-12-31'
ORDER BY trade_date;
```

## 总结

- ✅ **存储方式**：每个交易日每条股票 = 1条记录
- ✅ **10年数据**：约2500个交易日 × 1条记录/天 = 约2500条记录/股票
- ✅ **唯一性**：通过 (symbol, trade_date, period_type) 确保唯一性
- ✅ **数据完整性**：每条记录包含该交易日的完整数据（价格、成交量、技术指标等）
- ✅ **支持更新**：如果重复采集，会更新已存在的记录
