# X_2指标实现分析

## 一、公式回顾

```
X_2 = (收盘价 - 20日最低价) / (20日最高价 - 20日最低价) × 100
```

其中：
- `CLOSE`：收盘价
- `LLV(LOW,20)`：20日最低价（最近20个交易日的最低价中的最低值）
- `HHV(HIGH,20)`：20日最高价（最近20个交易日的最高价中的最高值）

## 五、具体实现代码

### Python实现示例

```python
import pandas as pd
import numpy as np

def calculate_X2(df, period=20):
    """
    计算X_2指标：收盘价在N日价格区间中的相对位置
    
    Args:
        df: DataFrame，包含'close_price', 'high_price', 'low_price'列
        period: 计算周期，默认20
    
    Returns:
        Series: X_2指标值（0-100），索引与df相同
    """
    close = df['close_price']
    high = df['high_price']
    low = df['low_price']
    
    # 计算N日最低价（LLV）
    llv_low = low.rolling(window=period, min_periods=1).min()
    
    # 计算N日最高价（HHV）
    hhv_high = high.rolling(window=period, min_periods=1).max()
    
    # 计算区间宽度
    range_width = hhv_high - llv_low
    
    # 计算X_2，处理除零错误
    X_2 = np.where(
        range_width > 0,
        (close - llv_low) / range_width * 100,
        50  # 如果区间宽度为0（价格没有波动），设置为50（中间位置）
    )
    
    return pd.Series(X_2, index=df.index, name='x2')
```
