# 用户登录历史记录功能说明

**日期**：2026-01-16  
**功能**：记录用户每次登录尝试的详细信息

---

## 一、功能概述

新增了用户登录历史记录功能，用于记录用户每次登录尝试的详细信息，包括：
- ✅ 登录成功记录
- ✅ 登录失败记录（包括失败原因）
- ✅ IP地址、User-Agent、设备类型、浏览器、操作系统等信息
- ✅ 登录时间、会话ID等

---

## 二、数据库表结构

### 2.1 表名：`user_login_history`

**字段说明**：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `id` | BIGINT | 主键ID |
| `user_id` | BIGINT | 用户ID（登录成功时记录，失败时为NULL） |
| `username` | VARCHAR(50) | 用户名（登录时使用的用户名） |
| `login_status` | VARCHAR(20) | 登录状态（success=成功，failed=失败） |
| `failure_reason` | VARCHAR(255) | 失败原因（如：密码错误、用户不存在、用户已禁用等） |
| `ip_address` | VARCHAR(50) | 登录IP地址 |
| `user_agent` | VARCHAR(500) | 用户代理（浏览器信息） |
| `login_time` | DATETIME | 登录时间 |
| `session_id` | VARCHAR(255) | 会话ID（登录成功时记录） |
| `location` | VARCHAR(100) | 登录地点（可根据IP解析，可选） |
| `device_type` | VARCHAR(50) | 设备类型（PC、Mobile、Tablet等） |
| `browser` | VARCHAR(100) | 浏览器类型（Chrome、Firefox、Safari等） |
| `os` | VARCHAR(100) | 操作系统（Windows、macOS、Linux、Android、iOS等） |

**索引**：
- `idx_user_id` - 用户ID索引
- `idx_username` - 用户名索引
- `idx_login_status` - 登录状态索引
- `idx_login_time` - 登录时间索引
- `idx_ip_address` - IP地址索引
- `idx_session_id` - 会话ID索引

**外键**：
- `user_id` 外键关联 `users.id`（ON DELETE SET NULL）

## 三、代码实现

### 3.1 登录历史管理模块

**文件**：`utils/login_history.py`

**主要功能**：
1. **解析User-Agent**：`parse_user_agent()` 方法
   - 提取设备类型（PC、Mobile、Tablet）
   - 提取浏览器类型（Chrome、Firefox、Safari等）
   - 提取操作系统（Windows、macOS、Linux、Android、iOS等）

2. **记录登录历史**：`record_login()` 方法
   - 记录登录成功或失败的详细信息
   - 自动解析User-Agent信息
   - 支持记录失败原因

3. **查询登录历史**：`get_login_history()` 方法
   - 支持按用户ID、用户名、日期范围、登录状态查询
   - 支持分页（limit参数）

### 3.2 登录代码修改

**文件**：`web_app.py`

**修改内容**：
1. **导入模块**：添加 `LoginHistoryManager` 导入
2. **登录成功时记录**：
   - 记录用户名、用户ID、登录状态（success）
   - 记录IP地址、User-Agent、会话ID
   - 自动解析设备类型、浏览器、操作系统

3. **登录失败时记录**：
   - 记录用户名、登录状态（failed）
   - 记录失败原因（密码错误、用户不存在、用户已禁用）
   - 记录IP地址、User-Agent

### 3.3 API接口

**接口**：`GET /api/users/login-history`

**功能**：查询登录历史记录

**权限**：
- 管理员：可以查看所有用户的登录历史
- 普通用户：只能查看自己的登录历史

**查询参数**：
- `user_id`（可选）：用户ID
- `username`（可选）：用户名
- `start_date`（可选）：开始日期（YYYY-MM-DD）
- `end_date`（可选）：结束日期（YYYY-MM-DD）
- `login_status`（可选）：登录状态（'success' 或 'failed'）
- `limit`（可选）：返回记录数限制（默认100）

**返回格式**：
```json
{
    "success": true,
    "data": [
        {
            "id": 1,
            "user_id": 1,
            "username": "admin",
            "login_status": "success",
            "failure_reason": null,
            "ip_address": "192.168.1.100",
            "user_agent": "Mozilla/5.0...",
            "login_time": "2026-01-16 13:30:00",
            "session_id": "abc123...",
            "device_type": "PC",
            "browser": "Chrome",
            "os": "Windows 10/11"
        }
    ]
}
```

## 七、数据维护

### 7.1 数据清理

**建议定期清理旧数据**：
```sql
-- 删除90天前的登录历史记录
DELETE FROM user_login_history 
WHERE login_time < DATE_SUB(NOW(), INTERVAL 90 DAY);
```

### 7.2 数据统计

**统计登录成功/失败次数**：
```sql
SELECT 
    login_status,
    COUNT(*) as count
FROM user_login_history
GROUP BY login_status;
```

**统计每日登录次数**：
```sql
SELECT 
    DATE(login_time) as date,
    COUNT(*) as count
FROM user_login_history
GROUP BY DATE(login_time)
ORDER BY date DESC;
```

## 八、注意事项

1. **表不存在时**：如果表不存在，登录历史记录功能会自动跳过，不会影响登录功能
2. **性能考虑**：大量登录记录可能影响查询性能，建议定期清理旧数据
3. **隐私保护**：登录历史包含敏感信息（IP地址、User-Agent），需要妥善保管
