# 如何修改股票代码

## 方法一：在配置文件中设置默认股票代码（推荐）

编辑 `config.py` 文件，修改 `DEFAULT_STOCK_SYMBOL` 的值：

```python
# 默认股票代码（如果命令行未指定，将使用此代码）
DEFAULT_STOCK_SYMBOL = "600519"  # 改成你想要的股票代码，如 "000001", "000002" 等
```

然后运行程序时，直接按回车就会使用这个默认代码。

## 方法二：命令行参数（最常用）

运行程序时直接指定股票代码：

```bash
python main.py --symbol 600519
```

或者：

```bash
python main.py --symbol 000001
```

## 方法三：交互式输入

直接运行程序，不指定参数：

```bash
python main.py
```

然后根据提示输入股票代码。

## 方法四：直接修改代码中的默认值

如果你想固定使用某个股票代码，可以直接修改 `main.py` 文件第 54-58 行：

```python
# 获取股票代码
if args.symbol:
    symbol = args.symbol
else:
    symbol = "600519"  # 直接在这里改成你想要的股票代码
```

## 常用股票代码示例

- 600519 - 贵州茅台
- 000001 - 平安银行
- 000002 - 万科A
- 600036 - 招商银行
- 000858 - 五粮液
- 600276 - 恒瑞医药
- 000725 - 京东方A
- 600887 - 伊利股份

## 注意事项

1. 股票代码必须是6位数字
2. 上海股票代码以 60 开头（如 600519）
3. 深圳股票代码以 00 或 30 开头（如 000001, 300015）
4. 确保股票代码正确，否则无法获取数据
