## 一、支持自动恢复的任务类型

所有存储在 `scheduled_tasks` 表中且 `is_active = 1` 的任务都会在服务重启后自动恢复。

### 1.1 股票数据任务

| 任务类型 | 说明 | 执行方法 |
|---------|------|---------|
| `stock_history_update` | 股票历史数据增量更新 | `_execute_stock_history_update()` |
| `stock_data_collection_cn` | A股数据收集 | `_execute_cn_stock_data_collection()` |
| `stock_data_collection_us` | 美股数据收集 | `_execute_us_stock_data_collection()` |

### 1.2 股票分析任务

| 任务类型 | 说明 | 执行方法 |
|---------|------|---------|
| `stock_analysis` | 股票分析任务（全量分析/个股分析） | `_execute_stock_analysis()` |

**任务配置示例**：
```json
{
  "limit": 100,           // 全量分析：分析股票数量（0=全部）
  "sort_type": "turnover", // 排序方式：turnover/random
  "symbols": ["000001", "600519"]  // 个股分析：股票代码列表
}
```

### 1.3 模型训练/学习任务

| 任务类型 | 说明 | 执行方法 |
|---------|------|---------|
| `model_evaluation` | 模型评估任务 | `_execute_model_evaluation()` |
| `model_optimization` | 模型优化任务 | `_execute_model_optimization()` |
| `adaptive_optimization` | 自适应优化任务 | `_execute_adaptive_optimization()` |
| `comprehensive_evaluation` | 综合评估任务 | `_execute_comprehensive_evaluation()` |
| `online_learning` | 在线学习任务 | `_execute_online_learning()` |
| `model_backtest` | 模型回测任务 | `_execute_model_backtest()` |
| `automated_backtest` | 自动化回测任务 | `_execute_automated_backtest()` |

**推荐配置**：

| 任务类型 | 调度方式 | 执行时间 | 说明 |
|---------|---------|---------|------|
| `model_evaluation` | 每日 | 15:30 | 每天收盘后评估模型性能 |
| `adaptive_optimization` | 每周 | 20:00 | 每周日晚上根据市场状态自动优化 |
| `comprehensive_evaluation` | 每周 | 21:00 | 每周日晚上进行综合评估 |
| `online_learning` | 每日 | 16:00 | 每天收盘后批量更新权重 |
| `model_backtest` | 每周 | 22:00 | 每周日晚上进行回测 |
| `automated_backtest` | 每月 | 22:00 | 每月最后一天进行深度回测 |

### 1.4 新闻抓取任务

| 任务类型 | 说明 | 执行方法 |
|---------|------|---------|
| `news_crawl` | 新闻抓取任务 | `_execute_news_crawl()` |

**任务配置示例**：
```json
{
  "task_type": "all",        // all/market/stock
  "symbol": "600519",        // 股票代码（stock类型需要）
  "interval_minutes": 60,    // 抓取间隔（分钟）
  "limit": 15                // 每个新闻源的限制数量
}
```

### 1.5 备份任务

| 任务类型 | 说明 | 执行方法 |
|---------|------|---------|
| `backup` | 数据备份任务 | `_execute_backup()` |

## 二、不支持自动恢复的任务

### 2.1 NewsTaskManager 管理的任务

**存储位置**：`news_crawl_tasks` 表

**特点**：
- 使用独立的 `NewsTaskManager` 管理
- 不会自动恢复
- 需要手动启动

**解决方案**：
- 使用 `ScheduledTaskManager` 创建 `news_crawl` 类型的任务
- 或者修改 `NewsTaskManager` 支持自动加载

### 2.2 analysis_tasks 表中的任务

**存储位置**：`analysis_tasks` 表

**特点**：
- 一次性任务
- 不会自动恢复
- 需要手动启动

**解决方案**：
- 使用 `ScheduledTaskManager` 创建 `stock_analysis` 类型的定时任务

## 三、任务创建方式

### 3.1 通过Web界面创建

**设置页面 → 任务管理 → 创建定时任务**

支持创建所有类型的定时任务。

### 3.2 通过API创建

```python
POST /api/scheduled/tasks
{
    "task_name": "每日股票分析",
    "task_type": "stock_analysis",
    "schedule_type": "daily",
    "schedule_time": "15:30",
    "task_config": {
        "limit": 100,
        "sort_type": "turnover"
    },
    "is_active": 1
}
```

### 3.3 通过代码创建

```python
from utils.scheduled_task_manager import ScheduledTaskManager

manager = ScheduledTaskManager()

# 创建股票分析任务
task_id = manager.create_task(
    task_name='每日股票分析',
    task_type='stock_analysis',
    schedule_type='daily',
    schedule_time='15:30',
    task_config={
        'limit': 100,
        'sort_type': 'turnover'
    },
    is_active=1
)

# 创建模型评估任务
task_id = manager.create_task(
    task_name='每日模型评估',
    task_type='model_evaluation',
    schedule_type='daily',
    schedule_time='15:30',
    is_active=1
)
```

## 四、验证方法

### 4.1 查看所有启用的任务

```sql
SELECT id, task_name, task_type, schedule_type, schedule_time, is_active, next_run_time
FROM scheduled_tasks
WHERE is_active = 1
ORDER BY task_type, task_name;
```

### 4.2 查看任务执行历史

```sql
SELECT task_id, task_name, task_type, start_time, status, message
FROM scheduled_task_history
ORDER BY start_time DESC
LIMIT 50;
```

## 五、总结

### 5.1 自动恢复范围

**✅ 完全支持自动恢复**：
- 所有存储在 `scheduled_tasks` 表中的任务
- 包括：股票数据、股票分析、模型训练/学习、新闻抓取（通过ScheduledTaskManager创建）、备份等所有类型
- 只要 `is_active = 1`，就会自动恢复

**❌ 不支持自动恢复**：
- `news_crawl_tasks` 表中的新闻抓取任务（需要手动启动）
- `analysis_tasks` 表中的一次性股票分析任务（需要手动启动）

### 5.2 关键点

1. **任务存储位置**：`scheduled_tasks` 表
2. **恢复条件**：`is_active = 1`
3. **恢复时机**：服务启动时自动初始化
4. **恢复范围**：所有任务类型都支持
