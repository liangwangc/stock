#### 1.3 预测流程

```
1. 数据准备
   ├── 获取股票历史数据（60天）
   ├── 获取股票基本信息（名称、行业、概念）
   └── 判断预测目标日期（今天/明天）

2. 并行多因子分析（5个核心因子 + ML模型）
   ├── 第一阶段：独立分析（并行）
   │   ├── market_overall：市场整体预测
   │   ├── news：新闻情感分析
   │   ├── capital_flow：资金流向分析
   │   └── market_sentiment_index：市场情绪指标
   │
   └── 第二阶段：数据依赖分析（并行）
       ├── technical：技术指标分析（MACD、RSI、KDJ等）
       ├── market：市场情绪分析
       └── history：历史模式分析

3. 权重动态调整
   ├── 市场状态识别（牛市/熊市/震荡市）
   ├── 权重优化（基于历史准确率）
   └── 权重归一化（确保总和=1）

4. 因子融合计算
   final_score = Σ(factor_score_i × weight_i)

5. 概率转换（动态Sigmoid）
   up_probability = sigmoid(final_score × dynamic_coefficient)

6. 置信度计算（增强版）
   confidence = f(因子一致性, 数据质量, 历史准确率, 市场状态)

7. 预测价格和涨跌幅计算（优化版）
   ├── 波动率系数（EWMA方法）
   ├── 趋势调整因子（短期+中期+长期）
   └── 异常检测调整

8. 生成预测结果
   ├── 预测方向（上涨/下跌/震荡）
   ├── 上涨/下跌概率
   ├── 置信度
   └── 预测价格和涨幅
```

### 2.1 准确率计算

**数据来源**：`stock_predictions` 表  
**时间范围**：最近30天  
**计算公式**：
```
准确率 = (命中数 / 总数) × 100%
```

**命中判断**：
- 预测方向 = 实际方向 → 命中
- 预测方向 ≠ 实际方向 → 未命中

SELECT

    COUNT(*) as count,
    SUM(CASE WHEN prediction_hit = '命中' THEN 1 ELSE 0 END) as hit_count,
    SUM(CASE WHEN prediction_hit = '命中' THEN 1 ELSE 0 END) * 100.0 / COUNT(*) as accuracy

  AND prediction_hit IS NOT NULL

-- 2. 查看置信度分布和准确率
SELECT 
    CASE 
        WHEN confidence >= 0.7 THEN '高置信度(>=0.7)'
        WHEN confidence >= 0.5 THEN '中置信度(0.5-0.7)'
        ELSE '低置信度(<0.5)'
    END as confidence_range,
    COUNT(*) as count,
    SUM(CASE WHEN prediction_hit = '命中' THEN 1 ELSE 0 END) as hit_count,
    SUM(CASE WHEN prediction_hit = '命中' THEN 1 ELSE 0 END) * 100.0 / COUNT(*) as accuracy
FROM stock_predictions
WHERE target_date >= DATE_SUB(NOW(), INTERVAL 30 DAY)
  AND prediction_hit IS NOT NULL
GROUP BY confidence_range;

-- 3. 查看因子得分与准确率的关系
SELECT 
    CASE 
        WHEN JSON_EXTRACT(factors, '$.technical.score') > 0.5 THEN '技术指标看涨'
        WHEN JSON_EXTRACT(factors, '$.technical.score') < -0.5 THEN '技术指标看跌'
