# 增加偏差值字段分析与建议

**日期**: 2026-01-16  
**问题**: 在 `stock_predictions` 表中增加偏差值字段（预测值-真实值），是否对模型学习和模型训练有帮助？

---

## 一、当前表结构分析

### 1.1 现有字段

**`stock_predictions` 表已有字段**:
- ✅ `predicted_change_pct` - 预测涨跌幅（%）
- ✅ `actual_change_pct` - 实际涨跌幅（%）
- ✅ `predicted_close_price` - 预测收盘价
- ✅ `actual_price` - 实际价格
- ✅ `prediction_hit` - 预测命中情况（命中/未命中）

**缺失字段**:
- ❌ `deviation_pct` - 偏差值（预测涨跌幅 - 实际涨跌幅）
- ❌ `deviation_price` - 价格偏差（预测收盘价 - 实际价格）
- ❌ `absolute_deviation_pct` - 绝对偏差（|预测涨跌幅 - 实际涨跌幅|）
- ❌ `relative_deviation_pct` - 相对偏差（偏差 / 实际涨跌幅）

### 2.1 模型性能评估（已使用，但未存储）

**代码位置**: `utils/model_performance_evaluator.py` 第76-92行

**当前实现**:
```python
# 计算幅度误差（MAE）
magnitude_errors = []
for r in results:
    if r.get('actual_change_pct') is not None:
        # 根据预测方向估算预测涨跌幅
        if r.get('prediction') == '上涨':
            predicted_change = r.get('up_probability', 0.5) * 5.0  # 简化估算
        elif r.get('prediction') == '下跌':
            predicted_change = -r.get('down_probability', 0.5) * 5.0
        else:
            predicted_change = 0.0
        
        actual_change = float(r.get('actual_change_pct', 0))
        error = abs(predicted_change - actual_change)  # 临时计算，未存储
        magnitude_errors.append(error)

magnitude_mae = sum(magnitude_errors) / len(magnitude_errors) if magnitude_errors else 0.0
```

**问题**:
- ⚠️ 使用简化的预测涨跌幅估算（`up_probability * 5.0`），而不是实际的 `predicted_change_pct`
- ⚠️ 偏差值临时计算，未存储到数据库
- ⚠️ 每次评估都需要重新计算，效率低

## 三、增加偏差值字段的价值分析

### 3.1 对模型学习的帮助 ✅

**价值**:
1. **快速分析预测偏差**
   - 可以直接查询偏差值，无需每次计算
   - 支持按偏差值范围筛选和分析

2. **优化参数时考虑偏差**
   - 可以基于偏差值优化参数（不仅考虑方向准确率）
   - 可以设置偏差阈值，过滤偏差过大的预测

3. **分析偏差分布**
   - 可以统计偏差的分布（均值、标准差、分位数）
   - 可以识别系统性偏差（总是高估或低估）

4. **提升评估效率**
   - 避免每次评估时重新计算偏差
   - 支持快速查询和分析

**示例SQL**:
```sql
-- 查询偏差值最大的10条预测
SELECT symbol, target_date, 
       predicted_change_pct, actual_change_pct,
       (predicted_change_pct - actual_change_pct) as deviation_pct
FROM stock_predictions
WHERE actual_change_pct IS NOT NULL
ORDER BY ABS(deviation_pct) DESC
LIMIT 10;

-- 统计偏差分布
SELECT 
    AVG(deviation_pct) as avg_deviation,
    STDDEV(deviation_pct) as std_deviation,
    MIN(deviation_pct) as min_deviation,
    MAX(deviation_pct) as max_deviation
FROM stock_predictions
WHERE deviation_pct IS NOT NULL;
```

---

### 3.2 对模型训练的帮助 ✅

**价值**:
1. **作为特征使用**
   - 可以将历史偏差值作为特征，帮助模型学习预测偏差的模式
   - 例如：如果历史偏差较大，当前预测的置信度应该降低

2. **作为标签使用（回归任务）**
   - 可以训练一个模型专门预测偏差值
   - 用于校准预测结果

3. **分析训练数据质量**
   - 可以识别偏差过大的样本，过滤或加权处理
   - 可以分析不同市场状态下的偏差分布

4. **模型评估**
   - 可以直接使用偏差值评估模型性能（MAE、RMSE）
   - 无需重新计算

**示例**:
```python
# 作为特征
features = [
    'ma5', 'ma10', 'rsi', 'macd', ...,
    'historical_avg_deviation',  # 历史平均偏差
    'historical_std_deviation',  # 历史偏差标准差
]

# 作为标签（偏差预测模型）
label = deviation_pct  # 预测偏差值
```

---

### 3.3 对系统监控的帮助 ✅

**价值**:
1. **偏差告警**
   - 可以设置偏差阈值告警（如偏差 > 5%）
   - 可以监控偏差趋势

2. **性能分析**
   - 可以分析不同股票、不同市场状态下的偏差
   - 可以识别偏差异常的模式

## 五、建议实施方案

### 5.1 数据库字段设计

**建议添加字段**:
```sql
ALTER TABLE `stock_predictions` 
ADD COLUMN `deviation_pct` DECIMAL(8, 4) DEFAULT NULL 
    COMMENT '偏差值（预测涨跌幅 - 实际涨跌幅，%）' 
    AFTER `actual_change_pct`;

ALTER TABLE `stock_predictions` 
ADD COLUMN `absolute_deviation_pct` DECIMAL(8, 4) DEFAULT NULL 
    COMMENT '绝对偏差（|预测涨跌幅 - 实际涨跌幅|，%）' 
    AFTER `deviation_pct`;

ALTER TABLE `stock_predictions` 
ADD INDEX `idx_deviation_pct` (`deviation_pct`);
ALTER TABLE `stock_predictions` 
ADD INDEX `idx_absolute_deviation_pct` (`absolute_deviation_pct`);
```

**字段说明**:
- `deviation_pct`: 有符号偏差（正数表示高估，负数表示低估）
- `absolute_deviation_pct`: 绝对偏差（用于评估预测准确性）

UPDATE stock_predictions
SET 
    deviation_pct = predicted_change_pct - actual_change_pct,
    absolute_deviation_pct = ABS(predicted_change_pct - actual_change_pct)
