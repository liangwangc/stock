## 三、流式处理方案设计

### 3.1 方案1：分批加载（推荐）

**优点**：
- ✅ 实现简单
- ✅ 内存可控
- ✅ 可以复用现有代码

**实现方式**：
```python
def load_training_data_streaming(self, 
                                start_date: str,
                                end_date: str,
                                batch_size: int = 1000,
                                symbols: Optional[List[str]] = None):
    """
    流式加载训练数据（分批加载）
    
    Args:
        batch_size: 每批加载的股票数量
    """
    # 1. 获取所有股票代码
    all_symbols = self._get_all_symbols(symbols)
    
    # 2. 分批处理
    for i in range(0, len(all_symbols), batch_size):
        batch_symbols = all_symbols[i:i+batch_size]
        
        # 3. 加载当前批次数据
        batch_df = self._load_batch_data(
            start_date, end_date, batch_symbols
        )
        
        # 4. 处理当前批次（生成特征）
        batch_features = self._process_batch(batch_df)
        
        # 5. 返回生成器（yield）
        yield batch_features
        
        # 6. 清理内存
        del batch_df, batch_features
        gc.collect()
```

**使用方式**：
```python
# 训练时使用生成器
for batch_features in data_loader.load_training_data_streaming(...):
    # 增量训练模型
    model.partial_fit(batch_features, batch_labels)
```

**适用场景**：
- ✅ 数据量超过内存限制
- ✅ 需要增量训练
- ✅ 内存受限环境

### 3.2 方案2：数据库游标（高级）

**优点**：
- ✅ 内存占用最小
- ✅ 可以处理任意大小的数据

**缺点**：
- ⚠️ 实现复杂
- ⚠️ 性能可能较慢（逐条处理）

**实现方式**：
```python
def load_training_data_cursor(self, 
                             start_date: str,
                             end_date: str,
                             batch_size: int = 10000):
    """
    使用数据库游标流式加载数据
    """
    sql = """
        SELECT * FROM stock_history_data
        WHERE trade_date BETWEEN %s AND %s
        ORDER BY symbol, trade_date
    """
    
    # 使用服务器端游标（MySQL）
    cursor = self.db.connection.cursor(
        cursorclass=pymysql.cursors.SSCursor  # 服务器端游标
    )
    cursor.execute(sql, (start_date, end_date))
    
    # 分批读取
    while True:
        batch = cursor.fetchmany(batch_size)
        if not batch:
            break
        
        # 转换为DataFrame并处理
        df = pd.DataFrame(batch)
        yield self._process_batch(df)
        
        del df
        gc.collect()
    
    cursor.close()
```

**适用场景**：
- ✅ 数据量非常大（>50GB）
- ✅ 内存严重受限（<4GB）
- ⚠️ 不推荐用于常规训练（性能较慢）

### 3.3 方案3：内存映射文件（mmap）

**优点**：
- ✅ 可以处理大于内存的文件
- ✅ 操作系统自动管理内存

**缺点**：
- ⚠️ 需要先将数据写入文件
- ⚠️ 实现复杂

**适用场景**：
- ✅ 数据需要多次访问
- ✅ 数据量非常大（>100GB）
