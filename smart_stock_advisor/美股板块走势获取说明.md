# 美股板块走势获取功能说明

## 功能概述

由于单个美股历史数据获取困难（API速率限制），新增了**获取前一天美股板块和行业走势**的功能。该功能通过获取板块ETF（如XLK、XLF等）的数据来反映各板块的整体走势。

## 使用方法

### 1. 基本使用

```python
from data_source.us_stock_data_source import USStockDataSource

# 创建数据源实例
ds = USStockDataSource()

# 获取所有板块前一天的走势
result = ds.get_all_sectors_yesterday_performance()
```

### 2. 返回数据格式

返回一个字典，键为板块名称（英文），值为包含走势信息的字典：

```python
{
    'Energy': {
        'symbol': 'XLE',
        'success': True,
        'date': '2026-01-11',
        'close': 85.20,
        'open': 84.50,
        'high': 85.80,
        'low': 84.30,
        'volume': 1000000,
        'change_pct': 1.5  # 涨跌幅（%）
    },
    'Materials': {
        ...
    },
    ...
}
```

### 3. 支持的板块

系统支持11个标准GICS板块：

| 板块名称（英文） | ETF代码 | 中文名称 |
|----------------|---------|---------|
| Energy | XLE | 能源 |
| Materials | XLB | 材料 |
| Industrials | XLI | 工业 |
| Consumer Discretionary | XLY | 可选消费 |
| Consumer Staples | XLP | 必需消费 |
| Health Care | XLV | 医疗保健 |
| Financials | XLF | 金融 |
| Information Technology | XLK | 信息技术 |
| Communication Services | XLC | 通信服务 |
| Utilities | XLU | 公用事业 |
| Real Estate | XLRE | 房地产 |

## 技术实现

### 1. 数据获取策略

- **数据源**：使用板块ETF（SPDR Sector ETFs）作为板块走势的代理
- **时间范围**：获取最近3天的数据，确保能获取到前一天的数据
- **容错处理**：如果找不到前一天的数据，使用最后一条可用数据

### 2. 涨跌幅计算

- 如果有前两天的数据，计算涨跌幅：`(今日收盘 - 昨日收盘) / 昨日收盘 * 100`
- 如果数据不足，`change_pct` 为 `None`

### 3. 速率限制处理

- 每个板块数据获取后延迟0.5秒，避免触发API速率限制
- 如果某个板块获取失败，不影响其他板块的获取

## 使用场景

### 1. 替代单个股票数据

当单个美股历史数据获取困难时，可以使用板块走势数据作为参考：

```python
# 获取科技板块走势
result = ds.get_all_sectors_yesterday_performance()
tech_performance = result.get('Information Technology', {})

if tech_performance.get('success'):
    print(f"科技板块涨跌: {tech_performance.get('change_pct', 0):+.2f}%")
```

### 2. 板块轮动分析

分析不同板块的表现，识别强势和弱势板块：

```python
result = ds.get_all_sectors_yesterday_performance()

# 按涨跌幅排序
sorted_sectors = sorted(
    [(k, v) for k, v in result.items() if v.get('success')],
    key=lambda x: x[1].get('change_pct', 0) or 0,
    reverse=True
)

print("涨幅前3的板块:")
for sector_name, data in sorted_sectors[:3]:
    print(f"  {sector_name}: {data.get('change_pct', 0):+.2f}%")
```

### 3. 与A股预测结合

由于美股比A股早一天收盘，可以使用美股板块走势来预测A股相应板块的表现：

```python
# 获取美股板块走势
us_sectors = ds.get_all_sectors_yesterday_performance()

# 映射到A股板块
# 例如：美股科技板块 -> A股计算机、电子等
tech_performance = us_sectors.get('Information Technology', {})
if tech_performance.get('success') and tech_performance.get('change_pct', 0) > 0:
    print("美股科技板块上涨，可能利好A股科技股")
```

## 注意事项

1. **数据时效性**：获取的是**前一天**的数据，不是实时数据
2. **ETF代表性问题**：ETF走势可能不完全代表板块内所有股票的表现
3. **API限制**：虽然已添加延迟，但在高并发场景下仍可能遇到速率限制
4. **数据可用性**：如果ETF数据获取失败，该板块的`success`字段为`False`

## 故障排除

### 问题1：所有板块都获取失败

**可能原因**：
- API速率限制
- 网络问题
- 数据源不可用

**解决方案**：
- 增加延迟时间（修改代码中的`time.sleep(0.5)`为更长的值）
- 检查网络连接
- 稍后重试

### 问题2：找不到前一天的数据

**可能原因**：
- 前一天是周末或节假日（美股休市）
- 数据源延迟

**解决方案**：
- 系统会自动使用最后一条可用数据
- 检查日志中的警告信息

### 问题3：涨跌幅为None

**可能原因**：
- 数据不足（只有一天的数据）

**解决方案**：
- 这是正常情况，表示无法计算涨跌幅
- 可以只使用收盘价等绝对数据
