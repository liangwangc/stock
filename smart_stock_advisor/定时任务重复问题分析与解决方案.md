# 定时任务重复问题分析与解决方案

## 一、问题描述

启动程序时发现加载了多个重复的定时任务，例如：
- **北向资金收集** (ID: 23) 和 **北向资金每日获取** (ID: 33)
- **市场指数收集** (ID: 22) 和 **市场指数每日获取** (ID: 34)
- **每日主力资金收集** (ID: 24) 和 **主力资金每日获取** (ID: 36)

## 二、定时任务存储位置

**数据库表**：`scheduled_tasks`

**表结构**：
- `id`: 任务ID（主键）
- `task_name`: 任务名称
- `task_type`: 任务类型（如：`north_bound_capital`, `market_index` 等）
- `schedule_type`: 调度类型（`daily`, `hourly`, `weekly`, `interval` 等）
- `schedule_time`: 执行时间（格式：HH:MM:SS）
- `schedule_weekdays`: 执行星期（1-7，逗号分隔）
- `is_active`: 是否启用（1=启用，0=禁用）
- `task_config`: 任务配置（JSON格式）
- `created_at`: 创建时间

## 三、检查重复任务

### 方法1：使用SQL查询（推荐）

执行以下SQL语句查看重复任务：

```sql
-- 查看所有启用的任务
SELECT 
    id,
    task_name,
    task_type,
    schedule_type,
    schedule_time,
    schedule_weekdays,
    is_active,
    created_at
FROM scheduled_tasks
WHERE is_active = 1
ORDER BY task_type, schedule_type, schedule_time;

-- 查找重复的任务（相同任务类型、调度类型、调度时间）
SELECT 
    task_type,
    schedule_type,
    schedule_time,
    schedule_weekdays,
    COUNT(*) as duplicate_count,
    GROUP_CONCAT(id ORDER BY id) as task_ids,
    GROUP_CONCAT(task_name ORDER BY id SEPARATOR ' | ') as task_names
FROM scheduled_tasks
WHERE is_active = 1
GROUP BY task_type, schedule_type, schedule_time, schedule_weekdays
HAVING COUNT(*) > 1
ORDER BY duplicate_count DESC, task_type;
```

## 四、重复任务分析

根据日志，发现的重复任务：

| 任务类型 | 重复任务 | 说明 |
|---------|---------|------|
| **北向资金** | ID: 23 (15:30) vs ID: 33 (17:00) | 两个任务都在收集北向资金数据 |
| **市场指数** | ID: 22 (15:30) vs ID: 34 (16:30) | 两个任务都在收集市场指数数据 |
| **主力资金** | ID: 24 (16:30) vs ID: 36 (17:00) | 两个任务都在收集主力资金数据 |

**可能的原因**：
1. 不同时间创建了相同功能的任务
2. 任务名称不同但功能相同
3. 没有及时清理旧任务

## 五、解决方案

### 方案1：禁用重复任务（推荐）

**原则**：保留ID最小的任务（通常是最早创建的），禁用其他重复任务

**SQL语句**：
```sql
-- 先查看要禁用的任务（确认无误后再执行UPDATE）
SELECT 
    t1.id,
    t1.task_name,
    t1.task_type,
    t1.schedule_type,
    t1.schedule_time,
    t1.created_at
FROM scheduled_tasks t1
INNER JOIN (
    SELECT task_type, schedule_type, schedule_time, schedule_weekdays, MIN(id) as min_id
    FROM scheduled_tasks
    WHERE is_active = 1
    GROUP BY task_type, schedule_type, schedule_time, schedule_weekdays
    HAVING COUNT(*) > 1
) t2 ON t1.task_type = t2.task_type 
    AND t1.schedule_type = t2.schedule_type 
    AND t1.schedule_time = t2.schedule_time
    AND (t1.schedule_weekdays = t2.schedule_weekdays OR (t1.schedule_weekdays IS NULL AND t2.schedule_weekdays IS NULL))
WHERE t1.is_active = 1 AND t1.id != t2.min_id
ORDER BY t1.task_type, t1.schedule_time;

-- 确认无误后，执行以下语句禁用重复任务
UPDATE scheduled_tasks 
SET is_active = 0 
WHERE id IN (
    SELECT id FROM (
        SELECT t1.id
        FROM scheduled_tasks t1
        INNER JOIN (
            SELECT task_type, schedule_type, schedule_time, schedule_weekdays, MIN(id) as min_id
            FROM scheduled_tasks
            WHERE is_active = 1
            GROUP BY task_type, schedule_type, schedule_time, schedule_weekdays
            HAVING COUNT(*) > 1
        ) t2 ON t1.task_type = t2.task_type 
            AND t1.schedule_type = t2.schedule_type 
            AND t1.schedule_time = t2.schedule_time
            AND (t1.schedule_weekdays = t2.schedule_weekdays OR (t1.schedule_weekdays IS NULL AND t2.schedule_weekdays IS NULL))
        WHERE t1.is_active = 1 AND t1.id != t2.min_id
    ) AS temp
);
```

### 方案2：手动禁用特定任务

如果只想禁用特定的重复任务：

```sql
-- 禁用ID为 33, 34, 36 的任务（保留 23, 22, 24）
UPDATE scheduled_tasks SET is_active = 0 WHERE id IN (33, 34, 36);

-- 或者根据任务名称禁用
UPDATE scheduled_tasks 
SET is_active = 0 
WHERE task_name IN ('北向资金每日获取', '市场指数每日获取', '主力资金每日获取')
  AND is_active = 1;
```

### 方案3：删除重复任务（谨慎使用）

**注意**：删除操作不可恢复，建议先备份数据！

```sql
-- 先查看要删除的任务
SELECT * FROM scheduled_tasks WHERE id IN (33, 34, 36);

-- 确认无误后删除
DELETE FROM scheduled_tasks WHERE id IN (33, 34, 36);
```

## 六、预防措施

### 1. 创建任务前检查

在创建新任务前，检查是否已存在相同类型的任务：

```sql
SELECT * FROM scheduled_tasks 
WHERE task_type = 'north_bound_capital' 
  AND is_active = 1;
```

### 2. 定期检查重复任务

定期运行检查脚本，及时发现并清理重复任务。

### 3. 统一任务命名规范

建议使用统一的命名规范，例如：
- `{数据类型}_{操作类型}_{调度时间}`
- 例如：`北向资金_每日收集_17:00`
