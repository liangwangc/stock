# 偏差值字段在模型训练中的使用分析

**日期**：2026-01-16

## 一、偏差值字段说明

### 1.1 字段定义

新添加的三个字段：
- `deviation_pct`: 偏差值（预测涨跌幅 - 实际涨跌幅，有符号）
- `absolute_deviation_pct`: 绝对偏差值（|预测涨跌幅 - 实际涨跌幅|）
- `deviation_price`: 价格偏差（预测收盘价 - 实际价格）

### 1.2 字段特性

**重要特性**：这些字段是**事后数据**（Post-hoc Data）
- ✅ 只有在预测完成并知道实际结果后才能计算
- ❌ **预测时无法获得**（因为还没有实际值）
- ✅ 存储在 `stock_predictions` 表中

## 三、是否应该加入模型训练？

### 3.1 作为特征使用 ❌ **不建议**

**原因**：
1. **预测时无法获得**：这些字段是事后计算的，预测时还没有实际值
2. **数据泄露**：如果作为特征，会导致数据泄露（使用未来信息预测未来）
3. **逻辑错误**：模型训练时使用这些字段，但预测时无法提供，会导致特征不一致

**结论**：**不应该**作为模型训练的特征

### 3.2 作为标签使用 ✅ **可以考虑**

**场景**：训练模型预测偏差值（回归任务）

**用途**：
- 训练模型预测"预测偏差"（元学习）
- 评估预测的不确定性
- 校准预测置信度

**实现方式**：
```python
# 在微调训练时，可以使用偏差值作为标签
label = deviation_pct  # 预测偏差值
# 训练回归模型：输入特征 -> 输出偏差值
```

**注意**：这需要单独的训练任务，不是常规的涨跌方向预测

### 3.3 作为元数据使用 ✅ **建议实现**

**用途**：
- 数据质量评估
- 模型性能分析
- 训练样本筛选（如只使用偏差较小的样本）

**实现方式**：
- 在 `load_training_data()` 中加载这些字段
- 在 `prepare_features()` 中排除这些字段（不作为特征）
- 保留在DataFrame中，用于后续分析和筛选
