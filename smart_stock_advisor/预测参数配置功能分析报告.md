# 预测参数配置功能分析报告

## 一、当前实现分析

### 1. 参数存储方式
**位置**：`config.py`
- **预测模型配置** (`PREDICTION_CONFIG`)：包含8个权重因子、最小置信度、回看天数
- **技术指标配置** (`INDICATOR_CONFIG`)：包含MA、RSI、MACD、KDJ、CCI等参数
- **新闻分析配置** (`NEWS_CONFIG`)：包含新闻数量、情感阈值等
- **实时交易配置** (`TRADING_CONFIG`)：包含信号阈值、止损止盈等

### 2. 参数使用方式
**位置**：`predictor/stock_predictor.py`
- `StockPredictor.__init__()` 中直接读取：`self.config = PREDICTION_CONFIG`
- 参数在类实例化时固定，后续无法动态修改
- 所有预测逻辑都使用 `self.config` 和 `self.indicator_config`

### 3. 前端界面
**位置**：`templates/settings.html`
- 存在"参数设置"菜单项：`switchPanel('params')`
- 需要检查是否有对应的面板实现

### 4. 当前问题

#### ❌ 问题1：硬编码配置
- 所有参数都在 `config.py` 中硬编码
- 修改参数需要重启服务
- 无法针对不同用户或场景使用不同配置

#### ❌ 问题2：配置不独立
- 配置与代码耦合
- 没有配置版本管理
- 无法保存配置历史

#### ❌ 问题3：运行时不可变更
- `StockPredictor` 实例化时读取配置，后续不变
- 需要重启服务才能生效
- 无法动态调整参数

#### ❌ 问题4：前端缺失
- 参数设置面板可能未实现或功能不完整
- 无法通过界面修改参数

## 二、优化方案设计

### 1. 数据库设计

#### 表1：`prediction_config` - 预测配置主表
```sql
CREATE TABLE `prediction_config` (
    `id` INT AUTO_INCREMENT PRIMARY KEY,
    `config_name` VARCHAR(100) NOT NULL COMMENT '配置名称',
    `description` TEXT COMMENT '配置描述',
    `is_default` TINYINT(1) DEFAULT 0 COMMENT '是否默认配置',
    `is_active` TINYINT(1) DEFAULT 1 COMMENT '是否激活',
    `created_by` INT COMMENT '创建人ID',
    `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    `updated_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY `uk_config_name` (`config_name`)
) COMMENT='预测配置表';
```

#### 表2：`prediction_config_values` - 配置值表
```sql
CREATE TABLE `prediction_config_values` (
    `id` INT AUTO_INCREMENT PRIMARY KEY,
    `config_id` INT NOT NULL COMMENT '配置ID',
    `category` VARCHAR(50) NOT NULL COMMENT '配置分类 (prediction/indicator/news/trading)',
    `param_key` VARCHAR(100) NOT NULL COMMENT '参数键',
    `param_value` TEXT NOT NULL COMMENT '参数值（JSON格式）',
    `param_type` VARCHAR(20) NOT NULL COMMENT '参数类型 (number/boolean/string)',
    `description` VARCHAR(255) COMMENT '参数描述',
    `min_value` DECIMAL(10,4) COMMENT '最小值',
    `max_value` DECIMAL(10,4) COMMENT '最大值',
    `updated_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (`config_id`) REFERENCES `prediction_config`(`id`) ON DELETE CASCADE,
    UNIQUE KEY `uk_config_param` (`config_id`, `category`, `param_key`)
) COMMENT='配置值表';
```

#### 表3：`prediction_config_history` - 配置历史表
```sql
CREATE TABLE `prediction_config_history` (
    `id` BIGINT AUTO_INCREMENT PRIMARY KEY,
    `config_id` INT NOT NULL COMMENT '配置ID',
    `action` VARCHAR(20) NOT NULL COMMENT '操作类型 (create/update/delete/activate)',
    `old_values` JSON COMMENT '修改前的值',
    `new_values` JSON COMMENT '修改后的值',
    `changed_by` INT COMMENT '修改人ID',
    `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (`config_id`) REFERENCES `prediction_config`(`id`) ON DELETE CASCADE
) COMMENT='配置历史表';
```

### 2. 后端设计

#### 配置管理器模块
**文件**：`utils/prediction_config_manager.py`

**功能**：
- 从数据库加载配置
- 缓存配置到内存（提高性能）
- 支持配置热更新（无需重启）
- 配置验证（权重总和、范围检查等）

**关键方法**：
```python
class PredictionConfigManager:
    def get_config(self, config_id: int = None) -> Dict
    def save_config(self, config_name: str, values: Dict, user_id: int) -> int
    def update_config(self, config_id: int, values: Dict, user_id: int) -> bool
    def delete_config(self, config_id: int) -> bool
    def activate_config(self, config_id: int) -> bool
    def get_active_config(self) -> Dict
    def validate_config(self, values: Dict) -> Tuple[bool, str]
```

#### API端点
**文件**：`web_app.py`

```python
GET    /api/prediction/configs              # 获取所有配置列表
GET    /api/prediction/config/{id}          # 获取指定配置
GET    /api/prediction/config/active        # 获取当前激活配置
POST   /api/prediction/config               # 创建新配置
PUT    /api/prediction/config/{id}          # 更新配置
DELETE /api/prediction/config/{id}          # 删除配置
POST   /api/prediction/config/{id}/activate # 激活配置
POST   /api/prediction/config/validate      # 验证配置
```

### 3. 前端设计

#### 参数设置面板结构
1. **配置管理**：
   - 配置列表（显示所有配置，标记激活的）
   - 创建/编辑/删除/激活配置
   - 配置模板（预设常用配置）

2. **预测权重配置**：
   - 8个权重因子滑块/输入框
   - 实时显示权重总和（应为100%）
   - 一键平衡权重功能

3. **技术指标参数**：
   - MA参数（短期、长期）
   - RSI参数（默认、短期、中期）
   - MACD参数（快线、慢线、信号线）
   - KDJ参数（周期、K/D平滑周期）
   - CCI周期

4. **置信度设置**：
   - 最小置信度阈值
   - 高置信度阈值
   - 回看天数

5. **实时交易参数**（可选）：
   - 信号阈值
   - 止损止盈
   - 仓位管理

### 4. 运行时加载机制

#### 方案1：单例模式 + 缓存
- `PredictionConfigManager` 使用单例模式
- 配置加载后缓存到内存
- `StockPredictor` 每次预测前从缓存读取最新配置

#### 方案2：配置刷新机制
- 提供配置刷新接口
- 定时检查配置是否更新（可选）
- 支持手动刷新配置
