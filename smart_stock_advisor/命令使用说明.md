## 命令使用说明（入口脚本 & 功能模式总览）

本项目主要通过 `main.py` 和 `predictor/realtime_trading_advisor.py` 两个入口脚本提供功能。  
下面把常用命令及其含义统一整理在一起，方便查阅。

---

## 一、主程序入口：`main.py`

在项目根目录 `smart_stock_advisor` 下执行（示例使用 `py`，也可以用 `python`）：

### 1. 单只股票静态预测

- **命令：**
  - `py main.py --symbol 600519`
- **含义：**
  - 对指定股票（如贵州茅台 600519）做 **静态趋势预测**（偏向明天的方向判断）。
  - 执行完整的多因子分析（技术指标、新闻情感、市场情绪、资金流向、板块轮动、估值、美股映射等）。
  - 生成内容：
    - 更新 `stock_predictions.csv`（总预测记录，含目标日期/实际涨跌/是否命中等）。
    - 各种因子 CSV（位于 `data/`）：
      - `technical_indicators_data.csv`（技术指标）
      - `news_sentiment_data.csv`（新闻情感）
      - `market_sentiment_data.csv`（市场情绪）
      - `north_bound_capital_data.csv`（北向资金）
      - `margin_trading_data.csv`（融资融券）
      - `main_force_capital_data.csv`（主力资金）
      - `sector_rotation_data.csv`（板块轮动）
      - `prediction_factors_data.csv`（综合预测因子）
      - `cost_distribution_data.csv`（历史/当日成本分布）
    - 生成/更新图文报告（位于 `reports/`）：
      - PNG 图：`prediction_600519_YYYYMMDD_HHMMSS.png`
      - 交互趋势图 HTML：`prediction_600519_..._interactive.html`
      - 完整文字+图形详情报告：`prediction_600519_..._full_report.html`
    - 重新生成：
      - `stock_list.html`（总体列表页）
      - 每只股票的历史预测页面：`reports/history_*.html`

### 2. 单只股票简化版预测（不生成复杂图表）

- **命令：**
  - `py main.py --symbol 600519 --simple`
- **含义：**
  - 只做预测并生成简化版可视化，不生成完整报告，适合快速查看结果。
  - 仍会更新 `stock_predictions.csv` 和 `data/` 下的各类因子 CSV。

### 3. 批量预测全部 A 股（按成交额排序，支持限制数量）

- **命令示例：**
  - 预测成交额最高的 5 只股票：
    - `py main.py --all --limit 5`
  - 预测全部 A 股（不限制数量，注意耗时较长）：
    - `py main.py --all`
- **含义：**
  - 自动从 AkShare 获取全部 A 股列表及其成交额，按成交额从高到低排序。
  - 对前 `limit` 只股票逐一执行预测。
  - **不会弹出图形窗口**，只在后台生成文件：
    - 对每只股票：
      - 更新 `stock_predictions.csv`
      - 更新各类因子 CSV（`data/*.csv`）
      - 生成 PNG 和 HTML 报告到 `reports/` 目录（使用 `visualize_no_display_v2`）
  - 批量结束后，重新生成：
    - `stock_list.html`
    - 所有股票的 `reports/history_*.html`

## 二、实时交易决策模式（通过 `main.py` 入口）

实时模式的主要逻辑在 `predictor/realtime_trading_advisor.py` 中实现，但可以直接用 `main.py` 调用。

### 1. 单次实时交易决策

- **命令：**
  - `py main.py --realtime --symbol 600519`
  - 如有持仓信息：
    - `py main.py --realtime --symbol 600519 --holding --cost 1800`
- **含义：**
  - 在当前时刻获取：
    - 实时行情：当前价格、涨跌幅、当日高低点、换手率、振幅等。
    - 实时资金流向：主力净流入、总净流入、资金趋势。
    - 盘口五档：买卖盘数据。
    - 静态趋势预测（预测明天方向和概率）。
  - 综合上述信息，生成一次 **实时交易决策**：
    - 操作建议：`BUY / SELL / ADD / REDUCE / HOLD / WAIT / AVOID` 等。
    - 建议强度：强烈 / 适中 / 中性。
    - 买入/卖出价位建议、止损价、目标价、仓位建议。
    - 决策理由、风险提示。
  - 显示方式：
    - 控制台日志打印详细决策结果。
    - 生成包含实时数据和决策的图表（第一行右上角红色框 + 第三行实时面板）。
    - 完整 HTML 报告中的 `【实时行情与交易决策】` 区块展示详细信息。
  - 数据存储：
    - `data/realtime_trading_decisions_data.csv` 中追加一条快照：
      - 记录字段包括：当前价格、涨跌幅、上下概率、置信度、信号强度、操作建议、交易时段、资金净流入、理由、风险提示等。

### 2. 实时监控模式（持续轮询，预警用）

- **命令示例：**
  - 基本示例：
    - `py main.py --monitor --symbol 600519 --interval 30`
  - 带持仓成本：
    - `py main.py --monitor --symbol 600519 --interval 60 --holding --cost 1800`
- **含义：**
  - 通过 `RealtimeTradingAdvisor.monitor_realtime()` 按固定时间间隔（`interval` 秒）重复执行 `get_realtime_decision`，直到：
    - 收盘 / 周末自动退出，或
    - 用户 Ctrl+C 中断。
  - 每一轮都会：
    - 获取最新实时行情、资金流、盘口数据。
    - 计算新的实时信号和交易建议。
    - 当 `action` 由 `HOLD` 切换为 `BUY/SELL/ADD/REDUCE` 等重要变动时，在日志中输出 **“信号变化提醒”**。
  - 数据存储：
    - 每一轮的决策都会写入 `data/realtime_trading_decisions_data.csv`，`mode='monitor'`。
    - 后续可用来分析：在监控模式下哪些信号频繁、在什么时段触发、多长时间内重复等。

### 3. 批量扫描实时机会（找多只股票里的买入候选）

- **命令示例：**
  - 从成交额最高的 50 只股票里扫描买入机会：
    - `py main.py --scan --limit 50`
- **含义：**
  - 通过 `RealtimeTradingAdvisor.batch_scan()`：
    - 使用 `StockDataSource.get_all_stock_list(limit=limit, sort_by_turnover=True)` 获取股票列表。
    - 对每只股票执行一次 `get_realtime_decision`（`holding=False`），只保留 BUY / ADD 信号。
    - 对机会按 `signal_strength` 和 `up_probability` 排序，输出前 N 个（当前默认 10 个）。
  - 输出：
    - 控制台列出每个机会的：
      - 股票代码、名称、当前价、涨跌幅、上涨概率、置信度、操作建议、强度等。
  - 数据存储：
    - 每次扫描得到的实时决策也会写入 `data/realtime_trading_decisions_data.csv`，`mode='scan'`。

## 三、实时交易顾问独立入口：`realtime_trading_advisor.py`

该脚本可以单独运行，主要用于直接操作实时交易顾问模块（与 `main.py` 的实时模式等价）。

### 1. 单次决策

- **命令：**
  - `py predictor/realtime_trading_advisor.py --symbol 600519`
  - 或带持仓信息：
    - `py predictor/realtime_trading_advisor.py --symbol 600519 --holding --cost 1800`
- **含义：**
  - 与 `py main.py --realtime --symbol ...` 类似，执行一次实时交易决策，并在控制台打印结果。

### 2. 实时监控

- **命令：**
  - `py predictor/realtime_trading_advisor.py --symbol 600519 --monitor --interval 30`
- **含义：**
  - 与 `py main.py --monitor --symbol ...` 等价，持续实时监控，间隔 `interval` 秒刷新一次决策。

### 3. 批量扫描

- **命令：**
  - `py predictor/realtime_trading_advisor.py --scan --limit 50`
- **含义：**
  - 从成交额最高的若干股票中筛选 BUY / ADD 信号最强的机会列表。

## 四、分析与评估脚本（离线复盘用）

这些脚本不会参与线上预测，只用于后续的“自我学习”和参数调优。

### 1. 信号质量评估：`analysis/review_signal_quality.py`

- **命令：**
  - `py -m analysis.review_signal_quality`
- **含义：**
  - 基于 `stock_predictions.csv`：
    - 按上涨概率区间（0–50、50–60、…、90–100）分桶，统计每个区间的预测命中率（prediction_hit）。
  - 基于 `data/realtime_trading_decisions_data.csv`：
    - 按 `mode`（single/realtime/monitor/scan）统计记录数和占比。
    - 按 `action`（BUY/SELL/ADD/REDUCE/HOLD/...）统计使用频率。
    - 按交易时段（`trading_session`）查看 BUY/SELL/ADD/REDUCE 在不同时段的触发数量。

### 2. 实时决策事后收益标注：`analysis/label_realtime_outcomes.py`

- **命令：**
  - `py -m analysis.label_realtime_outcomes`
- **含义：**
  - 读取 `data/realtime_trading_decisions_data.csv` 中尚未标注的实时决策记录。
  - 对每条记录：
    - 使用 `StockDataSource.get_stock_data(symbol, days=90)` 获取最近日线数据。
    - 找出 **决策日期之后的第一个交易日收盘价** 作为 `future_price`。
    - 计算 `future_return_pct`：
      - \((\text{future_price} - \text{current_price}) / \text{current_price} \times 100\%\)
    - 根据简单规则打标签 `outcome_label`：
      - 对 BUY / ADD：
        - `future_return_pct >= +2%` → `good`
        - `-2% < future_return_pct < +2%` → `neutral`
        - `future_return_pct <= -2%` → `bad`
      - 对 SELL / REDUCE：
        - `future_return_pct <= -2%` → `good`（卖出后确实跌了）
        - `-2% < future_return_pct < +2%` → `neutral`
        - `future_return_pct >= +2%` → `bad`（卖飞）
      - 其他动作 → `unknown`
  - 结果直接写回 `data/realtime_trading_decisions_data.csv`，新增三列：
    - `future_price`, `future_return_pct`, `outcome_label`

## 五、常见组合场景示例

1. **盘前 / 盘中做静态预测 + 图表查看（单只股票）：**
   - `py main.py --symbol 600519`

2. **收盘后跑一批高成交额股票的预测，用于当日复盘：**
   - `py main.py --all --limit 50`

3. **盘中盯一只票的实时预警（带成本价）：**
   - `py main.py --monitor --symbol 600519 --interval 30 --holding --cost 1800`

4. **盘中扫描热门股里的实时买入机会：**
   - `py main.py --scan --limit 100`

5. **收盘后分析今天所有静态预测和实时决策的信号质量：**
   - `py -m analysis.review_signal_quality`
   - `py -m analysis.label_realtime_outcomes`
