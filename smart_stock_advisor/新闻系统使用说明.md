# 新闻系统使用说明

## 一、系统概述

新闻系统实现了以下功能：

1. **新闻抓取**：从13个新闻源抓取市场新闻和股票新闻
2. **新闻存储**：将新闻保存到数据库，包含完整的信息和元数据
3. **情感分析**：自动分析新闻的情感倾向（利好/利空/中性）
4. **股票关联**：自动将新闻关联到相关股票（通过代码、名称、行业、板块）

### 2. 新闻存储

```python
from utils.news_storage import NewsStorage

storage = NewsStorage()

# 保存单条新闻（会自动进行情感分析和股票关联）
news = {
```

### 3. 情感分析

新闻保存时会自动进行情感分析，结果保存在以下字段：

- `sentiment`: positive/negative/neutral（情感倾向）
- `sentiment_score`: -1到1（情感得分，正数表示利好，负数表示利空）
- `sentiment_confidence`: 0到1（置信度）
- `is_positive`: 1=利好，0=非利好
- `is_negative`: 1=利空，0=非利空

**判断逻辑**：
- `is_positive = 1`: `sentiment == 'positive'` AND `sentiment_score > 0.1`
- `is_negative = 1`: `sentiment == 'negative'` AND `sentiment_score < -0.1`

### 4. 股票关联

新闻保存时会自动关联股票，关联方式：

1. **直接匹配**（relevance_score = 1.0）:
   - 新闻中直接提到股票代码（如：600519）
   - 新闻中直接提到股票名称（如：贵州茅台）

2. **行业匹配**（relevance_score = 0.5-0.7）:
   - 新闻中提到行业关键词（如：银行、医药、科技等）
   - 自动匹配该行业下的所有股票

**关联信息保存在**：
- `symbol`: 关联的股票代码
- `sector`: 关联的板块
- `industry`: 关联的行业
- `relevance_type`: 相关性类型（direct/industry/market）
- `relevance_score`: 相关性得分（0到1）

### 3. 计算新闻权重

```python
def calculate_news_weight(news):
    """计算新闻权重（用于调整交易信号强度）"""
    weight = 1.0
    
    # 相关性权重
    if news['relevance_type'] == 'direct':
        weight *= 1.5  # 直接关联权重更高
    elif news['relevance_type'] == 'industry':
        weight *= 1.2  # 行业关联权重中等
    
    # 置信度权重
    weight *= news['sentiment_confidence']
    
    # 情感强度权重
    weight *= abs(news['sentiment_score'])
    
    return weight
```

## 六、数据库表结构

### news_articles 表

主要字段：

**基本信息**：
- `id`: 新闻ID（主键）
- `title`: 新闻标题
- `content`: 新闻内容
- `summary`: 新闻摘要
- `publish_time`: 发布时间
- `fetch_time`: 抓取时间
- `source`: 新闻来源
- `source_url`: 新闻URL

**关联信息**：
- `symbol`: 关联股票代码
- `sector`: 关联板块
- `industry`: 关联行业
- `concept`: 关联概念

**情感分析**：
- `sentiment`: 情感倾向（positive/negative/neutral）
- `sentiment_score`: 情感得分（-1到1）
- `sentiment_confidence`: 置信度（0到1）
- `is_positive`: 是否利好（1/0）
- `is_negative`: 是否利空（1/0）

**相关性**：
- `relevance_type`: 相关性类型（direct/industry/market）
- `relevance_score`: 相关性得分（0到1）

## 七、注意事项

1. **新闻源配置**：
   - 部分新闻源需要API密钥（如TuShare需要token）
   - 部分新闻源可能因为网站结构变化而失效
   - 建议定期检查新闻源的可用性

2. **情感分析**：
   - 目前基于关键词匹配，准确率有限
   - 建议结合人工审核或引入机器学习模型
   - 否定词处理可能需要改进

3. **股票关联**：
   - 目前只保存主要关联（相关性最高的股票）
   - 如需支持多对多关系，可以创建 `news_stock_mapping` 表
   - 行业匹配可能产生大量关联，建议设置阈值

4. **性能优化**：
   - 批量处理时建议使用多线程
   - 股票信息已缓存，减少数据库查询
   - 建议定期清理过期新闻
