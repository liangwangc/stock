## 三、代码分离详情

### 3.1 `predict_before_close` 方法的优化

#### 3.1.1 API调用优化

**优化1: 缓存 `realtime_quote`**
```python
# 提前获取realtime_quote用于异常检测
realtime_quote_for_anomaly = self.data_source.get_realtime_quote(symbol)
anomaly_result = self._detect_anomalies_with_realtime_quote(symbol, realtime_quote_for_anomaly)

# 后续复用realtime_quote，避免重复调用
if price_source == "历史数据最新价格":
    if realtime_quote_cache:  # 复用之前获取的
        current_price = realtime_quote_cache.get('current_price')
```

**效果**: 减少1次 `get_realtime_quote` 调用（节省约32秒）

**优化2: 缓存 `stock_info`**
```python
# 提前获取stock_info
stock_info_cache = self.data_source.get_stock_info(symbol, skip_pe_pb=False)

# 获取股票名称（使用缓存）
if stock_info_cache:
    stock_name = stock_info_cache.get('name', ...)

# 估值分析（使用缓存）
'valuation': lambda: self._calculate_valuation_score_with_cache(symbol, stock_info_cache)
```

**效果**: 减少1次 `get_stock_info` 调用（节省约10秒）

**优化3: 移除不必要的 `get_all_stock_list` 调用**
```python
# 不再调用get_all_stock_list获取全部股票列表
# 直接使用stock_info_cache获取股票名称
```

**效果**: 减少1次 `get_all_stock_list` 调用（节省约5-10秒）

## 六、功能对比

### 6.1 相同点

两个方法都包含：
- ✅ 异常情况检测
- ✅ 股票数据获取（优先数据库）
- ✅ 多因子分析（技术指标、新闻、资金流向等）

- ✅ 权重优化
- ✅ 置信度计算
- ✅ 预测结果生成

### 6.2 不同点

| 特性 | `predict()` | `predict_before_close()` |
|------|------------|------------------------|
| **用途** | 设置页面股票分析 | 主页未收盘-明天预测 |
| **预测类型** | `after_close` | `before_close` |
| **API调用优化** | 无特殊优化 | 缓存复用，减少调用 |

| **估值分析** | 每次调用API | 使用缓存的 `stock_info` |
