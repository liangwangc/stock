# 批量收集10年历史数据使用指南

## 一、准备工作


### 2. 确保数据库表已创建

```bash
# A股历史数据表
python database/create_stock_history_table.py

# 美股历史数据表
python scripts/create_us_stock_tables.py
```

## 二、数据收集方法

### 方法1：使用启动脚本（推荐，Windows）

```bash
# Windows：双击运行或命令行执行
scripts\start_data_collection.bat

# Linux/Mac：先添加执行权限
chmod +x scripts/start_data_collection.sh
./scripts/start_data_collection.sh
```

启动脚本会提示选择市场类型（A股/美股/测试模式）。

### 方法2：直接使用Python脚本

#### A股数据收集

```bash
# 基本用法（每批50只股票，默认延迟1秒）
python scripts/batch_collect_10years_data.py --market cn

# 自定义批次大小和延迟
python scripts/batch_collect_10years_data.py --market cn --batch-size 30 --delay 1.5

# 继续之前的进度
python scripts/batch_collect_10years_data.py --market cn --resume

# 收集5年数据（而不是10年）
python scripts/batch_collect_10years_data.py --market cn --years 5

# 测试模式：只收集5只股票，1年数据（用于测试）
python scripts/batch_collect_10years_data.py --market cn --batch-size 5 --years 1
```

#### 美股数据收集

```bash
# 基本用法
python scripts/batch_collect_10years_data.py --market us

# 自定义参数
python scripts/batch_collect_10years_data.py --market us --batch-size 50 --delay 1.0

# 继续之前的进度
python scripts/batch_collect_10years_data.py --market us --resume
```

### 推荐执行顺序

1. **先测试**（确保脚本正常工作）：
   ```bash
   python scripts/batch_collect_10years_data.py --market cn --batch-size 5 --years 1
   ```

2. **开始正式收集**（A股）：
   ```bash
   python scripts/batch_collect_10years_data.py --market cn --batch-size 50 --delay 1.0
   ```

3. **如果中断，继续进度**：
   ```bash
   python scripts/batch_collect_10years_data.py --market cn --resume
   ```

## 三、进度管理

### 进度文件位置

- A股进度：`data/collect_progress_cn.json`
- 美股进度：`data/collect_progress_us.json`

### 进度文件格式

```json
{
  "completed_symbols": ["000001", "000002", ...],
  "failed_symbols": [
    {
      "symbol": "600xxx",
      "error": "错误信息",
      "time": "2024-01-01 12:00:00"
    }
  ],
  "current_batch": 5,
  "total_symbols": 5000,
  "start_time": "2024-01-01 10:00:00",
  "last_update": "2024-01-01 12:30:00"
}
```

### 断点续传

- 使用 `--resume` 参数可以继续之前的进度
- 脚本会自动跳过已完成和已失败的股票
- 每只股票处理完成后自动保存进度，中断不会丢失数据

## 四、数据量估算

### A股数据量
- **股票数量**：约5000只
- **每只股票**：10年 × 250个交易日 = 约2500条记录
- **总记录数**：约 **1250万条**
- **预计存储**：约 **25GB**（含索引）

### 美股数据量
- **股票数量**：约3000只（主要股票）
- **每只股票**：10年 × 252个交易日 = 约2520条记录
- **总记录数**：约 **756万条**
- **预计存储**：约 **15GB**（含索引）

## 五、性能优化建议

### 1. 批次大小调整
- **小批次（20-30只）**：API限制严格时使用，更稳定
- **中批次（50只）**：推荐，平衡速度和稳定性
- **大批次（100只）**：API稳定时使用，更快但风险更高

### 2. 延迟设置
- **默认1秒**：适用于大多数API
- **0.5秒**：API稳定时可尝试，加快速度
- **2秒**：API限制严格时使用，更安全

### 3. 分时段收集
- 建议在非交易时间（晚上）进行大量数据收集
- 避开API高峰期

## 六、错误处理

### 常见错误

1. **API限制错误**
   - 解决：增加延迟时间（--delay 2.0）
   - 减小批次大小（--batch-size 20）

2. **网络超时**
   - 解决：脚本会自动重试，或手动使用--resume继续

3. **数据库连接错误**
   - 解决：检查数据库配置，确保数据库服务运行

### 失败股票处理

失败股票记录在进度文件的 `failed_symbols` 中，可以：
1. 查看失败原因
2. 手动重试失败的股票
3. 或使用--resume自动跳过已失败的股票

## 七、数据验证

### 检查收集进度

```python
import json
import os

progress_file = 'data/collect_progress_cn.json'
with open(progress_file, 'r', encoding='utf-8') as f:
    progress = json.load(f)
    
print(f"总股票数: {progress['total_symbols']}")
print(f"已完成: {len(progress['completed_symbols'])}")
print(f"失败: {len(progress['failed_symbols'])}")
print(f"剩余: {progress['total_symbols'] - len(progress['completed_symbols']) - len(progress['failed_symbols'])}")
```

### 验证数据完整性

```sql
-- 检查A股数据数量
SELECT symbol, COUNT(*) as record_count, 
       MIN(trade_date) as first_date, 
       MAX(trade_date) as last_date
FROM stock_history_data
WHERE period_type = 'daily'
GROUP BY symbol
ORDER BY record_count DESC
LIMIT 20;

-- 检查美股数据数量
SELECT symbol, COUNT(*) as record_count,
       MIN(trade_date) as first_date,
       MAX(trade_date) as last_date
FROM us_stock_history_data
WHERE period_type = 'daily'
GROUP BY symbol
ORDER BY record_count DESC
LIMIT 20;
```

## 八、注意事项

1. **数据量大**：10年数据收集需要很长时间（可能数天），建议分批进行
2. **API限制**：遵守数据源的API限制，避免被封禁
3. **磁盘空间**：确保有足够的磁盘空间（至少50GB）
4. **数据库性能**：大量数据插入可能影响数据库性能，建议在低峰期进行
5. **定期备份**：数据收集过程中定期备份数据库
