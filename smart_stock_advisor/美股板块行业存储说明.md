# 美股板块和行业信息存储说明

## 概述

美股数据收集系统**已经实现了板块和行业信息的存储**，包括：

1. ✅ 股票基本信息表中的板块和行业代码
2. ✅ 板块与股票的映射关系（us_sector_stock_map表）
3. ✅ 行业与股票的映射关系（us_industry_stock_map表）
4. ✅ 板块和行业信息表（us_sectors, us_industries表）

## 数据流程

### 1. 数据获取

当调用 `collect_stock_history()` 收集股票数据时：

1. **获取股票基本信息**：调用 `data_source.get_stock_info(symbol)`
   - 从yfinance获取股票的sector和industry名称
   - 自动将sector名称映射到GICS代码（如："Technology" -> "45"）
   - 对于industry，如果找不到标准GICS代码，会生成临时代码

2. **保存股票基本信息**：调用 `storage.save_stock_info(stock_info)`
   - 保存到 `us_stock_info` 表
   - 包含：symbol, name_en, exchange, sector_code, industry_code等

3. **保存映射关系**：
   - 调用 `storage.save_sector_stock_map()` 保存板块映射
   - 调用 `storage.save_industry_stock_map()` 保存行业映射
   - 这些映射保存在 `us_sector_stock_map` 和 `us_industry_stock_map` 表中

### 3. 行业代码生成

如果yfinance返回的industry名称无法找到标准GICS代码，系统会：

1. 先查询数据库中是否已存在相同名称的行业
2. 如果存在，使用现有的industry_code
3. 如果不存在，根据sector_code生成临时代码：
   - 格式：`{sector_code}{序号}`（如：45001表示Technology板块下的第1个行业）
   - 保存到 `us_industries` 表

## 数据表结构

### us_stock_info 表
- `symbol`: 股票代码
- `sector_code`: 所属板块代码（GICS）
- `industry_code`: 所属行业代码（GICS或生成）
- 其他基本信息

### us_sector_stock_map 表
- `symbol`: 股票代码
- `sector_code`: 板块代码
- `is_primary`: 是否主要板块（1=是，0=否）
- 支持多对多关系（一只股票可以属于多个板块）

### us_industry_stock_map 表
- `symbol`: 股票代码
- `industry_code`: 行业代码
- `is_primary`: 是否主要行业
- 支持多对多关系（一只股票可以属于多个行业）

## 查询示例

### 查询股票的板块和行业信息

```sql
-- 查询股票的基本信息（包含板块和行业代码）
SELECT symbol, name_en, sector_code, industry_code
FROM us_stock_info
WHERE symbol = 'AAPL';

-- 查询股票所属的板块（带板块名称）
SELECT s.sector_code, s.sector_name_en, s.sector_name_cn
FROM us_sector_stock_map m
JOIN us_sectors s ON m.sector_code = s.sector_code
WHERE m.symbol = 'AAPL';

-- 查询股票所属的行业（带行业名称）
SELECT i.industry_code, i.industry_name_en, i.industry_name_cn
FROM us_industry_stock_map m
JOIN us_industries i ON m.industry_code = i.industry_code
WHERE m.symbol = 'AAPL';
```

### 查询某个板块的所有股票

```sql
SELECT s.symbol, si.name_en
FROM us_sector_stock_map s
JOIN us_stock_info si ON s.symbol = si.symbol
WHERE s.sector_code = '45'  -- Technology板块
ORDER BY s.symbol;
```

### 查询某个行业的所有股票

```sql
SELECT i.symbol, si.name_en
FROM us_industry_stock_map i
JOIN us_stock_info si ON i.symbol = si.symbol
WHERE i.industry_code = '451020'  -- 某个行业代码
ORDER BY i.symbol;
```

## 注意事项

1. **行业代码**：
   - yfinance通常不返回完整的GICS行业代码
   - 系统会基于industry名称和sector_code生成临时代码
   - 如果需要标准GICS代码，可以从其他数据源补充

2. **板块映射**：
   - yfinance返回的sector名称可能与标准GICS名称略有不同
   - 系统已实现名称映射，可以处理常见的名称变体

3. **数据完整性**：
   - 如果yfinance没有返回sector或industry信息，这些字段将为空
   - 某些新上市或特殊股票可能没有完整的分类信息
