## 修复内容

### 1. 新增方法：`get_actual_stock_change()`

**文件**：`smart_stock_advisor/data_source/stock_data_source.py`

**方法签名**：
```python
def get_actual_stock_change(self, symbol: str, target_date: str, current_price: float = None) -> Dict:
```

**功能**：
1. 从 `stock_history_data` 表查询目标日期的收盘价
2. 如果没有提供 `current_price`，从 `stock_predictions` 表查询预测时的价格
3. 计算实际涨跌幅：`(actual_close - current_price) / current_price * 100`
4. 判断实际方向：
   - 涨跌幅 > 0.01%：上涨
   - 涨跌幅 < -0.01%：下跌
   - 其他：平盘
5. 返回格式化的数据字典

**数据获取优先级**：
1. **优先从数据库获取**：使用 `StockHistoryStorage.get_stock_history_data()` 从 `stock_history_data` 表查询
2. **备用方案**：如果数据库没有数据，使用 `get_stock_data()` 方法从API获取

**返回格式**：
```python
{
    'success': True/False,
    'close': 实际收盘价,
    'change_pct': 实际涨跌幅（%）,
    'direction': 实际方向（上涨/下跌/平盘）,
    'message': 错误信息（如果失败）
}
```

## 数据流程

### 更新流程

```
1. 用户访问历史预测页面或保存新预测
   ↓
2. 触发 _update_historical_actual_data()
   ↓
3. 查询需要更新的记录（target_date < 今天 且 actual_price 为空）
   ↓
4. 对每条记录：
   a. 调用 get_actual_stock_change(symbol, target_date, current_price)
   b. 从 stock_history_data 表查询目标日期的收盘价
   c. 如果没有 current_price，从 stock_predictions 表查询
   d. 计算实际涨跌幅 = (实际收盘价 - 预测时价格) / 预测时价格 * 100
   e. 判断实际方向（上涨/下跌/平盘）
   f. 判断预测命中（命中/未命中）
   g. 调用 update_prediction_actual() 更新数据库
   ↓
5. 更新完成，记录日志
```

### 数据来源

| 字段 | 数据来源 | 说明 |
|------|----------|------|
| `actual_price` | `stock_history_data.close_price` | 目标日期的收盘价 |
| `actual_change_pct` | 计算得出 | `(actual_price - current_price) / current_price * 100` |
| `actual_direction` | 计算得出 | 根据 `actual_change_pct` 判断 |
| `prediction_hit` | 计算得出 | 根据预测方向和实际涨跌幅判断 |

## 注意事项

1. **数据依赖**：
   - 需要确保 `stock_history_data` 表中有目标日期的数据
   - 如果目标日期是周末或节假日，可能无法获取数据

2. **性能考虑**：
   - 批量更新时，如果记录数量很大，可能需要分批处理
   - 可以考虑添加缓存机制，避免重复查询

3. **错误处理**：
   - 如果获取实际数据失败，不会影响其他记录的更新
   - 错误会被记录到日志中

4. **数据一致性**：
   - 更新时会检查 `actual_price` 是否为空，避免重复更新
   - 使用 `symbol + target_date` 作为唯一标识
