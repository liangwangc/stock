# 新闻实时存储到数据库修复说明

## 一、问题

用户反馈：抓取的新闻没有在数据库中找到，需要把抓取的新闻（标题、内容、时间等）实时存储到数据库中。

## 二、问题分析

### 1. 当前保存逻辑

**`save_news_article` 方法**（`news_storage.py` 第107行）：
- ✅ 有保存逻辑
- ✅ 会提取标题、内容、时间等信息
- ✅ 会执行INSERT语句

**可能的问题**：
1. ❌ 事务没有正确提交（如果 `autocommit=False`）
2. ❌ 错误被捕获但没有详细记录
3. ❌ 重复检测导致没有保存（但应该返回existing_id）
4. ❌ 数据库表不存在
5. ❌ 数据库连接问题

### 2. 代码检查

**问题1：事务提交逻辑**
```python
# 原代码（第285行）
if not DB_CONFIG.get('autocommit', True):
    conn.commit()
```

**问题**：
- 如果 `autocommit=True`（默认），不会执行 `commit()`
- 但PyMySQL默认 `autocommit=True`，应该会自动提交
- 但为了确保，应该**总是执行commit()**

**问题2：错误处理**
- 错误被捕获但没有详细记录
- 没有验证保存是否成功

**问题3：表存在性检查**
- 没有检查 `news_articles` 表是否存在
- 如果表不存在，保存会失败

## 三、修复方案

### 1. 确保事务正确提交

**修改前**：
```python
if not DB_CONFIG.get('autocommit', True):
    conn.commit()
```

**修改后**：
```python
# 确保提交（无论autocommit设置如何）
conn.commit()
```

### 2. 添加保存成功验证

**新增验证逻辑**：
```python
# 验证保存成功
if news_id:
    verify_sql = "SELECT id, title FROM news_articles WHERE id = %s"
    verify_result = DBConnection.execute_query(verify_sql, (news_id,))
    if verify_result:
        self.logger.debug(f"保存新闻成功: {title[:50]}... (ID: {news_id})")
    else:
        self.logger.warning(f"保存新闻后验证失败: {title[:50]}... (ID: {news_id})")
        news_id = None
```

### 3. 确保表存在

**新增表存在性检查**：
```python
def _ensure_news_table_exists(self):
    """确保news_articles表存在"""
    try:
        sql_file = os.path.join(project_root, "database", "news_table.sql")
        if os.path.exists(sql_file):
            with open(sql_file, 'r', encoding='utf-8') as f:
                create_sql = f.read()
                DBConnection.execute_update(create_sql)
    except Exception as e:
        self.logger.warning(f"检查news_articles表时出错: {str(e)}")
```

### 4. 增强错误日志

**修改错误处理**：
- 记录详细的错误信息
- 记录新闻标题（便于排查）
- 记录SQL执行结果

### 2. 保存流程

**完整流程**：
1. 检查数据库是否启用
2. 确保 `news_articles` 表存在

8. **验证保存成功**（查询刚插入的记录）
9. 返回news_id

## 五、保存的字段

**`news_articles` 表字段**：
- `title` - 新闻标题（VARCHAR(500)）
- `content` - 新闻内容（TEXT）
- `summary` - 新闻摘要（TEXT，取内容前200字）
- `publish_time` - 发布时间（DATETIME）
- `fetch_time` - 抓取时间（DATETIME，当前时间）
- `source` - 新闻来源（VARCHAR(50)）
- `source_url` - 新闻原始URL（VARCHAR(1000)）
- `news_type` - 新闻类型（stock/market/policy/industry）
- `symbol` - 关联股票代码（VARCHAR(10)）
- `sector` - 关联板块（VARCHAR(100)）
- `industry` - 关联行业（VARCHAR(100)）
- `concept` - 关联概念（VARCHAR(200)）
- `sentiment` - 情感倾向（positive/negative/neutral）
- `sentiment_score` - 情感得分（-1到1）
- `sentiment_confidence` - 情感分析置信度（0到1）
- `is_positive` - 是否利好（1/0）
- `is_negative` - 是否利空（1/0）
- `is_policy` - 是否政策新闻（1/0）
- `keywords` - 匹配的关键词（JSON格式）
- `relevance_type` - 相关性类型（direct/industry/market）
- `relevance_score` - 相关性得分（0到1）
- `simhash` - SimHash值（用于相似度检测，可选）
