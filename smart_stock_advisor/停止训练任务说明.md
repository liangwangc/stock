# 停止训练任务说明

**创建日期**：2026-01-14

---

## 停止训练任务的方法

### 方法1：在运行训练的终端窗口按 Ctrl+C

如果训练脚本是在终端窗口中运行的，直接按 `Ctrl+C` 即可停止。

---

### 方法2：使用任务管理器

1. 打开任务管理器（`Ctrl+Shift+Esc`）
2. 找到 `python.exe` 进程
3. 右键点击 → 结束任务

---

### 方法3：使用PowerShell命令

```powershell
# 查看所有Python进程
Get-Process python

# 停止所有Python进程（谨慎使用）
Get-Process python | Stop-Process -Force

# 或停止特定进程ID
Stop-Process -Id <进程ID> -Force
```

---

### 方法4：使用命令行

```cmd
# 查看Python进程
tasklist | findstr python

# 停止所有Python进程
taskkill /F /IM python.exe
```

---

## 注意事项

⚠️ **强制停止训练任务**：
- 正在训练的模型可能不会保存
- 已保存的模型文件不受影响
- 数据库记录可能不完整

✅ **安全停止**：
- 如果训练接近完成，建议等待完成后再停止
- 训练脚本会自动保存模型，即使中途停止，已完成的模型也会保存

---

## 检查训练状态

训练停止后，可以检查：

1. **模型文件**：`models/xgb_classifier/` 目录
2. **数据库记录**：`trained_models` 表
3. **日志文件**：查看训练日志
