### 方法3：使用Python代码批量收集

```python
from utils.us_stock_collector import USStockCollector
from scripts.get_us_stock_list import get_stock_list_by_index

# 创建收集器
collector = USStockCollector()

# 获取S&P 500成分股
symbols = get_stock_list_by_index('sp500')
print(f"共 {len(symbols)} 只股票需要收集")

# 批量收集（每批50只，避免一次处理太多）
batch_size = 50
for i in range(0, len(symbols), batch_size):
    batch = symbols[i:i+batch_size]
    print(f"\n处理第 {i//batch_size + 1} 批，共 {len(batch)} 只股票...")
    
    result = collector.collect_batch_stocks(
        symbols=batch,
        period="10y",  # 10年数据
        delay=0.5      # 每只股票延迟0.5秒
    )
    
    print(f"成功: {result['success_count']}, 失败: {result['fail_count']}")
    
    # 每批之间休息一下
    if i + batch_size < len(symbols):
        import time
        time.sleep(5)  # 休息5秒
```

## 四、数据收集流程

### 完整流程示例

```python
"""
完整的美股数据收集流程
"""
import os
import sys

project_root = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
sys.path.insert(0, project_root)

from utils.us_stock_collector import USStockCollector
from scripts.get_us_stock_list import get_stock_list_by_index
import time

def collect_us_stocks_10years():
    """收集美股10年历史数据"""
    
    # 1. 初始化收集器
    collector = USStockCollector()
    
    # 2. 初始化板块数据
    print("初始化GICS板块数据...")
    collector.initialize_gics_sectors()
    
    # 3. 获取股票列表
    print("\n获取S&P 500成分股列表...")
    symbols = get_stock_list_by_index('sp500')
    
    if not symbols:
        print("无法获取股票列表，使用示例股票")
        symbols = ['AAPL', 'MSFT', 'GOOGL', 'AMZN', 'TSLA', 'META', 'NVDA', 'JPM', 'V', 'JNJ']
    
    print(f"共 {len(symbols)} 只股票需要收集数据")
    
    # 4. 批量收集（分批进行，避免一次处理太多）
    batch_size = 20  # 每批20只
    total_batches = (len(symbols) + batch_size - 1) // batch_size
    
    for i in range(0, len(symbols), batch_size):
        batch = symbols[i:i+batch_size]
        batch_num = i // batch_size + 1
        
        print(f"\n{'='*60}")
        print(f"处理第 {batch_num}/{total_batches} 批")
        print(f"股票: {', '.join(batch[:5])}... (共 {len(batch)} 只)")
        print(f"{'='*60}")
        
        result = collector.collect_batch_stocks(
            symbols=batch,
            period="10y",
            delay=0.5
        )
        
        print(f"\n批次结果:")
        print(f"  成功: {result['success_count']}")
        print(f"  失败: {result['fail_count']}")
        
        if result['fail_list']:
            print(f"  失败的股票: {', '.join(result['fail_list'])}")
        
        # 批次之间休息
        if i + batch_size < len(symbols):
            print(f"\n等待5秒后处理下一批...")
            time.sleep(5)
    
    print(f"\n{'='*60}")
    print("所有股票数据收集完成！")
    print(f"{'='*60}")

if __name__ == '__main__':
    collect_us_stocks_10years()
```

## 五、数据验证

### 检查已收集的数据

```sql
-- 查看已收集的股票数量
SELECT COUNT(DISTINCT symbol) as stock_count 
FROM us_stock_history_data;

-- 查看每只股票的记录数
SELECT symbol, COUNT(*) as record_count, 
       MIN(trade_date) as first_date, 
       MAX(trade_date) as last_date
FROM us_stock_history_data
GROUP BY symbol
ORDER BY record_count DESC
LIMIT 20;

-- 查看数据覆盖的时间范围
SELECT MIN(trade_date) as earliest_date, 
       MAX(trade_date) as latest_date,
       DATEDIFF(MAX(trade_date), MIN(trade_date)) as days_span
FROM us_stock_history_data;

-- 查看某个股票的数据
SELECT trade_date, open_price, close_price, high_price, low_price, volume
FROM us_stock_history_data

ORDER BY trade_date DESC
LIMIT 10;
```

## 六、增量更新

系统支持增量更新，默认不会重复下载已存在的数据。

### 每日更新（收盘后运行）

```python
from utils.us_stock_collector import USStockCollector
from datetime import datetime, timedelta

collector = USStockCollector()

# 获取需要更新的股票列表
symbols = ['AAPL', 'MSFT', 'GOOGL']  # 或从数据库查询

# 更新最近30天的数据（确保没有遗漏）
end_date = datetime.now().date()
start_date = end_date - timedelta(days=30)

for symbol in symbols:
    result = collector.collect_stock_history(
        symbol=symbol,
        start_date=start_date.strftime('%Y-%m-%d'),
        end_date=end_date.strftime('%Y-%m-%d'),
        update_existing=False  # False=不更新已存在的数据，True=强制更新
    )
    print(f"{symbol}: {result.get('message')}")
```

## 七、注意事项

### 1. 时间成本

- 收集单只股票的10年数据大约需要2-5秒
- S&P 500全部500只股票大约需要2-3小时（包含延迟）
- 建议分批进行，每批20-50只股票

### 2. 数据源限制

- yfinance有请求频率限制，建议每只股票之间延迟0.5-1秒
- 如果遇到429错误（Too Many Requests），增加延迟时间
- 可以使用代理或VPN提高稳定性

### 3. 数据完整性

- 某些历史数据可能不完整（如IPO前的数据）
- 退市股票的数据可能在某日期后停止
- 技术指标需要足够的历史数据才能计算（如MA200需要200个交易日）

### 4. 存储空间

- 每只股票10年数据大约占用1-5MB（取决于字段完整度）
- S&P 500全部股票大约需要500MB-2.5GB存储空间
- 建议定期备份数据库

## 八、故障排除

### 问题1：yfinance未安装

**错误**：`ModuleNotFoundError: No module named 'yfinance'`

**解决**：
```bash
pip install yfinance
```

### 问题2：获取股票列表失败

**错误**：无法从Wikipedia获取股票列表

**解决**：
- 检查网络连接
- 尝试使用手动指定的股票列表
- 或者从其他数据源获取股票列表

### 问题3：数据获取失败

**错误**：某些股票数据获取失败

**解决**：
- 检查股票代码是否正确
- 检查股票是否已退市
- 增加请求延迟时间
- 查看日志获取详细错误信息

### 问题4：数据库连接失败

**错误**：无法连接到数据库

**解决**：
- 检查数据库配置（config_db.py）
- 确认数据库服务已启动
- 检查用户权限

## 九、最佳实践

### 1. 分批收集

建议将大量股票分批收集，避免：
- 一次性请求过多导致频率限制
- 网络中断导致全部失败
- 内存占用过大

### 2. 保存进度

可以在收集过程中保存进度，便于中断后继续：

```python
import json

# 保存已完成的股票列表
completed_symbols = []
with open('completed_symbols.json', 'w') as f:
    json.dump(completed_symbols, f)

# 中断后继续
with open('completed_symbols.json', 'r') as f:
    completed_symbols = json.load(f)

remaining_symbols = [s for s in all_symbols if s not in completed_symbols]
```

### 3. 定期更新

建议每天收盘后运行增量更新脚本，确保数据是最新的。

### 4. 数据验证

收集完成后，建议运行数据验证脚本，检查：
- 数据完整性
- 时间范围是否正确
- 是否有异常值
