# 定时任务启动错误修复说明

## 一、问题描述

设置页面 → 股票数据获取 → 启动定时任务时出现错误：
```
'datetime.timedelta' object has no attribute 'strftime'
```

## 二、问题原因

### 1. 数据库字段类型问题
- `scheduled_tasks` 表中的 `schedule_time` 字段是 `TIME` 类型
- MySQL的 `TIME` 类型在某些数据库驱动中可能被转换为 Python 的 `timedelta` 对象
- 代码中假设 `schedule_time` 如果不是字符串，就是 `datetime.time` 或 `datetime` 对象，并调用 `strftime()` 方法
- `timedelta` 对象没有 `strftime()` 方法，导致错误

### 2. 错误位置
- `_schedule_task()` 方法第179行（修复前）
- `_update_next_run_time()` 方法第1031行（修复前）

## 三、修复内容

### 1. 添加时间规范化函数（`scheduled_task_manager.py`）

**新增函数**：`_normalize_schedule_time()`（第158-188行）

**功能**：
- 统一处理 `schedule_time` 的各种可能类型
- 支持字符串、`timedelta`、`datetime.time`、`datetime` 等类型
- 统一转换为 `HH:MM:SS` 格式的字符串

**实现逻辑**：
```python
def _normalize_schedule_time(self, schedule_time) -> Optional[str]:
    if schedule_time is None:
        return None
    
    if isinstance(schedule_time, str):
        # 已经是字符串，直接返回
        return schedule_time
    elif isinstance(schedule_time, timedelta):
        # timedelta对象：转换为HH:MM:SS格式
        total_seconds = int(schedule_time.total_seconds())
        hours = total_seconds // 3600
        minutes = (total_seconds % 3600) // 60
        seconds = total_seconds % 60
        return f"{hours:02d}:{minutes:02d}:{seconds:02d}"
    elif hasattr(schedule_time, 'strftime'):
        # datetime.time或datetime对象：使用strftime
        try:
            return schedule_time.strftime('%H:%M:%S')
        except:
            return str(schedule_time)
    else:
        # 其他类型：转换为字符串
        return str(schedule_time)
```

### 2. 修复 `_schedule_task()` 方法（第190-225行）

**修改前**：


### 3. 修复 `_update_next_run_time()` 方法（第1048-1081行）

**修改前**：
```python
if schedule_time:
    time_str = str(schedule_time) if isinstance(schedule_time, str) else schedule_time.strftime('%H:%M:%S')
    hour, minute = map(int, time_str.split(':'))
```

**修改后**：
```python
if schedule_time:
    time_str = self._normalize_schedule_time(schedule_time)
    if time_str:
        # 解析时间字符串（HH:MM:SS或HH:MM）
        time_parts = time_str.split(':')
        hour = int(time_parts[0]) if len(time_parts) > 0 else 15
        minute = int(time_parts[1]) if len(time_parts) > 1 else 5
```

### 4. 修复 `hourly` 类型处理（第228-233行）

**修改前**：
```python
elif schedule_type == 'hourly':
    if schedule_time:
        minute = int(str(schedule_time).split(':')[1]) if ':' in str(schedule_time) else 0
```

**修改后**：
```python
elif schedule_type == 'hourly':
    if schedule_time:
        time_str = self._normalize_schedule_time(schedule_time)
        if time_str and ':' in time_str:
            minute = int(time_str.split(':')[1]) if len(time_str.split(':')) > 1 else 0
        else:
            minute = 0
```
