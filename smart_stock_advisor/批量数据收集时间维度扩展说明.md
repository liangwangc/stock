# 批量数据收集时间维度扩展说明

## 一、功能概述

为 `batch_collect_10years_data.py` 脚本增加灵活的时间维度支持，除了原有的"年"单位外，新增支持"月"、"周"、"日"单位。

## 二、新增参数

### 1. `--time-range` 和 `--time-unit`（推荐使用）

**用法示例**：
```bash
# 收集最近30天的数据
py scripts\batch_collect_10years_data.py --market cn --time-range 30 --time-unit day --batch-size 1000 --delay 1.0 --threads 10

# 收集最近3个月的数据
py scripts\batch_collect_10years_data.py --market cn --time-range 3 --time-unit month --batch-size 1000 --delay 1.0 --threads 10

# 收集最近4周的数据
py scripts\batch_collect_10years_data.py --market cn --time-range 4 --time-unit week --batch-size 1000 --delay 1.0 --threads 10

# 收集最近1年的数据
py scripts\batch_collect_10years_data.py --market cn --time-range 1 --time-unit year --batch-size 1000 --delay 1.0 --threads 10
```

### 2. `--years`（兼容旧版本，支持小数）

**用法示例**：
```bash
# 收集最近0.1年（约36天）的数据
py scripts\batch_collect_10years_data.py --market cn --years 0.1 --batch-size 1000 --delay 1.0 --threads 10

# 收集最近10年的数据
py scripts\batch_collect_10years_data.py --market cn --years 10 --batch-size 1000 --delay 1.0 --threads 10
```

## 三、参数优先级

1. **优先级1**：`--time-range` + `--time-unit`（如果同时提供）
2. **优先级2**：`--years`（如果提供了 `--years`）
3. **默认值**：10年（如果都没有提供）

## 四、时间单位转换

### 转换规则

| 时间单位 | 转换为年数 | 示例 |
|---------|-----------|------|
| year | 1.0 | 1 year = 1.0 year |
| month | 1/12 ≈ 0.0833 | 1 month = 0.0833 year |
| week | 1/52 ≈ 0.0192 | 1 week = 0.0192 year |
| day | 1/365 ≈ 0.0027 | 1 day = 0.0027 year |

### 转换公式

```python
if time_unit == 'year':
    years = time_range
elif time_unit == 'month':
    years = time_range / 12.0
elif time_unit == 'week':
    years = time_range / 52.0
elif time_unit == 'day':
    years = time_range / 365.0
```

## 五、实现细节

### 1. 参数解析（`main()` 函数）

**新增参数**：
```python
parser.add_argument('--time-range', type=float, default=None,
                   help='收集时间范围数值（与--time-unit配合使用，例如：30 表示30个单位）')
parser.add_argument('--time-unit', choices=['year', 'month', 'week', 'day'], default=None,
                   help='时间单位（year=年, month=月, week=周, day=日）。与--time-range配合使用')
parser.add_argument('--years', type=float, default=None,  # 改为float类型
                   help='收集多少年的数据（例如：10 表示10年，0.1 表示约36天）')
```

**参数解析逻辑**：
```python
# 优先级：--time-range + --time-unit > --years
if args.time_range is not None and args.time_unit:
    # 使用新的时间单位参数
    time_range = args.time_range
    time_unit = args.time_unit
    # 转换为年数（用于兼容现有接口）
    if time_unit == 'year':
        years = time_range
    elif time_unit == 'month':
        years = time_range / 12.0
    elif time_unit == 'week':
        years = time_range / 52.0
    elif time_unit == 'day':
        years = time_range / 365.0
    time_range_str = f"{time_range} {time_unit}"
elif args.years is not None:
    # 使用旧的years参数（兼容旧版本）
    years = args.years
    time_range_str = f"{years} year(s)"
else:
    # 默认值
    years = 10
    time_range_str = "10 year(s)"
```

### 3. 日期范围计算优化（`collect_stock_history_data`）

**优化前**：
```python
start_date = end_date - timedelta(days=years * 365)
```

**优化后**：
```python
# 计算实际天数（支持小数年数）
days = int(years * 365)
if years < 1:
    # 对于小于1年的情况，使用更精确的计算
    days = int(years * 365.25)  # 考虑闰年
elif years >= 1:
    # 对于大于等于1年的情况，使用整数天数
    days = int(years * 365)

start_date = end_date - timedelta(days=days)
```

### 4. 日志显示优化

**显示格式**：
- 如果 `years >= 1`：显示为 "X年" 或 "X.X年"
- 如果 `years >= 1/12`：显示为 "X个月" 或 "X.X个月"
- 如果 `years >= 1/52`：显示为 "X周" 或 "X.X周"
- 否则：显示为 "X天"

**示例**：
```
开始采集 000001 近30天（30天）的历史数据（批量模式: True）...
开始采集 000001 近3个月（91天）的历史数据（批量模式: True）...
开始采集 000001 近4周（28天）的历史数据（批量模式: True）...
开始采集 000001 近1年（365天）的历史数据（批量模式: True）...
```

### 5. 美股时间单位转换

**美股API支持的时间单位**：`1d`, `5d`, `1mo`, `3mo`, `6mo`, `1y`, `2y`, `5y`, `10y`, `ytd`, `max`

**转换逻辑**：
```python
if years >= 10:
    period = '10y'
elif years >= 5:
    period = '5y'
elif years >= 2:
    period = '2y'
elif years >= 1:
    period = '1y'
elif years >= 0.5:  # 6个月
    period = '6mo'
elif years >= 0.25:  # 3个月
    period = '3mo'
elif years >= 1/12:  # 1个月
    period = '1mo'
elif years >= 5/365:  # 5天
    period = '5d'
else:
    period = '1d'
```
