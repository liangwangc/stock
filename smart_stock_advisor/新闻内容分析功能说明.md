# 新闻内容分析功能说明

**日期**：2026-01-16  
**功能**：分析新闻的发布时间和真实性，避免误导股票预测

---

## 一、功能概述

新增了新闻内容分析功能，在新闻获取后自动进行以下分析：

1. **发布时间分析**：
   - 解析和验证发布时间
   - 判断时间质量（good/normal/suspicious/invalid）
   - 检测时间异常（未来时间、过旧时间等）

2. **真实性验证**：
   - 检测可疑关键词（如"内幕消息"、"保证收益"等）
   - 验证来源可信度（官方、权威媒体 vs 不可靠来源）
   - 评估内容质量（标题长度、内容长度等）

3. **可靠性评估**：
   - 综合发布时间和真实性分析，计算可靠性得分（0-1）
   - 判断是否应该用于股票预测
   - 生成警告信息

## 二、数据库字段

### 2.1 新增字段

执行SQL脚本添加新字段：
```bash
py scripts/execute_sql_script.py database/add_news_analysis_fields.sql
```

**新增字段**：
- `reliability_score` - 可靠性得分（0-1）
- `is_reliable` - 是否可靠（1=可靠，0=不可靠）
- `should_use_for_prediction` - 是否应该用于预测（1=是，0=否）
- `time_quality` - 时间质量（good/normal/suspicious/invalid）
- `time_analysis_result` - 发布时间分析结果（JSON）
- `credibility_score` - 可信度得分（0-1）
- `credibility_analysis_result` - 真实性分析结果（JSON）
- `analysis_warnings` - 分析警告信息（JSON数组）

## 三、功能实现

### 3.1 发布时间分析

**分析内容**：
- 解析多种时间格式（标准格式、相对时间等）
- 验证时间有效性（不能是未来时间）
- 判断时间质量：
  - `good`：24小时内，时间较新
  - `normal`：1-7天内，时间正常
  - `suspicious`：7-30天前或未来时间，时间可疑
  - `invalid`：无法解析或明显异常

**示例**：
```python
{
    'publish_time': datetime(2026, 1, 16, 10, 30),
    'is_valid': True,
    'time_quality': 'good',
    'reason': '发布时间较新（2.5小时前）',
    'time_delta': 2.5
}
```

### 3.2 真实性验证

**检测项目**：

1. **可疑关键词检测**：
   - "内幕消息"、"绝密"、"独家爆料"
   - "保证收益"、"稳赚不赔"、"100%"
   - "加微信"、"加QQ"、"联系QQ"
   - "投资群"、"股票群"、"VIP群"
   - "代操盘"、"代操作"、"分成"
   - 等等

2. **来源可信度**：
   - **可信来源**：上交所、深交所、证监会、新华社、人民日报、证券时报等
   - **不可信来源**：个人、网友、爆料、传闻、传言等

3. **内容质量**：
   - 标题长度（<10字符扣分）
   - 内容长度（<50字符扣分）

**可信度得分计算**：
- 基础分：1.0
- 每个可疑关键词：-0.1
- 不可信来源：-0.3
- 可信来源：+0.2
- 内容过短：-0.2
- 最终得分：0-1之间

### 3.3 可靠性评估

**综合得分计算**：
- 时间质量权重：50%
- 可信度权重：50%
- 最终得分：0-1之间

**判断标准**：
- `reliability_score >= 0.6`：可靠，可以用于预测
- `reliability_score < 0.6`：不可靠，不建议用于预测

## 四、使用方式

### 4.1 自动分析

新闻抓取时会自动进行内容分析，无需手动调用。

### 4.2 手动分析

```python
from utils.news_content_analyzer import NewsContentAnalyzer

analyzer = NewsContentAnalyzer()

# 分析新闻
news = {
    'title': '某股票大涨',
    'content': '...',
    'source': '证券时报',
    'publish_time': '2026-01-16 10:30:00'
}

result = analyzer.analyze_news(news)
print(f"可靠性得分: {result['reliability_score']}")
print(f"是否可靠: {result['is_reliable']}")
print(f"警告: {result['warnings']}")

# 判断是否应该用于预测
should_use, reason = analyzer.should_use_for_prediction(news, result)
print(f"是否用于预测: {should_use}, 原因: {reason}")
```

### 4.3 查询分析结果

```sql
-- 查询不可靠的新闻
SELECT id, title, reliability_score, is_reliable, should_use_for_prediction
FROM news_articles
WHERE is_reliable = 0 OR should_use_for_prediction = 0;

-- 查询时间质量可疑的新闻
SELECT id, title, time_quality, reliability_score
FROM news_articles
WHERE time_quality = 'suspicious' OR time_quality = 'invalid';

-- 查询可靠性得分较低的新闻
SELECT id, title, reliability_score, credibility_score
FROM news_articles
WHERE reliability_score < 0.6
ORDER BY reliability_score ASC;
```

## 五、应用场景

### 5.1 股票预测过滤

在股票预测时，只使用可靠性高的新闻：
```python
# 查询可靠的新闻
sql = """
    SELECT * FROM news_articles
    WHERE symbol = %s
      AND should_use_for_prediction = 1
      AND reliability_score >= 0.6
      AND publish_time >= DATE_SUB(NOW(), INTERVAL 7 DAY)
    ORDER BY publish_time DESC
"""
```

### 5.2 新闻质量监控

定期检查新闻质量，识别可疑新闻：
```python
# 统计不可靠新闻数量
sql = """
    SELECT 
        COUNT(*) as total,
        SUM(CASE WHEN is_reliable = 0 THEN 1 ELSE 0 END) as unreliable_count,
        AVG(reliability_score) as avg_score
    FROM news_articles
    WHERE created_at >= DATE_SUB(NOW(), INTERVAL 1 DAY)
"""
```

### 5.3 来源质量评估

评估各新闻源的质量：
```sql
SELECT 
    source,
    COUNT(*) as total,
    AVG(reliability_score) as avg_reliability,
    SUM(CASE WHEN is_reliable = 0 THEN 1 ELSE 0 END) as unreliable_count
FROM news_articles
GROUP BY source
ORDER BY avg_reliability DESC;
```

## 六、注意事项

1. **字段不存在时**：如果数据库字段不存在，分析结果不会保存，但不会影响新闻保存功能

2. **分析失败时**：如果分析过程出错，新闻仍会保存，但标记为默认可靠性（0.5分，可靠）

3. **性能影响**：内容分析会增加少量处理时间（每条新闻约10-50ms），但可以显著提高预测质量

4. **阈值调整**：可以根据实际需求调整可靠性阈值（默认0.6）
