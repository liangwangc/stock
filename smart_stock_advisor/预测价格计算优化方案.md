## 一、当前问题分析

### 1.1 当前计算逻辑

```python
# 当前代码（stock_predictor.py 第3219-3225行）
probability_diff = up_probability - down_probability  # -1 到 1
max_change_pct = 10.0  # 固定最大涨跌幅 10%
predicted_change_pct = np.tanh(probability_diff * 3) * max_change_pct * confidence
predicted_close_price = current_price * (1 + predicted_change_pct / 100.0)
```

### 1.2 存在的问题

1. **固定最大涨跌幅10%**
   - ❌ 所有股票都使用10%，不符合实际情况
   - ST股票：5%
   - 创业板：20%
   - 主板：10%

2. **固定tanh系数3**
   - ❌ 不考虑股票的历史波动率
   - 高波动股票应该使用更大的系数
   - 低波动股票应该使用更小的系数

3. **没有考虑价格趋势**
   - ❌ 只基于当前价格，没有考虑短期、中期趋势
   - 上涨趋势中，预测价格应该更乐观
   - 下跌趋势中，预测价格应该更保守

4. **没有考虑支撑阻力位**
   - ❌ 没有识别关键支撑位和阻力位
   - 预测价格接近阻力位时，应该更保守
   - 预测价格接近支撑位时，可能有反弹

## 二、优化方案

### 2.1 根据股票特性调整最大涨跌幅

**实现逻辑**：
```python
def get_max_change_pct(symbol: str, stock_name: str = None) -> float:
    """
    根据股票特性获取最大涨跌幅
    
    Args:
        symbol: 股票代码
        stock_name: 股票名称（可选）
    
    Returns:
        最大涨跌幅（百分比）
    """
    # ST股票：5%
    if stock_name and ('ST' in stock_name or '*ST' in stock_name):
        return 5.0
    
    # 创业板：300开头，20%
    if symbol.startswith('300'):
        return 20.0
    
    # 科创板：688开头，20%
    if symbol.startswith('688'):
        return 20.0
    
    # 主板：600/000/001开头，10%
    if symbol.startswith(('600', '000', '001')):
        return 10.0
    
    # 默认：10%
    return 10.0
```

### 2.2 根据历史波动率调整tanh系数

**实现逻辑**：
```python
def calculate_volatility_adjusted_coefficient(
    data: pd.DataFrame, 
    period: int = 20
) -> float:
    """
    根据历史波动率计算调整后的tanh系数
    
    Args:
        data: 股票历史数据（包含close_price或change_pct）
        period: 计算波动率的周期（默认20天）
    
    Returns:
        调整后的系数（范围：1.5-4.5）
    """
    if data.empty or len(data) < period:
        return 3.0  # 默认系数
    
    # 计算日收益率
    if 'change_pct' in data.columns:
        returns = data['change_pct'].tail(period).values / 100.0
    else:
        prices = data['close'].tail(period + 1).values
        returns = np.diff(prices) / prices[:-1]
    
    # 计算波动率（标准差）
    volatility = np.std(returns)
    
    # 基准波动率（A股平均日波动率约2%）
    base_volatility = 0.02
    
    # 调整系数：波动率越高，系数越大
    # 系数范围：1.5（低波动）到 4.5（高波动）
    if volatility > 0:
        coefficient = 1.5 + (volatility / base_volatility) * 1.0
        coefficient = max(1.5, min(4.5, coefficient))
    else:
        coefficient = 3.0
    
    return coefficient
```

### 2.3 考虑价格趋势

**实现逻辑**：
```python
def calculate_trend_adjustment(
    data: pd.DataFrame,
    short_period: int = 5,
    medium_period: int = 20
) -> float:
    """
    计算价格趋势调整因子
    
    Args:
        data: 股票历史数据
        short_period: 短期周期（默认5天）
        medium_period: 中期周期（默认20天）
    
    Returns:
        趋势调整因子（范围：0.9-1.1）
        - >1.0：上涨趋势，预测更乐观
        - <1.0：下跌趋势，预测更保守
    """
    if data.empty or len(data) < medium_period:
        return 1.0  # 无调整
    
    prices = data['close'].tail(medium_period + 1).values
    
    # 计算短期趋势（最近5天）
    short_trend = (prices[-1] - prices[-short_period]) / prices[-short_period]
    
    # 计算中期趋势（最近20天）
    medium_trend = (prices[-1] - prices[-medium_period]) / prices[-medium_period]
    
    # 综合趋势（短期权重60%，中期权重40%）
    combined_trend = short_trend * 0.6 + medium_trend * 0.4
    
    # 转换为调整因子（趋势每1%对应0.01的调整）
    # 上涨趋势：调整因子 > 1.0（更乐观）
    # 下跌趋势：调整因子 < 1.0（更保守）
    adjustment = 1.0 + combined_trend * 0.5
    
    # 限制范围：0.9-1.1
    adjustment = max(0.9, min(1.1, adjustment))
    
    return adjustment
```

### 2.4 综合优化后的计算逻辑

```python
def calculate_predicted_price_optimized(
    symbol: str,
    stock_name: str,
    current_price: float,
    up_probability: float,
    down_probability: float,
    confidence: float,
    data: pd.DataFrame
) -> Dict[str, float]:
    """
    优化后的预测价格计算
    
    Returns:
        {
            'predicted_change_pct': 预测涨跌幅,
            'predicted_close_price': 预测收盘价,
            'max_change_pct': 使用的最大涨跌幅,
            'volatility_coefficient': 使用的波动率系数,
            'trend_adjustment': 趋势调整因子
        }
    """
    # 1. 获取股票特性相关的最大涨跌幅
    max_change_pct = get_max_change_pct(symbol, stock_name)
    
    # 2. 计算历史波动率调整系数
    volatility_coefficient = calculate_volatility_adjusted_coefficient(data)
    
    # 3. 计算价格趋势调整因子
    trend_adjustment = calculate_trend_adjustment(data)
    
    # 4. 计算概率差异
    probability_diff = up_probability - down_probability
    
    # 5. 使用调整后的系数计算涨跌幅
    predicted_change_pct = (
        np.tanh(probability_diff * volatility_coefficient) * 
        max_change_pct * 
        confidence * 
        trend_adjustment
    )
    
    # 6. 计算预测收盘价
    predicted_close_price = current_price * (1 + predicted_change_pct / 100.0)
    
    return {
        'predicted_change_pct': predicted_change_pct,
        'predicted_close_price': predicted_close_price,
        'max_change_pct': max_change_pct,
        'volatility_coefficient': volatility_coefficient,
        'trend_adjustment': trend_adjustment
    }
```
