# 新功能说明

**位置：** `index.html` 登录页面

**功能：**
- ✅ 账号+密码登录（不再是简单的用户名登录）
- ✅ 密码验证
- ✅ 登录错误提示
- ✅ 默认管理员账号提示

**默认管理员账号：**

- 密码：`admin123`

### 2. 后端管理页面

**位置：** `admin.html`

**功能：**
- ✅ 账户管理（添加/修改/删除账户）
- ✅ 登录日志查看
- ✅ 权限控制（仅管理员可访问）

**访问方式：**
1. 使用管理员账号登录
2. 点击右下角的"⚙️ 管理"按钮
3. 或直接访问：`http://localhost:8000/admin.html`

### 3. 账户管理功能

**功能列表：**
- ✅ 查看所有用户列表
- ✅ 添加新用户（设置用户名、密码、角色、每日目标）
- ✅ 编辑用户信息（可修改密码、角色、状态等）
- ✅ 删除用户（不能删除自己）
- ✅ 用户状态管理（激活/禁用）

**用户角色：**
- `admin` - 管理员（可访问后台管理）
- `user` - 普通用户（只能使用学习功能）

### 4. 登录日志管理

**功能：**
- ✅ 查看所有登录记录
- ✅ 显示登录时间、IP地址、登录状态
- ✅ 显示登录失败原因
- ✅ 分页显示（每页50条）

**日志信息包括：**
- 用户名
- 登录时间
- IP地址
- 登录状态（成功/失败）
- 失败原因（如果失败）

## 📋 使用步骤

### 第一步：升级数据库

**重要：** 首次使用新功能前，必须执行数据库升级脚本！

```bash
# 方法1：使用MySQL命令行
mysql -u root -p word_app < database_upgrade.sql

# 方法2：使用phpMyAdmin
# 1. 打开 phpMyAdmin
# 2. 选择 word_app 数据库
# 3. 点击"导入"
# 4. 选择 database_upgrade.sql 文件
# 5. 点击"执行"
```

**升级脚本会：**
- ✅ 添加密码字段到users表
- ✅ 添加角色字段（admin/user）
- ✅ 创建登录日志表
- ✅ 创建默认管理员账户（admin/admin123）

### 第二步：登录系统

1. 打开 `index.html`
2. 输入账号和密码
3. 默认管理员：`admin` / `admin123`

### 第三步：访问后台管理

**方法1：** 管理员登录后，点击右下角"⚙️ 管理"按钮

**方法2：** 直接访问 `admin.html`

### 第四步：管理账户

1. **添加用户：**
   - 点击"账户管理"标签
   - 点击"+ 添加用户"按钮
   - 填写用户信息
   - 点击"保存"

2. **编辑用户：**
   - 在用户列表中点击"编辑"按钮
   - 修改信息（密码留空则不修改）
   - 点击"保存"

3. **删除用户：**
   - 在用户列表中点击"删除"按钮
   - 确认删除
   - 注意：不能删除自己的账户

### 第五步：查看登录日志

1. 点击"登录日志"标签
2. 查看所有登录记录
3. 使用分页按钮浏览更多记录

## 🐛 常见问题

### Q: 登录时提示"用户不存在"？
A: 确保已执行数据库升级脚本，并创建了默认管理员账户。

### Q: 无法访问管理页面？
A: 确保使用管理员账号登录，普通用户无法访问。

### Q: 忘记管理员密码？
A: 可以手动重置：
```sql
UPDATE users SET password = MD5('新密码') WHERE username = 'admin';
```

### Q: 如何修改默认管理员密码？
A: 登录后，在管理页面编辑自己的账户信息，修改密码。
