# 单词库例句格式说明

## 📋 例句格式要求

### 格式标准
- **格式**：`英文例句。中文翻译`
- **分隔符**：使用中文句号（。）分隔，不使用换行符
- **示例**：
  ```
  Hello, how are you?。你好，你好吗？
  ```

### 格式要求
1. ✅ **必须包含英文和中文**
2. ✅ **使用句号（。）分隔**
3. ✅ **英文在前，中文在后**

## 🔧 改进内容

### 1. 翻译功能增强
- 使用多个翻译API（MyMemory、Google Translate、LibreTranslate）
- 如果第一次翻译失败，自动重试一次
- 确保所有英文例句都有对应的中文翻译

### 2. 格式统一
- 所有例句统一为：`英文。中文` 格式
- 自动将换行符（\n）替换为句号（。）
- 自动检测并修复格式不正确的例句

### 3. 更新脚本改进
- `update_word_bank_examples.php` - 更新现有单词的例句
- `import_all_grades.php` - 导入新单词时确保格式正确
- `import_word_bank.php` - 导入新单词时确保格式正确

## 🚀 使用方法

### 更新现有单词的例句

```bash
# 运行更新脚本
D:\xampp\php\php.exe update_word_bank_examples.php

# 或使用批处理文件
双击运行：更新单词库例句.bat
```

### 选择更新模式
- **模式1**：只更新缺少例句的单词
- **模式2**（推荐）：更新所有需要完善的单词（缺少例句或例句不完整）
- **模式3**：强制更新所有单词

## 📊 改进效果

- ✅ 所有单词都有完整的例句（英文+中文）
- ✅ 例句格式统一：`英文。中文`
- ✅ 自动翻译功能确保英文例句都有中文翻译
- ✅ 翻译失败时自动重试，提高成功率

## ⚠️ 注意事项

1. **翻译API限制**：
   - MyMemory API：免费，但可能有请求频率限制
   - Google Translate：免费，但可能不稳定
   - 如果翻译失败，会重试一次

2. **更新耗时**：
   - 每个单词需要调用API，约0.2-0.5秒
   - 如果单词很多，更新可能需要一些时间

3. **格式检查**：
   - 更新脚本会自动检查并修复格式
   - 确保所有例句都是 `英文。中文` 格式
