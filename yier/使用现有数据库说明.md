# 使用现有数据库说明

## ✅ 可以使用本地现有数据库

项目可以连接到您本地已有的 MySQL 数据库，只需要修改配置即可。

## 🔧 修改数据库配置

### 方法1：直接编辑 api.php（推荐）

打开 `api.php` 文件，找到第17-21行：

```php
// --- 2. 数据库配置 ---
$db_host = 'localhost';
$db_user = 'root';
$db_pass = 'root'; // 你的数据库密码
$db_name = 'word_app'; // 你的数据库名
```

**修改为您的数据库信息：**

```php
$db_host = 'localhost';           // 数据库主机（通常是localhost）
$db_user = '你的用户名';          // 数据库用户名
$db_pass = '你的密码';            // 数据库密码
$db_name = '你的数据库名';        // 数据库名称
```

### 方法2：使用配置脚本

双击运行：
```
配置数据库.bat
```

选择选项1，输入您的数据库信息。

## 📋 数据库要求

### 必需的表结构

您的数据库需要包含以下表：

#### 1. users 表（用户表）

```sql
CREATE TABLE users (
    id INT NOT NULL AUTO_INCREMENT,
    username VARCHAR(50) NOT NULL,
    daily_goal INT DEFAULT 5,
    created_at TIMESTAMP NULL DEFAULT CURRENT_TIMESTAMP,
    password VARCHAR(255) DEFAULT NULL,
    role ENUM('user','admin') DEFAULT 'user',
    created_by INT DEFAULT NULL,
    is_active TINYINT(1) DEFAULT 1,
    last_login DATETIME DEFAULT NULL,
    PRIMARY KEY (id),
    UNIQUE KEY username (username)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

#### 2. words 表（单词表）

```sql
CREATE TABLE words (
    id INT NOT NULL AUTO_INCREMENT,
    user_id INT NOT NULL,
    word VARCHAR(100) NOT NULL,
    pronunciation VARCHAR(100) DEFAULT '',
    meaning TEXT,
    example TEXT,
    date_added DATE NOT NULL,
    next_review DATE NOT NULL,
    interval_days INT DEFAULT 0,
    ef_factor FLOAT DEFAULT 2.5,
    repetitions INT DEFAULT 0,
    status ENUM('new','learning','review','mastered') DEFAULT 'new',
    PRIMARY KEY (id),
    KEY user_id (user_id),
    CONSTRAINT words_ibfk_1 FOREIGN KEY (user_id) REFERENCES users (id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

#### 3. login_logs 表（登录日志表，可选）

```sql
CREATE TABLE login_logs (
    id INT NOT NULL AUTO_INCREMENT,
    user_id INT NOT NULL,
    username VARCHAR(50) NOT NULL,
    login_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    ip_address VARCHAR(45) DEFAULT NULL,
    user_agent TEXT,
    login_status ENUM('success','failed') DEFAULT 'success',
    fail_reason VARCHAR(255) DEFAULT NULL,
    PRIMARY KEY (id),
    KEY idx_user_id (user_id),
    KEY idx_login_time (login_time),
    KEY idx_username (username),
    CONSTRAINT fk_login_logs_user FOREIGN KEY (user_id) REFERENCES users (id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

## 🚀 快速设置步骤

### 如果数据库已存在但没有表结构：

1. **修改 api.php 配置**
   - 修改数据库名、用户名、密码

2. **导入表结构**
   ```bash
   mysql -u 你的用户名 -p 你的数据库名 < word_app_backup_20260129.sql
   ```

3. **升级数据库（添加新功能）**
   ```bash
   mysql -u 你的用户名 -p 你的数据库名 < database_upgrade.sql
   ```

### 如果数据库已存在且有表结构：

1. **修改 api.php 配置**
   - 只需修改数据库名、用户名、密码

2. **检查表结构**
   - 确保有 `users` 和 `words` 表
   - 如果没有 `login_logs` 表，执行升级脚本

3. **创建默认管理员**
   ```sql
   INSERT INTO users (username, password, role, daily_goal) 
   VALUES ('admin', MD5('admin123'), 'admin', 5)
   ON DUPLICATE KEY UPDATE password = MD5('admin123'), role = 'admin';
   ```

## 💡 常见场景

### 场景1：使用 XAMPP 的 MySQL，但数据库名不同

**修改 api.php：**
```php
$db_name = '你的数据库名';
```

**然后创建表结构：**
- 使用 phpMyAdmin 导入 `word_app_backup_20260129.sql`
- 导入 `database_upgrade.sql`

### 场景2：使用远程数据库

**修改 api.php：**
```php
$db_host = '192.168.1.100';  // 数据库服务器IP
$db_user = '远程用户名';
$db_pass = '远程密码';
$db_name = '数据库名';
```

### 场景3：数据库密码不是 root

**修改 api.php：**
```php
$db_pass = '你的实际密码';
```

## ⚠️ 注意事项

1. **字符集**
   - 确保数据库使用 `utf8mb4` 字符集
   - 确保表使用 `utf8mb4_unicode_ci` 排序规则

2. **权限**
   - 确保数据库用户有创建表、插入、更新、删除的权限

3. **表结构**
   - 如果表已存在但结构不同，可能需要调整
   - 建议先备份现有数据

4. **默认管理员**
   - 如果使用现有数据库，需要手动创建管理员账户
   - 或执行升级脚本会自动创建
