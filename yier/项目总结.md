# 付一二（MemoCalendar）项目总结

## 📋 项目概述

**项目名称：** 付一二（MemoCalendar）  
**项目类型：** 基于艾宾浩斯遗忘曲线的单词记忆网站  
**开发语言：** PHP + MySQL + JavaScript  
**项目位置：** `d:\wjw_work\yier\`

## 🎯 项目功能

### 核心功能
1. **用户系统**
   - 用户登录/自动注册
   - 每日学习目标设置
   - 用户数据隔离

2. **单词管理**
   - ✨ 单词录入（支持有道词典自动查询）
   - 📅 日历打卡显示
   - 📝 补录/预约录入功能
   - 📊 每日学习统计

3. **学习系统**
   - 🎴 卡片式学习界面
   - 🧠 基于艾宾浩斯遗忘曲线的智能复习算法
   - ⭐ 复习质量评分（1-5分）
   - 🔊 语音朗读功能

4. **统计功能**
   - 📈 记忆熟练度分布图表（困难/良好/大师）
   - 📉 未来7天复习压力预测
   - 💾 数据导出（CSV格式）

5. **其他功能**
   - 🌙 深色模式切换
   - 📱 响应式设计，支持移动端
   - ⏰ 时区设置（北京时间）

## 🗄️ 数据库结构

### 数据库名：`word_app`

### 表1：users（用户表）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT | 主键，自增 |
| username | VARCHAR(50) | 用户名（唯一） |
| daily_goal | INT | 每日目标（默认5） |
| created_at | TIMESTAMP | 创建时间 |

### 表2：words（单词表）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT | 主键，自增 |
| user_id | INT | 用户ID（外键） |
| word | VARCHAR(100) | 单词 |
| pronunciation | VARCHAR(100) | 音标 |
| meaning | TEXT | 中文释义 |
| example | TEXT | 例句 |
| date_added | DATE | 添加日期 |
| next_review | DATE | 下次复习日期 |
| interval_days | INT | 复习间隔天数 |
| ef_factor | FLOAT | 易度因子（默认2.5） |
| repetitions | INT | 复习次数 |
| status | ENUM | 状态：new/learning/review/mastered |

## 📊 API接口列表

### 用户相关
- `POST api.php?action=login` - 用户登录/注册
- `POST api.php?action=update_settings` - 更新用户设置

### 单词相关
- `POST api.php?action=add_word` - 添加单词
- `GET api.php?action=calendar_data&uid={id}&month={YYYY-MM}` - 获取日历数据
- `GET api.php?action=day_details&uid={id}&date={YYYY-MM-DD}` - 获取某日详情
- `GET api.php?action=get_home_data&uid={id}&limit={n}` - 获取首页数据

### 学习相关
- `POST api.php?action=submit_review` - 提交复习结果
- `GET api.php?action=get_stats&uid={id}` - 获取统计数据

### 工具相关
- `GET api.php?action=lookup&word={word}` - 查词代理（有道词典）
- `GET api.php?action=export_csv&uid={id}` - 导出CSV
