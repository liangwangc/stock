# PK排行榜功能使用说明

## 1. 数据库表创建

在开始使用PK功能之前，需要先创建相关的数据库表。

### 方法一：使用SQL脚本（推荐）

执行以下SQL脚本创建表：

```bash
# Windows PowerShell
D:\xampp\mysql\bin\mysql.exe -u root -proot -P 3307 word_app < create_pk_tables.sql

# 或者直接在MySQL客户端执行
mysql -u root -proot -P 3307 word_app < create_pk_tables.sql
```

### 方法二：手动执行SQL

打开MySQL客户端，连接到数据库 `word_app`，然后执行 `create_pk_tables.sql` 文件中的SQL语句。

## 2. 功能说明

### 2.1 排行榜周期

- **今日**：显示今天的学习排名
- **本周**：显示本周（周一到今天）的学习排名
- **本月**：显示本月（1号到今天）的学习排名
- **本年**：显示本年（1月1日到今天）的学习排名

### 2.2 排名规则

排名按照以下优先级排序：
1. 学习单词总数（total_words）
2. 已掌握单词数（mastered_words）
3. 连续打卡天数（streak_days）
4. 学习天数（study_days）

### 2.3 排名变化标识

- 📈 **上升**：排名比前一天上升
- 📉 **下降**：排名比前一天下降
- ➡️ **不变**：排名与前一天相同
- ✨ **新上榜**：首次出现在排行榜中

### 2.4 前三名特殊标识

- 🥇 **第一名**：金色渐变背景
- 🥈 **第二名**：银色渐变背景
- 🥉 **第三名**：铜色渐变背景

## 3. 使用方式

1. 登录系统后，点击底部导航栏的 **"PK"** 按钮
2. 选择要查看的排行榜周期（今日/本周/本月/本年）
3. 查看排行榜列表，了解自己和其他用户的学习情况

## 4. 注意事项

- 排行榜数据会实时计算，首次查看可能需要几秒钟加载
- 排名变化需要至少两天的数据才能显示
- 只有在该周期内有学习记录的用户才会出现在排行榜中

## 5. 技术说明

### 5.1 数据库表结构

- **user_rankings**：用户排名快照表（可选，用于缓存排名数据）
- **user_ranking_history**：用户排名历史表（用于计算排名变化）

### 5.2 API接口

- **接口**：`api.php?action=get_rankings`
- **参数**：
  - `uid`：当前用户ID
  - `period`：排名周期（day/week/month/year）
  - `date`：排名日期（可选，默认今天）

### 5.3 数据更新

排行榜数据会在每次查看时实时计算，确保数据的准确性。排名历史会自动保存到 `user_ranking_history` 表中，用于计算排名变化。
