# 项目配置指南

## 快速开始

### 步骤 1: 检查环境

运行环境检查脚本：
```bash
check_environment.bat
```

或者手动检查：
- ✅ PHP 7.4+ 
- ✅ MySQL 5.7+ / MariaDB 10.3+
- ✅ Web服务器（可选，可用PHP内置服务器）

### 步骤 2: 启动 MySQL 服务

#### Windows

**方法一：使用服务管理器**
1. 按 `Win + R`，输入 `services.msc`
2. 找到 MySQL 服务，右键选择"启动"

**方法二：使用命令行**
```bash
# 启动 MySQL 服务
net start MySQL

# 或者（如果服务名不同）
net start MySQL80
net start MySQL57
```

**方法三：使用 XAMPP/WAMP**
- XAMPP: 启动 XAMPP Control Panel，点击 MySQL 的 Start 按钮
- WAMP: 点击系统托盘图标，选择 MySQL → Service → Start/Resume Service

#### Linux

```bash
# Ubuntu/Debian
sudo systemctl start mysql
# 或
sudo service mysql start

# CentOS/RHEL
sudo systemctl start mysqld
```

### 步骤 3: 导入数据库

#### 方法一：使用命令行（推荐）

```bash
# Windows
mysql -u root -p < word_app_backup_20260129.sql

# Linux
mysql -u root -p < word_app_backup_20260129.sql
```

输入密码后，数据库会自动创建并导入数据。

#### 方法二：使用 MySQL Workbench

1. 打开 MySQL Workbench
2. 连接到本地 MySQL 服务器
3. 选择 `Server` → `Data Import`
4. 选择 `Import from Self-Contained File`
5. 选择 `word_app_backup_20260129.sql`
6. 在 `Default Target Schema` 中选择或创建 `word_app`
7. 点击 `Start Import`

#### 方法三：使用 phpMyAdmin

1. 打开 phpMyAdmin（通常在 http://localhost/phpmyadmin）
2. 创建新数据库 `word_app`（字符集选择 `utf8mb4_unicode_ci`）
3. 选择该数据库
4. 点击"导入"标签
5. 选择 `word_app_backup_20260129.sql` 文件
6. 点击"执行"

### 步骤 4: 配置数据库连接

编辑 `api.php` 文件，找到以下代码（约第17-21行）：

```php
$db_host = 'localhost';      // 数据库主机
$db_user = 'root';           // 数据库用户名
$db_pass = 'root';           // 数据库密码（修改为你的密码）
$db_name = 'word_app';       // 数据库名
```

**重要：** 将 `$db_pass = 'root';` 修改为你的实际 MySQL root 密码。

### 步骤 5: 测试数据库连接

#### 方法一：使用 Python 脚本（推荐）

```bash
# 1. 安装 pymysql（如果未安装）
pip install pymysql

# 2. 运行测试
python test_db_connection.py
```

#### 方法二：使用 PHP 测试脚本

**使用 PHP 内置服务器：**
```bash
# 启动服务器
php -S localhost:8000

# 在浏览器访问
http://localhost:8000/test_db.php
```

**使用 Apache/Nginx：**
- 将项目文件复制到 Web 服务器目录
- 在浏览器访问：`http://localhost/yier/test_db.php`

#### 方法三：使用 MySQL 命令行

```bash
mysql -u root -p
```

然后执行：
```sql
USE word_app;
SHOW TABLES;
SELECT COUNT(*) FROM users;
SELECT COUNT(*) FROM words;
```

### 步骤 6: 启动 Web 服务器

#### 方法一：PHP 内置服务器（开发环境，推荐）

打开浏览器，访问：
- PHP内置服务器: `http://localhost:8000`

- 或根据你的配置访问

## 常见问题排查

### 问题 1: 数据库连接失败

**错误信息：** `Database Connection Failed`

**解决方法：**

1. **检查 MySQL 服务是否运行**
   ```bash
   # Windows
   net start MySQL
   
   # Linux
   sudo systemctl status mysql
   ```

2. **检查用户名密码**
   - 确认 `api.php` 中的用户名和密码正确
   - 测试连接：
     ```bash
     mysql -u root -p
     ```

3. **检查数据库是否存在**
   ```sql
   SHOW DATABASES;
   ```
   如果没有 `word_app`，需要导入数据库

4. **检查用户权限**
   ```sql
   GRANT ALL PRIVILEGES ON word_app.* TO 'root'@'localhost';
   FLUSH PRIVILEGES;
   ```

### 问题 2: PHP 无法连接数据库

**错误信息：** `Call to undefined function mysqli_connect()`

**解决方法：**

1. **检查 PHP mysqli 扩展**
   ```bash
   php -m | grep mysqli
   ```

2. **启用 mysqli 扩展**
   - 编辑 `php.ini`
   - 找到并取消注释：`extension=mysqli`
   - 重启 Web 服务器

3. **Windows 用户（XAMPP）**
   - 编辑 `C:\xampp\php\php.ini`
   - 取消注释：`extension=mysqli`
   - 重启 Apache

### 问题 3: 时区问题

**现象：** 日期显示不正确

**解决方法：**

项目已设置时区为 `Asia/Shanghai`，如果仍有问题：

1. **检查 PHP 时区**
   ```php
   // 在 php.ini 中设置
   date.timezone = Asia/Shanghai
   ```

2. **检查 MySQL 时区**
   ```sql
   SET time_zone = '+08:00';
   ```

### 问题 4: 跨域问题

**现象：** 前端无法访问 API

**解决方法：**

项目已设置 CORS 头，如果仍有问题：

1. **检查 api.php 中的 CORS 设置**
   ```php
   header("Access-Control-Allow-Origin: *");
   ```

2. **开发环境可以使用浏览器插件禁用 CORS**

### 问题 5: 文件权限问题（Linux）

**解决方法：**
```bash
# 设置文件权限
chmod 644 api.php index.html
chmod 755 .
```
