========================================
快速配置数据库 - 使用本地现有数据库
========================================

【方法1】使用配置脚本（推荐）
----------------------------------------
双击运行: 修改数据库配置.bat

按提示输入：
  - 数据库主机（默认: localhost）
  - 数据库用户名（默认: root）
  - 数据库密码（如果为空直接回车）
  - 数据库名称（必填）

脚本会自动修改 api.php 文件

【方法2】手动修改（简单直接）
----------------------------------------
1. 打开 api.php 文件
2. 找到第17-21行：

   $db_host = 'localhost';
   $db_user = 'root';
   $db_pass = 'root';
   $db_name = 'word_app';

3. 修改为您的数据库信息：

   $db_host = 'localhost';        // 通常是localhost
   $db_user = '您的用户名';        // 修改这里
   $db_pass = '您的密码';          // 修改这里
   $db_name = '您的数据库名';      // 修改这里

4. 保存文件

【数据库要求】
----------------------------------------
您的数据库需要包含以下表：

必需的表：
  - users（用户表）
  - words（单词表）

可选的表：
  - login_logs（登录日志表）

【如果数据库中没有这些表】
----------------------------------------
需要导入表结构：

方法1: 使用命令行
  mysql -u 用户名 -p 数据库名 < word_app_backup_20260129.sql
  mysql -u 用户名 -p 数据库名 < database_upgrade.sql

方法2: 使用 phpMyAdmin
  1. 选择您的数据库
  2. 点击"导入"
  3. 先导入 word_app_backup_20260129.sql
  4. 再导入 database_upgrade.sql

【验证配置】
----------------------------------------
修改配置后：

1. 运行: 测试数据库连接.bat
   或
2. 访问项目，尝试登录

如果连接失败，会显示具体错误信息

【示例】
----------------------------------------
如果您的数据库信息是：
  - 数据库名: mydb
  - 用户名: root
  - 密码: 123456

则修改 api.php 为：
  $db_host = 'localhost';
  $db_user = 'root';
  $db_pass = '123456';
  $db_name = 'mydb';
