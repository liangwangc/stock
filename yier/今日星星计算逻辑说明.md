# 今日星星计算逻辑说明

## 一、当前逻辑（修复后）

### 1.1 计算公式

**今日获得的星星数 = 今天实际学习过的单词数**

具体计算：
```php
// 1. 统计今天新添加的单词数
$today_new_count = COUNT(*) FROM words WHERE user_id = ? AND date_added = ?

// 2. 统计今天复习的单词数（通过word_review_logs表）
$today_reviewed_count = COUNT(DISTINCT word_id) FROM word_review_logs 
    WHERE user_id = ? AND review_date = ?

// 3. 今日总学习数 = 新学单词数 + 复习单词数
$today_learned_count = $today_new_count + $today_reviewed_count;

// 4. 今日获得的星星 = 今日总学习数（每个单词1颗星）
$today_stars = $today_learned_count;
```

### 1.2 说明

- **每个单词1颗星**：无论是新学的单词还是复习的单词，每个单词都算1颗星
- **基于实际学习**：只统计今天实际学习过的单词，不包括：
  - 单词库导入但还没学习的单词
  - 今天应该学习但还没学习的单词

## 二、修复前的问题

### 2.1 错误的计算方式

**修复前**：
```php
$today_stars = count($list_reviews) + count($list_new);
```

**问题**：
- `$list_reviews` 和 `$list_new` 是"今天应该学习的单词队列"，不是"今天实际学习过的单词"
- 如果用户点击"开始学习"导入了10个单词，但只学习了3个，星星数会显示10（错误），而不是3（正确）

### 2.2 修复后的正确方式

**修复后**：
```php
$today_stars = $today_learned_count; // 使用实际学习的单词数
```

**效果**：
- 只统计今天实际学习过的单词
- 如果今天学习了3个新单词 + 9个复习单词 = 12个单词，星星数显示12（正确）

## 三、示例说明

### 示例1：新用户第一天学习

**场景**：
- 用户设置daily_goal=10
- 点击"开始学习"，单词库导入10个单词
- 实际学习了3个单词

**计算**：
- `today_new_count` = 10（今天添加了10个单词）
- `today_reviewed_count` = 0（没有复习）
- `today_learned_count` = 10 + 0 = 10
- `today_stars` = 10

**注意**：这里统计的是"添加的单词数"，因为新单词的`date_added`就是今天。但实际学习需要通过`word_review_logs`表来确认。

### 示例2：学习+复习

**场景**：
- 今天学习了3个新单词
- 今天复习了9个旧单词

**计算**：
- `today_new_count` = 3（今天新添加的单词）
- `today_reviewed_count` = 9（通过word_review_logs表统计今天复习的单词）
- `today_learned_count` = 3 + 9 = 12
- `today_stars` = 12

### 示例3：只复习，不学新单词

**场景**：
- 今天没有学习新单词
- 今天复习了5个旧单词

**计算**：
- `today_new_count` = 0
- `today_reviewed_count` = 5
- `today_learned_count` = 0 + 5 = 5
- `today_stars` = 5

## 四、数据来源

### 4.1 新学单词数（today_new_count）

**数据来源**：`words` 表的 `date_added` 字段
```sql
SELECT COUNT(*) as today_new 
FROM words 
WHERE user_id = ? AND date_added = ?
```

**说明**：
- 统计今天添加的所有单词（包括手动录入和单词库导入）
- 注意：这个统计的是"添加的单词"，不是"学习的单词"

### 4.2 复习单词数（today_reviewed_count）

**数据来源**：`word_review_logs` 表
```sql
SELECT COUNT(DISTINCT word_id) as today_reviewed 
FROM word_review_logs 
WHERE user_id = ? AND review_date = ?
```

**说明**：
- 统计今天实际复习过的不同单词数
- 使用`DISTINCT word_id`确保每个单词只统计一次（即使复习了多次）

## 五、潜在问题与优化建议

### 5.1 当前逻辑的问题

**问题**：`today_new_count`统计的是"添加的单词数"，不是"学习的单词数"

**示例**：
- 用户点击"开始学习"，单词库导入10个单词（`date_added`=今天）
- 但用户只学习了3个单词（在`word_review_logs`表中有记录）
- 当前逻辑：`today_stars = 10 + 0 = 10`（错误）
- 正确逻辑：应该只统计`word_review_logs`表中的记录

### 5.2 优化建议

**建议**：统一使用`word_review_logs`表统计实际学习过的单词

```php
// 统计今天实际学习过的单词（包括新学和复习）
$stmt = prepare_check($conn, "
    SELECT COUNT(DISTINCT word_id) as today_learned 
    FROM word_review_logs 
    WHERE user_id = ? AND review_date = ?
");
$stmt->bind_param("is", $uid, $today);
$stmt->execute();
$today_learned_result = $stmt->get_result()->fetch_assoc();
$today_learned_count = (int)($today_learned_result['today_learned'] ?? 0);

// 今日获得的星星 = 今天实际学习过的单词数
$today_stars = $today_learned_count;
```

**优点**：
- 只统计实际学习过的单词
- 不统计单词库导入但还没学习的单词
- 更准确地反映用户的学习情况
