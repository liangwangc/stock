========================================
新功能快速开始指南
========================================

【重要】首次使用前必须执行数据库升级！

步骤1: 升级数据库
----------------------------------------
方法1: MySQL命令行
  mysql -u root -p word_app < database_upgrade.sql

方法2: phpMyAdmin
  1. 打开 phpMyAdmin
  2. 选择 word_app 数据库
  3. 点击"导入"
  4. 选择 database_upgrade.sql
  5. 点击"执行"

步骤2: 登录系统
----------------------------------------
1. 打开 index.html
2. 输入账号: admin
3. 输入密码: admin123
4. 点击登录

步骤3: 访问后台管理
----------------------------------------
方法1: 点击右下角"⚙️ 管理"按钮
方法2: 直接访问 admin.html

步骤4: 管理账户
----------------------------------------
- 添加用户: 点击"+ 添加用户"
- 编辑用户: 点击用户列表中的"编辑"
- 删除用户: 点击用户列表中的"删除"
- 查看日志: 点击"登录日志"标签
