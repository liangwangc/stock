========================================
付一二项目 - 启动命令
========================================

方法1: 双击运行（最简单）
----------------------------------------
  启动.bat
  或
  简单启动.bat

方法2: 手动命令（如果已安装XAMPP）
----------------------------------------
  C:\xampp\php\php.exe -S localhost:8000

方法3: 如果PHP在系统PATH中
----------------------------------------
  php -S localhost:8000

方法4: 使用XAMPP Control Panel
----------------------------------------
  1. 打开 XAMPP Control Panel
  2. 启动 Apache 和 MySQL
  3. 将项目复制到: C:\xampp\htdocs\yier\
  4. 访问: http://localhost/yier/

========================================
常见问题
========================================

问题: "The system cannot find the path specified"
解决: 
  1. 检查 XAMPP 是否安装在 C:\xampp\
  2. 如果安装在其他位置，修改启动脚本中的路径
  3. 或使用 XAMPP Control Panel 方式

问题: 端口8000被占用
解决: 使用其他端口，例如:
  php -S localhost:8080

问题: PHP未安装
解决: 安装 XAMPP
  下载: https://www.apachefriends.org/
