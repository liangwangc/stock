# 家长听写问题解决方案

## 📋 一、问题1：重复学习不会新加入单词

### 1.1 当前逻辑

**代码位置：** `index.html` 第1530-1539行

**当前行为：**
- 如果今天已经学习过，使用今天学习过的单词进行重复学习
- **不会添加新单词**

**逻辑说明：**
```javascript
if (hasLearnedToday) {
    // 今天已经学习过，使用今天学习过的单词（重复学习，不添加新单词）
    this.queue = checkTodayData.queue || [];
    this.showToast('重复学习模式：只学习今天已学过的单词，不会记录学习状态', 'success');
}
```

### 1.2 问题分析

**这是设计逻辑，不是bug：**
- ✅ "重复学习"的字面意思就是重复学习今天已学过的单词
- ✅ 如果重复学习时添加新单词，就不是"重复学习"了

**用户可能的期望：**
- 可能希望重复学习时也能添加新单词？

### 1.3 解决方案

**方案1：保持当前逻辑（推荐）**
- ✅ 重复学习 = 只学习今天已学过的单词
- ✅ 符合"重复学习"的字面意思
- ✅ 如果需要学习新单词，应该点击"开始学习"按钮（第一次学习）

**方案2：修改为"继续学习"**
- 如果今天已经学习过，询问用户：
  - 选项A：重复学习今天已学过的单词
  - 选项B：继续学习新单词（添加新单词到队列）

**建议：** 保持当前逻辑，因为"重复学习"就是重复学习已学过的单词。

## 📋 二、问题2：家长听写的单词与日历显示的单词不一致

### 2.1 问题原因

#### 2.1.1 家长听写获取单词的逻辑

**API：** `get_today_learned_words_for_dictation`

**查询逻辑：**
```php
SELECT DISTINCT w.*
FROM words w
WHERE w.user_id = ?
AND (
    -- 今天新添加的单词
    (w.date_added = ?)
    OR
    -- 今天复习过的单词（通过word_review_logs表）
    EXISTS (
        SELECT 1 
        FROM word_review_logs rl 
        WHERE rl.word_id = w.id 
        AND rl.user_id = ? 
        AND rl.review_date = ?
    )
)
```

**返回的单词：**
1. ✅ 今天新添加的单词（`date_added = 今天`）
2. ✅ 今天复习过的单词（`word_review_logs.review_date = 今天`）

#### 2.1.2 日历显示单词的逻辑

**API：** `day_details`

**查询逻辑：**
```php
SELECT * FROM words 
WHERE user_id = ? AND date_added = ?
```

**返回的单词：**
- ❌ **只包括指定日期添加的单词**（`date_added = 指定日期`）
- ❌ **不包括复习过的单词**

### 2.2 不一致的原因

| 项目 | 家长听写 | 日历显示 |
|------|---------|---------|
| **查询条件** | `date_added = 今天` OR `review_date = 今天` | `date_added = 指定日期` |
| **包括新添加的单词** | ✅ 是（今天） | ✅ 是（指定日期） |
| **包括复习过的单词** | ✅ 是（今天复习过的） | ❌ 否 |

**举例说明：**

假设：
- 今天（2026-01-29）新添加了5个单词
- 今天复习了3个单词（这3个单词是昨天添加的）

**家长听写显示：**
- 5个今天新添加的单词
- 3个今天复习过的单词
- **总计：8个单词**

**日历显示（点击今天）：**
- 5个今天新添加的单词
- **总计：5个单词**

**结果：不一致！**

### 2.3 解决方案

**方案1：修改日历显示逻辑（推荐）**

**修改 `day_details` API，使其与家长听写一致：**

```php
// 修改前
SELECT * FROM words 
WHERE user_id = ? AND date_added = ?

// 修改后
SELECT DISTINCT w.*
FROM words w
WHERE w.user_id = ?
AND (
    -- 指定日期添加的单词
    (w.date_added = ?)
    OR
    -- 指定日期复习过的单词（通过word_review_logs表）
    EXISTS (
        SELECT 1 
        FROM word_review_logs rl 
        WHERE rl.word_id = w.id 
        AND rl.user_id = ? 
        AND rl.review_date = ?
    )
)
ORDER BY 
    -- 优先显示复习过的单词
    CASE WHEN EXISTS (
        SELECT 1 FROM word_review_logs rl2 
        WHERE rl2.word_id = w.id AND rl2.user_id = ? AND rl2.review_date = ?
    ) THEN 0 ELSE 1 END,
    w.date_added ASC, w.id ASC
```

**优点：**
- ✅ 日历显示与家长听写一致
- ✅ 日历显示更完整（包括复习过的单词）
- ✅ 用户可以看到指定日期学习的所有单词（新学+复习）

**缺点：**
- ⚠️ 需要修改后端API

**方案2：保持当前逻辑，但明确说明差异**

**在界面上说明：**
- 日历显示：只显示指定日期添加的单词
- 家长听写：显示今天学习过的所有单词（新学+复习）

**优点：**
- ✅ 不需要修改代码
- ✅ 明确说明差异

**缺点：**
- ❌ 用户可能仍然觉得不一致

**推荐：方案1（修改日历显示逻辑）**

elseif ($action === 'day_details') {
    $uid = (int)$_GET['uid'];
    $date = $_GET['date'];
    
    // 检查word_review_logs表是否存在
    $table_exists = false;
    $check_table = $conn->query("SHOW TABLES LIKE 'word_review_logs'");
    if ($check_table && $check_table->num_rows > 0) {
        $table_exists = true;
    }
    
    if ($table_exists) {
        // 如果word_review_logs表存在，使用完整查询（包括复习过的单词）
        $stmt = prepare_check($conn, "
            SELECT DISTINCT w.*
            FROM words w
            WHERE w.user_id = ?
            AND (
                -- 指定日期添加的单词
                (w.date_added = ?)
                OR
                -- 指定日期复习过的单词（通过word_review_logs表）
                EXISTS (
                    SELECT 1 
                    FROM word_review_logs rl 
                    WHERE rl.word_id = w.id 
                    AND rl.user_id = ? 
                    AND rl.review_date = ?
                )
            )
            ORDER BY 
                -- 优先显示复习过的单词
                CASE WHEN EXISTS (
                    SELECT 1 FROM word_review_logs rl2 
                    WHERE rl2.word_id = w.id AND rl2.user_id = ? AND rl2.review_date = ?
                ) THEN 0 ELSE 1 END,
                w.date_added ASC, w.id ASC
        ");
        if (!$stmt) {
            echo json_encode(["error" => "SQL准备失败: " . $conn->error]);
            exit;
        }
        $stmt->bind_param("isisis", $uid, $date, $uid, $date, $uid, $date);
    } else {
        // 如果word_review_logs表不存在，只查询指定日期添加的单词
        $stmt = prepare_check($conn, "SELECT * FROM words WHERE user_id = ? AND date_added = ?");
        if (!$stmt) {
            echo json_encode(["error" => "SQL准备失败: " . $conn->error]);
            exit;
        }
        $stmt->bind_param("is", $uid, $date);
    }
    
    if (!$stmt->execute()) {
        echo json_encode(["error" => "SQL执行失败: " . $stmt->error]);
        exit;
    }
    
    echo json_encode($stmt->get_result()->fetch_all(MYSQLI_ASSOC));
}
