# EF因子（记忆难度因子）详细说明

## 📋 一、什么是EF因子？

**EF因子（Easiness Factor，易度因子）** 是SM-2算法中的一个核心参数，用于衡量**单词的记忆难度**。

- **全称**：Easiness Factor（易度因子）
- **中文名**：记忆难度因子
- **作用**：衡量单词对当前用户来说，记忆的难易程度

---

## 🎯 二、EF因子的数值含义

### 2.1 数值范围

- **最小值**：1.3（不能低于1.3）
- **最大值**：理论上可以无限大，但实际使用中通常在 1.3 - 3.5 之间
- **初始值**：2.5（所有新单词的默认值）

### 2.2 数值含义

| EF值 | 含义 | 说明 |
|------|------|------|
| **>= 2.5** | **容易记住** | 单词对你来说比较容易，记忆难度低 |
| **1.6 - 2.5** | **中等难度** | 单词记忆难度中等 |
| **< 1.6** | **困难** | 单词对你来说比较难，记忆难度高 |

### 2.3 为什么 >= 2.5 表示"容易记住"？

**原因：**

1. **初始值是2.5**：所有新单词的EF因子初始值都是2.5
2. **答对会增加EF值**：每次答对，EF因子会增加（变容易）
3. **答错会降低EF值**：每次答错，EF因子会降低（变困难）
4. **>= 2.5 表示至少保持初始难度或更容易**：如果EF因子 >= 2.5，说明单词至少保持了初始难度，或者变得更简单了

**简单理解：**
- **EF >= 2.5** = 单词至少和刚开始学的时候一样容易，或者更容易了 ✅
- **EF < 2.5** = 单词比刚开始学的时候更难了 ❌

## 📈 三、EF因子如何变化？

### 3.1 变化规则

**代码位置：** `api.php` - `submit_review` API (第1131行)

**变化公式：**
```php
$ef = max(1.3, $ef + (0.1 - (5 - $q) * (0.08 + (5 - $q) * 0.02)));
```

**变化规则：**

| 答题结果 | quality值 | EF变化 | 说明 |
|----------|-----------|--------|------|
| **答对** | 5 | **增加** | EF因子增加（变容易） |
| **模糊** | 3 | **略微增加** | EF因子略微增加 |
| **答错** | 1 | **降低** | EF因子降低（变困难） |

### 3.2 具体变化示例

#### 示例1：连续答对（EF值逐渐增加）

| 次数 | 答题结果 | EF变化 | 新的EF值 |
|------|----------|--------|----------|
| 第1次 | 答对（quality=5） | +0.1 | 2.5 → **2.6** |
| 第2次 | 答对（quality=5） | +0.1 | 2.6 → **2.7** |
| 第3次 | 答对（quality=5） | +0.1 | 2.7 → **2.8** |
| 第4次 | 答对（quality=5） | +0.1 | 2.8 → **2.9** |
| 第5次 | 答对（quality=5） | +0.1 | 2.9 → **3.0** ✅ **达到掌握标准** |

#### 示例2：答错（EF值降低）

| 次数 | 答题结果 | EF变化 | 新的EF值 |
|------|----------|--------|----------|
| 初始 | - | - | 2.5 |
| 第1次 | 答错（quality=1） | -0.2 | 2.5 → **2.3** ❌ **低于2.5** |

**说明：** 答错后EF值会降低，单词变困难，需要更多复习。

## 🔄 四、EF因子在复习间隔计算中的作用

### 4.1 复习间隔计算公式

**代码位置：** `api.php` - `submit_review` API (第1128行)

**公式：**
```php
$int = round($int * $ef);  // 新间隔 = 当前间隔 × EF因子
```

### 4.2 具体示例

假设当前复习间隔是6天：

| EF值 | 新间隔计算 | 新间隔 | 说明 |
|------|------------|--------|------|
| **3.0**（容易） | 6 × 3.0 = 18 | **18天** | EF值高，间隔长，复习频率低 |
| **2.5**（初始） | 6 × 2.5 = 15 | **15天** | 标准间隔 |
| **2.0**（中等） | 6 × 2.0 = 12 | **12天** | EF值降低，间隔缩短 |
| **1.5**（困难） | 6 × 1.5 = 9 | **9天** | EF值低，间隔短，复习频率高 |

**结论：**
- **EF值越高** → 复习间隔越长 → 单词越容易记住 ✅
- **EF值越低** → 复习间隔越短 → 单词越难记住 ❌

## 🎯 五、EF因子与掌握状态的关系

### 5.1 掌握条件

**单词被标记为"已掌握"需要同时满足：**
1. `repetitions >= 5`（复习次数 >= 5次）
2. `ef_factor >= 2.5`（EF因子 >= 2.5，表示容易记住）

**代码位置：** `api.php` - `submit_review` API (第1137-1138行)

```php
if ($reps >= 5 && $ef >= 2.5) {
    $status = 'mastered';  // 已掌握
}
```

### 5.2 为什么需要两个条件？

**原因：**

1. **`repetitions >= 5`**：确保单词经过了足够的复习次数
2. **`ef_factor >= 2.5`**：确保单词的记忆难度至少保持在初始水平或更容易

**如果只有 `repetitions >= 5`，但 `ef_factor < 2.5`：**
- 说明虽然复习了5次，但单词仍然比较难（EF值低于初始值）
- 这种情况下，单词不应该被标记为"已掌握"，因为记忆还不够稳定

**示例：**

| 情况 | repetitions | ef_factor | 是否掌握 | 说明 |
|------|-------------|-----------|----------|------|
| 情况1 | 5 | 3.0 | ✅ **是** | 复习5次，EF值高，容易记住 |
| 情况2 | 5 | 2.5 | ✅ **是** | 复习5次，EF值保持初始水平 |
| 情况3 | 5 | 2.0 | ❌ **否** | 复习5次，但EF值低于初始值，还不够稳定 |
| 情况4 | 3 | 3.0 | ❌ **否** | EF值高，但复习次数不够 |

## 📊 六、EF因子的实际应用

### 6.1 在复习优先级排序中的应用

**代码位置：** `api.php` - `calculateReviewPriority` 函数 (第328-329行)

```php
// ef_factor越低（越难），优先级越高
$priority += (3.0 - ($word['ef_factor'] ?? 2.5)) * 3;
```

**说明：**
- EF值越低（越难），优先级越高
- 困难的单词会优先出现在复习列表中

**示例：**

| 单词 | EF值 | 优先级计算 | 优先级 | 说明 |
|------|------|------------|--------|------|
| 单词A | 1.5 | (3.0 - 1.5) × 3 = 4.5 | **高** | 困难单词，优先复习 |
| 单词B | 2.5 | (3.0 - 2.5) × 3 = 1.5 | **中** | 标准难度 |
| 单词C | 3.0 | (3.0 - 3.0) × 3 = 0 | **低** | 容易单词，优先级低 |

### 6.2 在难度分布统计中的应用

**代码位置：** `api.php` - `get_efficiency_stats` API (第1394行)

```php
SELECT CASE 
    WHEN ef_factor < 1.6 THEN 'hard'      -- 困难
    WHEN ef_factor BETWEEN 1.6 AND 2.5 THEN 'medium'  -- 中等
    ELSE 'easy'                           -- 容易
END as level
```

**说明：**
- 根据EF值将单词分为：困难、中等、容易三个等级
- 用于统计用户的学习难度分布

## 🎓 七、总结

### 7.1 EF因子的核心概念

| 概念 | 说明 |
|------|------|
| **全称** | Easiness Factor（易度因子） |
| **作用** | 衡量单词的记忆难度 |
| **初始值** | 2.5 |
| **范围** | 1.3 - 3.5（通常） |
| **变化** | 答对增加，答错降低 |

### 7.2 EF >= 2.5 的含义

**`ef_factor >= 2.5` 表示：**

1. ✅ **单词至少保持初始难度**：EF值 >= 初始值2.5
2. ✅ **或者变得更简单**：EF值 > 2.5，说明答对次数多，单词变容易了
3. ✅ **记忆难度低**：单词对你来说比较容易记住
4. ✅ **复习间隔可以更长**：因为容易记住，所以不需要频繁复习

### 7.3 为什么需要 >= 2.5 才能掌握？

**原因：**

- **确保记忆稳定性**：如果EF值 < 2.5，说明单词比刚开始学的时候更难了，记忆还不够稳定
- **双重保障**：`repetitions >= 5` 确保复习次数足够，`ef_factor >= 2.5` 确保记忆难度至少保持在初始水平
- **科学依据**：基于SM-2算法的研究，只有当EF值保持在初始水平或更高时，才认为单词真正掌握

### 7.4 实际应用场景

| 场景 | EF值 | 说明 |
|------|------|------|
| **新单词** | 2.5 | 初始值，标准难度 |
| **连续答对** | 2.5 → 2.6 → 2.7 → ... | EF值逐渐增加，变容易 |
| **答错** | 2.5 → 2.3 | EF值降低，变困难 |
| **达到掌握** | >= 2.5 且 repetitions >= 5 | 满足两个条件，标记为已掌握 |
| **复习优先级** | 越低越优先 | EF值低的单词优先复习 |
