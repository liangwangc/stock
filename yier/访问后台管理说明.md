# 访问后台管理页面说明

## 🎯 后端管理页面位置

**文件：** `admin.html`

**访问地址：** `http://localhost:8000/admin.html`（或您的服务器地址）

## ✅ 访问方法

### 方法1：通过登录后的管理按钮（推荐）

1. **使用管理员账号登录**
   - 打开 `index.html`
   - 账号：`admin`
   - 密码：`admin123`

2. **点击管理按钮**
   - 登录成功后，右下角会显示"⚙️ 管理"按钮
   - 点击该按钮即可进入后台管理页面

### 方法2：直接访问URL

**直接浏览器访问：**
```
http://localhost:8000/admin.html
```

**注意：** 
- 如果未登录或不是管理员，会被重定向到首页
- 需要先使用管理员账号登录

### 方法3：从首页导航

如果已登录为管理员：
- 在浏览器地址栏直接输入：`admin.html`
- 或点击浏览器书签（如果已保存）

## 🔐 权限要求

**必须是管理员账号才能访问！**

- ✅ `admin` 角色可以访问
- ❌ `user` 角色无法访问（会被重定向）

### 第一次访问：

1. **启动服务器**

   双击运行: 一键启动.bat

2. **打开登录页面**
   ```
   浏览器访问: http://localhost:8000
   ```

3. **使用管理员账号登录**

   - 密码：`admin123`

4. **进入后台管理**
   - **方法A：** 点击右下角"⚙️ 管理"按钮
   - **方法B：** 浏览器访问 `http://localhost:8000/admin.html`

## ⚠️ 常见问题

### Q: 点击管理按钮没反应？

**解决方法：**
1. 检查是否使用管理员账号登录
2. 检查浏览器控制台是否有错误（F12）
3. 尝试直接访问 `admin.html`

### Q: 访问 admin.html 被重定向到首页？

**原因：** 未登录或不是管理员

**解决方法：**
1. 使用管理员账号登录
2. 确保登录状态已保存（检查 localStorage）

### Q: 找不到管理按钮？

**原因：** 可能不是管理员账号

**解决方法：**
1. 确认使用的是 `admin` 账号登录
2. 检查用户角色是否为 `admin`
3. 或直接访问 `admin.html`

### Q: 管理页面显示"无权限访问"？

**解决方法：**
1. 确认使用的是管理员账号
2. 检查数据库中用户角色是否为 `admin`
3. 重新登录

## 🔍 验证管理员权限

如果无法确定是否为管理员：

1. **检查登录后的用户信息**
   - 打开浏览器控制台（F12）
   - 输入：`localStorage.getItem('user')`
   - 查看返回的 JSON 中 `role` 字段是否为 `"admin"`

2. **检查数据库**
   ```sql
   SELECT username, role FROM users WHERE username = 'admin';
   ```
   应该显示 `role = 'admin'`
