### 6. ✅ 总任务量计算

**需求：**
- 第1天：daily_goal
- 第2天：daily_goal * 2
- 第3天及以后：daily_goal * 2.4（固定）

**代码实现：** `api.php` - `calculateTotalTask()` 函数 (第130-149行)
```php
function calculateTotalTask($conn, $uid, $daily_goal, $today) {
    $is_first_login = isFirstLogin($conn, $uid, $today);
    
    if ($is_first_login) {
        return $daily_goal; // 第1天
    }
    
    $dates = getLearningDates($conn, $uid, 30);
    $distinct_days = count($dates);
    
    if ($distinct_days == 2) {
        return $daily_goal * 2; // 第2天
    } elseif ($distinct_days >= 3) {
        return $daily_goal * 2.4; // 第3天及以后
    }
    
    return $daily_goal; // 默认
}
```

**检查结果：** ✅ **一致**

**注意：** 使用`getLearningDates()`函数基于实际学习日期判断天数，更准确。
