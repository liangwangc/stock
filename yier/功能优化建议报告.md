# 功能优化建议报告

## 📋 需求分析

### 需求1：学习模式选择后高亮显示
**问题：** 选中模式后，界面和功能没有明显变化，用户无法感知当前模式

**建议：**
1. **视觉反馈**：选中的模式高亮显示（背景色、边框、图标变化）
2. **功能区分**：或者关闭另一种模式，只显示当前模式
3. **状态提示**：在设置页面显示当前激活的模式

---

### 需求2：按钮改名和完成逻辑修改
**问题：** 
- 按钮名称需要更明确："开始学习" → "家长听写"，"听写" → "自动听写"
- 完成逻辑：只要完成一种听写，另一种也算完成
- 允许多次学习，但不再计分

**建议：**
1. **按钮改名**：修改按钮文本
2. **完成逻辑**：完成一种听写后，另一种自动标记为完成（但不计分）
3. **多次学习**：允许重复学习，但只记录第一次的分数

---

### 需求3：复习单词权重统一
**问题：** 目前听写模式权重高，学习模式权重低，需要统一

**建议：**
1. **统一权重**：两种模式的权重改为相同
2. **代码修改**：修改 `calculateReviewPriority` 函数

---

### 需求4：PK页面增加"全部"时间段和多种排序
**问题：** 
- 缺少"全部"时间段选项
- 排序方式单一，需要支持多种排序指标

**建议：**
1. **增加"全部"时间段**：统计所有时间的数据
2. **多种排序方式**：支持按打卡总天数、连续打卡天数、总掌握单词量等排序
3. **排序选择器**：添加排序下拉框

---

## 🎯 详细优化方案

### 一、学习模式选择后高亮显示

#### 1.1 当前状态分析

**代码位置：** `index.html` 第560-565行

```html
<div class="input-row">
    <label>默认学习模式</label>
    <select id="setting-study-mode" style="...">
        <option value="card">卡片学习</option>
        <option value="dictation">听写模式</option>
    </select>
</div>
```

**问题：**
- 选择后没有视觉反馈
- 没有显示当前激活的模式
- 用户不知道选择后有什么变化

#### 1.2 优化方案

**方案A：高亮显示（推荐）**

1. **设置页面显示当前模式**
   - 在设置页面添加当前模式提示卡片
   - 选中的模式高亮显示（背景色、边框）

2. **主页显示当前模式**
   - 在"开始学习"按钮附近显示当前模式标签
   - 或者根据模式改变按钮样式

**方案B：关闭另一种模式**

1. **根据选择隐藏/显示按钮**
   - 选择"卡片学习"：只显示"开始学习"按钮
   - 选择"听写模式"：只显示"听写"按钮

**推荐方案：方案A（高亮显示）**

**实现步骤：**
1. 在设置页面添加模式状态显示卡片
2. 选择模式后，高亮显示选中的选项
3. 在主页显示当前激活的模式标签

### 二、按钮改名和完成逻辑修改

#### 2.1 当前状态分析

**代码位置：** `index.html` 第301-306行

```html
<button onclick="app.startSession()" id="start-btn">
    开始学习
</button>
<button onclick="app.startDictation()" id="dictation-btn">
    🎧 听写
</button>
```

**功能分析：**
- `startSession()`：卡片学习模式
- `startDictation()`：听写模式

#### 2.2 优化方案

**修改内容：**

1. **按钮改名**
   - "开始学习" → "家长听写"
   - "听写" → "自动听写"

2. **完成逻辑修改**
   - 完成"家长听写"后，"自动听写"自动标记为完成（但不计分）
   - 完成"自动听写"后，"家长听写"自动标记为完成（但不计分）
   - 允许多次学习，但只记录第一次的分数

**实现步骤：**

1. **修改按钮文本**
   ```html
   <button onclick="app.startSession()" id="start-btn">
       家长听写
   </button>
   <button onclick="app.startDictation()" id="dictation-btn">
       🎧 自动听写
   </button>
   ```

2. **修改完成逻辑**
   - 在 `submit_review` API 中，检查另一种模式是否已完成
   - 如果已完成，自动标记当前模式为完成（但不计分）
   - 添加 `is_repeat` 字段，标记是否为重复学习

3. **多次学习处理**
   - 检查 `word_review_logs` 表，如果已有记录，标记为重复学习
   - 重复学习不更新分数，但可以更新学习记录

### 三、复习单词权重统一

#### 3.1 当前状态分析

**代码位置：** `api.php` - `calculateReviewPriority` 函数 (第210-337行)

**当前权重：**

| 项目 | 听写模式权重 | 学习模式权重 |
|------|-------------|-------------|
| 连续忘记 | 20 | 5 |
| 连续模糊 | 12 | 3 |
| 连续记住 | -5 | -1 |
| 总失败率 | 15 | - |

**问题：** 听写模式权重明显高于学习模式

#### 3.2 优化方案

**统一权重：**

| 项目 | 统一权重 |
|------|---------|
| 连续忘记 | 10（两种模式相同） |
| 连续模糊 | 6（两种模式相同） |
| 连续记住 | -3（两种模式相同） |
| 总失败率 | 8（两种模式相同） |

**实现步骤：**

1. **修改 `calculateReviewPriority` 函数**
   ```php
   // 统一权重
   $priority += $dictationConsecutiveForgot * 10;  // 改为10
   $priority += $dictationConsecutiveVague * 6;    // 改为6
   $priority -= $dictationConsecutiveRemembered * 3; // 改为-3
   
   $priority += $studyConsecutiveForgot * 10;      // 改为10（与听写相同）
   $priority += $studyConsecutiveVague * 6;        // 改为6（与听写相同）
   $priority -= $studyConsecutiveRemembered * 3;   // 改为-3（与听写相同）
   ```

2. **修改SQL查询中的优先级计算**
   - 在 `prepare_study_queue` API 中，统一两种模式的权重

### 四、PK页面增加"全部"时间段和多种排序

#### 4.1 当前状态分析

**代码位置：** `index.html` 第403-408行

```html
<select id="pk-period" onchange="app.loadRankings()">
    <option value="day">今日</option>
    <option value="week" selected>本周</option>
    <option value="month">本月</option>
    <option value="year">本年</option>
</select>
```

**排序逻辑：** `api.php` 第2443-2454行

```php
usort($rankings, function($a, $b) {
    if ($a['total_words'] != $b['total_words']) {
        return $b['total_words'] - $a['total_words'];
    }
    if ($a['mastered_words'] != $b['mastered_words']) {
        return $b['mastered_words'] - $a['mastered_words'];
    }
    if ($a['streak_days'] != $b['streak_days']) {
        return $b['streak_days'] - $a['streak_days'];
    }
    return $b['study_days'] - $a['study_days'];
});
```

**问题：**
- 缺少"全部"时间段
- 排序方式固定，无法切换

**1. 增加"全部"时间段**

```

// 根据排序方式排序
usort($rankings, function($a, $b) use ($sort_by) {
    // 主排序
    if ($a[$sort_by] != $b[$sort_by]) {
        return $b[$sort_by] - $a[$sort_by];
    }
    // 次排序（固定）
    if ($a['total_words'] != $b['total_words']) {
        return $b['total_words'] - $a['total_words'];
    }
    if ($a['mastered_words'] != $b['mastered_words']) {
        return $b['mastered_words'] - $a['mastered_words'];
    }
    return $b['study_days'] - $a['study_days'];
});
```
