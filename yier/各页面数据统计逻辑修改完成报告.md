## 📋 修改内容总结

### 1. 主页（get_home_data API）✅ 已修改

#### 1.1 修改内容

**修改前：**
- **要复习**：`total_review_count`（所有需要复习的单词数，不限制数量）
- **新单词**：`display_new_count`（如果启用单词库显示目标数，否则显示实际数）
- **今天任务**：`daily_goal`（每日目标）

**修改后：**
- **要复习**：`review_display_count`（复习单词40% + 昨天新单词全量）
- **新单词**：`display_new_count`（100%的每日目标）
- **今天任务**：`total_task`（根据天数显示不同的总任务量）
  - 第1天：`daily_goal`
  - 第2天：`daily_goal * 2`
  - 第3天及以后：`daily_goal * 2.4`

#### 1.2 代码修改详情

**新增逻辑：**
```php
// 检查用户是否是第一次登录
$is_first_login = ($total_words == 0) || ($words_before_today == 0 && $total_words > 0);

// 计算复习单词（40%）和昨天新单词
if (!$is_first_login) {
    $review_count_target = max(1, ceil($daily_goal * 0.4)); // 复习单词（40%）
    
    // 昨天新单词（全量）
    $yesterday = date('Y-m-d', strtotime("$today -1 day"));
    $yesterday_review_count = count(昨天date_added的单词);
}

// 要复习显示：复习单词（40%）+ 昨天新单词（全量）
$review_display_count = $review_count_target + $yesterday_review_count;

// 新单词目标：100%的每日目标
$new_word_target = $daily_goal; // 100%

// 计算今天任务（总任务量）
$total_task = $daily_goal; // 默认第1天
if (!$is_first_login) {
    $distinct_days = count(不同的学习天数);
    if ($distinct_days == 2) {
        $total_task = $daily_goal * 2; // 第2天
    } elseif ($distinct_days >= 3) {
        $total_task = $daily_goal * 2.4; // 第3天及以后
    }
}
```

**返回数据更新：**
```php
"stats" => [
    "review_count" => $review_display_count,  // 要复习：复习单词（40%）+ 昨天新单词（全量）
    "new_count" => $display_new_count,   // 新单词：今天新单词（100%）
    "review_count_target" => $review_count_target,  // 复习单词（40%）
    "yesterday_review_count" => $yesterday_review_count,  // 昨天新单词（全量）
    "total_pending" => $total_task,  // 今天任务：根据天数显示不同的总任务量
    "is_first_login" => $is_first_login  // 是否是第一次登录
]
```

### 2. PK页面（get_rankings API）✅ 已修改

#### 2.1 修改内容

**修改前：**
- **完成率计算**：`(平均每日学习数 / daily_goal) * 100`

**修改后：**
- **完成率计算**：`(平均每日学习数 / 平均每日任务量) * 100`
  - 平均每日任务量根据学习天数计算：
    - 第1天：`daily_goal`
    - 第2天：`daily_goal * 1.5`
    - 第3天及以后：`daily_goal * 2.4`

#### 2.2 代码修改详情

```php
// 计算平均每日任务量（根据学习天数）
$avg_daily_task = $daily_goal; // 默认第1天
if ($study_days >= 3) {
    // 第3天及以后：使用固定任务量
    $avg_daily_task = $daily_goal * 2.4;
} elseif ($study_days == 2) {
    // 第2天：平均任务量
    $avg_daily_task = $daily_goal * 1.5; // (daily_goal + daily_goal * 2) / 2
}

// 完成率计算
$avg_daily_words = $total_words / $study_days;
$completion_rate = round(min(100, ($avg_daily_words / $avg_daily_task) * 100), 1);
```

## 🔍 注意事项

### 1. 主页统计显示

- **要复习**：现在显示的是"复习单词（40%）+ 昨天新单词（全量）"，而不是所有需要复习的单词数
- **新单词**：现在固定显示100%的每日目标，不再根据单词库状态调整
- **今天任务**：现在根据天数显示不同的总任务量，而不是固定的每日目标

### 2. PK页面完成率

- **完成率计算**：现在使用平均每日任务量作为分母，而不是固定的`daily_goal`
- **平均每日任务量**：根据学习天数动态计算
  - 第1天：`daily_goal`
  - 第2天：`daily_goal * 1.5`
  - 第3天及以后：`daily_goal * 2.4`

### 3. 数据一致性

- 主页统计和实际学习队列应该保持一致
- PK页面完成率应该反映用户的实际学习情况
