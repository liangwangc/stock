# 复习单词占每日学习总量说明

## 一、当前实现逻辑

### 1. 复习单词数量计算

**位置**：`api.php` - `prepare_study_queue` API

**计算方式**：

#### 步骤1：计算复习目标数量（用于限制复习单词数量）
```php
$new_word_count = COUNT(*) FROM words WHERE status = 'new' AND date_added <= today
$review_count_target = max(1, ceil($new_word_count * 0.5)); // 50%的复习量，至少1个
```

**说明**：
- 复习目标数量 = **已学单词总数 × 50%**（至少1个）
- 这个数量用于**限制实际复习的单词数量**（LIMIT）

#### 步骤2：统计实际需要复习的单词数量
```php
$total_review_count = COUNT(*) FROM words 
WHERE status != 'new' AND next_review <= today
```

**说明**：
- 这是**所有需要复习的单词数量**（不限制）
- 包括所有 `next_review <= today` 的单词

#### 步骤3：计算新单词目标数量
```php
$new_word_target = max(0, $daily_goal - $total_review_count);
```

**说明**：
- 新单词目标数 = **每日目标 - 实际复习单词数量**
- 如果复习单词数量 >= 每日目标，新单词数量 = 0
- 如果复习单词数量 < 每日目标，新单词数量 = daily_goal - total_review_count

### 2. 实际队列组成

**最终队列**：
```php
$final_queue = array_merge($list_reviews, $list_new);
```

**说明**：
- `$list_reviews`：复习单词（最多 `review_count_target` 个，按优先级排序）
- `$list_new`：新单词（最多 `new_word_target` 个）

## 二、复习单词占比分析

### 情况1：复习单词数量 < 每日目标

**示例**：
- 每日目标：10个
- 实际复习单词数量：3个
- 新单词目标数：10 - 3 = **7个**

**占比**：
- 复习单词：**3个（30%）**
- 新单词：**7个（70%）**

### 情况2：复习单词数量 >= 每日目标

**示例**：
- 每日目标：10个
- 实际复习单词数量：15个
- 新单词目标数：max(0, 10 - 15) = **0个**

**占比**：
- 复习单词：**10个（100%，但实际有15个需要复习）**
- 新单词：**0个（0%）**

**注意**：虽然实际有15个需要复习，但队列中只包含10个（因为 `review_count_target` 的限制）

### 情况3：第一次登录

**示例**：
- 每日目标：10个
- 实际复习单词数量：0个（第一次登录）
- 新单词目标数：10 - 0 = **10个**

**占比**：
- 复习单词：**0个（0%）**
- 新单词：**10个（100%）**

## 三、当前逻辑的问题

### 问题1：复习单词数量限制不合理

**当前逻辑**：
- 复习目标数量 = 已学单词总数 × 50%
- 但实际复习单词数量可能远大于这个目标

**示例**：
- 已学单词总数：100个
- 复习目标数量：100 × 50% = 50个
- 但实际需要复习的单词：80个（因为很多单词的next_review都到了）
- 结果：只复习50个，剩下30个被忽略

### 问题2：新单词数量计算不合理

**当前逻辑**：
- 新单词目标数 = daily_goal - total_review_count
- 如果复习单词数量很多，新单词数量可能为0

**问题**：
- 用户可能希望每天都能学习一些新单词
- 如果复习单词太多，新单词数量为0，用户可能觉得没有进步

---

## 四、建议的优化方案

### 方案1：固定比例分配（推荐）

**逻辑**：
- 复习单词数量 = daily_goal × 复习比例（如30%）
- 新单词数量 = daily_goal × 新单词比例（如70%）

**示例**（复习30%，新单词70%）：
- 每日目标：10个
- 复习单词：10 × 30% = **3个**
- 新单词：10 × 70% = **7个**

**优点**：
- ✅ 每天都有新单词学习
- ✅ 复习和新单词比例固定，用户预期明确
- ✅ 不会因为复习单词太多而影响新单词学习

### 方案2：动态调整（根据复习单词数量）

**逻辑**：
- 如果复习单词数量 <= daily_goal × 50%：
  - 复习单词：实际数量
  - 新单词：daily_goal - 复习数量
- 如果复习单词数量 > daily_goal × 50%：
  - 复习单词：daily_goal × 50%（限制）
  - 新单词：daily_goal × 50%（保证）

**示例**：
- 每日目标：10个
- 如果复习单词 <= 5个：全部复习，剩余学新单词
- 如果复习单词 > 5个：复习5个，新单词5个

**优点**：
- ✅ 保证每天都有新单词学习
- ✅ 复习单词数量有上限，不会太多

### 方案3：优先级分配

**逻辑**：
- 优先复习高优先级的单词（听写错误多的）
- 如果复习单词数量 < daily_goal，剩余学新单词
- 如果复习单词数量 >= daily_goal，只复习，不学新单词

**优点**：
- ✅ 优先复习困难的单词
- ✅ 简单直接

---

## 五、当前实现总结

### 当前逻辑：

1. **复习目标数量**：已学单词总数 × **50%**（至少1个）
2. **实际复习数量**：所有 `next_review <= today` 的单词（不限制）
3. **新单词目标数**：**daily_goal - 实际复习数量**
4. **最终队列**：复习单词（最多review_count_target个）+ 新单词（最多new_word_target个）

### 占比情况：

- **动态变化**，取决于需要复习的单词数量
- **如果复习单词少**：复习占比低，新单词占比高
- **如果复习单词多**：复习占比高，新单词占比低（可能为0）

### 问题：

- ⚠️ 复习目标数量（50%）和实际复习数量可能不一致
- ⚠️ 如果复习单词太多，新单词数量可能为0
- ⚠️ 用户可能希望每天都能学习新单词

---

## 六、建议

**建议采用方案1（固定比例分配）**：
- 复习单词：每日目标 × 30%
- 新单词：每日目标 × 70%

这样可以：
- ✅ 保证每天都有新单词学习
- ✅ 复习和新单词比例固定
- ✅ 用户预期明确
