### 1. 高优先级问题修复 ✅

#### 1.1 进度百分比计算修复 ✅

**位置：** `api.php` - `get_home_data` API (第955行)

**修改前：**
```php
$progress_percent = $daily_goal > 0 ? min(100, round(($today_learned_count / $daily_goal) * 100)) : 0;
```

**修改后：**
```php
// 使用实际总任务量计算进度百分比
// 注意：$total_task已经在上面计算好了（使用calculateTotalTask函数），根据天数显示不同的总任务量
$progress_percent = $total_task > 0 ? min(100, round(($today_learned_count / $total_task) * 100)) : 0;
```

**影响：**
- 进度百分比现在准确反映实际学习进度
- 第3天及以后，进度百分比基于`daily_goal * 2.4`计算

---

#### 1.2 统计/设置页面完成率修复 ✅

**位置：** `api.php` - `get_efficiency_stats` API (第1477-1492行)

**修改前：**
```php
$completion_rate = round(min(100, ($today_studied_words / $daily_goal) * 100), 1);
```

**修改后：**
```php
// 使用公共函数计算总任务量
$total_task = calculateTotalTask($conn, $uid, $daily_goal, $today);

```

**影响：**
- 完成率现在准确反映实际学习情况
- 考虑了不同天数的总任务量差异

#### 1.3 前端按钮进度显示修复 ✅

**位置：** `index.html` - `updTodo()` 函数 (第1099行、第1049行)


### 2. 代码质量优化 ✅

#### 2.1 提取公共函数 ✅

**新增函数：** `calculateTotalTask()`

**位置：** `api.php` (第70-103行)

**功能：**
- 计算总任务量（根据天数显示不同的总任务量）
- 第1天：`daily_goal`
- 第2天：`daily_goal * 2`
- 第3天及以后：`daily_goal * 2.4`

**使用位置：**
- `get_home_data` API
- `get_efficiency_stats` API
- `prepare_study_queue` API（已使用，但代码中直接实现）

**好处：**
- 减少代码重复
- 统一逻辑，易于维护
- 确保计算一致性
