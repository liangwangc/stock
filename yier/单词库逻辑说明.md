# 单词库使用逻辑说明

## 📋 表结构说明

### 1. word_bank 表（单词库表）
**作用**：只读的单词库，存储所有年级的单词数据

**特点**：
- ✅ **只读**：不存储学习状态，不进行任何更新操作
- ✅ **共享**：所有用户共享同一个单词库
- ✅ **静态**：单词数据固定，不会因为用户学习而改变

**字段**：
- `id`: 主键
- `grade`: 年级（grade1-grade12）
- `word`: 单词
- `pronunciation`: 音标
- `meaning`: 中文释义
- `example`: 例句
- `word_order`: 单词顺序

### 2. words 表（用户学习表）
**作用**：存储用户学习的单词及其学习状态

**特点**：
- ✅ **用户专属**：每个用户有独立的单词记录
- ✅ **动态**：学习状态会随着学习进度更新
- ✅ **状态管理**：记录学习状态、复习日期、EF因子等

**关键字段**：
- `user_id`: 用户ID
- `word`: 单词
- `status`: 学习状态（new, learning, mastered）
- `source`: 单词来源（manual手动录入, word_bank单词库）
- `next_review`: 下次复习日期
- `ef_factor`: EF因子（记忆难度）
- `repetitions`: 重复次数
- `interval_days`: 间隔天数

## 🔄 单词库使用流程

### 步骤1：自动导入（get_home_data）
```
用户访问首页
  ↓
检查是否启用单词库
  ↓
调用 importWordBankWords()
  ↓
从 word_bank 表读取单词
  ↓
插入到 words 表（source='word_bank', status='new'）
```

### 步骤2：学习单词
```
用户开始学习
  ↓
从 words 表获取单词（优先手动录入）
  ↓
用户学习单词
  ↓
提交学习结果（记住/模糊/忘记）
  ↓
更新 words 表的状态（status, next_review, ef_factor等）
```

### 步骤3：复习单词
```
根据 next_review 日期
  ↓
从 words 表获取需要复习的单词
  ↓
用户复习
  ↓
更新 words 表的状态
```

## 📊 学习状态标识

### status 字段（学习状态）

| 状态 | 说明 | 何时设置 |
|------|------|---------|
| `new` | 新词，未学习 | 导入时或手动添加时 |
| `learning` | 学习中 | 第一次学习但未完全掌握 |
| `mastered` | 已掌握 | 多次复习后达到稳定状态 |

### source 字段（单词来源）

| 来源 | 说明 | 用途 |
|------|------|------|
| `manual` | 手动录入 | 区分手动录入的单词 |
| `word_bank` | 单词库 | 区分从单词库导入的单词 |

**重要**：`source` 字段**不影响**学习状态，只是用来：
1. 区分单词来源
2. 优先显示手动录入的单词
3. 统计单词来源

## 🎯 核心逻辑

### 1. word_bank 表的作用
- ✅ **只读单词库**：存储单词数据，不存储学习状态
- ✅ **数据源**：提供单词的音标、词义、例句
- ✅ **不操作数据**：不会因为用户学习而更新

### 2. words 表的作用
- ✅ **用户学习记录**：每个用户的学习数据
- ✅ **状态管理**：记录学习状态、复习计划
- ✅ **动态更新**：随着学习进度更新状态

### 3. 导入逻辑
```php
// 从 word_bank 导入到 words
INSERT INTO words (
    user_id, word, pronunciation, meaning, example,
    date_added, next_review, status, source
) VALUES (
    ?, ?, ?, ?, ?,
    ?, ?, 'new', 'word_bank'  // 初始状态：new，来源：word_bank
)
```

### 4. 学习状态更新
```php
// 学习后更新状态
UPDATE words SET
    status = ?,           // new -> learning -> mastered
    next_review = ?,      // 下次复习日期
    ef_factor = ?,        // EF因子
    repetitions = ?,      // 重复次数
    interval_days = ?     // 间隔天数
WHERE id = ?
```

## 🔍 关键代码位置

### 1. 导入单词库单词
**文件**：`api.php`
**函数**：`importWordBankWords()`
**位置**：第45-95行

**逻辑**：
- 检查今天是否已导入足够数量
- 从 `word_bank` 表读取未导入的单词
- 插入到 `words` 表，标记 `source='word_bank'`, `status='new'`

### 2. 获取学习任务
**文件**：`api.php`
**函数**：`get_home_data`
**位置**：第222-295行

**逻辑**：
- 优先显示待复习的单词（`status != 'new'`）
- 然后显示新词：
  - 优先：手动录入（`source='manual'`）
  - 补充：单词库（`source='word_bank'`）

### 3. 提交学习结果
**文件**：`api.php`
**函数**：`submit_review`
**位置**：第346-422行

**逻辑**：
- 根据学习结果（记住/模糊/忘记）
- 更新 `words` 表的状态
- 计算下次复习日期和EF因子

## 💡 设计要点

### ✅ 优点
1. **数据分离**：单词库和学习记录分离，结构清晰
2. **状态管理**：学习状态在 `words` 表中统一管理
3. **来源标识**：通过 `source` 字段区分单词来源
4. **优先级**：手动录入优先显示

### 📝 注意事项
1. **word_bank 表只读**：不会因为用户学习而更新
2. **words 表动态**：学习状态会实时更新
3. **source 不影响状态**：只是标识来源，不影响学习逻辑
4. **状态在 words 表**：所有学习状态都在 `words` 表中管理

## 🎓 总结

**word_bank 表**：
- 📚 只读的单词库
- 🔒 不存储学习状态
- 📖 提供单词数据（音标、词义、例句）

**words 表**：
- 📝 用户学习记录
- 🔄 动态更新学习状态
- 📊 管理复习计划

**学习流程**：
1. 从 `word_bank` 导入 → `words` 表（`status='new'`, `source='word_bank'`）
2. 用户学习 → 更新 `words` 表状态（`status`, `next_review`等）
3. 复习管理 → 根据 `next_review` 从 `words` 表获取复习任务

**状态标识**：
- `status`: 学习状态（new, learning, mastered）
- `source`: 单词来源（manual, word_bank）
- 两者独立，`source` 不影响学习状态
