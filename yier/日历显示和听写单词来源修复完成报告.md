# 日历显示和听写单词来源修复完成报告

## ✅ 一、修改内容

### 1.1 日历显示逻辑修改

**修改位置：** `api.php` 第754-851行（`day_details` API）

**修改内容：**
- **如果点击今天**：返回学习队列的三种分类
  - **头天**（昨天学习的单词）- 全量
  - **复习**（以前学的单词根据权重进行复习）- 40%的daily_goal
  - **新单词**（用户设置的数量）- 100%的daily_goal
- **如果点击其他日期**：返回该日期的学习情况（添加的单词 + 复习过的单词）

**返回格式（今天）：**
```json
{
  "yesterday_words": [...],  // 头天（昨天学习的单词）
  "review_words": [...],      // 复习（以前学的单词根据权重）
  "new_words": [...],          // 新单词（用户设置的数量）
  "stats": {
    "yesterday_count": 10,
    "review_count": 4,
    "new_word_count": 10,
    "total_count": 24
  }
}
```

### 1.3 听写单词来源修改

**修改位置：** `index.html` 第1695-1710行（`startDictation` 函数）

**修改内容：**
- 使用 `prepare_study_queue` API 获取学习队列（而不是 `get_today_learned_words_for_dictation`）
- 学习队列 = 头天（昨天学习的单词）+ 复习（40%的daily_goal）+ 新单词（100%的daily_goal）

**修改前：**
```javascript
const res = await fetch(`api.php?action=get_today_learned_words_for_dictation&uid=${this.user.id}`);
```

**修改后：**
```javascript
const res = await fetch(`api.php?action=prepare_study_queue&uid=${this.user.id}`);
```

### 1.4 重复学习逻辑优化

**修改位置：** `index.html` 第1530-1554行（`startSession` 函数）

**修改内容：**
- 如果今天已经学习过，使用 `prepare_study_queue` API 获取学习队列结构（头天+复习+新单词）
- 然后只保留今天已经学习过的单词（通过 `get_today_learned_words_for_dictation` API 过滤）
- 这样可以保持队列的顺序（头天+复习+新单词），但只学习今天已经学习过的单词

**逻辑说明：**
1. 调用 `prepare_study_queue` API 获取完整的学习队列（头天+复习+新单词）
2. 调用 `get_today_learned_words_for_dictation` API 获取今天已经学习过的单词ID列表
3. 过滤出今天已经学习过的单词（保持队列顺序）
