## 方法二：使用MySQL命令行测试

### 步骤1：打开MySQL命令行
```bash
mysql -u root -p
```
输入密码（默认可能是 `root` 或空）

### 步骤2：测试连接和查询
```sql
-- 显示所有数据库
SHOW DATABASES;

-- 使用word_app数据库
USE word_app;

-- 显示所有表
SHOW TABLES;

-- 查询用户数量
SELECT COUNT(*) FROM users;

-- 查询单词数量
SELECT COUNT(*) FROM words;

-- 查看最近5个用户
SELECT id, username, daily_goal, created_at FROM users ORDER BY id DESC LIMIT 5;

-- 查看用户ID=1的单词
SELECT word, pronunciation, meaning, status FROM words WHERE user_id = 1 LIMIT 5;
```

## 常见错误及解决方法

### 错误1：`Can't connect to MySQL server`

**原因：** MySQL服务未启动

**解决方法：**
- Windows: 打开服务管理器，启动MySQL服务
- 或使用：`net start MySQL`
- XAMPP: 在控制面板点击MySQL的Start按钮

### 错误2：`Access denied for user 'root'@'localhost'`

**原因：** 密码错误

**解决方法：**
1. 检查 `api.php` 中的密码是否正确
2. 尝试重置MySQL root密码
3. 或创建新用户并授权

### 错误3：`Unknown database 'word_app'`

**原因：** 数据库未创建

**解决方法：**
```bash
# 导入数据库
mysql -u root -p < word_app_backup_20260129.sql
```

### 错误4：`Table 'word_app.users' doesn't exist`

**原因：** 表未创建

**解决方法：**
```sql
USE word_app;
SHOW TABLES;  -- 检查表是否存在
-- 如果不存在，重新导入数据库
```
