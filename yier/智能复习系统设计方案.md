# 智能复习系统设计方案

## 一、当前words表字段分析

### 现有字段
```sql
CREATE TABLE words (
    id INT PRIMARY KEY AUTO_INCREMENT,
    user_id INT NOT NULL,
    word VARCHAR(100) NOT NULL,
    pronunciation VARCHAR(100) DEFAULT '',
    meaning TEXT,
    example TEXT,
    date_added DATE NOT NULL,              -- 首次添加日期
    next_review DATE NOT NULL,             -- 下次复习日期
    interval_days INT DEFAULT 0,           -- 复习间隔天数
    ef_factor FLOAT DEFAULT 2.5,           -- 记忆难度因子（SM-2算法）
    repetitions INT DEFAULT 0,             -- 复习次数
    status ENUM('new','learning','review','mastered') DEFAULT 'new',
    source ENUM('manual','word_bank') DEFAULT 'manual',
    forgot_count INT DEFAULT 0,            -- 忘记按钮点击次数
    vague_count INT DEFAULT 0,             -- 模糊按钮点击次数
    remembered_count INT DEFAULT 0         -- 记住按钮点击次数
);
```

### 字段用途分析
- ✅ **已有**：`date_added`（首次学习日期）、`next_review`（下次复习日期）
- ✅ **已有**：`forgot_count`、`vague_count`、`remembered_count`（点击次数统计）
- ❌ **缺失**：每次复习的具体日期记录
- ❌ **缺失**：区分学习模式和听写模式的记录
- ❌ **缺失**：每次复习的质量评分历史

## 二、需求分析

### 需求1：第一天学习的单词纳入第二天复习
**现状**：`next_review`字段可以记录下次复习日期，但无法追溯历史复习记录。

**问题**：
- 无法知道某个单词在哪些日期被复习过
- 无法分析复习效果趋势

### 需求2：记录每天学习后的听写情况
**现状**：`forgot_count`、`vague_count`、`remembered_count`记录了总次数，但：
- 无法区分是学习模式还是听写模式
- 无法知道每次点击的具体日期
- 无法分析听写和学习的效果差异

### 需求3：第三天根据历史情况智能抽取复习单词
**现状**：基于SM-2算法的`next_review`和`ef_factor`，但：
- 无法根据"连续三次记住"这样的模式来判断
- 无法根据"每次都是忘记/模糊"来重点复习

### 需求4：复习单词量占新学单词量的50%
**现状**：没有复习量控制机制

```sql
    repetitions_before INT COMMENT '复习前的repetitions',
    repetitions_after INT COMMENT '复习后的repetitions',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '记录创建时间',

    KEY idx_word_id (word_id),
    KEY idx_user_id (user_id),
    KEY idx_review_date (review_date),
```

## 四、功能实现逻辑

### 4.1 复习记录逻辑（修改 `submit_review` API）

**流程**：
1. 用户点击"忘记/模糊/记住"
2. 记录到 `word_review_logs` 表（包括复习前和复习后的状态）
3. 更新 `words` 表的统计字段
4. 计算复习优先级

**伪代码**：
```php

// 更新单词统计（以听写为主）
function updateWordStats($wordId, $reviewMode) {
    // 获取最近5次复习记录（区分听写和学习模式）
    $allReviews = getRecentReviews($wordId, 5);
    $dictationReviews = array_filter($allReviews, function($r) {
        return $r['review_mode'] == 'dictation';
    });
    $studyReviews = array_filter($allReviews, function($r) {
        return $r['review_mode'] == 'study';
    });
    
    // ===== 听写模式统计（主要）=====
    $dictationConsecutiveRemembered = 0;
    $dictationConsecutiveForgot = 0;
    
    // 听写模式连续记住次数（从最新到最旧）
    foreach ($dictationReviews as $review) {
        if ($review['quality'] == 5 && $review['should_advance'] == 1) {
            $dictationConsecutiveRemembered++;
        } else {
            break;
        }
    }
    
    // 听写模式连续忘记次数（从最新到最旧）
    foreach ($dictationReviews as $review) {
        if ($review['quality'] == 1) {
            $dictationConsecutiveForgot++;
        } else {
            break;
        }
    }
    
    // ===== 学习模式统计（辅助）=====
    $studyConsecutiveRemembered = 0;
    $studyConsecutiveForgot = 0;
    
    // 学习模式连续记住次数
    foreach ($studyReviews as $review) {
        if ($review['quality'] == 5 && $review['should_advance'] == 1) {
            $studyConsecutiveRemembered++;
        } else {
            break;
        }
    }
    
    // 学习模式连续忘记次数
    foreach ($studyReviews as $review) {
        if ($review['quality'] == 1) {
            $studyConsecutiveForgot++;
        } else {
            break;
        }
    }
    
    // ===== 综合统计（以听写为主）=====
    // 如果听写模式有记录，优先使用听写模式的统计
    // 如果听写模式没有记录，使用学习模式的统计
    $consecutiveRemembered = count($dictationReviews) > 0 
        ? $dictationConsecutiveRemembered 
        : $studyConsecutiveRemembered;
    
    $consecutiveForgot = count($dictationReviews) > 0 
        ? $dictationConsecutiveForgot 
        : $studyConsecutiveForgot;
    
    // 计算复习优先级（以听写为主）
    $priority = calculatePriority($wordId);
    
    // 更新words表
    updateWord([
        'last_review_date' => $today,
        'last_review_mode' => $reviewMode,
        'consecutive_remembered' => $consecutiveRemembered,
        'consecutive_forgot' => $consecutiveForgot,
        'review_priority' => $priority
    ]);
}
```

### 4.2 智能复习抽取逻辑（修改 `get_home_data` API）

**需求**：
- 第三天根据历史情况抽取需要复习的单词
- 复习量 = 新学单词量 × 50%

**算法设计（以听写为主）**：

```php
function getReviewWords($userId, $today, $newWordCount) {
    $reviewCount = ceil($newWordCount * 0.5); // 50%的复习量
    
    // 1. 最高优先级：听写模式连续忘记的单词（50%）
    $priority1 = getWordsByDictationCondition($userId, [
        'dictation_consecutive_forgot' => ['>=', 2], // 听写连续忘记2次以上
        'next_review' => ['<=', $today]
    ], $reviewCount * 0.5); // 50%给听写困难的单词
    
    // 2. 高优先级：听写模式有失败记录的单词（30%）
    $priority2 = getWordsByDictationCondition($userId, [
        'has_dictation_fail' => true, // 听写有失败记录
        'next_review' => ['<=', $today],
        'dictation_consecutive_forgot' => ['<', 2] // 但不是连续忘记2次以上
    ], $reviewCount * 0.3); // 30%给听写需要巩固的单词
    
    // 3. 中优先级：没有听写记录，但学习模式表现差的单词（10%）
    $remaining = $reviewCount - count($priority1) - count($priority2);
    $priority3 = getWordsByStudyCondition($userId, [
        'has_dictation_review' => false, // 没有听写记录
        'study_consecutive_forgot' => ['>=', 2], // 学习模式连续忘记2次以上
        'next_review' => ['<=', $today]
    ], $remaining * 0.5); // 10%的一半给学习模式表现差的单词
    
    // 4. 正常复习：按review_priority和next_review排序（剩余）
    $finalRemaining = $reviewCount - count($priority1) - count($priority2) - count($priority3);
    $priority4 = getWordsByCondition($userId, [
        'next_review' => ['<=', $today],
        'status' => ['!=', 'new']
    ], $finalRemaining, 'review_priority DESC, next_review ASC'); // 按优先级和日期排序
    
    return array_merge($priority1, $priority2, $priority3, $priority4);
}

// 判断是否需要复习（以听写为主）
function shouldReview($wordId, $today) {
    $word = getWord($wordId);
    $recentReviews = getRecentReviews($wordId, 5);
    
    // 分离听写模式和学习模式的记录
    $dictationReviews = array_filter($recentReviews, function($r) {
        return $r['review_mode'] == 'dictation';
    });
    $studyReviews = array_filter($recentReviews, function($r) {
        return $r['review_mode'] == 'study';
    });
    
    // ===== 优先判断听写模式 =====
    
    // 情况1：听写模式连续3次记住，且最后一次是7天前 → 一周后抽查
    if (count($dictationReviews) >= 3) {
        $allDictationRemembered = true;
        foreach ($dictationReviews as $review) {
            if ($review['quality'] != 5 || $review['should_advance'] != 1) {
                $allDictationRemembered = false;
                break;
            }
        }
        if ($allDictationRemembered) {
            $lastDictationDate = $dictationReviews[0]['review_date'];
            $daysSince = (strtotime($today) - strtotime($lastDictationDate)) / 86400;
            if ($daysSince >= 7) {
                return true; // 一周后抽查
            }
            return false; // 一周内不复习（听写表现好）
        }
    }
    
    // 情况2：听写模式每次都是忘记/模糊 → 第二天重点复习
    if (count($dictationReviews) >= 2) {
        $allDictationFailed = true;
        foreach ($dictationReviews as $review) {
            if ($review['quality'] == 5) {
                $allDictationFailed = false;
                break;
            }
        }
        if ($allDictationFailed) {
            $lastDictationDate = $dictationReviews[0]['review_date'];
            $daysSince = (strtotime($today) - strtotime($lastDictationDate)) / 86400;
            if ($daysSince >= 1) {
                return true; // 第二天重点复习（听写表现差）
            }
        }
    }
    
    // 情况3：听写模式有失败记录 → 需要复习
    if (count($dictationReviews) > 0) {
        $hasDictationFail = false;
        foreach ($dictationReviews as $review) {
            if ($review['quality'] < 5) {
                $hasDictationFail = true;
                break;
            }
        }
        if ($hasDictationFail && $word['next_review'] <= $today) {
            return true; // 听写有失败，需要复习
        }
    }
    
    // ===== 辅助判断学习模式（权重较低）=====
    
    // 情况4：如果没有听写记录，但有学习记录，且学习模式表现差 → 需要复习
    if (count($dictationReviews) == 0 && count($studyReviews) >= 2) {
        $allStudyFailed = true;
        foreach ($studyReviews as $review) {
            if ($review['quality'] == 5) {
                $allStudyFailed = false;
                break;
            }
        }
        if ($allStudyFailed && $word['next_review'] <= $today) {
            return true; // 学习模式表现差，需要复习（但优先级较低）
        }
    }
    
    // 情况5：学习模式连续3次记住，但没有听写验证 → 需要听写验证
    if (count($studyReviews) >= 3 && count($dictationReviews) == 0) {
        $allStudyRemembered = true;
        foreach ($studyReviews as $review) {
            if ($review['quality'] != 5 || $review['should_advance'] != 1) {
                $allStudyRemembered = false;
                break;
            }
        }
        if ($allStudyRemembered && $word['next_review'] <= $today) {
            return true; // 学习模式表现好，但需要听写验证
        }
    }
    
    // 情况6：按next_review判断（默认情况）
    return $word['next_review'] <= $today;
}
```

### 4.3 复习优先级计算（以听写为主，学习为辅）

```php
function calculatePriority($wordId) {
    $word = getWord($wordId);
    $recentReviews = getRecentReviews($wordId, 5);
    
    // 分离听写模式和学习模式的记录
    $dictationReviews = array_filter($recentReviews, function($r) {
        return $r['review_mode'] == 'dictation';
    });
    $studyReviews = array_filter($recentReviews, function($r) {
        return $r['review_mode'] == 'study';
    });
    
    $priority = 0;
    
    // ===== 听写模式权重（主要判断依据）=====
    
    // 1. 听写模式连续忘记次数（权重最高）
    $dictationConsecutiveForgot = 0;
    foreach ($dictationReviews as $review) {
        if ($review['quality'] == 1) {
            $dictationConsecutiveForgot++;
        } else {
            break;
        }
    }
    $priority += $dictationConsecutiveForgot * 20; // 听写忘记权重：20
    
    // 2. 听写模式连续模糊次数
    $dictationConsecutiveVague = 0;
    foreach ($dictationReviews as $review) {
        if ($review['quality'] == 3) {
            $dictationConsecutiveVague++;
        } else {
            break;
        }
    }
    $priority += $dictationConsecutiveVague * 12; // 听写模糊权重：12
    
    // 3. 听写模式连续记住次数（降低优先级）
    $dictationConsecutiveRemembered = 0;
    foreach ($dictationReviews as $review) {
        if ($review['quality'] == 5 && $review['should_advance'] == 1) {
            $dictationConsecutiveRemembered++;
        } else {
            break;
        }
    }
    $priority -= $dictationConsecutiveRemembered * 5; // 听写记住降低优先级：-5
    
    // 4. 听写模式总失败率（忘记+模糊）
    $dictationTotal = count($dictationReviews);
    if ($dictationTotal > 0) {
        $dictationFailCount = count(array_filter($dictationReviews, function($r) {
            return $r['quality'] < 5;
        }));
        $dictationFailRate = $dictationFailCount / $dictationTotal;
        $priority += $dictationFailRate * 15; // 听写失败率权重：15
    }
    
    // ===== 学习模式权重（辅助判断）=====
    
    // 5. 学习模式连续忘记次数（权重较低）
    $studyConsecutiveForgot = 0;
    foreach ($studyReviews as $review) {
        if ($review['quality'] == 1) {
            $studyConsecutiveForgot++;
        } else {
            break;
        }
    }
    $priority += $studyConsecutiveForgot * 5; // 学习忘记权重：5（比听写低）
    
    // 6. 学习模式连续模糊次数
    $studyConsecutiveVague = 0;
    foreach ($studyReviews as $review) {
        if ($review['quality'] == 3) {
            $studyConsecutiveVague++;
        } else {
            break;
        }
    }
    $priority += $studyConsecutiveVague * 3; // 学习模糊权重：3
    
    // 7. 学习模式连续记住次数（降低优先级，但影响较小）
    $studyConsecutiveRemembered = 0;
    foreach ($studyReviews as $review) {
        if ($review['quality'] == 5 && $review['should_advance'] == 1) {
            $studyConsecutiveRemembered++;
        } else {
            break;
        }
    }
    $priority -= $studyConsecutiveRemembered * 1; // 学习记住降低优先级：-1（影响很小）
    
    // ===== 其他因素 =====
    
    // 8. 距离上次复习时间越长，优先级越高
    if ($word['last_review_date']) {
        $daysSince = (strtotime($today) - strtotime($word['last_review_date'])) / 86400;
        $priority += min($daysSince, 7) * 2; // 最多7天
    }
    
    // 9. ef_factor越低（越难），优先级越高
    $priority += (3.0 - $word['ef_factor']) * 3;
    
    // 10. 如果只有学习模式记录，没有听写记录，提高优先级（需要听写验证）
    if (count($dictationReviews) == 0 && count($studyReviews) > 0) {
        $priority += 8; // 需要听写验证
    }
    
    return max(0, $priority); // 确保不为负数
}
```

## 五、数据流程示例

### 场景：第一天学习10个单词

## 六、优化建议

### 6.1 数据库优化
1. **索引优化**：
   - `word_review_logs` 表需要 `(word_id, review_date)` 联合索引
   - `words` 表需要 `(user_id, review_priority DESC, next_review)` 联合索引

2. **数据归档**：
   - 超过90天的复习记录可以归档到历史表
   - 减少主表数据量，提高查询性能

### 6.2 算法优化（以听写为主）
1. **复习优先级动态调整**：
   - **听写模式权重占主导**：听写失败权重（20）远高于学习失败权重（5）
   - 根据用户的听写表现动态调整权重
   - 例如：如果用户听写模式表现差，进一步提高听写失败权重

2. **复习量动态调整**：
   - 不是固定50%，可以根据用户的听写掌握速度调整
   - 例如：如果听写模式掌握速度快，可以降低到30%
   - 如果听写模式掌握速度慢，可以提高到70%
   - **重点**：听写模式表现差的单词，复习量可以提高到80%

3. **遗忘曲线优化**：
   - **听写模式的遗忘曲线优先**：听写模式的表现更真实反映掌握情况
   - 结合艾宾浩斯遗忘曲线和SM-2算法
   - 根据听写模式的历史数据优化 `ef_factor` 的计算
   - 学习模式的数据作为辅助参考

### 6.3 用户体验优化
1. **复习提醒**：
   - 显示"这个单词你已经连续忘记3次了，加油！"
   - 显示"这个单词你已经连续记住3次了，很棒！"

2. **学习报告（以听写为主）**：
   - 显示每个单词的复习历史（**突出显示听写模式记录**）
   - **重点显示听写模式和学习模式的效果对比**（听写模式用红色/绿色标识）
   - **优先显示听写模式表现差的单词**（需要重点关注）
   - 显示"这个单词听写模式连续失败3次，需要重点复习"
   - 显示"这个单词听写模式连续记住3次，可以一周后再复习"

3. **自适应学习**：
   - 根据用户的表现自动调整复习策略
   - 例如：如果某个单词连续5次记住，可以标记为"已掌握"，减少复习频率
