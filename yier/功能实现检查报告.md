## 四、复习间隔逻辑（SM-2算法）

### ✅ 已实现

**位置**：`api.php` - `submit_review` API

**实现情况**：

#### 答对后的处理：
- ✅ **会隔一段时间再复习**（不是下一次就不复习）
- ✅ 第1次答对：间隔 **1天**（line 991）
- ✅ 第2次答对：间隔 **6天**（line 994）
- ✅ 第3次及以后：间隔 = **round(当前间隔 × ef_factor)**（line 996）
- ✅ 间隔逐渐增加：1天 → 6天 → 12天 → 24天...

#### 答错后的处理：
- ✅ 间隔缩短：**1天**（明天重点复习）（line 1020）
- ✅ EF因子降低：`ef_factor - 0.2`（line 1019）
- ✅ 重置复习次数：`repetitions = 0`（line 1018）

#### 状态转换：
- ✅ `repetitions >= 5 && ef_factor >= 2.5` → `status = 'mastered'`（line 1005-1006）
- ✅ `repetitions >= 3` → `status = 'review'`（line 1007-1008）
- ✅ 其他 → `status = 'learning'`（line 1009-1010）

#### 复习单词查询：
- ✅ 查询条件：`status != 'new' AND next_review <= today`（line 758）
- ✅ **即使 `status='mastered'`，只要 `next_review <= today`，仍然会复习**

**代码位置**：
- `api.php` line 982-1014：复习间隔计算
- `api.php` line 758：复习单词查询条件
