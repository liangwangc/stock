### 1.3 PK页面（get_rankings API）

**当前显示：**
- **学习单词数**：使用`word_review_logs`表统计实际学习过的单词数
- **完成率**：`(平均每日学习数 / daily_goal) * 100`
  - 平均每日学习数 = 总学习单词数 / 学习天数
  - 如果只有1天数据：`(今天学习的单词数 / daily_goal) * 100`

**新需求逻辑：**
- **学习单词数**：基于实际学习记录，不需要修改
- **完成率**：需要考虑新的总任务量逻辑
  - 第1天：总任务量 = `daily_goal`
  - 第2天：总任务量 = `daily_goal * 2`
  - 第3天及以后：总任务量 = `daily_goal * 2.4`

**是否需要修改：** ✅ **需要修改**

**修改建议：**
1. 完成率计算需要考虑不同天数的总任务量
2. 第1天：`(实际学习数 / daily_goal) * 100`
3. 第2天：`(实际学习数 / (daily_goal * 2)) * 100`
4. 第3天及以后：`(实际学习数 / (daily_goal * 2.4)) * 100`

**问题：**
- PK页面是按周期统计的（今日、本周、本月、本年），不是按单天统计
- 如何计算完成率？是使用平均每日任务量，还是使用实际总任务量？

**建议方案：**
- **方案1**：使用平均每日任务量（推荐）
  - 第1天：`daily_goal`
  - 第2天：`daily_goal * 1.5`（平均）
  - 第3天及以后：`daily_goal * 2.4`（固定）
  - 完成率 = `(平均每日学习数 / 平均每日任务量) * 100`
  
- **方案2**：使用实际总任务量
  - 需要知道用户是第几天，然后使用对应的总任务量
  - 完成率 = `(实际学习数 / 实际总任务量) * 100`

### 2.2 PK页面完成率计算

**当前代码位置：** `api.php` - `get_rankings` API

**当前逻辑：**
```php
// 完成率计算
if ($study_days > 0 && $daily_goal > 0) {
    $avg_daily_words = $total_words / $study_days;
    $completion_rate = round(min(100, ($avg_daily_words / $daily_goal) * 100), 1);
} elseif ($total_words > 0 && $daily_goal > 0) {
    $completion_rate = round(min(100, ($total_words / $daily_goal) * 100), 1);
}
```

**问题：**
- 当前使用`daily_goal`作为分母，但实际总任务量是变化的
- 第1天：`daily_goal`
- 第2天：`daily_goal * 2`
- 第3天及以后：`daily_goal * 2.4`

**修改建议：**
- **方案1**：使用平均每日任务量
  ```php
  // 计算平均每日任务量
  // 第1天：daily_goal
  // 第2天：daily_goal * 2
  // 第3天及以后：daily_goal * 2.4
  // 平均每日任务量 = (第1天任务量 + 第2天任务量 + 第3天及以后任务量) / 学习天数
  // 简化：如果学习天数 >= 3，使用 daily_goal * 2.4
  // 如果学习天数 == 2，使用 daily_goal * 1.5
  // 如果学习天数 == 1，使用 daily_goal
  
  if ($study_days >= 3) {
      $avg_daily_task = $daily_goal * 2.4;
  } elseif ($study_days == 2) {
      $avg_daily_task = $daily_goal * 1.5; // (daily_goal + daily_goal * 2) / 2
  } else {
      $avg_daily_task = $daily_goal;
  }
  
  $completion_rate = round(min(100, ($avg_daily_words / $avg_daily_task) * 100), 1);
  ```

- **方案2**：使用实际总任务量（需要知道每天的任务量）
  - 需要查询用户每天的学习情况，然后计算实际总任务量
  - 比较复杂，不推荐
