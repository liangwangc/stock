# 学习队列数量问题修复方案

## 📋 问题分析

### 问题1：新单词只有7个，应该是10个

**原因：**
1. **单词库导入不足**：如果单词库中没有足够的单词，或者导入失败，就无法达到10个
2. **手动录入不足**：如果用户手动录入了3个单词，单词库导入了4个单词，总共7个，不足10个
3. **导入逻辑问题**：`importWordBankWords` 函数可能没有强制导入到10个

**当前逻辑：**
```php
// 计算还需要导入的数量
$need_import = max(0, $daily_goal - $today_manual - $today_imported);

// 如果单词库中没有足够的单词，就无法导入
if (empty($bank_words)) {
    return ['imported' => 0, ...];
}
```

**问题：**
- ⚠️ 如果单词库中没有足够的单词，就不会导入，导致新单词不足10个
- ⚠️ 没有提示用户单词库不足

### 问题2：复习单词是13个，应该是14个

**原因：**
1. **昨天学习的单词不是10个**：如果昨天实际学习了7个单词（不是10个），那么复习单词就是7个（昨天）+ 4个（40%）= 11个
2. **日历显示的统计逻辑**：日历显示是按照 `status` 字段来分类的，可能不准确

**当前逻辑：**
- 日历显示：`status='new'` → "新词"，`status!='new'` → "复习"
- 但是，今天复习过的单词（`review_date = 今天`）的 `status` 可能不是 `'new'`，所以显示为"复习"

**问题：**
- ⚠️ 日历显示的统计可能不准确
- ⚠️ 需要检查昨天实际学习了多少个单词

---

## 🔧 解决方案

### 方案1：确保新单词数量达到10个

**修改 `importWordBankWords` 函数：**

1. **强制导入到10个**
   - 如果手动录入+单词库导入不足10个，继续从单词库导入
   - 如果单词库中没有足够的单词，提示用户

2. **添加提示信息**
   - 如果导入不足，返回提示信息
   - 前端显示提示，告知用户单词库不足

### 方案2：修复日历显示的统计逻辑

**修改 `day_details` API：**

1. **返回统计信息**
   - 返回新单词数量（`date_added = 指定日期` 且 `status='new'`）
   - 返回复习单词数量（`review_date = 指定日期`）

2. **修改前端显示**
   - 在日历弹窗中显示统计信息
   - 显示"新单词：X个，复习单词：Y个"
