# 复习单词选择逻辑详细说明

## 一、问题1：如果第一天学习+听力状态都很好，什么时候会安排复习？

### 1.1 复习间隔计算（SM-2算法）

**第1天学习+听力状态都很好（都答对了）**：

#### 第1次学习（学习模式，答对了）：
- `repetitions = 0 → 1`
- `ef_factor = 2.5 → 2.6`（增加）
- `interval_days = 1`
- `next_review = 第2天`（明天）

#### 第1次复习（听写模式，答对了）：
- `repetitions = 1 → 2`
- `ef_factor = 2.6 → 2.7`（增加）
- `interval_days = 6`
- `next_review = 第8天`（第2天 + 6天）

#### 第2次复习（如果第8天答对了）：
- `repetitions = 2 → 3`
- `ef_factor = 2.7 → 2.8`（增加）
- `interval_days = round(6 × 2.8) = 17`
- `next_review = 第25天`（第8天 + 17天）

#### 第3次复习（如果第25天答对了）：
- `repetitions = 3 → 4`
- `ef_factor = 2.8 → 2.9`（增加）
- `interval_days = round(17 × 2.9) = 49`
- `next_review = 第74天`（第25天 + 49天）

#### 第4次复习（如果第74天答对了）：
- `repetitions = 4 → 5`
- `ef_factor = 2.9 → 3.0`（增加）
- `interval_days = round(49 × 3.0) = 147`
- `next_review = 第221天`（第74天 + 147天）
- `status = 'mastered'`（已掌握）

### 1.2 答案总结

**如果第一天学习+听力状态都很好**：
- ✅ **第2天会安排复习**（`next_review = 第2天`）
- ✅ **第8天会安排复习**（`next_review = 第8天`）
- ✅ **第25天会安排复习**（`next_review = 第25天`）
- ✅ **间隔逐渐增加**：1天 → 6天 → 17天 → 49天 → 147天...
- ✅ **即使状态变为"已掌握"（mastered），仍然会定期复习**

**关键点**：
- 状态好的单词**不会停止复习**，只是**间隔会逐渐增加**
- 这是**间隔重复算法**的核心原理，帮助形成长期记忆

## 二、问题2：40%的复习中，会有一部分单词状态好的进来吗？

### 2.1 复习单词的查询条件

**查询条件**：
```sql
WHERE status != 'new' AND next_review <= today
```

**说明**：
- ✅ 只要`next_review <= 今天`，单词就会出现在复习列表中
- ✅ **不管状态好坏**，只要到了复习时间，就会出现在列表中
- ✅ 包括：
  - 状态好的单词（`status='mastered'`，但`next_review <= 今天`）
  - 状态差的单词（`status='learning'`，`next_review <= 今天`）
  - 正常复习的单词（`status='review'`，`next_review <= 今天`）

### 2.2 优先级排序逻辑

**排序规则**：`ORDER BY calculated_priority DESC, w.next_review ASC`

**优先级分数计算**：

#### 优先级1：听写模式连续忘记2次以上（分数：1000+）
```sql
WHEN COUNT(CASE WHEN rl_dict.review_mode = 'dictation' AND rl_dict.quality = 1 THEN 1 END) >= 2 
THEN 1000 + w.review_priority
```
- **状态**：表现最差
- **优先级**：最高（1000+）

#### 优先级2：听写模式有失败记录但少于2次（分数：500+）
```sql
WHEN COUNT(CASE WHEN rl_dict.review_mode = 'dictation' AND rl_dict.quality < 5 THEN 1 END) > 0
THEN 500 + w.review_priority
```
- **状态**：表现较差
- **优先级**：较高（500+）

#### 优先级3：没有听写记录，但学习模式表现差（分数：200+）
```sql
WHEN COUNT(CASE WHEN rl_dict.review_mode = 'dictation' THEN 1 END) = 0
AND COUNT(CASE WHEN rl_study.review_mode = 'study' AND rl_study.quality = 1 THEN 1 END) >= 2
THEN 200 + w.review_priority
```
- **状态**：表现一般
- **优先级**：中等（200+）

#### 优先级4：正常复习（分数：review_priority）
```sql
ELSE w.review_priority
```
- **状态**：表现好或正常
- **优先级**：正常（review_priority，通常较小）

**第二排序**：`w.next_review ASC`（如果优先级相同，按`next_review`升序，越早的越优先）

### 2.3 40%复习单词的选择逻辑

**选择过程**：

1. **查询所有需要复习的单词**：
   ```sql
   WHERE status != 'new' AND next_review <= today
   ```
   - 包括状态好的单词（`mastered`，但`next_review <= 今天`）
   - 包括状态差的单词（`learning`，`next_review <= 今天`）
   - 包括正常复习的单词（`review`，`next_review <= 今天`）

2. **按优先级排序**：
   - 优先级1（1000+）：表现最差的单词
   - 优先级2（500+）：表现较差的单词
   - 优先级3（200+）：表现一般的单词
   - 优先级4（review_priority）：表现好的单词

3. **选择前40%**：
   ```sql
   LIMIT review_count_target  -- 例如：daily_goal=10，则review_count_target=4
   ```

### 2.4 答案总结

**40%的复习中，会有一部分单词状态好的进来吗？**

**答案**：**会的，但优先级较低**

**具体情况**：

1. **如果表现差的单词很多**：
   - ✅ 40%的复习单词**主要是表现差的单词**（优先级1、2、3）
   - ✅ 状态好的单词**可能不会进入**40%的复习列表（因为优先级低）

2. **如果表现差的单词较少**：
   - ✅ 40%的复习单词**会包括状态好的单词**（优先级4）
   - ✅ 因为表现差的单词不够40%，所以会补充状态好的单词

3. **如果所有单词状态都很好**：
   - ✅ 40%的复习单词**全部是状态好的单词**
   - ✅ 按`next_review`排序，越早的越优先

### 2.5 具体示例

**示例1：表现差的单词很多**

假设：
- `daily_goal = 10`
- `review_count_target = 4`（40%）
- 需要复习的单词：
  - 优先级1（1000+）：5个（表现最差）
  - 优先级2（500+）：3个（表现较差）
  - 优先级3（200+）：2个（表现一般）
  - 优先级4（review_priority）：10个（表现好）

**结果**：
- ✅ 40%的复习单词 = 4个
- ✅ 选择：优先级1的5个中选4个（或优先级1的5个 + 优先级2的3个中选4个）
- ❌ 状态好的单词（优先级4）**不会进入**40%的复习列表

**示例2：表现差的单词较少**

假设：
- `daily_goal = 10`
- `review_count_target = 4`（40%）
- 需要复习的单词：
  - 优先级1（1000+）：1个（表现最差）
  - 优先级2（500+）：1个（表现较差）
  - 优先级3（200+）：1个（表现一般）
  - 优先级4（review_priority）：10个（表现好）

**结果**：
- ✅ 40%的复习单词 = 4个
- ✅ 选择：优先级1的1个 + 优先级2的1个 + 优先级3的1个 + 优先级4的1个
- ✅ 状态好的单词（优先级4）**会进入**40%的复习列表

**示例3：所有单词状态都很好**

假设：
- `daily_goal = 10`
- `review_count_target = 4`（40%）
- 需要复习的单词：
  - 优先级4（review_priority）：10个（表现好）

**结果**：
- ✅ 40%的复习单词 = 4个
- ✅ 选择：优先级4的10个中选4个（按`next_review`排序，越早的越优先）
- ✅ 40%的复习单词**全部是状态好的单词**

## 三、总结

### 3.1 问题1的答案

**如果第一天学习+听力状态都很好，什么时候会安排复习？**

- ✅ **第2天会安排复习**（`next_review = 第2天`）
- ✅ **第8天会安排复习**（`next_review = 第8天`）
- ✅ **间隔逐渐增加**：1天 → 6天 → 17天 → 49天 → 147天...
- ✅ **即使状态变为"已掌握"（mastered），仍然会定期复习**

### 3.2 问题2的答案

**40%的复习中，会有一部分单词状态好的进来吗？**

- ✅ **会的，但优先级较低**
- ✅ **如果表现差的单词很多**：40%主要是表现差的单词，状态好的单词可能不会进入
- ✅ **如果表现差的单词较少**：40%会包括状态好的单词
- ✅ **如果所有单词状态都很好**：40%全部是状态好的单词

### 3.3 关键点

1. **复习单词不会丢失**：
   - 只要`next_review <= 今天`，单词就会出现在复习列表中
   - 不管状态好坏，只要到了复习时间，就会出现在列表中

2. **优先级排序**：
   - 表现差的单词优先级高（优先复习）
   - 表现好的单词优先级低（后复习）

3. **40%的选择逻辑**：
   - 优先选择表现差的单词（优先级1、2、3）
   - 如果表现差的单词不够，会补充表现好的单词（优先级4）

4. **状态好的单词也会复习**：
   - 即使状态很好，只要`next_review <= 今天`，仍然会出现在复习列表中
   - 这是**间隔重复算法**的核心原理，帮助形成长期记忆
