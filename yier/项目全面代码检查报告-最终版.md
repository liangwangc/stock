### 1.1 第一次登录判断逻辑不准确 ⚠️ **高优先级**

**问题位置：** `api.php` - `calculateTotalTask()` 和 `prepare_study_queue()` (第72-85行, 第2472行)

**当前逻辑：**
```php
$is_first_login = ($total_words == 0) || ($words_before_today == 0 && $total_words > 0);
```

**问题分析：**
- ❌ 如果用户今天添加了单词但还没学习，会被判断为"第一次登录"
- ❌ 应该检查是否有**学习记录**（`word_review_logs`表），而不是只检查`words`表的`date_added`
- ❌ `date_added`表示添加日期，不是学习日期

**修复建议：**
```php
// 检查是否有学习记录（word_review_logs表）
function isFirstLogin($conn, $user_id, $today) {
    // 检查word_review_logs表是否存在
    $check_table = $conn->query("SHOW TABLES LIKE 'word_review_logs'");
    if ($check_table && $check_table->num_rows > 0) {
        // 使用word_review_logs表判断
        $stmt = prepare_check($conn, "
            SELECT COUNT(*) as learning_count
            FROM word_review_logs
            WHERE user_id = ? AND review_date < ?
        ");
        $stmt->bind_param("is", $user_id, $today);
        $stmt->execute();
        $result = $stmt->get_result()->fetch_assoc();
        return (int)($result['learning_count'] ?? 0) == 0;
    } else {
        // 回退到旧逻辑（兼容性）
        $stmt = prepare_check($conn, "
            SELECT COUNT(*) as total_words, 
                   COUNT(CASE WHEN date_added < ? THEN 1 END) as words_before_today
            FROM words 
            WHERE user_id = ?
        ");
        $stmt->bind_param("si", $today, $user_id);
        $stmt->execute();
        $user_history = $stmt->get_result()->fetch_assoc();
        $total_words = (int)($user_history['total_words'] ?? 0);
        $words_before_today = (int)($user_history['words_before_today'] ?? 0);
        return ($total_words == 0) || ($words_before_today == 0 && $total_words > 0);
    }
}
```

**影响范围：**
- `calculateTotalTask()` - 总任务量计算
- `prepare_study_queue()` - 学习队列准备
- `get_home_data()` - 首页数据显示

### 1.2 连续打卡天数计算不准确 ⚠️ **高优先级**

**问题位置：** `api.php` - `calculateCheckInStreak()` (第146-183行)

**当前逻辑：**
```php
$stmt = $conn->prepare("SELECT DISTINCT date_added FROM words WHERE user_id = ? ORDER BY date_added DESC LIMIT 30");
```

**问题分析：**
- ❌ 使用`words.date_added`（添加日期）而不是`word_review_logs.review_date`（学习日期）
- ❌ 如果用户今天添加了单词但没学习，会被计入连续打卡
- ❌ 应该基于**实际学习日期**计算

**修复建议：**
```php
function calculateCheckInStreak($conn, $user_id, $today) {
    // 检查word_review_logs表是否存在
    $check_table = $conn->query("SHOW TABLES LIKE 'word_review_logs'");
    if ($check_table && $check_table->num_rows > 0) {
        // 使用word_review_logs表（更准确）
        $stmt = $conn->prepare("SELECT DISTINCT review_date FROM word_review_logs WHERE user_id = ? ORDER BY review_date DESC LIMIT 30");
    } else {
        // 回退到旧逻辑（兼容性）
        $stmt = $conn->prepare("SELECT DISTINCT date_added FROM words WHERE user_id = ? ORDER BY date_added DESC LIMIT 30");
    }
    $stmt->bind_param("i", $user_id);
    $stmt->execute();
    $result = $stmt->get_result();
    
    $dates = [];
    while ($row = $result->fetch_assoc()) {
        $dates[] = $row['review_date'] ?? $row['date_added'];
    }
    
    if (empty($dates)) {
        return 0;
    }
    
    // 检查今天是否有学习记录
    $has_today = in_array($today, $dates);
    $check_date = $has_today ? $today : date('Y-m-d', strtotime("$today -1 day"));
    
    $streak = 0;
    $current_date = $check_date;
    
    foreach ($dates as $date) {
        if ($date === $current_date) {
            $streak++;
            $current_date = date('Y-m-d', strtotime("$current_date -1 day"));
        } elseif ($date < $current_date) {
            break;
        }
    }
    
    return $streak;
}
```

**影响范围：**
- PK页面排行榜
- 学习统计页面
- 首页连续打卡显示

$stmt = $conn->prepare("SELECT LOWER(word) as word FROM words WHERE user_id = ?");
$stmt->bind_param("i", $user_id);
$stmt->execute();
$imported_words = [];
$result = $stmt->get_result();

## 📊 五、数据一致性问题

### 5.1 words表和word_review_logs表数据不一致 ⚠️ **高优先级**

**问题位置：** 多个API函数

**问题分析：**
- ⚠️ 有些查询使用`words.date_added`
- ⚠️ 有些查询使用`word_review_logs.review_date`
- ⚠️ 两个字段的含义不同：
  - `date_added`：单词添加日期
  - `review_date`：单词学习/复习日期

**影响：**
- 统计不准确
- 连续打卡计算不准确
- 第一次登录判断不准确

**修复建议：**
- 统一使用`word_review_logs.review_date`作为学习日期
- `words.date_added`仅用于记录添加日期
- 所有学习相关的统计都基于`word_review_logs`表
