# 复习逻辑优化说明

## 一、优化需求

### 1.1 原有逻辑
- 第一天：5个新单词，没有复习单词
- 第二天：40%复习（2个）+ 60%新单词（3个）= 5个
- 第三天：40%复习（2个）+ 60%新单词（3个）= 5个

### 1.2 优化后的逻辑

**第一天**：
- 5个新单词，没有复习单词

**第二天**：
- 复习：前一天学习的所有新单词（5个）
- 新单词：固定数量（5个，daily_goal）
- 总计：10个

**第三天**：
- 复习：前一天学习的所有新单词（5个）
- 新单词：固定数量（5个，daily_goal）
- 其他复习单词：40%的复习单词（基于next_review，2个）
- 总计：12个

**第四天及以后**：
- 复习：前一天学习的所有新单词（5个）
- 新单词：固定数量（5个，daily_goal）
- 其他复习单词：40%的复习单词（基于next_review）
- 总计：10个 + 其他复习单词

## 二、实现逻辑

### 2.1 代码修改

**修改位置**：`api.php` 的 `prepare_study_queue` API

**修改内容**：

1. **获取前一天学习的所有新单词**：
   ```php
   $yesterday = date('Y-m-d', strtotime("$today -1 day"));
   SELECT w.* FROM words w
   WHERE w.user_id = ? AND w.date_added = ?
   ```

2. **获取基于next_review的复习单词**（现有逻辑，40%）：
   ```php
   SELECT w.*, ...
   FROM words w
   WHERE w.user_id = ? 
     AND w.status != 'new' 
     AND w.next_review <= ?
     AND w.date_added != ?  -- 排除前一天学习的单词
   ORDER BY calculated_priority DESC, w.next_review ASC
   LIMIT remaining_review_target
   ```

3. **合并复习单词**：
   ```php
   $list_reviews = array_merge($yesterday_words, $list_reviews_by_next_review);
   ```
   - 前一天学习的单词优先级最高（先复习）
   - 然后是基于next_review的复习单词

### 2.2 关键点

1. **不改变现有复习逻辑**：
   - 保持40%的复习单词逻辑（基于next_review）
   - 保持优先级排序逻辑（表现差的单词优先）

2. **增加前一天学习的单词**：
   - 从第二天开始，每天都会复习前一天学习的所有新单词
   - 这些单词优先级最高（先复习）

3. **新单词数量固定**：
   - 新单词数量 = daily_goal（固定）
   - 不受复习单词数量影响

## 四、注意事项

### 4.1 复习单词数量可能超过daily_goal

**情况**：
- 如果前一天学习的单词数量 > daily_goal，复习单词数量会超过daily_goal
- 例如：第1天学习了10个单词，daily_goal=5，第2天复习单词=10个

**处理**：
- ✅ 这是正常的，因为需要复习前一天学习的所有单词
- ✅ 新单词数量仍然保持固定（daily_goal）

### 4.2 其他复习单词的数量计算

**逻辑**：
- `remaining_review_target = max(0, review_count_target - yesterday_review_count)`
- 如果前一天学习的单词数量 >= 40%，其他复习单词数量 = 0
- 如果前一天学习的单词数量 < 40%，其他复习单词数量 = 40% - 前一天学习的单词数量

**示例**：
- daily_goal = 10，review_count_target = 4（40%）
- 前一天学习的单词 = 5个
- remaining_review_target = max(0, 4 - 5) = 0
- 其他复习单词 = 0个

## 五、总结

### 5.1 优化效果

1. ✅ **保证复习**：前一天学习的所有单词都会在第二天复习
2. ✅ **固定新单词**：新单词数量保持固定（daily_goal）
3. ✅ **保持现有逻辑**：不改变基于next_review的复习逻辑
4. ✅ **优先级排序**：前一天学习的单词优先级最高

### 5.2 关键点

- **第一天**：只有新单词，没有复习单词
- **第二天开始**：复习前一天学习的所有新单词 + 固定新单词数量 + 其他复习单词（40%）
- **不改变现有逻辑**：保持40%的复习单词逻辑和优先级排序
