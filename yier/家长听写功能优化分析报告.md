# 家长听写功能优化分析报告

## 📋 一、当前功能状态分析

### 1.1 当前实现逻辑

**功能位置：** `index.html` 第757-759行（卡片学习模式）

**三个状态按钮：**
```html
<button onclick="app.rate(1, false)">忘记</button>  <!-- shouldAdvance=false，不跳转 -->
<button onclick="app.rate(3, false)">模糊</button>  <!-- shouldAdvance=false，弹出确认对话框 -->
<button onclick="app.rate(5, true)">记住</button>   <!-- shouldAdvance=true，立即跳转 -->
```

**当前行为：**
1. **忘记按钮**：点击后不跳转，继续学习当前单词，可以多次点击
2. **模糊按钮**：点击后弹出确认对话框，用户选择"继续学习"或"跳过"
3. **记住按钮**：点击后立即跳转到下一个单词

### 1.2 用户反馈的问题

1. ❌ **"只点击一次就进入下一个页面"**：用户希望所有按钮点击一次就跳转
2. ❌ **"忘记、模糊不需要根据状态一直点击"**：用户不希望多次点击，点击一次就应该记录并跳转
3. ✅ **使用场景**：小朋友已经在书本学习后，由家长来抽查，只需要记录状态即可

## 🔍 二、需求分析

### 2.1 用户真实需求

**核心需求：**
- ✅ 家长抽查模式：点击一次状态按钮，记录状态，立即跳转到下一个单词
- ✅ 不需要多次点击：忘记、模糊、记住都只点击一次
- ✅ 简化流程：不需要确认对话框，不需要根据状态决定是否跳转

**期望行为：**
```
显示单词 → 家长点击状态（忘记/模糊/记住）→ 记录状态 → 立即跳转下一个单词
```

### 2.2 与当前逻辑的差异

| 项目 | 当前逻辑 | 期望逻辑 |
|------|---------|---------|
| **忘记按钮** | 点击不跳转，可多次点击 | 点击一次，记录状态，立即跳转 |
| **模糊按钮** | 点击弹出确认对话框 | 点击一次，记录状态，立即跳转 |
| **记住按钮** | 点击立即跳转 ✅ | 点击立即跳转 ✅ |
| **确认对话框** | 模糊按钮需要确认 | 不需要确认对话框 |

#### 1. **复习计划更新逻辑** (`api.php` 第1152-1219行)

**当前逻辑：**
```php

// 2. 模糊（quality=3）且确认跳转：更新
```

**修改后：**
```php

    // 更新复习计划

```

**影响：**
- ✅ **忘记的单词**：现在会更新复习计划（降低EF因子，明天重点复习）
- ✅ **模糊的单词**：现在会更新复习计划（保持当前状态，略微增加EF因子）
- ✅ **记住的单词**：保持不变（正常推进）
