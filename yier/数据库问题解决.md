# 数据库问题解决指南

## ❌ 错误信息

```
Database Connection Failed: Unknown database 'word_app'
```

**原因：** 数据库 `word_app` 不存在，需要先创建数据库。

## ✅ 解决方案

### 方法1：使用自动创建脚本（推荐）

**双击运行：**
```
创建数据库.bat
```

这个脚本会自动：
1. ✅ 查找 MySQL
2. ✅ 检查 MySQL 服务状态
3. ✅ 创建 `word_app` 数据库
4. ✅ 导入数据库结构
5. ✅ 升级数据库（添加新功能）

### 方法2：手动创建（使用 MySQL 命令行）

#### 步骤1：打开 MySQL 命令行

**如果使用 XAMPP：**
```bash
C:\xampp\mysql\bin\mysql.exe -u root
```

**如果使用 WAMP：**
```bash
C:\wamp64\bin\mysql\mysql8.0.31\bin\mysql.exe -u root
```

**如果 MySQL 在系统 PATH 中：**
```bash
mysql -u root -p
```

#### 步骤2：创建数据库

```sql
CREATE DATABASE word_app CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE word_app;
```

#### 步骤3：导入数据库结构

**在命令行中：**
```bash
# 退出 MySQL（输入 exit）
# 然后执行：
mysql -u root word_app < word_app_backup_20260129.sql
```

**或在 MySQL 中：**
```sql
SOURCE d:/wjw_work/yier/word_app_backup_20260129.sql;
```

#### 步骤4：升级数据库（添加新功能）

```bash
mysql -u root word_app < database_upgrade.sql
```

### 方法3：使用 phpMyAdmin（图形界面）

#### 步骤1：打开 phpMyAdmin

- XAMPP: 在 XAMPP Control Panel 点击 MySQL 的 "Admin" 按钮
- WAMP: 访问 `http://localhost/phpmyadmin`

#### 步骤2：创建数据库

1. 点击左侧 "新建"
2. 数据库名：`word_app`
3. 排序规则：`utf8mb4_unicode_ci`
4. 点击 "创建"

#### 步骤3：导入数据库

1. 选择 `word_app` 数据库
2. 点击 "导入" 标签
3. 选择文件：`word_app_backup_20260129.sql`
4. 点击 "执行"

#### 步骤4：升级数据库

1. 确保已选择 `word_app` 数据库
2. 点击 "导入" 标签
3. 选择文件：`database_upgrade.sql`
4. 点击 "执行"

## 🔍 检查数据库是否创建成功

### 方法1：使用 MySQL 命令行

```sql
SHOW DATABASES;
USE word_app;
SHOW TABLES;
```

应该看到：
- `users` 表
- `words` 表
- `login_logs` 表（如果执行了升级脚本）

### 方法2：使用 phpMyAdmin

1. 打开 phpMyAdmin
2. 左侧应该能看到 `word_app` 数据库
3. 点击查看，应该能看到所有表

## ⚠️ 常见问题

### Q: MySQL 服务未启动？

**解决方法：**
- XAMPP: 打开 XAMPP Control Panel，点击 MySQL 的 "Start" 按钮
- WAMP: 确保 MySQL 服务运行（系统托盘图标）

### Q: 找不到 MySQL 命令？

**解决方法：**
1. 使用完整路径：
   - XAMPP: `C:\xampp\mysql\bin\mysql.exe`
   - WAMP: `C:\wamp64\bin\mysql\mysql8.0.31\bin\mysql.exe`

2. 或使用 phpMyAdmin（图形界面）

### Q: 导入时提示权限错误？

**解决方法：**
1. 确保使用 root 用户
2. 检查 MySQL 用户权限
3. 或使用 phpMyAdmin

### Q: 数据库密码不是空？

**解决方法：**
1. 修改 `api.php` 第20行的密码：
   ```php
   $db_pass = '你的密码';
   ```

2. 修改 `创建数据库.bat` 中的密码：
   ```bat
   set DB_PASS=你的密码
   ```

### Q: 导入后还是报错？

**检查项：**
1. ✅ 数据库 `word_app` 是否存在
2. ✅ 表 `users` 和 `words` 是否存在
3. ✅ `api.php` 中的数据库配置是否正确
4. ✅ MySQL 服务是否运行
