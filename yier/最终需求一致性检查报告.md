function calculateTotalTask($conn, $uid, $daily_goal, $today) {
    $is_first_login = isFirstLogin($conn, $uid, $today);

}

## 🔍 其他潜在问题检查

### 1. ⚠️ 第2天判断逻辑的边界情况

**问题：** `distinct_days == 1` 的判断可能不准确

**场景分析：**
- 如果用户昨天学习了，今天还没学习：`distinct_days == 1` ✅ 正确（第2天）
- 如果用户今天已经学习了：`distinct_days == 2` ❌ 会被判断为第3天

**当前代码：**
```php
$dates = getLearningDates($conn, $uid, 30);
$distinct_days = count($dates);

if ($distinct_days == 1) {
    // 第2天：复习单词=0个
    $review_count_target = 0;
} else {
    // 第3天及以后：复习单词=40%
    $review_count_target = max(1, ceil($daily_goal * 0.4));
}
```

**潜在问题：**
- ⚠️ 如果用户今天已经学习了，`distinct_days`会包含今天，可能=2
- ⚠️ 但此时应该判断为第2天还是第3天？

**建议：**
- 应该检查"昨天是否有学习记录"而不是"学习日期数"
- 或者检查"今天之前的学习日期数"

**修复建议：**
```php
// 检查昨天是否有学习记录
$yesterday = date('Y-m-d', strtotime("$today -1 day"));
$dates = getLearningDates($conn, $uid, 30);
$has_yesterday = in_array($yesterday, $dates);

// 检查今天之前的学习日期数
$dates_before_today = array_filter($dates, function($date) use ($today) {
    return $date < $today;
});
$distinct_days_before_today = count($dates_before_today);

if ($distinct_days_before_today == 1) {
    // 第2天：昨天有学习记录，今天之前只有1个学习日期
    $review_count_target = 0;
} else {
    // 第3天及以后：今天之前有2个或更多学习日期
    $review_count_target = max(1, ceil($daily_goal * 0.4));
}
```
