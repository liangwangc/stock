# 单词库扩展和例句补全说明

## 📋 改进内容

### 1. 例句补全功能增强

#### 问题
- 更新脚本现在可以补全中文例句，但没有英文例句的单词无法补全英文例句

#### 解决方案

**改进 `update_word_bank_examples.php`：**

1. **只有中文没有英文的情况**：
   - 检测到只有中文没有英文时，从 Free Dictionary API 获取英文例句
   - 将英文例句与中文例句组合，格式为：`英文。中文`

2. **完全没有例句的情况**：
   - 如果单词完全没有例句，从 Free Dictionary API 获取英文例句
   - 自动翻译英文例句为中文
   - 组合格式：`英文。中文`

3. **补全逻辑**：
   ```php
   // 如果只有中文没有英文，从Free Dictionary API获取英文例句
   if (!$hasEnglish && $hasChinese) {
       $freeDictResult = fetchWordFromFreeDictionaryAPI($word);
       if ($freeDictResult && !empty($freeDictResult['example'])) {
           $exampleEn = $freeDictResult['example'];
           $example = $exampleEn . "。" . $example; // 英文在前，中文在后
       }
   }
   
   // 完全没有例句，尝试从Free Dictionary API获取
   elseif (empty($example)) {
       $freeDictResult = fetchWordFromFreeDictionaryAPI($word);
       if ($freeDictResult && !empty($freeDictResult['example'])) {
           $exampleEn = $freeDictResult['example'];
           $exampleCn = translateToChinese($exampleEn);
           if (!empty($exampleCn)) {
               $example = $exampleEn . "。" . $exampleCn;
           } else {
               $example = $exampleEn; // 至少保留英文
           }
       }
   }
   ```

## 🚀 使用方法

### 1. 更新现有单词的例句（补全英文例句）

运行更新脚本：

```bash
php update_word_bank_examples.php
```

选择更新模式：
- `1`：只更新完全没有例句的单词
- `2`：更新不完整的例句（推荐，包括只有中文没有英文的情况）
- `3`：强制更新所有单词的例句

### 2. 导入新的扩展单词

运行批量导入脚本：

```bash
php import_all_grades.php
```

这将导入所有年级的扩展单词列表。

### 3. 单独导入某个年级

运行交互式导入脚本：

```bash
php import_word_bank.php
```

然后选择要导入的年级。

## 📝 注意事项

1. **API 限制**：
   - Free Dictionary API 和翻译 API 可能有请求频率限制
   - 更新大量单词时，脚本会自动添加延迟（`usleep(500000)`）以避免被限制

2. **翻译质量**：
   - 翻译 API 的质量可能因单词而异
   - 建议人工检查重要单词的例句翻译

3. **数据备份**：
   - 在更新或导入大量数据前，建议备份数据库
   - 可以使用以下 SQL 命令备份：
     ```sql
     CREATE TABLE word_bank_backup AS SELECT * FROM word_bank;
     ```

4. **例句格式**：
   - 所有例句统一格式：`英文。中文`
   - 使用中文句号（。）作为分隔符
