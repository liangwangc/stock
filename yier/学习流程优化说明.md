# 学习流程优化说明

## 功能概述

优化了学习流程中的"忘记"、"模糊"、"记住"三个按钮的逻辑，现在会根据状态决定是否跳转到下一个单词，并记录每个单词的点击次数。

## 数据库更新

### 1. 执行SQL脚本

首先需要执行以下SQL脚本，添加三个字段来记录点击次数：

```sql
-- 文件：add_review_count_fields.sql
USE word_app;

ALTER TABLE words 
ADD COLUMN forgot_count INT DEFAULT 0 COMMENT '忘记按钮点击次数',
ADD COLUMN vague_count INT DEFAULT 0 COMMENT '模糊按钮点击次数',
ADD COLUMN remembered_count INT DEFAULT 0 COMMENT '记住按钮点击次数';

ALTER TABLE words ADD INDEX idx_review_counts (forgot_count, vague_count, remembered_count);
```

**执行方法：**
- 使用MySQL客户端（如phpMyAdmin、Navicat）执行
- 或使用命令行：`mysql -u用户名 -p数据库名 < add_review_count_fields.sql`

## 功能说明

### 1. 忘记按钮（红色）
- **行为**：点击后**不跳转**，继续学习当前单词
- **记录**：`forgot_count` 字段 +1
- **复习计划**：不更新复习计划，单词保持当前状态
- **提示**：显示"💪 继续加油，再试一次！"

### 2. 模糊按钮（黄色）
- **行为**：点击后弹出确认对话框，用户可以选择：
  - **继续学习**：不跳转，继续学习当前单词
  - **跳过**：跳转到下一个单词，并更新复习计划
- **记录**：`vague_count` 字段 +1
- **复习计划**：只有选择"跳过"时才更新

### 3. 记住按钮（绿色）
- **行为**：点击后**立即跳转**到下一个单词
- **记录**：`remembered_count` 字段 +1
- **复习计划**：更新复习计划，按照SM-2算法计算下次复习时间

## 使用场景

### 场景1：单词太难，需要多练习
1. 看到单词后，点击"忘记"
2. 系统记录点击次数，但不跳转
3. 卡片重新显示，可以继续学习
4. 可以多次点击"忘记"，系统会累计记录

### 场景2：单词有点印象但不确定
1. 看到单词后，点击"模糊"
2. 弹出确认对话框
3. 选择"继续学习"：继续练习当前单词
4. 选择"跳过"：进入下一个单词，系统会按照"模糊"状态更新复习计划

### 场景3：单词完全掌握
1. 看到单词后，点击"记住"
2. 立即跳转到下一个单词
3. 系统记录"记住"次数，并更新复习计划

## 数据统计

数据库中的 `words` 表现在包含以下字段：
- `forgot_count`：忘记按钮点击次数
- `vague_count`：模糊按钮点击次数
- `remembered_count`：记住按钮点击次数

这些数据可以用于：
- 分析哪些单词最难（forgot_count高）
- 分析哪些单词需要更多练习（vague_count高）
- 分析学习效果（remembered_count高）
- 后续优化复习算法

## 注意事项

1. **必须先执行SQL脚本**，否则会出现数据库错误
2. 点击次数会实时记录到数据库，即使不跳转也会记录
3. "忘记"和"模糊（继续学习）"不会更新复习计划，只有"记住"和"模糊（跳过）"才会更新
4. 听写模式和学习模式都支持这个功能

## 测试建议

1. 执行SQL脚本后，刷新页面
2. 选择一个单词，点击"忘记"，确认不跳转
3. 点击"模糊"，测试确认对话框
4. 点击"记住"，确认跳转到下一个单词
5. 检查数据库中对应单词的 `forgot_count`、`vague_count`、`remembered_count` 字段是否正确更新
