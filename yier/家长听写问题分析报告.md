## 📋 一、问题1：重复学习不会新加入单词

### 1.1 当前逻辑

**位置：** `index.html` 第1530-1539行

**代码逻辑：**
```javascript
if (hasLearnedToday) {
    // 今天已经学习过，使用今天学习过的单词（重复学习，不添加新单词）
    this.queue = checkTodayData.queue || [];
    
    if (!this.queue || this.queue.length === 0) {
        return alert("今天学习过的单词列表为空，无法进行重复学习。");
    }
    
    // 提示用户这是重复学习
    this.showToast('重复学习模式：只学习今天已学过的单词，不会记录学习状态', 'success');
} else {
    // 今天还没有学习过，需要导入单词并准备新的学习队列
    const res = await fetch(`api.php?action=import_words_for_study&uid=${this.user.id}`);
    // ...
}
```

### 1.2 问题分析

**用户反馈：**
> "家长听写重复学习的时候，只会把今天学习的单词再次学习。不会新加入单词。"

**当前行为：**
- ✅ 如果今天已经学习过，使用今天学习过的单词进行重复学习
- ❌ 不会添加新单词

**用户期望：**
- ❓ 可能希望重复学习时也能添加新单词？

### 1.3 需求确认

**需要确认：**
1. **重复学习的定义是什么？**
   - 选项A：重复学习 = 只学习今天已学过的单词（当前逻辑）
   - 选项B：重复学习 = 学习今天已学过的单词 + 添加新单词

2. **如果重复学习时添加新单词，是否会影响"今天学习过的单词"的定义？**
   - 如果添加新单词，这些新单词算不算"今天学习过的单词"？

### 1.4 建议方案

**方案1：保持当前逻辑（推荐）**
- ✅ 重复学习 = 只学习今天已学过的单词
- ✅ 符合"重复学习"的字面意思
- ✅ 不会影响"今天学习过的单词"的定义

**方案2：重复学习时也添加新单词**
- ⚠️ 需要修改逻辑：重复学习时也调用 `import_words_for_study`
- ⚠️ 需要明确：新添加的单词是否算"今天学习过的单词"

## 📋 二、问题2：家长听写的单词与日历显示的单词不一致

### 2.1 当前逻辑

#### 2.1.1 家长听写获取单词的逻辑

**位置：** `api.php` 第2869-2995行

**API：** `get_today_learned_words_for_dictation`

**查询逻辑：**
```php
SELECT DISTINCT w.*
FROM words w
WHERE w.user_id = ?
AND (
    -- 今天新添加的单词
    (w.date_added = ?)
    OR
    -- 今天复习过的单词（通过word_review_logs表）
    EXISTS (
        SELECT 1 
        FROM word_review_logs rl 
        WHERE rl.word_id = w.id 
        AND rl.user_id = ? 
        AND rl.review_date = ?
    )
)
ORDER BY 
    -- 优先显示今天复习过的单词（需要更多练习）
    CASE WHEN EXISTS (...) THEN 0 ELSE 1 END,
    w.date_added ASC, w.id ASC
```

**返回的单词：**
1. ✅ 今天新添加的单词（`date_added = 今天`）
2. ✅ 今天复习过的单词（`word_review_logs.review_date = 今天`）

### 2.2 问题分析

**用户反馈：**
> "家长听写的单词为什么跟主页日历点击显示的单词不一致？"

**可能的原因：**

1. **查询条件不同**
   - 家长听写：`date_added = 今天` OR `word_review_logs.review_date = 今天`

3. **数据来源不同**
   - 家长听写：包括今天新添加的单词 + 今天复习过的单词
