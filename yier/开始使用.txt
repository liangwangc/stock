步骤1: 运行完整诊断
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
双击运行: 完整诊断.bat

这会检查：
  ✅ 项目文件是否完整
  ✅ PHP/MySQL/Python环境
  ✅ MySQL服务状态
  ✅ 数据库配置
  ✅ 数据库连接测试

步骤2: 根据诊断结果配置
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

如果MySQL服务未启动：
  • 打开服务管理器（Win+R，输入 services.msc）
  • 找到MySQL服务（可能是MySQL、MySQL80、MySQL57等）
  • 右键选择"启动"
  • 或使用XAMPP/WAMP控制面板启动MySQL

如果数据库未导入：
  • 方法1（命令行）:
    mysql -u root -p < word_app_backup_20260129.sql
    
  • 方法2（MySQL Workbench）:
    1. 打开MySQL Workbench
    2. Server → Data Import
    3. 选择 word_app_backup_20260129.sql
    4. 导入到 word_app 数据库

如果密码不正确：
  • 编辑 api.php 文件
  • 找到第20行: $db_pass = 'root';
  • 修改为你的实际MySQL密码

步骤3: 启动项目
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

方法1: PHP内置服务器（推荐用于开发测试）
  • 双击运行: 启动服务器.bat
  • 浏览器访问: http://localhost:8000

方法2: Apache/Nginx（用于生产环境）
  • 将项目复制到Web服务器目录
  • 启动Apache/Nginx
  • 浏览器访问对应地址

❌ 常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

问题1: "Can't connect to MySQL server"
解决: MySQL服务未启动，请启动MySQL服务

问题2: "Access denied for user 'root'@'localhost'"
解决: 密码错误，修改 api.php 第20行的密码

问题3: "Unknown database 'word_app'"
解决: 数据库未导入，运行导入命令

问题4: PHP未安装
解决: 安装XAMPP/WAMP或单独安装PHP

问题5: Python测试失败
解决: 安装pymysql: pip install pymysql
