# 项目启动说明

## 📋 项目结构分析

这是一个 **前后端分离** 的项目：

- **前端**: `index.html` - 使用 JavaScript fetch API 调用后端
- **后端**: `api.php` - PHP 文件，需要 Web 服务器运行
- **数据库**: MySQL (`word_app`)

## ⚠️ 重要：为什么不能直接打开 index.html？

**不能直接双击打开 `index.html` 的原因：**

1. 前端使用 `fetch('api.php?action=login')` 调用后端
2. `api.php` 是 PHP 文件，必须通过 **Web 服务器** 运行
3. 直接打开 HTML 文件使用的是 `file://` 协议，无法执行 PHP
4. 浏览器会报 CORS 错误或 404 错误

## ✅ 正确的启动方式

### 方法一：PHP 内置服务器（推荐）

**步骤1：检查 PHP 是否安装**
```bash
php --version
```

**步骤2：启动服务器**
```bash
cd d:\wjw_work\yier
php -S localhost:8000
```

**或直接双击运行：**
- `启动项目.bat` （推荐，有完整检查）
- `启动服务器.bat` （简单版本）

**步骤3：访问项目**
```
http://localhost:8000
```

### 方法二：使用 XAMPP

**步骤1：安装 XAMPP**
- 下载：https://www.apachefriends.org/
- 安装到 `C:\xampp\`

**步骤2：复制项目**
```bash
# 将项目文件夹复制到
C:\xampp\htdocs\yier\
```

**步骤3：启动服务**
1. 打开 XAMPP Control Panel
2. 启动 **Apache** 服务
3. 启动 **MySQL** 服务

**步骤4：访问项目**
```
http://localhost/yier/
```

### 方法三：使用 WAMP

**步骤1：安装 WAMP**
- 下载：https://www.wampserver.com/
- 安装到 `C:\wamp64\`

**步骤2：复制项目**
```bash
# 将项目文件夹复制到
C:\wamp64\www\yier\
```

**步骤3：启动服务**
1. 启动 WAMP
2. 确保 Apache 和 MySQL 服务运行

**步骤4：访问项目**
```
http://localhost/yier/
```

## 🔍 启动前检查清单

在启动前，确保：

- [ ] **PHP 已安装**（运行 `php --version` 检查）
- [ ] **MySQL 服务已启动**
- [ ] **数据库已导入**（运行 `mysql -u root -p < word_app_backup_20260129.sql`）
- [ ] **数据库密码已配置**（编辑 `api.php` 第20行）
- [ ] **端口未被占用**（默认8000，可改为8080）

## 🐛 常见启动问题

### 问题1：`php 不是内部或外部命令`

**原因：** PHP 未安装或未添加到 PATH

**解决方法：**
1. 安装 XAMPP/WAMP（推荐）
2. 或单独安装 PHP：
   - 下载：https://windows.php.net/download/
   - 解压到 `C:\php\`
   - 添加到系统 PATH

### 问题2：`端口已被占用`

**解决方法：**
```bash
# 使用其他端口
php -S localhost:8080

# 或查找占用8000端口的进程并关闭
netstat -ano | findstr :8000
taskkill /PID <进程ID> /F
```

### 问题3：`数据库连接失败`

**解决方法：**
1. 检查 MySQL 服务是否运行
2. 检查 `api.php` 中的密码是否正确
3. 运行 `测试数据库连接.bat` 测试连接

### 问题4：`页面显示但功能不工作`

**原因：** API 调用失败

**检查：**
1. 打开浏览器开发者工具（F12）
2. 查看 Console 和 Network 标签
3. 检查是否有错误信息

**常见错误：**
- `Failed to fetch` - 服务器未启动或路径错误
- `404 Not Found` - api.php 路径不正确
- `500 Internal Server Error` - PHP 错误或数据库连接失败
