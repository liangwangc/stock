# 卡片学习与听写模式功能区别说明

## 📋 一、概述

在"统计/设置"页面中，有一个"偏好学习模式"设置，可以选择：
- **卡片学习**（card）
- **听写模式**（dictation）

这两种模式在功能上有显著区别，下面详细说明。

---

## 🎴 二、卡片学习模式（Card Study Mode）

### 2.1 功能特点

**入口：** 点击主页的 **"开始学习"** 按钮

**学习方式：**
- ✅ 显示单词（正面）
- ✅ 显示音标（IPA）
- ✅ 点击卡片翻转查看词义和例句（背面）
- ✅ 可以点击喇叭播放读音
- ✅ 手动选择掌握状态：忘记/模糊/记住

**界面展示：**
```
┌─────────────────────┐
│       🔊            │
│                     │
│      pencil         │
│   /ˈpensəl/         │
│                     │
│  [点击查看词义]      │
│                     │
└─────────────────────┘
```

翻转后：
```
┌─────────────────────┐
│       🔊            │
│                     │
│      pencil         │
│   /ˈpensəl/         │
│                     │
│  铅笔                │
│  I need a pencil.   │
│                     │
│ [忘记] [模糊] [记住] │
└─────────────────────┘
```

### 2.2 学习流程

1. **显示单词** → 用户看到单词和音标
2. **点击卡片** → 翻转查看词义和例句
3. **选择状态** → 手动点击"忘记"、"模糊"或"记住"
4. **记录学习** → 记录到数据库，`review_mode = 'study'`

### 2.3 数据记录

**记录字段：**
- `review_mode = 'study'`（学习模式）
- `quality = 1/3/5`（根据用户选择）
- `review_date = 今天`
- 记录到 `word_review_logs` 表

### 2.4 适用场景

- ✅ **初次学习新单词**：需要看到词义和例句
- ✅ **理解记忆**：通过视觉和语义理解单词
- ✅ **快速浏览**：可以快速查看多个单词

---

## 🎧 三、听写模式（Dictation Mode）

### 3.1 功能特点

**入口：** 点击主页的 **"🎧 听写"** 按钮

**学习方式：**
- ✅ **只播放读音**，不显示单词
- ✅ 用户需要**手动输入**听到的单词
- ✅ 系统**自动判断**掌握状态（根据尝试次数）
- ✅ 只能听写**今天学习过的单词**

**界面展示：**
```
┌─────────────────────┐
│       🔊            │
│   [点击播放读音]      │
│   已播放 1 次         │
│                     │
│ 请输入听到的单词：    │
│ ┌─────────────────┐ │
│ │                 │ │
│ └─────────────────┘ │
│                     │
│   [输入框]           │
└─────────────────────┘
```

### 3.2 智能判断机制

**根据尝试次数自动判断：**

| 尝试次数 | 判断结果 | 说明 |
|---------|---------|------|
| **2次内写对** | ✅ **记住**（quality=5） | 自动跳转下一个单词 |
| **3-4次内写对** | ⚠️ **模糊**（quality=3） | 自动跳转下一个单词 |
| **5次后写错** | ❌ **忘记**（quality=1） | 显示正确答案，自动跳转 |

**详细流程：**

1. **第1-2次写对**：
   - ✅ 显示："🎉 太棒了！2次内就写对了！"
   - ✅ 自动标记为"记住"（quality=5）
   - ✅ 自动跳转到下一个单词

2. **第3-4次写对**：
   - ✅ 显示："👍 不错！4次内写对了！"
   - ✅ 自动标记为"模糊"（quality=3）
   - ✅ 自动跳转到下一个单词

3. **第5次后写错**：
   - ❌ 显示正确答案
   - ❌ 自动标记为"忘记"（quality=1）
   - ❌ 自动跳转到下一个单词

4. **第1-4次写错**：
   - ❌ 只显示："✗ 错误（第X次尝试）"
   - ❌ **不显示正确答案**（鼓励继续尝试）
   - ❌ 清空输入框，继续尝试

### 3.3 数据记录

**记录字段：**
- `review_mode = 'dictation'`（听写模式）
- `quality = 1/3/5`（根据尝试次数自动判断）
- `review_date = 今天`
- 记录到 `word_review_logs` 表

**特殊说明：**
- ✅ 听写模式的表现**权重更高**（是学习模式的4倍）
- ✅ 听写模式连续忘记2次以上 → **最高优先级复习**
- ✅ 听写模式有失败记录 → **高优先级复习**

### 3.4 适用场景

- ✅ **巩固记忆**：检验是否真正掌握单词拼写
- ✅ **听力训练**：通过听音识词
- ✅ **拼写练习**：提高单词拼写能力
- ✅ **重点复习**：听写错误的单词会被标记为高优先级

## 🔄 四、两种模式的主要区别

### 4.1 学习方式对比

| 对比项 | 卡片学习模式 | 听写模式 |
|-------|-------------|---------|
| **显示内容** | 单词、音标、词义、例句 | 只播放读音，不显示单词 |
| **交互方式** | 点击翻转查看词义 | 手动输入听到的单词 |
| **状态判断** | 手动选择（忘记/模糊/记住） | 自动判断（根据尝试次数） |
| **单词来源** | 今日任务队列（复习+新单词） | 今天学习过的单词 |
| **难度** | 较低（可以看到词义） | 较高（需要回忆拼写） |

### 4.2 数据记录对比

| 对比项 | 卡片学习模式 | 听写模式 |
|-------|-------------|---------|
| **review_mode** | `'study'` | `'dictation'` |
| **权重** | 较低（×5） | 较高（×20） |
| **优先级** | 一般 | 高（听写错误优先复习） |

### 4.3 复习优先级对比

**听写模式权重（主要判断依据）：**
- 连续忘记次数：**×20**（最高权重）
- 连续模糊次数：**×12**（较高权重）
- 总失败率：**×15**（失败率越高，优先级越高）

**学习模式权重（辅助判断）：**
- 连续忘记次数：**×5**（权重较低，是听写的1/4）
- 连续模糊次数：**×3**（权重最低）

**优先级排序：**
1. **优先级1（分数：1000+）**：听写模式连续忘记2次以上
2. **优先级2（分数：500+）**：听写模式有失败记录但少于2次
3. **优先级3（分数：200+）**：没有听写记录，但学习模式表现差（忘记2次以上）

## ⚙️ 五、偏好学习模式设置

### 5.1 设置位置

**路径：** 统计/设置 → 偏好设置 → 默认学习模式

**选项：**
- 卡片学习（card）
- 听写模式（dictation）

### 5.2 设置作用

**当前实现：**
- ⚠️ **注意**：这个设置目前**没有实际作用**
- ⚠️ 点击"开始学习"按钮时，**总是使用卡片学习模式**
- ⚠️ 听写模式需要**单独点击"🎧 听写"按钮**进入

**建议的使用方式：**
1. **卡片学习**：用于初次学习新单词
2. **听写模式**：用于巩固和检验已学单词

## 📊 六、学习建议

### 6.1 推荐学习流程

**第一天（新单词）：**
1. 使用 **卡片学习模式** 学习新单词
2. 理解词义和例句
3. 选择掌握状态

**第二天（复习）：**
1. 使用 **卡片学习模式** 复习（快速浏览）
2. 使用 **听写模式** 检验是否真正掌握
3. 听写错误的单词会被标记为高优先级，重点复习

### 6.2 最佳实践

- ✅ **新单词**：先用卡片学习模式理解
- ✅ **复习单词**：先用卡片学习模式快速浏览，再用听写模式检验
- ✅ **重点单词**：听写模式表现差的单词，系统会自动提高复习优先级

## ✅ 八、总结

### 8.1 核心区别

1. **卡片学习模式**：
   - 显示完整信息（单词、音标、词义、例句）
   - 手动选择掌握状态
   - 适合初次学习

2. **听写模式**：
   - 只播放读音，需要手动输入
   - 自动判断掌握状态（根据尝试次数）
   - 适合巩固和检验
   - **权重更高**，听写错误的单词优先复习

### 8.2 使用建议

- ✅ **新单词** → 使用卡片学习模式
- ✅ **复习单词** → 先用卡片学习模式，再用听写模式检验
- ✅ **重点单词** → 听写模式表现差的单词会被自动标记为高优先级
