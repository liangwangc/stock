# 掌握计算逻辑说明

## 📋 一、掌握状态的定义

**已掌握（mastered）**：单词经过多次复习，达到稳定记忆状态。

---

## 🎯 二、掌握状态的判断条件

### 2.1 自动标记为"已掌握"的条件

**代码位置：** `api.php` - `submit_review` API (第1137-1138行)

**判断条件：**
```php
if ($reps >= 5 && $ef >= 2.5) {
    $status = 'mastered';  // 已掌握
}
```

**条件说明：**
- ✅ **`repetitions >= 5`**：单词已复习至少5次
- ✅ **`ef_factor >= 2.5`**：记忆难度因子（EF因子）>= 2.5（表示记忆难度较低，容易记住）

**两个条件必须同时满足**，单词才会被标记为"已掌握"。

---

## 📊 三、状态转换规则

### 3.1 完整的状态转换流程

| 状态 | 条件 | 说明 |
|------|------|------|
| `new` | 初始状态 | 新添加的单词，还未学习 |
| `learning` | `repetitions < 3` | 学习中，复习次数少于3次 |
| `review` | `repetitions >= 3` | 复习中，复习次数>=3次但未达到掌握标准 |
| `mastered` | `repetitions >= 5` 且 `ef_factor >= 2.5` | 已掌握，达到稳定记忆状态 |

### 3.2 状态转换代码

**代码位置：** `api.php` - `submit_review` API (第1133-1143行)

```php
// 状态转换规则：
// - repetitions >= 5 且 ef_factor >= 2.5：已掌握（mastered）
// - repetitions >= 3：复习中（review）
// - 其他：学习中（learning）
if ($reps >= 5 && $ef >= 2.5) {
    $status = 'mastered';
} elseif ($reps >= 3) {
    $status = 'review';
} else {
    $status = 'learning';
}
```

## 📈 四、已掌握单词的统计逻辑

### 4.1 统计条件

**统计条件：** `status = 'mastered'` **或** `repetitions >= 5`

**SQL查询示例：**
```sql
SELECT COUNT(*) as mastered_words
FROM words 
WHERE user_id = ? 
  AND (status = 'mastered' OR repetitions >= 5)
```

**说明：**
- 使用 **`OR`** 条件，满足任一条件即统计为"已掌握"
- 原因：有些单词可能 `repetitions >= 5` 但 `ef_factor < 2.5`，状态可能还是 `review`，但实际已经复习了5次以上，也应该算作"已掌握"

### 4.2 统计位置

#### 4.2.1 学习统计（`get_learning_stats` API）

**代码位置：** `api.php` 第2211-2217行

```php
// 已掌握单词数（status='mastered'或repetitions>=5）
$stmt = prepare_check($conn, "
    SELECT COUNT(*) as mastered 
    FROM words 
    WHERE user_id = ? 
      AND (status = 'mastered' OR repetitions >= 5)
");
```

**用途：** 统计/设置页面显示"掌握单词数"

---

#### 4.2.2 效率统计（`get_efficiency_stats` API）

**代码位置：** `api.php` 第1552-1562行

```php
// 统计所有已掌握的单词（不限制时间范围），这样更准确
$stmt = prepare_check($conn, "
    SELECT COUNT(*) as total_mastered_words
    FROM words 
    WHERE user_id = ? 
      AND (status = 'mastered' OR repetitions >= 5)
");
```

**用途：** 计算"掌握速度"（掌握单词数 / 学习天数）

---

#### 4.2.3 PK排行榜（`get_rankings` API）

**代码位置：** `api.php` 第2299行、第2319行

**使用 `word_review_logs` 表统计（更准确）：**
```sql
COUNT(DISTINCT CASE 
    WHEN w.status = 'mastered' OR w.repetitions >= 5 
    THEN rl.word_id 
END) as mastered_words
```

**回退逻辑（兼容性）：**
```sql
SUM(CASE 
    WHEN w.status = 'mastered' OR w.repetitions >= 5 
    THEN 1 
    ELSE 0 
END) as mastered_words
```

**用途：** PK页面显示"已掌握单词数"

## 🔄 五、已掌握单词的复习逻辑

### 5.1 重要特性

**即使单词被标记为"已掌握"（`status='mastered'`），仍然会定期复习！**

### 5.2 复习条件

**代码位置：** `api.php` - `prepare_study_queue` API

**复习单词查询条件：**
```sql
WHERE user_id = ? 
  AND status != 'new' 
  AND next_review <= ?
```

**说明：**
- ✅ `status != 'new'`：排除新单词
- ✅ `next_review <= today`：下次复习日期到了或已过期
- ✅ **即使 `status='mastered'`，只要 `next_review <= today`，仍然会复习**

### 5.3 为什么已掌握还要复习？

1. **防止遗忘**：即使单词已经掌握，如果不定期复习，仍然会遗忘
2. **长期记忆**：通过间隔重复，将短期记忆转化为长期记忆
3. **科学依据**：基于艾宾浩斯遗忘曲线和SM-2算法

## 📝 六、EF因子（记忆难度因子）说明

### 6.1 EF因子的作用

- **初始值**：2.5
- **作用**：衡量单词的记忆难度
  - **EF值越高**：单词越容易记住（记忆难度低）
  - **EF值越低**：单词越难记住（记忆难度高）

### 6.2 EF因子的变化规则

**代码位置：** `api.php` - `submit_review` API (第1131行)

```php
$ef = max(1.3, $ef + (0.1 - (5 - $q) * (0.08 + (5 - $q) * 0.02)));
```

**变化规则：**
- **答对（quality=5）**：EF因子增加（变容易）
- **模糊（quality=3）**：EF因子略微增加
- **答错（quality=1）**：EF因子降低（变困难）
- **最小值**：1.3（不能低于1.3）

### 6.3 EF因子与掌握的关系

- **掌握条件之一**：`ef_factor >= 2.5`
- 如果单词复习了5次以上，但EF因子 < 2.5，说明记忆还不够稳定，不会被标记为"已掌握"

## 🎯 七、掌握速度计算

### 7.1 计算公式

**掌握速度 = 总掌握单词数 / 总学习天数**

**代码位置：** `api.php` - `get_efficiency_stats` API (第1589-1595行)

```php
// 掌握速度 = 总掌握单词数 / 总学习天数
if ($total_study_days > 0) {
    $mastery_speed = round($total_mastered_words / $total_study_days, 1);
} elseif ($total_mastered_words > 0) {
    // 如果有掌握单词但还没有学习天数，使用1天作为基准
    $mastery_speed = round($total_mastered_words / 1, 1);
} else {
    $mastery_speed = 0;
}
```

**示例：**
- 总掌握单词数：50个
- 总学习天数：10天
- 掌握速度 = 50 / 10 = **5.0个/天**

## 📊 八、总结

### 8.1 掌握判断条件

| 条件 | 说明 |
|------|------|
| `repetitions >= 5` | 单词已复习至少5次 |
| `ef_factor >= 2.5` | 记忆难度因子 >= 2.5（容易记住） |
| **两个条件同时满足** | 单词被标记为 `status='mastered'` |

### 8.2 统计逻辑

| 统计位置 | 统计条件 | 说明 |
|----------|----------|------|
| 学习统计 | `status='mastered'` **或** `repetitions>=5` | 满足任一条件即统计 |
| 效率统计 | `status='mastered'` **或** `repetitions>=5` | 用于计算掌握速度 |
| PK排行榜 | `status='mastered'` **或** `repetitions>=5` | 基于实际学习记录统计 |

### 8.3 重要特性

✅ **已掌握单词仍然会复习**：即使 `status='mastered'`，只要 `next_review <= today`，仍然会出现在复习列表中

✅ **双重判断标准**：使用 `status='mastered'` **或** `repetitions>=5` 统计，确保统计准确

✅ **基于实际学习记录**：PK排行榜使用 `word_review_logs` 表统计，只统计实际学习过的单词
