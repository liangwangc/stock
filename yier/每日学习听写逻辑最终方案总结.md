# 每日学习/听写逻辑最终方案总结

## 📋 一、最终确认的需求逻辑

### 1.1 核心公式

**每日学习/听写队列 = 复习单词（40%）+ 昨天学习的新单词（全量）+ 今天学习的新单词（100%）**

**关键约束：**
- **总任务量固定**：从第三天开始，每天总任务量固定（不再无限递增）
- **复习算法**：使用SM-2算法的`next_review`作为依据，同时考虑单词的掌握程度
- **复习优先级**：使用听写错误次数、学习表现作为优先级排序

### 1.2 逐日逻辑示例（假设每日目标=10个）

#### 第一天
- **复习单词（40%）**：0个（没有历史记录）
- **昨天学习的新单词**：0个（没有昨天）
- **今天学习的新单词**：10个（100%）
- **总任务**：10个
- **队列**：[新单词1, 新单词2, ..., 新单词10]

#### 第二天
- **复习单词（40%）**：0个（第一天没有需要复习的）
- **昨天学习的新单词**：10个（第一天的10个新单词，全量强制复习）
- **今天学习的新单词**：10个（100%）
- **总任务**：20个
- **队列**：[第一天单词1, 第一天单词2, ..., 第一天单词10, 新单词1, 新单词2, ..., 新单词10]

#### 第三天（开始固定总任务量）
- **复习单词（40%）**：4个（daily_goal * 0.4 = 10 * 0.4 = 4个）
  - 从前面所有天（第1天）中抽取，使用SM-2算法的`next_review`作为依据
  - 考虑单词的掌握程度（听写错误次数、学习表现）
  - 最多抽取4个（从第1天的10个单词中抽取4个）
- **昨天学习的新单词**：10个（第二天的10个新单词，全量强制复习）
- **今天学习的新单词**：10个（100%）
- **总任务**：24个（固定：4 + 10 + 10 = 24个）
- **队列**：[复习单词（选4个）, 第二天单词1, 第二天单词2, ..., 第二天单词10, 新单词1, 新单词2, ..., 新单词10]

#### 第四天（固定总任务量）
- **复习单词（40%）**：4个（daily_goal * 0.4 = 10 * 0.4 = 4个）
  - 从前面所有天（第1天、第2天）中抽取
  - 使用SM-2算法的`next_review`作为依据
  - 考虑单词的掌握程度（听写错误次数、学习表现）
  - 最多抽取4个（从第1、2天的20个单词中抽取4个）
- **昨天学习的新单词**：10个（第三天的10个新单词，全量强制复习）
- **今天学习的新单词**：10个（100%）
- **总任务**：24个（固定：4 + 10 + 10 = 24个）
- **队列**：[复习单词（选4个）, 第三天单词1, 第三天单词2, ..., 第三天单词10, 新单词1, 新单词2, ..., 新单词10]

#### 第五天及以后（固定总任务量）
- **复习单词（40%）**：4个（daily_goal * 0.4 = 10 * 0.4 = 4个）
  - 从前面所有天（第1天、第2天、第3天...）中抽取
  - 使用SM-2算法的`next_review`作为依据
  - 考虑单词的掌握程度（听写错误次数、学习表现）
  - 最多抽取4个（从前面所有天的单词中抽取4个）
- **昨天学习的新单词**：10个（前一天的10个新单词，全量强制复习）
- **今天学习的新单词**：10个（100%）
- **总任务**：24个（固定：4 + 10 + 10 = 24个）
- **队列**：[复习单词（选4个）, 前一天单词1, 前一天单词2, ..., 前一天单词10, 新单词1, 新单词2, ..., 新单词10]

### 1.3 关键特点

1. **新单词数量**：每天都是100%的每日目标（例如10个目标=10个新单词）
2. **昨天学习的新单词**：每天都会强制复习前一天学习的所有新单词（全量）
3. **复习单词（40%）**：
   - **数量计算**：`daily_goal * 0.4`（动态计算，根据设定的每日目标）
     - 例如：daily_goal=10，复习单词=4个
     - 例如：daily_goal=20，复习单词=8个
     - 例如：daily_goal=5，复习单词=2个
   - 从前面所有天（不包括昨天）中抽取
   - 使用SM-2算法的`next_review`作为依据
   - 考虑单词的掌握程度（听写错误次数、学习表现）
   - 最多抽取`daily_goal * 0.4`个
4. **总任务量固定**：从第三天开始，每天总任务量固定
5. **总任务量计算公式**：
   ```
   第1天：daily_goal（例如10个）
   第2天：daily_goal * 2（例如20个）
   第3天及以后：daily_goal * 0.4 + daily_goal + daily_goal = daily_goal * 2.4
     - 例如：daily_goal=10，总任务=24个
     - 例如：daily_goal=20，总任务=48个
     - 例如：daily_goal=5，总任务=12个
   ```

## 🔍 二、复习单词（40%）抽取算法设计

### 2.1 抽取范围

**从前面所有天（不包括昨天和今天）中抽取**

- **第3天**：从第1天抽取
- **第4天**：从第1、2天抽取
- **第5天**：从第1、2、3天抽取
- **第N天**：从第1天到第N-2天抽取

### 2.2 抽取依据

**使用SM-2算法的`next_review`作为主要依据**

1. **查询条件**：
   ```sql
   WHERE user_id = ?
     AND status != 'new'
     AND next_review <= 今天
     AND date_added != 昨天  -- 排除昨天学习的单词（已经在yesterday_words中）
     AND date_added < 昨天   -- 只从前面所有天抽取
   ```

2. **优先级排序**（分数越高，优先级越高）：
   - **优先级1**：听写模式连续忘记2次以上（分数：1000+）
   - **优先级2**：听写模式有失败记录但少于2次（分数：500+）
   - **优先级3**：没有听写记录，但学习模式表现差（分数：200+）
   - **优先级4**：正常复习（分数：review_priority）
   - **优先级5**：按`next_review`升序排序（越早需要复习的越优先）

3. **掌握程度考虑**：
   - 听写错误次数越多，优先级越高
   - 学习表现越差，优先级越高
   - `next_review`越早，优先级越高

### 2.3 抽取数量计算

**复习单词数量 = daily_goal * 0.4（动态计算，根据设定的每日目标）**

**示例：**
- 如果daily_goal=10，复习单词数量 = 10 * 0.4 = 4个
- 如果daily_goal=20，复习单词数量 = 20 * 0.4 = 8个
- 如果daily_goal=5，复习单词数量 = 5 * 0.4 = 2个

**抽取规则：**
- 第3天：最多抽取`daily_goal * 0.4`个
- 第4天：最多抽取`daily_goal * 0.4`个
- 第5天：最多抽取`daily_goal * 0.4`个

**如果前面所有天的单词不足：**
- 则实际抽取数量 = 前面所有天的单词数量（有多少抽多少）

### 2.4 抽取算法实现逻辑

```php
// 1. 计算复习单词数量
$fixed_total_task = 30; // 固定总任务量（从第三天开始）
$yesterday_new_count = count(昨天学习的新单词);
$today_new_count = $daily_goal; // 100%的每日目标
$review_count = max(0, $fixed_total_task - $yesterday_new_count - $today_new_count);

// 2. 查询前面所有天的单词（使用SM-2算法）
$stmt = prepare_check($conn, "
    SELECT w.*,
           -- 统计听写模式忘记次数
           COUNT(CASE WHEN rl_dict.review_mode = 'dictation' AND rl_dict.quality = 1 THEN 1 END) as dictation_forgot_count,
           -- 统计听写模式失败次数（quality < 5）
           COUNT(CASE WHEN rl_dict.review_mode = 'dictation' AND rl_dict.quality < 5 THEN 1 END) as dictation_fail_count,
           -- 统计学习模式忘记次数
           COUNT(CASE WHEN rl_study.review_mode = 'study' AND rl_study.quality = 1 THEN 1 END) as study_forgot_count,
           -- 计算优先级分数
           CASE 
               WHEN COUNT(CASE WHEN rl_dict.review_mode = 'dictation' AND rl_dict.quality = 1 THEN 1 END) >= 2 
               THEN 1000 + w.review_priority
               WHEN COUNT(CASE WHEN rl_dict.review_mode = 'dictation' AND rl_dict.quality < 5 THEN 1 END) > 0
               THEN 500 + w.review_priority
               WHEN COUNT(CASE WHEN rl_dict.review_mode = 'dictation' THEN 1 END) = 0
               AND COUNT(CASE WHEN rl_study.review_mode = 'study' AND rl_study.quality = 1 THEN 1 END) >= 2
               THEN 200 + w.review_priority
               ELSE w.review_priority
           END as calculated_priority
    FROM words w
    LEFT JOIN word_review_logs rl_dict ON w.id = rl_dict.word_id AND rl_dict.review_mode = 'dictation'
    LEFT JOIN word_review_logs rl_study ON w.id = rl_study.word_id AND rl_study.review_mode = 'study'
    WHERE w.user_id = ? 
      AND w.status != 'new' 
      AND w.next_review <= ?  -- SM-2算法依据
      AND w.date_added != ?   -- 排除昨天学习的单词
      AND w.date_added < ?    -- 只从前面所有天抽取
    GROUP BY w.id
    ORDER BY calculated_priority DESC, w.next_review ASC  -- 优先级排序
    LIMIT ?
");
$stmt->bind_param("isssi", $uid, $today, $yesterday, $yesterday, $review_count);
```

## 📊 三、固定总任务量设计

### 3.1 固定总任务量计算

**公式：**
```
固定总任务量 = daily_goal * 0.4 + daily_goal + daily_goal = daily_goal * 2.4
```

**示例：**
- 如果daily_goal=10：固定总任务量 = 10 * 2.4 = 24个
  - 复习单词：4个（10 * 0.4）
  - 昨天新单词：10个
  - 今天新单词：10个
- 如果daily_goal=20：固定总任务量 = 20 * 2.4 = 48个
  - 复习单词：8个（20 * 0.4）
  - 昨天新单词：20个
  - 今天新单词：20个
- 如果daily_goal=5：固定总任务量 = 5 * 2.4 = 12个
  - 复习单词：2个（5 * 0.4）
  - 昨天新单词：5个
  - 今天新单词：5个

### 3.2 总任务量规则

1. **第1天**：`daily_goal`（例如10个）
2. **第2天**：`daily_goal * 2`（例如20个）
3. **第3天及以后**：`daily_goal * 2.4`（例如daily_goal=10时为24个，daily_goal=20时为48个，固定）

### 3.3 特殊情况处理

**如果前面所有天的单词不足4个：**
- 则实际抽取数量 = 前面所有天的单词数量（有多少抽多少）
- 总任务量 = 实际复习单词数 + 昨天新单词数 + 今天新单词数

**示例：**
- 如果前面所有天只有2个单词需要复习，daily_goal=10
- 则实际复习单词数量 = 2个（不是4个）
- 总任务量 = 2 + 10 + 10 = 22个
