# 每日学习/听写逻辑修改完成报告

## ✅ 修改完成时间
2026-02-02

## 📋 修改内容总结

### 1. 核心逻辑修改

#### 1.1 新单词数量
- **修改前**：60%的每日目标（`daily_goal * 0.6`）
- **修改后**：100%的每日目标（`daily_goal`）

#### 1.2 复习单词数量
- **修改前**：40%的每日目标，但会根据前一天新单词数量动态调整
- **修改后**：固定为40%的每日目标（`daily_goal * 0.4`），动态计算

#### 1.3 复习单词来源
- **修改前**：前一天全量 + SM-2算法剩余40%配额
- **修改后**：前一天全量 + 前面所有天的40%（使用SM-2算法+掌握程度）

#### 1.4 总任务量
- **修改前**：相对稳定（12-16个，根据前一天新单词数动态调整）
- **修改后**：从第3天开始固定为`daily_goal * 2.4`
  - 第1天：`daily_goal`
  - 第2天：`daily_goal * 2`
  - 第3天及以后：`daily_goal * 2.4`（固定）

## 🔧 代码修改详情

### 2.1 `api.php` - `prepare_study_queue` API修改

#### 修改1：新单词数量计算
```php
// 修改前
$new_word_target = max(1, floor($daily_goal * 0.6)); // 60%

// 修改后
$new_word_target = $daily_goal; // 100%
```

#### 修改2：复习单词数量计算
```php
// 修改前
$review_count_target = max(1, ceil($daily_goal * 0.4)); // 40%
$remaining_review_target = max(0, $review_count_target - $yesterday_review_count);

// 修改后
$review_count_target = max(1, ceil($daily_goal * 0.4)); // 固定40%，动态计算
// 不再根据前一天新单词数量调整
```

#### 修改3：复习单词查询条件
```php
// 修改前
WHERE w.user_id = ? 
  AND w.status != 'new' 
  AND w.next_review <= ?
  AND w.date_added != ?  -- 排除前一天学习的单词

// 修改后
WHERE w.user_id = ? 
  AND w.status != 'new' 
  AND w.next_review <= ?  -- SM-2算法依据
  AND w.date_added != ?   -- 排除前一天学习的单词
  AND w.date_added < ?    -- 只从前面所有天抽取（新增）
```

#### 修改4：bind_param参数调整
```php
// 修改前
$stmt->bind_param("isis", $uid, $today, $yesterday, $remaining_review_target);

// 修改后
$stmt->bind_param("isssi", $uid, $today, $yesterday, $yesterday, $review_count_target);
// 添加了$yesterday参数（date_added < 昨天），使用$review_count_target而不是$remaining_review_target
```

#### 修改5：返回数据更新
```php
// 修改后返回的数据结构
[
    'queue' => $final_queue,
    'review_count' => count($list_reviews_by_next_review), // 复习单词（40%，不包括昨天新单词）
    'new_count' => count($list_new), // 今天新单词（100%）
    'total_review_count' => $total_review_count, // 所有需要复习的单词数
    'review_count_target' => $review_count_target, // 复习目标数量（40%）
    'new_word_target' => $new_word_target, // 新单词目标数量（100%）
    'yesterday_review_count' => $yesterday_review_count, // 前一天学习的新单词数量（全量强制复习）
    'is_first_login' => $is_first_login,
    'total_task' => count($final_queue) // 总任务量
]
```

## 🔍 注意事项

### 4.1 数据库查询优化

- 复习单词查询添加了`date_added < 昨天`条件，确保只从前面所有天抽取
- 查询使用SM-2算法的`next_review`作为主要依据
- 优先级排序：听写错误次数 > 学习表现 > 正常复习 > next_review

### 4.2 前端显示

- 主页显示"要复习"：复习单词（40%）+ 昨天新单词（全量）
- 主页显示"新单词"：今天新单词（100%）
- 主页显示"今天任务"：复习单词（40%）+ 昨天新单词（全量）+ 今天新单词（100%）

### 4.3 特殊情况处理

- **第一次登录**：复习单词=0个，新单词=100%
- **前面所有天的单词不足**：实际抽取数量=前面所有天的单词数量（有多少抽多少）
- **总任务量不足**：如果固定总任务量 < 昨天新单词数 + 今天新单词数，则复习单词数量=0
