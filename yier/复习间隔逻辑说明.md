# 复习间隔逻辑说明

## 一、当前复习逻辑（基于SM-2算法）

### 1. 答对后的处理方式

**答案：会隔一段时间再复习，不是下一次就不复习了**

系统使用**SM-2算法**（SuperMemo 2）来计算复习间隔，这是一个科学的间隔重复算法。

### 2. 复习间隔计算规则

当用户答对（quality=5）或模糊但跳转（quality=3 && should_advance=true）时：

#### 第一次复习（repetitions = 0）：
- 如果距离首次学习超过2天：间隔 = 距离天数
- 否则：间隔 = **1天**（明天复习）

#### 第二次复习（repetitions = 1）：
- 间隔 = **6天**（6天后复习）

#### 第三次及以后（repetitions >= 2）：
- 间隔 = **round(当前间隔 × ef_factor)**
- 间隔会**逐渐增加**（例如：6天 → 12天 → 24天 → 48天...）

### 3. EF因子（记忆难度因子）的变化

- **初始值**：2.5
- **答对（quality=5）**：ef_factor 增加（变容易）
- **模糊（quality=3）**：ef_factor 略微增加
- **答错（quality=1）**：ef_factor 降低（变困难）

### 4. 状态转换规则

| repetitions | ef_factor | 状态 | 说明 |
|-------------|-----------|------|------|
| < 3 | - | learning | 学习中 |
| >= 3 | - | review | 复习中 |
| >= 5 | >= 2.5 | mastered | 已掌握 |

**重要**：即使状态变为 `mastered`（已掌握），如果 `next_review` 到了，**仍然会出现在复习列表中**。

### 5. 复习单词的查询条件

```sql
WHERE status != 'new' AND next_review <= today
```

**说明**：
- ✅ `status != 'new'`：排除新单词
- ✅ `next_review <= today`：下次复习日期到了或已过期
- ✅ **即使 `status='mastered'`，只要 `next_review <= today`，仍然会复习**

## 二、具体示例

### 示例1：新单词的学习和复习流程

**第1天（今天）**：添加单词 "apple"
- `repetitions = 0`
- `ef_factor = 2.5`
- `next_review = 今天`（可以立即学习）
- `status = 'new'`

**第1天（学习后，答对了）**：
- `repetitions = 1`
- `ef_factor = 2.6`（增加）
- `interval_days = 1`
- `next_review = 明天`
- `status = 'learning'`

**第2天（复习，答对了）**：
- `repetitions = 2`
- `ef_factor = 2.7`（增加）
- `interval_days = 6`
- `next_review = 第8天`（2天后 + 6天）
- `status = 'learning'`

**第8天（复习，答对了）**：
- `repetitions = 3`
- `ef_factor = 2.8`（增加）
- `interval_days = round(6 × 2.8) = 17`
- `next_review = 第25天`（8天后 + 17天）
- `status = 'review'`

**第25天（复习，答对了）**：
- `repetitions = 4`
- `ef_factor = 2.9`（增加）
- `interval_days = round(17 × 2.9) = 49`
- `next_review = 第74天`（25天后 + 49天）
- `status = 'review'`

**第74天（复习，答对了）**：
- `repetitions = 5`
- `ef_factor = 3.0`（增加）
- `interval_days = round(49 × 3.0) = 147`
- `next_review = 第221天`（74天后 + 147天）
- `status = 'mastered'`（已掌握）

**第221天（复习，答对了）**：
- `repetitions = 6`
- `ef_factor = 3.1`（继续增加）
- `interval_days = round(147 × 3.1) = 456`
- `next_review = 第677天`（221天后 + 456天）
- `status = 'mastered'`（已掌握，但**仍然会复习**）

### 示例2：答错后的处理

**第1天（复习，答错了）**：
- `repetitions = 0`（重置）
- `ef_factor = 2.3`（降低，变困难）
- `interval_days = 1`
- `next_review = 明天`（明天重点复习）
- `status = 'learning'`

## 三、总结

### 答对后的处理方式：

1. ✅ **会隔一段时间再复习**（不是下一次就不复习了）
2. ✅ **间隔会逐渐增加**（1天 → 6天 → 12天 → 24天...）
3. ✅ **即使状态变为"已掌握"（mastered），仍然会复习**
4. ✅ **复习间隔根据记忆效果动态调整**（答对间隔增加，答错间隔缩短）

### 复习间隔的特点：

- **科学算法**：基于SM-2间隔重复算法
- **个性化**：根据每个单词的记忆难度（ef_factor）调整
- **长期记忆**：间隔逐渐增加，帮助形成长期记忆
- **持续复习**：即使已掌握，也会定期复习（间隔很长）

### 为什么即使"已掌握"还要复习？

这是**间隔重复**的核心原理：
- 即使单词已经掌握，如果不定期复习，仍然会遗忘
- 通过长期、间隔性的复习，可以形成**长期记忆**
- 间隔会很长（几个月甚至一年），但不会完全停止复习

## 四、当前实现的问题和建议

### 当前实现：
- ✅ 使用SM-2算法计算复习间隔
- ✅ 答对后间隔逐渐增加
- ✅ 答错后间隔缩短，重点复习
- ✅ 即使mastered状态也会复习

### 可能的优化建议：

1. **mastered状态的单词可以设置更长的间隔**
   - 当前：即使mastered，只要next_review到了就复习
   - 建议：mastered状态的单词可以设置最大间隔（如1年）

2. **添加"完全掌握"状态**
   - 如果连续多次（如10次）都答对，可以标记为"完全掌握"
   - "完全掌握"的单词可以不再出现在复习列表中

3. **根据复习历史调整间隔**
   - 当前：主要根据ef_factor和repetitions
   - 建议：结合word_review_logs的历史表现，更智能地调整间隔

## 五、结论

**回答您的问题**：

1. **复习的单词下一次如果答对了，是否需要隔一段时间再复习？**
   - ✅ **是的，会隔一段时间再复习**
   - 间隔根据SM-2算法计算，会逐渐增加

2. **还是下一次就不复习了？**
   - ❌ **不是，不会停止复习**
   - 即使状态变为"已掌握"，仍然会定期复习（间隔很长）

3. **还是那种方式？**
   - ✅ **使用间隔重复算法（SM-2）**
   - 答对后间隔逐渐增加，帮助形成长期记忆
   - 答错后间隔缩短，重点复习

**这是科学的记忆方法，符合艾宾浩斯遗忘曲线原理。**
