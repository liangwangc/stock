# 数据库检查说明

## ✅ 新增功能的数据需求分析

### 一、不需要新增数据库字段的功能

以下功能**完全基于现有数据计算**，**不需要**修改数据库结构：

1. ✅ **连续打卡天数** (`streak_days`)
   - 基于 `words` 表的 `date_added` 字段计算
   - 不需要新字段

2. ✅ **今日进度百分比** (`progress_percent`)
   - 基于 `words` 表的 `status` 和 `date_added` 字段计算
   - 不需要新字段

3. ✅ **今日星星数** (`today_stars`)
   - 基于 `words` 表的查询结果计算
   - 不需要新字段

4. ✅ **学习统计**（周/月统计）
   - 基于 `words` 表的 `date_added` 字段查询
   - 不需要新字段

5. ✅ **成就系统**
   - 基于计算结果动态显示
   - 不需要新字段

6. ✅ **日历显示学习数量**
   - 基于 `words` 表的 `date_added` 字段统计
   - 不需要新字段

### 二、需要检查的数据库字段

以下字段是**单词库功能**需要的，如果之前已经执行过 `word_bank_upgrade.sql`，则不需要再次修改：

#### 1. `users` 表需要以下字段：

```sql
-- 检查是否存在
SHOW COLUMNS FROM users LIKE 'enable_word_bank';
SHOW COLUMNS FROM users LIKE 'grade';
```

**需要的字段**：
- `enable_word_bank` TINYINT(1) DEFAULT 0 - 是否启用单词库
- `grade` VARCHAR(20) DEFAULT NULL - 年级（grade1-grade12）

#### 2. `words` 表需要以下字段：

```sql
-- 检查是否存在
SHOW COLUMNS FROM words LIKE 'source';
```

**需要的字段**：
- `source` ENUM('manual','word_bank') DEFAULT 'manual' - 单词来源

#### 3. `word_bank` 表需要存在：

```sql
-- 检查表是否存在
SHOW TABLES LIKE 'word_bank';
```

**需要的表结构**：
```sql
CREATE TABLE IF NOT EXISTS word_bank (
    id INT AUTO_INCREMENT PRIMARY KEY,
    grade VARCHAR(20) NOT NULL COMMENT '年级：grade1-grade12',
    word VARCHAR(100) NOT NULL,
    pronunciation VARCHAR(200),
    meaning TEXT,
    example TEXT,
    word_order INT DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    KEY idx_grade (grade),
    KEY idx_grade_order (grade, word_order),
    UNIQUE KEY uk_grade_word (grade, word)
);
```

## 🔍 检查步骤

### 步骤1：检查数据库字段是否存在

运行以下SQL检查：

```sql
-- 检查 users 表字段
SELECT COLUMN_NAME, DATA_TYPE, COLUMN_DEFAULT 
FROM INFORMATION_SCHEMA.COLUMNS 
WHERE TABLE_SCHEMA = 'word_app' 
  AND TABLE_NAME = 'users' 
  AND COLUMN_NAME IN ('enable_word_bank', 'grade');

-- 检查 words 表字段
SELECT COLUMN_NAME, DATA_TYPE, COLUMN_DEFAULT 
FROM INFORMATION_SCHEMA.COLUMNS 
WHERE TABLE_SCHEMA = 'word_app' 
  AND TABLE_NAME = 'words' 
  AND COLUMN_NAME = 'source';

-- 检查 word_bank 表是否存在
SELECT TABLE_NAME 
FROM INFORMATION_SCHEMA.TABLES 
WHERE TABLE_SCHEMA = 'word_app' 
  AND TABLE_NAME = 'word_bank';
```

### 步骤2：如果字段不存在，执行升级SQL

如果检查发现缺少字段，请执行：

```bash
# Windows PowerShell
D:\xampp\php\php.exe -r "echo file_get_contents('word_bank_upgrade.sql');" | mysql -u root -proot -P 3307 word_app

# 或者直接在MySQL客户端执行
mysql -u root -proot -P 3307 word_app < word_bank_upgrade.sql
```

或者手动在MySQL客户端执行 `word_bank_upgrade.sql` 文件的内容。

### 步骤3：检查现有数据的兼容性

#### 3.1 检查 `words` 表的 `source` 字段

如果 `words` 表已经有数据但没有 `source` 字段，执行升级SQL后，现有数据的 `source` 字段会自动设置为 `'manual'`（因为默认值是 `'manual'`），这是正确的。

#### 3.2 检查 `users` 表的字段

如果 `users` 表已经有数据：
- `enable_word_bank` 字段会自动设置为 `0`（默认值），表示未启用单词库
- `grade` 字段会自动设置为 `NULL`（默认值）

这些默认值都是安全的，不会影响现有功能。

## 📋 总结

### ✅ 不需要修改数据的情况

如果以下条件都满足，**不需要**修改数据库：

1. ✅ 之前已经执行过 `word_bank_upgrade.sql`
2. ✅ `users` 表已有 `enable_word_bank` 和 `grade` 字段
3. ✅ `words` 表已有 `source` 字段
4. ✅ `word_bank` 表已存在

### ⚠️ 需要修改数据的情况

如果以下任一条件不满足，**需要**执行 `word_bank_upgrade.sql`：

1. ❌ `users` 表缺少 `enable_word_bank` 或 `grade` 字段
2. ❌ `words` 表缺少 `source` 字段
3. ❌ `word_bank` 表不存在

## 🔧 执行升级SQL（如果需要）

如果检查发现缺少字段，执行：

```sql
-- 1. 添加 users 表字段
ALTER TABLE users 
ADD COLUMN IF NOT EXISTS enable_word_bank TINYINT(1) DEFAULT 0 COMMENT '是否启用单词库：1启用，0禁用',
ADD COLUMN IF NOT EXISTS grade VARCHAR(20) DEFAULT NULL COMMENT '年级：grade1-grade12（一年级到高三）';

-- 2. 添加 words 表字段
ALTER TABLE words 
ADD COLUMN IF NOT EXISTS source ENUM('manual','word_bank') DEFAULT 'manual' COMMENT '单词来源：manual手动录入，word_bank单词库';

-- 3. 创建 word_bank 表（如果不存在）
CREATE TABLE IF NOT EXISTS word_bank (
    id INT AUTO_INCREMENT PRIMARY KEY,
    grade VARCHAR(20) NOT NULL COMMENT '年级：grade1-grade12',
    word VARCHAR(100) NOT NULL,
    pronunciation VARCHAR(200),
    meaning TEXT,
    example TEXT,
    word_order INT DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    KEY idx_grade (grade),
    KEY idx_grade_order (grade, word_order),
    UNIQUE KEY uk_grade_word (grade, word)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='单词库表';
```

## ⚠️ 注意事项

1. **数据安全**：执行升级SQL前，建议先备份数据库
2. **默认值**：所有新增字段都有合理的默认值，不会影响现有数据
3. **向后兼容**：如果字段已存在，再次执行不会报错（使用 `IF NOT EXISTS`）
4. **单词库数据**：`word_bank` 表需要单独导入单词数据（使用 `import_all_grades.php`）

## 📝 结论

**大部分新增功能不需要修改数据库**，只需要确保单词库相关的字段和表存在即可。

如果之前已经执行过 `word_bank_upgrade.sql`，则**完全不需要**再次修改数据库。
