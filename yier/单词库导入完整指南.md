# 单词库导入完整指南

## 📋 表结构说明

### word_bank 表结构

```sql
CREATE TABLE word_bank (
    id INT NOT NULL AUTO_INCREMENT,
    grade VARCHAR(20) NOT NULL COMMENT '年级：grade1-grade12',
    word VARCHAR(100) NOT NULL COMMENT '单词',
    pronunciation VARCHAR(100) DEFAULT '' COMMENT '音标',
    meaning TEXT COMMENT '中文释义',
    example TEXT COMMENT '例句',
    word_order INT DEFAULT 0 COMMENT '单词顺序',
    created_at TIMESTAMP NULL DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (id),
    KEY idx_grade (grade),
    KEY idx_grade_order (grade, word_order),
    UNIQUE KEY uk_grade_word (grade, word)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='单词库表';
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| id | INT | 自动 | 主键，自增 | 1 |
| grade | VARCHAR(20) | 是 | 年级代码 | grade1 |
| word | VARCHAR(100) | 是 | 单词 | hello |
| pronunciation | VARCHAR(100) | 否 | 音标 | /həˈloʊ/ |
| meaning | TEXT | 否 | 中文释义 | 你好 |
| example | TEXT | 否 | 例句 | Hello, how are you? |
| word_order | INT | 否 | 单词顺序 | 1 |
| created_at | TIMESTAMP | 自动 | 创建时间 | 2026-01-29 10:00:00 |

### 唯一约束

- `uk_grade_word`: 同一年级不能有重复的单词

## 🔌 使用的API

### 1. Free Dictionary API（主要）

**API地址**: `https://api.dictionaryapi.dev/api/v2/entries/en/{word}`

**特点**:
- ✅ 完全免费
- ✅ 无需API Key
- ✅ 返回英文释义和例句
- ✅ 包含音标

**请求示例**:
```bash
curl https://api.dictionaryapi.dev/api/v2/entries/en/hello
```

**返回示例**:
```json
[
  {
    "word": "hello",
    "phonetic": "/həˈloʊ/",
    "meanings": [
      {
        "definitions": [
          {
            "definition": "used as a greeting",
            "example": "Hello, how are you?"
          }
        ]
      }
    ]
  }
]
```

### 2. 中文单词API（备用）

**API地址**: `https://api.52vmy.cn/api/wl/word?word={word}`

**特点**:
- ✅ 返回中文释义
- ✅ 更适合中文用户
- ✅ 包含音标和例句

**请求示例**:
```bash
curl "https://api.52vmy.cn/api/wl/word?word=hello"
```

**返回示例**:
```json
{
  "code": 200,
  "data": {
    "word": "hello",
    "accent": "/həˈloʊ/",
    "mean_cn": "你好",
    "sentence": [
      {
        "sentence": "Hello, how are you?",
        "translation": "你好，你好吗？"
      }
    ]
  }
}
```

## 🚀 导入方式

### 方式1：使用内置单词列表（最简单）

**步骤**:

1. 打开命令行，进入项目目录
2. 运行导入脚本：
   ```bash
   php import_word_bank.php
   ```
   或双击运行：`批量导入单词库.bat`

3. 选择要导入的年级：
   - 输入 `all` 导入所有年级
   - 输入 `1,2,3` 导入指定年级（1=一年级，2=二年级...）

4. 等待导入完成

**内置单词列表**:
- 每个年级包含30个常用单词
- 涵盖基础词汇、日常用语、学科词汇等
- 自动从API获取音标、词义、例句

### 方式2：从CSV文件导入

**步骤**:

1. 准备CSV文件（参考 `words_example.csv`）

2. CSV格式：
   ```csv
   word,pronunciation,meaning,example
   hello,/həˈloʊ/,你好,Hello, how are you?
   good,/ɡʊd/,好的,Have a good day!
   ```

3. 运行导入：
   ```bash
   php import_word_bank_from_file.php words.csv grade1
   ```

**参数说明**:
- `words.csv`: CSV文件路径
- `grade1`: 年级代码（grade1-grade12）

### 方式3：从纯文本文件导入

**步骤**:

1. 准备文本文件，每行一个单词：
   ```
   hello
   good
   thank
   ```

2. 运行导入：
   ```bash
   php import_word_bank_from_file.php words.txt grade1
   ```

3. 脚本会自动从API获取音标、词义、例句

SELECT grade, COUNT(*) as word_count 
FROM word_bank

ORDER BY grade;

## 🛠️ 故障排除

### 问题1：API请求失败

**症状**: 导入时显示"API无数据"或"失败"

**可能原因**:
- 网络连接问题
- API服务不可用
- 单词拼写错误

**解决方法**:
1. 检查网络连接
2. 运行 `test_word_api.php` 测试API
3. 使用CSV文件手动填写信息

### 问题2：数据库连接失败

**症状**: 提示"数据库连接失败"

**解决方法**:
1. 检查数据库服务是否运行
2. 检查数据库配置是否正确
3. 检查端口号（默认3307）

### 问题3：单词重复导入

**症状**: 提示"[跳过] xxx 已存在"

**说明**: 这是正常现象，脚本会自动跳过已存在的单词

### 问题4：中文释义缺失

**症状**: 导入的单词只有英文释义

**原因**: Free Dictionary API只返回英文释义

**解决方法**:
1. 使用CSV文件手动填写中文释义
2. 或导入后手动补充
