========================================
单词库导入测试运行说明
========================================

由于环境限制，无法直接运行测试，请按照以下步骤手动测试：

【方法1：使用批处理文件（推荐）】
----------------------------------------
1. 双击运行以下文件之一：
   - 快速测试导入.bat （只导入5个单词测试）
   - 测试API.bat （测试API是否可用）
   - 自动导入单词库.bat （完整导入工具）

2. 如果批处理文件无法运行，请使用方法2

【方法2：手动运行PHP脚本】
----------------------------------------
1. 打开命令行（CMD或PowerShell）
2. 进入项目目录：
   cd d:\wjw_work\yier

3. 找到PHP路径（选择其一）：
   - 如果PHP在PATH中：直接使用 php
   - XAMPP: C:\xampp\php\php.exe
   - XAMPP64: C:\xampp64\php\php.exe
   - WAMP: C:\wamp64\bin\php\php7.x.x\php.exe

4. 运行测试脚本：
   php test_import.php
   或
   C:\xampp\php\php.exe test_import.php

【方法3：测试API是否可用】
----------------------------------------
运行：
   php test_word_api.php

这会测试5个单词的API调用，检查：
- Free Dictionary API 是否可用
- 中文单词API 是否可用

【方法4：完整导入】
----------------------------------------
运行：
   php import_word_bank.php

然后输入：
- all （导入所有年级）
- 1,2,3 （导入指定年级）

【预期结果】
----------------------------------------
如果测试成功，应该看到：
✓ 成功导入单词
✓ 显示音标、词义、例句
✓ 数据库中有新记录

如果失败，可能原因：
✗ PHP未安装或不在PATH
✗ 数据库连接失败（检查api.php中的配置）
✗ 网络问题（API无法访问）
✗ 数据库表未创建（先运行word_bank_upgrade.sql）

【检查数据库】
----------------------------------------
导入后，可以使用以下SQL检查：

SELECT * FROM word_bank WHERE grade = 'grade1' LIMIT 10;

或运行：
   php -r "require 'api.php';"  # 这会检查数据库连接

【故障排除】
----------------------------------------
1. PHP未找到：
   - 安装XAMPP: https://www.apachefriends.org/
   - 或安装WAMP: https://www.wampserver.com/

2. 数据库连接失败：
   - 检查api.php中的数据库配置
   - 确保MySQL服务正在运行
   - 检查端口号（默认3307）

3. API请求失败：
   - 检查网络连接
   - 运行test_word_api.php测试API

4. 表不存在：
   - 运行word_bank_upgrade.sql创建表

确认功能正常后再批量导入。
