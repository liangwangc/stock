========================================
单词库功能使用指南
========================================

【功能说明】
支持从一年级到高三的单词库，系统可以根据每日学习目标自动导入单词。

【使用步骤】

第一步：升级数据库
----------------------------------------
执行单词库升级脚本：
  mysql -u root -p word_app < word_bank_upgrade.sql

或使用 phpMyAdmin 导入 word_bank_upgrade.sql

第二步：启用单词库
----------------------------------------
1. 登录系统
2. 点击"统计/设置"标签
3. 找到"📚 单词库设置"
4. 勾选"启用单词库"
5. 选择年级（一年级到高三）
6. 点击"保存设置"

第三步：开始学习
----------------------------------------
- 系统会自动根据每日目标导入单词
- 手动录入的单词会优先显示
- 单词库单词会自动补充

【功能特点】
----------------------------------------
✅ 手动录入的单词优先显示
✅ 单词库单词自动补充到每日目标
✅ 已导入的单词不会重复导入
✅ 支持12个年级（一年级到高三）
✅ 可以随时开启/关闭单词库

【逻辑说明】
----------------------------------------
任务生成规则：
1. 优先显示待复习的单词（必须完成）
2. 然后显示待新学的单词：
   - 优先：手动录入的单词
   - 补充：单词库导入的单词
   - 限制数量：每日目标（daily_goal）

自动导入规则：
- 每次访问首页时检查
- 如果今天已导入足够数量，不再导入
- 只导入未导入过的单词
- 导入数量 = 每日目标 - 今日已导入数量

【年级对应】
----------------------------------------
grade1  = 一年级
grade2  = 二年级
grade3  = 三年级
grade4  = 四年级
grade5  = 五年级
grade6  = 六年级
grade7  = 初一
grade8  = 初二
grade9  = 初三
grade10 = 高一
grade11 = 高二
grade12 = 高三

【注意事项】
----------------------------------------
1. 需要先执行数据库升级脚本
2. 当前只有示例单词库数据（5个一年级单词）
3. 需要导入完整的各年级单词库数据
4. 手动录入的单词始终优先显示
5. 关闭单词库后，只使用手动录入的单词

【示例场景】
----------------------------------------
场景1：启用单词库
- 每日目标：5个
- 启用单词库：是
- 年级：三年级
- 结果：每天自动从三年级单词库导入5个单词

场景2：手动录入优先
- 手动录入了3个单词
- 每日目标：5个
- 启用单词库：是
- 结果：显示3个手动录入 + 2个单词库单词

场景3：未启用单词库
- 启用单词库：否
- 结果：只使用手动录入的单词
