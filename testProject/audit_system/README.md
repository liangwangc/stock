# 🏛️ 稽核档案管理系统

一个完整的稽核档案管理系统，提供用户认证、档案管理、权限控制等功能。

## ✨ 主要功能

### 🔐 用户认证与权限管理
- **用户登录/登出**: 安全的用户认证系统
- **角色权限控制**: 支持管理员(admin)、稽核员(auditor)、普通用户(user)三种角色
- **密码加密**: 使用bcrypt进行密码加密存储
- **JWT Token**: 基于JWT的身份验证
- **账户锁定**: 登录失败次数过多时自动锁定账户

### 📁 档案管理
- **档案创建**: 支持创建新的稽核档案
- **档案编辑**: 更新档案信息和状态
- **档案查询**: 多条件搜索和筛选
- **档案分类**: 支持多级档案分类管理
- **附件管理**: 支持档案附件上传和管理

### 👥 用户管理
- **用户创建**: 管理员可以创建新用户
- **用户信息管理**: 管理用户基本信息
- **部门管理**: 支持多级部门结构
- **状态管理**: 用户账户状态控制

### 📊 系统功能
- **操作日志**: 记录所有用户操作
- **系统统计**: 档案和用户统计信息
- **通知系统**: 系统消息和提醒
- **数据备份**: 数据库备份和恢复

## 🚀 快速开始

### 1. 安装依赖

```bash
# 安装基础依赖
pip install -r requirements.txt

# 或者单独安装稽核系统依赖
pip install bcrypt PyJWT pymysql python-dotenv
```

### 2. 配置数据库

确保你的MySQL数据库配置正确，系统会自动连接到配置的数据库。

### 3. 初始化系统

```bash
# 运行系统初始化脚本
py audit_system/init_system.py
```

初始化过程包括：
- 创建数据库表结构
- 创建默认部门和数据分类
- 创建管理员用户
- 创建示例数据

### 4. 启动系统

```bash
# 启动稽核档案管理系统
py audit_system/main.py
```

## 📋 系统架构

### 目录结构
```
audit_system/
├── __init__.py              # 包初始化文件
├── models.py                # 数据模型定义
├── database.py              # 数据库连接和操作
├── auth.py                  # 用户认证和权限管理
├── main.py                  # 主程序入口
├── init_system.py           # 系统初始化脚本
├── database_schema.sql      # 数据库表结构
└── README.md                # 使用说明
```

### 核心模块

#### 1. 数据模型 (models.py)
- `User`: 用户模型
- `AuditFile`: 稽核档案模型
- `FileCategory`: 档案分类模型
- `Department`: 部门模型
- `AuditLog`: 操作日志模型
- `Notification`: 通知模型

#### 2. 数据库操作 (database.py)
- `DatabaseManager`: 数据库连接管理
- `UserDAO`: 用户数据访问对象
- `AuditFileDAO`: 档案数据访问对象
- `DepartmentDAO`: 部门数据访问对象
- `FileCategoryDAO`: 分类数据访问对象
- `AuditLogDAO`: 日志数据访问对象

#### 3. 认证授权 (auth.py)
- `AuthManager`: 用户认证管理
- `PermissionManager`: 权限控制管理

```python

    "host": "192.168.0.215",
    "port": 3306,
    "database": "nanan_data",
    "user": "root",
    "password": "Cdslyk@912",
    "charset": "utf8mb4"
}
```

### 安全配置
- JWT密钥: 在生产环境中请修改默认密钥
- 密码策略: 支持自定义密码复杂度要求
- 会话超时: 可配置token过期时间

## 👤 用户角色说明

### 管理员 (admin)
- 拥有系统所有权限
- 可以管理用户和系统设置
- 可以查看所有档案和日志

### 稽核员 (auditor)
- 可以创建、编辑、查看档案
- 可以查看操作日志
- 不能管理用户和系统设置

### 普通用户 (user)
- 可以查看档案
- 可以编辑自己创建的档案
- 权限受限

## 📱 使用流程

### 1. 用户登录
```
用户名: admin
密码: admin123 (或自定义密码)
```

### 2. 档案管理
1. 选择"档案管理"菜单
2. 创建新档案或查看现有档案
3. 编辑档案信息和状态
4. 上传相关附件

### 3. 用户管理 (仅管理员)
1. 选择"用户管理"菜单
2. 创建新用户账户
3. 设置用户角色和权限
4. 管理用户状态

### 4. 系统监控
1. 查看系统统计信息
2. 监控操作日志
3. 管理系统设置

## 🛠️ 开发说明

### 添加新功能
1. 在 `models.py` 中定义数据模型
2. 在 `database.py` 中添加数据访问对象
3. 在 `main.py` 中添加相应的菜单和功能
4. 更新权限控制逻辑

### 数据库迁移
1. 修改 `database_schema.sql` 文件
2. 运行初始化脚本更新表结构
3. 处理数据迁移逻辑

### 扩展权限系统
1. 在 `PermissionManager` 中添加新的权限检查方法
2. 在相应的功能模块中调用权限检查
3. 更新用户角色配置
